## 核心内容

### 1. 这场演讲解决什么问题

以前在实时渲染里加 AI，基本是"外挂"模式：GPU 渲染完，把图倒腾到 ANE (Apple Neural Engine) 跑个模型，再拿回来做后处理。中间的内存拷贝和同步开销让"实时"大打折扣。

Metal 4 提供了三个层级的解决方案，从黑盒到白盒，满足不同控制需求。

### 2. 第一层：MetalFX Denoising

路径追踪的帧预算通常只允许 1 spp (每像素采样数)，画面自然充满噪点。MetalFX Denoising 是平台集成的黑盒方案，专门解决低采样率下的实时降噪。

Maxon 的 Redshift Live 是最佳实践案例。启用 MetalFX Denoising 后，1 spp 的噪点画面变成了接近最终质量的干净图像，艺术家可以在视口里实时移动光源和物体。

集成 MetalFX 需要几个辅助输入：

- Diffuse Albedo（漫反射反照率）
- Depth（深度）
- Motion Vectors（运动向量）
- Normal（法线）

### 3. 运动向量的正确计算

MetalFX 的时序稳定性极度依赖干净的运动向量。必须正确处理相机抖动 (Jitter)：

```metal
#include <metal_stdlib>
using namespace metal;

// 计算仅相机运动的运动向量
float4 clipCurrent = viewProjCurrent * float4(worldPos, 1.0);
float2 ndcCurrent = clipCurrent.xy / clipCurrent.w;

float4 clipPrevious = viewProjPrevious * float4(worldPos, 1.0);
float2 ndcPrevious = clipPrevious.xy / clipPrevious.w;

float2 motion = ndcPrevious - ndcCurrent;

// 减去当前帧和上一帧的抖动偏移
float2 jitterCurrent = getJitter(frameIndex);
float2 jitterPrevious = getJitter(frameIndexPrevious);
motion -= jitterPrevious - jitterCurrent;
```

关键点：

- 运动向量必须在 NDC 空间计算
- 必须减去 TAA 抖动偏移，否则静止物体也会有非零运动向量
- 玻璃和镜子等反射/折射表面需要用 Primary Surface Replacement 技术处理

### 4. 第二层：ML Command Encoder

把离线训练好的模型（如神经 Tone Mapper）导出为 MPS Graph，直接在 Command Buffer 里和渲染 Pass 无缝调度。

```swift
// 在 Command Buffer 中插入 ML 推理
let mlEncoder = commandBuffer.makeMLCommandEncoder()
mlEncoder.setComputePipelineState(neuralToneMapPipeline)
mlEncoder.setTexture(renderTarget, index: 0)
mlEncoder.setTexture(outputTexture, index: 1)
mlEncoder.dispatchThreadgroups(threadgroups, threadsPerThreadgroup: threadsPerGroup)
mlEncoder.endEncoding()

// 紧接着做后处理
let blitEncoder = commandBuffer.makeBlitCommandEncoder()
// ...
```

不需要把数据搬出 GPU 内存，ML 推理和图形渲染在同一个 Command Buffer 里顺序执行。

### 5. 第三层：TensorOps API

最灵活的一层，允许你在 Metal Shader 里直接构建和运行小型神经网络，利用 M5 和 A19 Pro 芯片上的 Neural Accelerator。

典型应用场景：

- **神经纹理 (Neural Textures)**：用小型 MLP 替代传统纹理贴图，大幅减少内存占用
- **在线光照探针**：每帧用神经网络推断动态环境的间接光照
- **实时色调映射适应**：根据场景亮度分布在线微调 Tone Mapping 曲线

```metal
// 在 Shader 中定义一个小型 MLP
// 输入：位置 + 法线 + 粗糙度
// 输出：辐照度估计
TensorOps::MLP<3, 64, 64, 3> irradianceNet;

// 加载预训练权重
irradianceNet.loadWeights(weightsBuffer);

// 每像素在线推断
float3 input = float3(worldPos.xy, normal.z);
float3 irradiance = irradianceNet.infer(input);
```

### 6. Maxon 的最佳实践

Redshift Live 团队总结了三条关键经验：

1. **Albedo 必须干净**：MetalFX 依赖 Albedo 来区分材质属性。如果 Albedo 包含光照信息（如烘焙了 AO），降噪器会混淆。
2. **运动向量覆盖所有动态物体**：不只是相机运动，角色、粒子、植被摆动都需要贡献运动向量。缺失的运动向量会导致时序鬼影。
3. **Primary Surface Replacement 处理反射**：对于玻璃和镜子，用菲涅尔项把反射/折射颜色混合进 Diffuse Albedo，骗过降噪器，能得到锐利的反射效果。

## 最佳实践

- **已有项目迁移**：别一上来就搞 TensorOps。第一步先把 MetalFX Denoising 接进你的路径追踪或光栅化管线，把 1 spp 或低分辨率渲染的画质拉上来。重点检查 Albedo 和 Motion Vectors 够不够干净。第二步，把那些又长又臭的后处理 Chain 用 ML Command Encoder 替换成离线训练好的 MPS Graph 模型。
- **新项目采用建议**：如果场景包含大量动态光照或需要实时适应的环境探针，直接尝试 TensorOps。用 PyTorch 训练一个极小的 MLP，导出权重，在 Shader 里做在线推断。
- **实战避坑**：处理玻璃和镜子时，MetalFX 容易被反射/折射搞晕。使用 Primary Surface Replacement 技术，用菲涅尔项把反射和折射的颜色混合进 Diffuse Albedo 里，能得到锐利得多的反射效果。
