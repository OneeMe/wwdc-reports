## Highlight

> iOS 27 让 CarPlay 从"驾驶辅助工具"升级为"车内全场景平台"：视频 App 可以在停车时直接浏览和播放内容，语音对话类 App 获得全新模板支持，所有 CarPlay App 都能用上增强的列表 UI、MiniPlayer 和语音控制覆盖层。导航 App 还新增了 Route Sharing（路线共享）能力。

---

## 核心内容

### 1. 这场演讲解决什么问题

过去 CarPlay 的应用场景很单一：开车时听听歌、导导航。停车时想看点视频？只能掏出手机。想做一个语音对话类的车内助手？没有合适的模板。iOS 27 彻底打开了这些限制。

Apple 这次新增了两个全新的 CarPlay App 类别：

- **Video Apps**：支持 AirPlay 视频流的应用现在可以在支持 video-in-car 功能的车机上直接浏览和播放视频内容（仅在停车时可用，开车时自动降级为音频-only）
- **Voice-based conversational apps**：语音对话类应用现在可以使用 `CPVoiceControlTemplate`，并且支持以 Overlay 形式悬浮在其他模板之上

### 2. CarPlay Video App：让停车时间更有价值

如果你的 App 已经支持 AirPlay 视频流，那么实现 CarPlay Video 只需要三步：

1. 在 Developer Portal 申请 CarPlay Video entitlement
2. 使用 CarPlay framework 提供视频浏览 UI（通过 `CPListTemplate` 等模板）
3. 通过 `CPSessionConfiguration` 检测车机是否支持视频，动态决定是否显示视频 Tab

```swift
// 检测车机是否支持视频功能
if CPSessionConfiguration.supportsVideo {
    // 添加视频浏览 Tab
    let videoTab = CPTabBarTemplate(templates: [videoListTemplate])
}
```

关键点：

- 视频 App 只在支持 video-in-car 的车机上显示。如果你的内容同时适合视频和音频收听，建议同时申请 Audio 和 Video entitlement，这样在所有车机上都能出现
- 开车时视频会自动降级为音频-only 播放，不需要你额外处理
- 使用 `CPPlaybackConfiguration` 的 `preferredPresentation` 来标记内容偏好视频还是音频播放

### 3. 列表和播放 UI 的全面增强

所有 CarPlay App 都能用上这些新 UI 能力：

**列表增强**：
- 列表项现在支持竖图和横图两种比例
- Card 元素支持缩略图 + Overlay（可以显示标题、播放进度、体育比分等）
- 新增 Details Header：在列表顶部突出展示单个项目（适合"当前播放集数"或"主视频 + 花絮"场景）

**MiniPlayer**：
- 新增 `CPNowPlayingTemplate` 的 MiniPlayer 模式
- 可以通过 `allowsMiniPlayer` 控制是否允许显示

```swift
// 禁用 MiniPlayer
CPNowPlayingTemplate.shared.allowsMiniPlayer = false
```

**语音控制**：
- `CPVoiceControlTemplate` 现在支持 Overlay 形式，可以悬浮在地图等界面之上
- 所有 App 类别都可以使用语音控制模板

### 4. 导航 App 的 Route Sharing

导航 App 现在可以将路线数据共享给车机系统，让车机的仪表盘、HUD 等设备也能显示转向信息。

```swift
// 启用路线共享
func mapTemplateShouldProvideRouteSharing(_ mapTemplate: CPMapTemplate) -> Bool {
    return true
}

// 针对某次行程禁用路线共享
trip.routeSegmentsAvailableForRegion = false
```

## 最佳实践

- **已有音视频项目**：立刻去 Developer Portal 申请 CarPlay Video entitlement。在代码里通过 `CPSessionConfiguration` 判断 `supportsVideo`，动态在 `CPTabBarTemplate` 里加视频 Tab。别硬编码，不然老车主看到点不动的视频 Tab 会提一堆一星差评
- **导航项目**：全面接入 Route Sharing。现在的车机仪表盘越来越智能，把路线数据喂给车厂，能大幅提升你的 App 在车企预装白名单里的权重
- **UI 适配**：CarPlay 的列表现在支持横竖图比例和复杂的 Overlay。把 `CPListItem` 的 `image` 和 `detailText` 利用起来，特别是 `CPPlaybackConfiguration`，一定要在播放状态改变时实时更新，别让用户看到进度条卡死
- **CarPlay Simulator**：iOS 27 的 CarPlay Simulator 支持更多功能测试，开发阶段就可以验证视频播放、语音控制等场景，不需要真车
