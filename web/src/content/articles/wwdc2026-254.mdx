## Highlight

> MusicKit 让任何 App 都能集成 Apple Music 的选歌、播放和订阅功能。`.musicPicker` 和 `.musicSubscriptionOffer` 两个 modifier 就能搞定选歌 UI 和订阅引导，不再需要手写几百行代码。

---

## 核心内容

### 1. 这场演讲解决什么问题

想在 App 里加背景音乐功能？以前你需要自己处理授权、订阅状态检查、选歌界面、播放控制……MusicKit 把这些全部打包好了，几行代码就能让用户体验 Apple Music 的海量曲库。

### 2. 项目配置

在 Xcode 中：

1. 注册 App ID 时勾选 **MusicKit** 服务
2. 在 Signing & Capabilities 中添加 **Media Library** capability
3. 填写使用说明（会显示在权限弹窗中）

开发者 token 会自动生成，无需手动管理。

### 3. 请求授权

```swift
let status = await MusicAuthorization.request()
```

这是异步方法，返回授权状态。MusicKit 会自动弹出权限提示。

### 4. 订阅状态检查

检查用户是否有活跃的 Apple Music 订阅：

```swift
@State var subscription: MusicSubscription?

var body: some View {
    VStack {
        if let subscription, subscription.canBecomeSubscriber {
            musicSubscriptionButton
        }
    }
    .task(id: isAuthorized) {
        self.subscription = try? await MusicSubscription.current
        for await subscription in MusicSubscription.subscriptionUpdates {
            self.subscription = subscription
        }
    }
}
```

### 5. 订阅引导

如果用户没有订阅，可以在 App 内引导订阅：

```swift
@State var showSubscriptionOffer = false

let options = MusicSubscriptionOffer.Options(
    messageIdentifier: .playMusic
)

var musicSubscriptionButton: some View {
    Button("Subscribe to Apple Music", systemImage: "music.note") {
        showSubscriptionOffer = true
    }
    .musicSubscriptionOffer(isPresented: $showSubscriptionOffer, options: options)
}
```

用户无需离开 App 即可完成订阅。开发者还可以通过 Apple Services Performance Partner Program 获得订阅佣金。

### 6. 音乐选择器

用 `.musicPicker` 让用户从 Apple Music 曲库或个人库中选择音乐：

```swift
@State var showMusicPicker = false
@State var selectedSong: Song? = nil

var musicPickerButton: some View {
    Button("Pick some Music", systemImage: "music.note.list") {
        showMusicPicker = true
    }
    .musicPicker(isPresented: $showMusicPicker, selection: $selectedSong)
}
```

### 7. 播放器选择

MusicKit 提供两种播放器：

- **`SystemMusicPlayer`**：与系统音乐 App 共享播放状态，支持锁屏控制
- **`ApplicationMusicPlayer`**：独立的应用内播放器，不影响系统音乐 App

对于健身、冥想等需要独立控制播放的 App，使用 `ApplicationMusicPlayer`：

```swift
let player = ApplicationMusicPlayer.shared
@State var state = ApplicationMusicPlayer.shared.state

var isPlaying: Bool {
    state.playbackStatus == .playing
}

var playPause: some View {
    Button(
        isPlaying ? "Pause" : "Play",
        systemImage: isPlaying ? "pause.fill" : "play.fill"
    ) {
        if isPlaying {
            player.pause()
        } else {
            Task {
                try await player.play()
            }
        }
    }
}

var controls: some View {
    HStack {
        Button("Back", systemImage: "backward.fill") {
            Task { try await player.skipToPreviousEntry() }
        }
        playPause
        Button("Next", systemImage: "forward.fill") {
            Task { try await player.skipToNextEntry() }
        }
    }
}
```

### 8. 显示封面和歌曲信息

```swift
@State var queue = ApplicationMusicPlayer.shared.queue

var body: some View {
    VStack {
        // 封面
        if let artwork = queue.currentEntry?.artwork {
            ArtworkImage(artwork, width: 200, height: 200)
        } else {
            RoundedRectangle(cornerRadius: 16)
                .fill(.quaternary)
                .frame(width: 200, height: 200)
        }

        // 歌曲信息
        if let currentSong = queue.currentEntry {
            Text(currentSong.title)
                .font(.title3.bold())

            if let subtitle = currentSong.subtitle {
                Text(subtitle)
                    .font(.subheadline)
                    .foregroundStyle(.secondary)
            }
        }
    }
}
```

### 9. 跨商店歌曲分享

通过歌曲 ID 获取跨地区商店的等效歌曲：

```swift
func fetchSongs(songIDs: [MusicItemID]) async throws -> (featured: Song?, other: [Song]) {
    var request = MusicCatalogResourceRequest<Song>(
        matching: \.id, memberOf: songIDs
    )
    request.options = [.findEquivalents]

    let response = try await request.response()

    let featuredSongID = songIDs[0]
    let featuredSong = response.item(for: featuredSongID)

    let others: [Song] = songIDs[1...].compactMap { songID in
        return response.item(for: songID)
    }

    return (featuredSong, others)
}
```

## 最佳实践

- **明确播放器类型**：音乐播放器用 `SystemMusicPlayer`，工具类 App 用 `ApplicationMusicPlayer`
- **处理订阅状态**：始终检查 `subscription.canBecomeSubscriber`，为未订阅用户提供引导
- **使用容器类型初始化队列**：用 `Album` 或 `Playlist` 初始化队列比传入 `Song` 数组更高效
- **监听播放状态变化**：用 `@State` 和 `.task` 监听 `MusicSubscription.subscriptionUpdates`
- **缓存封面图片**：`ArtworkImage` 会自动处理缓存，不需要额外处理
