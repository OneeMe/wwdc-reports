## Highlight

> Reality Composer Pro 3 从 Xcode 插件变成了独立 App，加了 Live Preview 实时推送到头显、Prototype 实例复用、Lightmap 光照烘焙和 AI 3D 生成助手——做复杂 visionOS 场景的迭代速度能快一倍。

---

## 核心内容

### 1. 这场演讲解决什么问题

以前用 Reality Composer Pro（RCP）做 visionOS 场景有几个明显痛点：

- 绑在 Xcode 里，每次改材质调灯光都要等编译
- 场景复用全靠手工拷贝，没有 Prefab 机制
- 光照效果只能在运行时看，编辑器里看不到间接光照
- 3D 资产全靠外部工具制作，没有内置生成能力

RCP 3 把这四个问题全解决了。

### 2. 独立 App + 项目结构

RCP 3 不再作为 Xcode developer tool 分发，直接从 developer.apple.com 下载，在 Applications 文件夹里启动。

项目结构：
- USD 文件导入后会自动组织成 import bundle，包含 geometry、materials、textures
- 场景中的每个对象叫 Entity，有 Transform Component 控制位置旋转缩放
- Entity 可以在 Hierarchy 面板中嵌套、重排序
- 按 `f` 键可以 framing 选中的 entity

### 3. Prototype 和实例复用

Prototype 是 RCP 3 的新功能，相当于 Unity 的 Prefab 或 Unreal 的 Blueprint。创建一个 Prototype 后，场景中可以有多个实例，修改 Prototype 源文件，所有实例自动更新。

工作流程：
1. 创建一个基础 entity（比如一棵树、一盏灯）
2. 把它转成 Prototype
3. 在场景中拖入多个实例
4. 修改 Prototype 的 material 或 geometry，所有实例同步变化

这对大型场景（森林、城市、展厅）特别有用，可以大幅减少重复资产的管理成本。

### 4. Lightmap 光照烘焙

RCP 3 内置了 light baker，可以为静态场景生成三种 lightmap：

- **Indirect lighting**：间接光照，让角落和阴影区域更真实
- **Ambient occlusion**：环境光遮蔽，增强接触阴影
- **Beauty**：完整光照贴图

工作流程：
1. 在场景中布置好光源（点光、聚光灯、方向光）
2. 标记需要烘焙的静态几何体
3. 运行 light baker 生成贴图
4. 运行时 RealityKit 自动应用这些贴图

关键点：

- Lightmap 只适用于静态几何体和静态光源
- 动态光源（如玩家携带的手电筒）仍然实时计算
- 烘焙后的场景 GPU 负载显著降低，因为间接光照不需要实时计算

### 5. Live Preview 实时推送到头显

RCP 3 支持把编辑中的场景直接推送到 Apple Vision Pro 上预览：

1. Mac 和 Vision Pro 在同一网络
2. 在 RCP 3 中选择目标设备
3. 场景实时同步到头显，在真实空间中查看效果

这比 Simulator 更接近真实体验，可以检查：
- 物体在真实房间中的比例感
- 光照和真实环境的融合效果
- 空间音频的定位准确性

### 6. Reality Composer Pro Assistant（AI 助手）

RCP 3 内置了 AI 助手，可以通过自然语言生成 3D 内容：

- 生成基础几何体（立方体、球体、圆柱等）
- 创建简单的材质和纹理
- 布置场景元素

注意：AI 生成的模型拓扑通常比较粗糙，适合作为白盒占位（blockout）或概念验证，最终发布前需要美术优化或替换。

### 7. Compute Simulation 组件

RCP 3 新增了 Compute Simulation component，可以在编辑器中直接运行 compute shader：

1. 创建一个 entity
2. 添加 Compute Simulation component
3. 选择项目中预定义的 Compute Graph
4. 在 Inspector 中调整参数，实时看到效果

这适合制作粒子效果、流体模拟、程序化动画等视觉特效。

## 最佳实践

- **项目迁移**：把 Xcode 里的 RCP 包剥离出来，用独立版 RCP 3 打开。把重复实体转为 Prototype，场景层级会清爽很多
- **新项目建议**：第一天就建立 Prototype 库。静态场景（建筑外壳、固定家具）无脑上 Lightmaps，能显著降低 Vision Pro 的 GPU 负载
- **Live Preview 的局限**：涉及复杂 SwiftUI 附件、手势识别或系统权限（空间音频、透视遮挡）的功能，仍需 Build & Run 到真机测试
- **AI 生成内容**：AI 助手生成的模型只能做占位，拓扑质量不足以直接发布。最终资产仍需专业工具制作
- **Lightmap 策略**：区分静态和动态内容。静态内容烘焙，动态内容保留实时光照。混合使用可以获得最佳性能和视觉效果
