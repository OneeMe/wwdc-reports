## Highlight

> Apple 推出团体和组织订阅功能，开发者可以通过 App 内购和 Apple Business/School Manager 两个渠道销售多座位订阅，并支持阶梯折扣定价。

## 核心内容

以前，一个用户想给团队成员买订阅，只能一个个账号买。跑俱乐部想给成员买健身 App 订阅，也需要每个人自己注册。这对小团队、公司、学校这些需要集体购买的场景来说很麻烦。

Apple 现在提供了两个解决方案：

**集团采购（Volume Purchasing）**：企业或学校通过 Apple Business Manager 或 Apple School Manager 批量购买订阅。他们可以用现有的设备管理服务分配座位，和分发 App 用的是同一套流程。适合有统一身份管理需求的大中型组织。

**团体购买（Group Purchases）**：用户直接在你的 App 里购买多个座位，然后通过邀请链接分享给其他人。适合小团队、朋友群组、俱乐部这些场景。Apple 提供现成的座位管理系统，开发者也可以用自己的邀请流程。

这两个功能对所有使用 StoreKit 2 的自动续订订阅默认开启。如果你的订阅开启了家庭共享，团体订阅功能会默认关闭，你可以自己决定如何配置。

## 详细内容

### 可用性配置（[00:43](https://developer.apple.com/videos/play/wwdc2026/391/?time=43)）

在 App Store Connect 中，你可以控制订阅在团体渠道的可用性：

- 默认情况下，订阅同时在 App 内购和 Apple Business/School Manager 可用
- 可以设置为仅在 Apple School Manager 可用，为教育机构提供专属价格
- 可以完全关闭团体销售，只保留个人订阅

### 阶梯定价（[01:53](https://developer.apple.com/videos/play/wwdc2026/391/?time=113)）

Apple 新增了 Volume Pricing 配置，支持最多 5 个价格区间。每个区间可以设置座位数量阈值和对应价格。

示例配置：
- 1-20 个座位：$19.99/月/座位
- 21-40 个座位：$13.99/月/座位
- 41 个座位以上：$10.99/月/座位

购买 50 个座位时，平均每个座位成本比基础价低约 20%。折扣能激励客户覆盖更多人员并整合采购。

这些配置直接在 App Store Connect 完成，不需要改代码。

### 购买流程（[03:02](https://developer.apple.com/videos/play/wwdc2026/391/?time=182)）

集团采购：Apple Business/School Manager 展示你的订阅并处理购买。你只需要确保订阅对组织可用。

团体购买：你需要构建 App 内 UI 来触发 StoreKit 2 购买流程。在推广流程中突出团体购买的价值，收集用户想要的座位数量，然后传给购买请求。

### 座位管理（[04:08](https://developer.apple.com/videos/play/wwdc2026/391/?time=248)）

集团采购的座位由组织通过设备管理服务分配，就像他们今天分发 App 一样。

团体购买会生成邀请链接供购买者分享给成员。Apple 提供的默认座位管理系统包含：
- 生成邀请链接
- 跟踪成员接受和分配
- 座位生命周期管理（如取消）

如果你已经有自己的邀请和成员管理系统，可以通过新的 App Store Server API 端点集成。新 API 还提供群组信息查询功能，可以获取某个客户加入的所有群组，以及群组的所有成员。

### 技术要求（[06:24](https://developer.apple.com/videos/play/wwdc2026/391/?time=384)）

- StoreKit 2 是必需的
- 新的 App Store Server API 端点用于自定义集成

## 核心启发

1. **在 App 内添加团体购买入口**
   在订阅页面增加"购买多个座位"选项，让小团队、俱乐部、朋友群组可以直接在 App 内完成多人订阅，无需通过 Apple Business Manager 的复杂流程。StoreKit 2 已原生支持团体购买，你只需要在 UI 中收集座位数量，然后传给标准的购买请求。入口：StoreKit 2 `Product.purchase()` + 团体购买配置。

2. **配置阶梯定价策略**
   在 App Store Connect 中设置最多 5 个价格区间，购买量越大单价越低。比如 1-20 座 $19.99/月，21-40 座 $13.99/月，41 座以上 $10.99/月，50 个座位的平均成本比单买低约 20%。阶梯折扣能激励客户扩大采购规模并整合订阅。入口：App Store Connect -> 订阅 -> Volume Pricing。

3. **为教育机构提供专属渠道**
   将特定订阅设置为仅在 Apple School Manager 可用，并设置教育折扣价。学校有统一的设备管理和身份系统，通过 ABM/ASM 采购是标准流程，这个渠道能帮你打开教育市场而不影响公开渠道定价。入口：App Store Connect 可用性配置中选择"仅在 Apple School Manager 可用"。

4. **集成自定义座位管理系统**
   如果你已有邀请和成员管理系统，通过新的 App Store Server API 端点与 Apple 的座位管理对接。这样能保持现有用户管理流程不变，同时获得团体订阅的收入和 Apple 的账单处理。入口：App Store Server API 群组信息查询端点。

5. **区分家庭共享与团体订阅的配置**
   检查现有订阅配置，决定是否为家庭共享用户开启团体购买。家庭共享和团体订阅默认互斥，需要根据产品定位选择：个人效率工具适合团体订阅，家庭娱乐内容适合家庭共享。入口：App Store Connect 中查看并调整订阅的"家庭共享"设置。
