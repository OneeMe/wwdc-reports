## Highlight

> Apple 用一个健身房用户旅程说明 system intelligence 可以在 App 安装前后通过 Maps 建议、App Clip、Siri Suggestions、Smart Stack 和 Shortcuts automation 把合适功能放到合适时间地点。

## 核心内容

很多 App 的增长问题并不发生在功能页里。用户还没安装 App 时，根本不知道你的功能存在。用户安装之后，也未必会在需要时想起打开它。一个健身房 App 如果只能等用户点图标，它就错过了很多真实场景。

这场 session 用一位准备健身的用户串起完整旅程。朋友在 Messages 里发来新健身房地址，用户还没有安装健身房 App，Maps 已经能根据地址给出路线建议。到店之后，前台的 NFC tag 可以打开 App Clip，让她直接查看课程表，不需要先去 App Store 搜索和下载。

当 App Clip 解决了问题，完整 App 的下载才有意义。用户开始在周日早晨计划一周课程，系统从使用模式里学习到这个习惯，于是在 Search 里提前显示 App。她后来常在下班后查看瑜伽课表，timely shortcut suggestions 又把这个入口放到 Search 结果里，省掉进入 App 再找页面的步骤。

用户变成熟手之后，问题变成信息是否及时。课程表变更可能让她错过团课，于是 iOS 14 的 widgets 和 Smart Stack 提供了新的入口：当课程表有变化时，Smart Stack 自动转到健身房 widget，让她在 Home Screen 上看到变化。最后，Shortcuts automation 可以在她到达健身房时运行，把查看公交时间和开始记录锻炼连成一个动作。

这条路径的核心不是让 App 看起来更聪明。它要求开发者先理解用户在什么时间、地点和心态下需要帮助，再把 App 的关键能力放到系统可以呈现的位置。

## 详细内容

### 从安装前开始设计用户旅程

（[00:24](https://developer.apple.com/videos/play/wwdc2020/10200/?time=24)）Apple 先把讨论范围放到 App 安装前。系统智能可以在用户下载 App 之前就提供帮助，并且沿着用户从新手到熟手的全过程持续发挥作用。这个 session 直接用一位用户和朋友去健身房的具体路径展开。

```text
朋友通过 Messages 发来新健身房地址
Maps 从地址识别出目的地
用户打开 Maps 前已经看到驾驶路线建议
用户还没有安装健身房 App
```

关键点：
- 第一个触点来自用户已经在做的事情：阅读朋友发来的地址。
- 系统建议不要求用户先知道健身房 App，也不要求她先打开 App Store。
- 对开发者来说，发现入口可能早于安装入口。

### 用 App Clip 承接当下任务

（[01:27](https://developer.apple.com/videos/play/wwdc2020/10200/?time=87)）用户到达健身房后，真正的问题是“今天有什么课”。iOS 14 的 App Clip 可以通过前台 NFC tag 打开，让她看到和完整 App 类似的课程表体验，同时避开下载完整 App 的摩擦。

```text
用户走到前台
手机靠近 NFC tag
App Clip 打开课程表
用户在 App Clip 内看到下载完整 App 的入口
```

关键点：
- App Clip 要对应一个眼前任务，这里是查看课程表。
- 它不替代完整 App，而是让用户先验证这个 App 能解决自己的问题。
- 下载完整 App 的入口出现在价值被看见之后，转化理由更清楚。

### 让 Search 和 Siri Suggestions 支持计划习惯

（[02:30](https://developer.apple.com/videos/play/wwdc2020/10200/?time=150)）用户下载完整 App 后，开始在周日早晨计划一周课程。她下拉进入 Search 时，即使还没有输入文字，App 也出现在 Siri Suggestions 中。transcript 明确说 Siri 会根据手机使用方式学习并预测她想打开的 App。

```text
用户周日早晨计划下周课程
她下拉打开 Search
Siri Suggestions 直接显示健身房 App
用户进入 App 查看课程安排
```

关键点：
- 建议入口来自重复行为，不是静态快捷方式。
- 周日早晨这个时间点很关键，因为它对应用户规划课程的习惯。
- App 的目标页要能承接这个入口，让用户继续做计划，而不是回到无关首页。

### 把常用页面变成及时建议

（[03:14](https://developer.apple.com/videos/play/wwdc2020/10200/?time=194)）用户熟悉 App 后，需求变得更具体。她喜欢瑜伽，经常在下班后查看瑜伽课表。最近她开始使用 timely shortcut suggestions，在 Search 中一点就能跳到瑜伽课表。

```text
用户下班后想找额外瑜伽课
她打开 Search
timely shortcut suggestion 显示瑜伽课表入口
点击后直接进入对应内容
```

关键点：
- 智能建议应该进入具体任务，不只是打开 App。
- “下班后查看瑜伽课表”比“打开健身房 App”更接近用户目标。
- 入口越接近目标页，用户越容易把 App 变成日常习惯。

### 用 Smart Stack 处理及时信息

（[03:54](https://developer.apple.com/videos/play/wwdc2020/10200/?time=234)）用户错过团课，是因为课程表更新没有及时被看到。iOS 14 的 widgets 和 Smart Stack 把信息带到 Home Screen。session 里的关键细节是：当课程表变化时，stack 会自动转到健身房 widget，让用户有时间处理变化。

```text
用户把健身房 widget 加入 Smart Stack
课程表发生变化
Smart Stack 自动转到健身房 widget
用户在 Home Screen 上看到变化并调整安排
```

关键点：
- Widget 的价值在于及时信息，而不是复制完整 App 界面。
- Smart Stack 负责在合适时机把相关 widget 转出来。
- 用户看到变化后，仍然可以点进 App 的正确位置继续处理。

### 用 Shortcuts automation 连接重复动作

（[04:49](https://developer.apple.com/videos/play/wwdc2020/10200/?time=289)）当用户已经频繁健身，她会在锻炼前重复几个动作：查看公交时间，打开 Mission Gym app 记录锻炼。Shortcuts automation 可以设置成到达健身房时运行，把这些动作放到同一个触发点后面。

```text
用户到达健身房
Shortcuts automation 被触发
她查看公交时间
她开始记录锻炼
```

关键点：
- 自动化适合已经稳定重复的动作。
- 触发点来自真实场景，这里是到达健身房。
- App 需要把可执行动作交给 Shortcuts，用户才能把它和其他 App 的动作组合起来。

## 核心启发

### 1. 为安装前场景设计第一个帮助点

**做什么**：列出用户遇到你的服务之前已经在做的事情，例如收到地址、看到门店标识、扫描桌牌或打开预约信息。

**为什么值得做**：session 的第一个有效触点发生在用户还没有安装健身房 App 时。系统建议先解决路线问题，再把用户带到后续体验。

**怎么开始**：选择一个安装前任务，写清楚用户已有输入、系统能识别的信号和下一步动作。不要从下载按钮开始，先从用户眼前的问题开始。

### 2. 把 App Clip 做成一个完整的小任务

**做什么**：为门店、场馆、活动或服务点设计一个 App Clip，只完成一个当下任务，比如查看课程表、排队、点单或预约。

**为什么值得做**：transcript 中的 App Clip 让用户在前台 NFC tag 旁直接看到课程表。她先获得价值，再决定是否下载完整 App。

**怎么开始**：从完整 App 中取出最短路径，保留完成任务必需的信息和操作。完成后再提供下载完整 App 的入口。

### 3. 为熟手用户准备具体入口

**做什么**：找出用户反复进入的二级页面，例如瑜伽课表、订单状态、常用路线或今日计划，把它设计成可以从 Search 中直接打开的入口。

**为什么值得做**：session 里的用户已经知道自己想看瑜伽课表。及时建议直接进入这个内容，比打开 App 首页更省步骤。

**怎么开始**：先选一个高频页面，定义它的目标用户、常见时间和进入后的默认状态。入口命中后，直接展示目标内容。

### 4. 用 widget 承担会过期的信息

**做什么**：把课程变更、排队进度、配送状态、余额提醒这类时间敏感信息放到 widget，而不是只依赖 App 内通知页。

**为什么值得做**：用户错过团课的原因是没有及时看到课程更新。Smart Stack 把健身房 widget 转出来，让 Home Screen 成为处理变化的地方。

**怎么开始**：找出一类用户会错过的信息，为它设计小尺寸和中尺寸展示。每个状态都要有清楚的下一步，例如查看详情、改约或打开对应页面。

### 5. 把到达场景做成自动化触发点

**做什么**：为到店、到家、上车、开始工作这类稳定场景设计 Shortcuts automation 中可执行的 App 动作。

**为什么值得做**：session 末尾的用户到达健身房后会重复查看公交时间和开始记录锻炼。自动化把这些动作放到一个触发点后面。

**怎么开始**：挑一个位置或时间触发场景，写出用户通常连续做的 2-3 个动作。先让你的 App 提供其中一个明确动作，再考虑和其他 App 组合。
