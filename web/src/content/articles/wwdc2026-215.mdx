## Highlight

> Apple 把 visionOS 上的原生 `<model>` 元素下放到了 iOS、iPadOS 和 macOS 的 Safari 中。现在向网页里添加 3D 模型就像添加图片一样简单：一个标签、一个 USDZ 文件，浏览器底层直接接管渲染，visionOS 上还有内置的立体渲染。不再需要引入庞大的 JS 库，也不用担心 WebGL 上下文丢失。

---

## 核心内容

### 1. 这场演讲解决什么问题

以前在网页上展示 3D 内容，开发者通常面临这些选择：

- 引入 Google 的 `model-viewer`（几十 KB 的 JS）
- 直接用 Three.js（更庞大，学习曲线陡峭）
- 在 visionOS 上还要专门处理立体渲染的 hack

这些方案的共同问题是：**你需要自己管理 WebGL 上下文、处理内存泄漏、适配不同平台**。

HTML Model Element 的解法是：**让浏览器原生支持 3D 渲染**。

### 2. 加载模型：像添加图片一样简单

```html
<!-- 使用 src 属性 -->
<model src="mallet.usdz"></model>

<!-- 使用 source 子标签指定 MIME 类型 -->
<model>
    <source src="mallet.usdz" type="model/vnd.usdz+zip">
</model>
```

跟 `<img>` 或 `<video>` 的用法完全一致。浏览器负责加载、解析、渲染，不需要任何插件。

### 3. 降级和加载状态处理

**图片降级**：在不支持 `<model>` 的浏览器里显示图片

```html
<model id="mallet" src="mallet.usdz">
    <img src="mallet.png" alt="Rubber mallet with wooden handle">
</model>
```

**加载状态**：3D 模型可能有几 MB 甚至几十 MB，需要用 `ready` promise 处理加载状态

```html
<model id="mallet" src="mallet.usdz"></model>

<script>
    const model = document.getElementById("mallet");
    model.ready.then(result => {
        // 隐藏 loading 指示器
    }).catch(error => {
        // 加载失败，显示降级内容
    });
</script>
```

**Polyfill**：对于还不支持 `<model>` 的浏览器，可以用 polyfill

```html
<script type="module">
    if (!window.HTMLModelElement) {
        import("model-element-polyfill.js").then(() => {
            // Polyfill 就绪
        });
    }
</script>
```

注意：polyfill 无法模拟 visionOS 上的立体渲染效果。

### 4. 样式和交互

**背景色**：Model 元素在自己的虚拟空间中渲染，不会继承页面背景

```html
<style>
    model {
        background-color: #f4f1ec;
    }
</style>
```

**轨道旋转**：让用户自由旋转模型

```html
<model id="mallet" src="mallet.usdz" stagemode="orbit"></model>
```

**自定义变换**：用 JavaScript 精确控制视角

```html
<model id="boot" src="boot.usdz"></model>
<button id="button-side">Side</button>
<button id="button-reset">Reset</button>

<script>
    const model = document.getElementById("boot");
    const initialTransform = model.entityTransform;

    document.getElementById("button-side").addEventListener("click", () => {
        const transform = new DOMMatrix();
        transform.rotateSelf(0, 135, 0);
        model.entityTransform = transform;
    });

    document.getElementById("button-reset").addEventListener("click", () => {
        model.entityTransform = initialTransform;
    });
</script>
```

关键点：
- 使用 `entityTransform` 前需要先禁用 orbit 模式（移除 `stagemode` 属性或设为 `"none"`）
- 手动变换时模型可能被裁剪，需要调整 Z 轴位移把模型拉回可视区域

### 5. 动画播放和 AR

**播放内置动画**：

```html
<model id="bottle" src="bottle.usdz"></model>
<button id="button-play" onclick="play(5)">Play</button>
<button id="button-reverse" onclick="play(-5)">Reverse</button>

<script>
    const model = document.getElementById("bottle");
    function play(rate) {
        model.playbackRate = rate;
        model.play();
    }
</script>
```

**AR Quick Look**：把模型包裹在 AR 链接中，点击后进入 AR 预览

```html
<a rel="ar" href="bottle.usdz">
    <model id="boot" src="bottle.usdz"></model>
</a>
```

### 6. 3D 资产准备

推荐 "Capture, Convert, Create" 三种方式获取 3D 资产：

- **Capture**：用 iPhone 扫描真实物体
- **Convert**：把现有文件（如 OBJ、FBX）转换为 USDZ
- **Create**：在 Blender 等工具中从零创建
- **AI 生成**：用 Tripo3D、Meshy.ai 等工具从图片或文字生成模型

**生产优化**：
- 用 `usdcrush` 命令行工具压缩 USDZ 文件，体积可减少 75%
- 用 `usdrecord` 批量渲染 fallback 图片

---

## 最佳实践

- **已有项目**：如果 `model-viewer` 跑得好好的，没必要立刻全量替换。新项目或者需要重点优化 visionOS 体验、追求极致首屏性能的，直接上 `<model>`
- **兼容性**：在 HTML 里引入 W3C 的 polyfill 脚本，通过 `window.HTMLModelElement` 判断环境，保证非 Safari 浏览器的基本可用性
- **性能**：把 `usdcrush` 加到 CI/CD 流程里。USDZ 文件动辄几 MB，压缩后体积能减 75% 且肉眼看不出画质损失，这对移动端首屏加载至关重要
- **动画**：做自定义旋转动画时，千万记得在 `requestAnimationFrame` 里先 `cancelAnimationFrame` 取消上一个动画，避免多个动画冲突
