## Highlight

> SwiftUI 的 shader、TimelineView 和 alignment guide 可以像管道一样组合起来，把一张静态封面图变成随音乐律动的动态视觉背景，同时让歌词视图与时间精准同步滚动——不需要写复杂的动画代码，只需要把几个简单的 building block 串起来。

---

## 核心内容

### 1. 这场演讲解决什么问题

做自定义视觉效果时，很多开发者会陷入两个极端：要么完全放弃 SwiftUI 去写 Metal，要么在 SwiftUI 里用大量 hack 拼凑效果。这场演讲展示了一条中间路线——用 SwiftUI 原生 API 的组合能力，搭建一条"创意管道"（creative pipeline），把 layout、shader、动画和交互有机地连接起来。

演讲用一个播客 App 的实战案例贯穿：从一张静态封面图和一段文字稿，做出 Apple Music 歌词视图那样的动态效果。核心思路是：每个 modifier 都是管道的一个阶段，数据流进去、被转换、再流向下一个阶段。

### 2. Layer Shader：在 SwiftUI 里写 Metal

Shader 是运行在 GPU 上的并行程序，每个像素独立计算颜色。SwiftUI 提供了三种 shader effect，其中 `layerEffect` 最适合对整张视图做后处理。

最简单的 shader 什么都不做，只是原样采样：

```swift
// SwiftUI 端：应用 layer effect
GeometryReader { proxy in
    CoverArtView()
        .layerEffect(
            ShaderLibrary.backgroundWarp(),
            maxSampleOffset: .zero
        )
}
.ignoresSafeArea()
```

```metal
// Metal 端：stitchable shader 函数
[[stitchable]] half4 backgroundWarp(
    float2 position, SwiftUI::Layer layer
) {
    return layer.sample(position);
}
```

关键点：

- `[[stitchable]]` 标记让 Metal 函数可以被 SwiftUI 动态拼接进渲染管线
- `SwiftUI::Layer` 是 SwiftUI 传入的图层句柄，通过 `sample()` 读取像素颜色
- `position` 是当前像素的坐标，每个像素独立执行

给 shader 加参数也很简单，SwiftUI 会自动把值传进去：

```metal
[[stitchable]] half4 backgroundWarp(
    float2 position, SwiftUI::Layer layer,
    float2 offset
) {
    return layer.sample(position + offset);
}
```

```swift
.layerEffect(
    ShaderLibrary.backgroundWarp(
        .float2(.init(x: proxy.size.width, y: 0))
    ),
    maxSampleOffset: .zero
)
```

### 3. 用噪声纹理做域扭曲（Domain Warping）

真正有趣的效果来自把噪声纹理作为位移图。演讲展示了 domain warping 技术——用噪声采样结果去偏移采样坐标，产生有机的扭曲效果：

```metal
[[stitchable]] half4 backgroundWarp(
    float2 position, SwiftUI::Layer layer,
    float2 size, texture2d<half> noiseTex
) {
    constexpr sampler s(address::repeat, filter::linear);
    float2 uv = position / size;

    // 第一次采样噪声
    half4 n = noiseTex.sample(s, uv);
    float2 q = float2(n.r, n.g);

    // 用第一次采样结果偏移坐标，再次采样（domain warping）
    n = noiseTex.sample(s, uv + q);

    // 计算最终偏移量
    float2 offset = (float2(n.r, n.g) - 0.5) * 200.0;

    return layer.sample(position + offset);
}
```

```swift
TimelineView(.animation) { timeline in
    let elapsed = timeline.date.timeIntervalSince(startDate)
    CoverArtView()
        .layerEffect(
            ShaderLibrary.backgroundWarp(
                .float2(proxy.size),
                .image(Image("NoiseTexture")),
                .float(elapsed)  // 时间驱动动画
            ),
            maxSampleOffset: .zero
        )
}
```

关键点：

- `texture2d<half>` 让 shader 读取 SwiftUI 传入的纹理图片
- `TimelineView(.animation)` 提供连续的时间驱动，让 shader 参数随时间变化
- Domain warping 的核心是"用噪声去扭曲噪声"，产生比单纯噪声更丰富的有机形态
- `maxSampleOffset` 告诉 SwiftUI 你的 shader 最多会偏移多少像素，用于优化渲染

### 4. Alignment Guide：精准控制视图锚点

演讲的后半部分展示了 alignment guide 的妙用。比如给歌词每行加一个时间戳 overlay，默认会居中，但你想让时间戳贴在左下角：

```swift
Text(line.text)
    .overlay(alignment: .bottomLeading) {
        Text(line.formattedTimestamp)
    }
```

更进一步，可以用 `alignmentGuide` 精确控制对齐位置。比如让时间戳的底部对齐到文本的顶部：

```swift
Text(line.text)
    .overlay(alignment: .bottomLeading) {
        Text(line.formattedTimestamp)
            .alignmentGuide(.bottom) { $0[.top] }
    }
```

配合 `ScrollViewReader` 和 `onChange`，可以实现时间同步的自动滚动：

```swift
@State private var playback = PlaybackState()

ScrollViewReader { scrollProxy in
    ScrollView {
        LazyVStack(alignment: .leading, spacing: 12) {
            ForEach(sampleTranscript) { line in
                Text(line.text)
                    .transcriptLineStyle(isCurrent:
                        line.id == playback.currentLineIndex
                    )
            }
        }
    }
    .onChange(of: playback.currentLineIndex) { _, i in
        scrollProxy.scrollTo(i, anchor: .center)
    }
}
```

## 最佳实践

- **从简单管道开始**：先让每个 stage 独立工作，再逐步连接。不要一开始就写复杂的 shader
- **善用 GeometryReader 传尺寸**：shader 通常需要知道视图大小来计算 UV 坐标，用 `proxy.size` 传入
- **maxSampleOffset 要设对**：如果 shader 会采样当前像素周围 50px 的范围，就把 `maxSampleOffset` 设为 `CGSize(width: 50, height: 50)`，SwiftUI 会据此优化
- **TimelineView 驱动动画**：比 `withAnimation` 更适合 shader 参数的持续更新，因为它与显示刷新同步
- **Alignment guide 解决精细布局**：当 `.position()` 或 `.offset()` 不够精确时，alignment guide 可以基于子视图的特定边缘对齐
