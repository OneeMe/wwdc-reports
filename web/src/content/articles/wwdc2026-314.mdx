## Highlight

> 瀑布流（Masonry Layout）终于有原生 CSS 方案了。`display: grid-lanes` 只约束一个轴（如列宽），另一个轴（行高）完全交给内容撑开。不需要 JavaScript 库，不需要算高度，Safari 26.4 已经可用。

---

## 核心内容

### 1. 这场演讲解决什么问题

前端做瀑布流布局一直是个痛点：

- Flexbox 只有一个轴，wrap 后会留下大片空白
- CSS Grid 把内容放进固定单元格，不同比例的图片要么被拉伸、要么被裁剪、要么溢出
- JavaScript 库（如 Masonry.js）需要监听 resize、计算高度、触发 reflow，性能差且代码重

Grid Lanes 是新的布局模式，定位在 Flexbox 和 Grid 之间：像 Grid 一样有多列，但每列的高度由内容决定，不会强制对齐。

### 2. Grid Lanes 的工作原理

布局模式回答两个问题：元素放哪里？占多少空间？

- **Flexbox**：一个轴，单 lane 流动，wrap 时继续沿同一方向
- **Grid**：两个轴，元素放在行列交叉的单元格中，不同高度会留下空白
- **Grid Lanes**：只约束一个轴（如列宽），另一个轴自由，内容依次填入最短的列

结果是紧密排列的交错布局，保留每个元素的自然比例。

### 3. 基础用法

```css
.container {
    display: grid-lanes;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}
```

三行代码创建一个三列瀑布流，gap 为 10px。`fr` 是 fractional unit，将可用空间分成等份。

**更多列定义方式**：

```css
/* 三列等宽 */
grid-template-columns: 1fr 1fr 1fr;

/* 中间列两倍宽 */
grid-template-columns: 1fr 2fr 1fr;

/* 自动填充，最小 200px */
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));

/* 混合 minmax */
grid-template-columns: repeat(auto-fill,
    minmax(8rem, 1fr) minmax(14rem, 2fr));
```

### 4. 控制单个元素

```css
.container {
    display: grid-lanes;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 10px;
}

/* 跨两列 */
.item {
    grid-column: span 2;
}

/* 从第 2 列开始，跨两列 */
.item-featured {
    grid-column: 2 / span 2;
}
```

### 5. 与 Subgrid 结合

子元素可以用 `subgrid` 继承父容器的列定义：

```css
.container {
    display: grid-lanes;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 10px;
}

.item {
    display: grid-lanes;  /* 或 display: grid */
    grid-template-columns: subgrid;
    grid-column: span 2;
}
```

子元素内部的布局会自动对齐到父容器的三列轨道。

### 6. Flow Tolerance：可访问性优化

`flow-tolerance` 控制元素在换行时的"容错度"：

```css
.container {
    display: grid-lanes;
    grid-template-columns: 1fr 1fr;
    gap: 10px;
    flow-tolerance: normal;  /* 默认值 */
}

/* 允许元素在换行时有 2.1em 的容差 */
.container {
    flow-tolerance: 2.1em;
}
```

当元素因为内容长度接近换行边界时，`flow-tolerance` 让布局更灵活，避免元素被不必要地推到下一列。这对可访问性很重要 — 当用户放大字体时，内容不会突然断裂到不期望的位置。

## 最佳实践

- **渐进增强**：用 `@supports (display: grid-lanes)` 检测支持度，不支持的浏览器回退到 JS 库
- **给图片设置 `aspect-ratio`**：避免异步加载图片导致高度突变和布局偏移（CLS）
- **Grid Lanes 不挑内容类型**：图片、文字、混合内容都能正常工作
- **用 `flow-tolerance` 改善可访问性**：特别是在响应式布局中，大字体不会破坏布局
- **Safari 26.4 已可用**：其他浏览器可在 flag 后启用
