## Highlight

> RealityKit 今年补上了游戏引擎最核心的"基建"：原生 NavMesh 寻路、软阴影、投影纹理、物理空间光照、布料模拟、LOD 自动切换、高斯 splat 渲染——以前要自己手搓或借 Unity 的活儿，现在原生 API 直接搞定。

---

## 核心内容

### 1. 这场演讲解决什么问题

在 visionOS 上做复杂的 3D 游戏或沉浸式体验，开发者长期面临几个痛点：

- NPC 寻路得自己实现 A* 算法或集成第三方引擎
- 虚拟物体的光影和真实房间融合得假
- 复杂场景性能难以控制，没有原生的 LOD 机制
- 想渲染真实世界扫描的高斯 splat 没有原生支持

RealityKit 今年的更新一次性解决了这些问题，让原生开发在功能层面可以真正对标 Unity PolySpatial。

### 2. 光照和阴影：从硬边到真实

**软阴影（Soft Shadows）：**

```swift
// 给壁炉的聚光灯启用软阴影
guard var shadow = hearthSpotlight.components[SpotLightComponent.Shadow.self] else {
    // handle error
}
shadow.lightSize = 0.7 // 光源直径，单位米
shadow.quality = .medium // .low = 硬阴影, .medium/.high = 软阴影

hearthSpotlight.components.set(shadow)
```

关键点：

- `lightSize` 表示光源直径，越大阴影边缘越柔和
- `quality` 控制阴影质量，`.low` 退化为硬阴影，`.medium`/`.high` 启用软阴影
- 软阴影更适合模拟面积光源（如窗户、灯罩），点光源可以用硬阴影

**投影纹理（Projective Textures）：**

```swift
let spotLightEntity = Entity()
spotLightEntity.components.set(SpotLightComponent(
    color: .white,
    intensity: intensity,
    innerAngleInDegrees: innerAngle,
    outerAngleInDegrees: outerAngle,
    attenuationRadius: attenuationRadius,
))

let projectiveTexture: TextureResource = generateStarsAndNebulaeTexture()
spotLightEntity.components.set(SpotLightComponent.ProjectiveTexture(
    texture: projectiveTexture
))
```

**物理空间光照（Physical Space Lighting）：**

```swift
// 让虚拟光源照亮真实房间
spotLightEntity.components.set(SpotLightComponent.SurroundingsLight())
```

关键点：

- `SurroundingsLight` 让虚拟光源影响真实环境的渲染，实现混合现实光照
- 配合投影纹理，可以做出"虚拟投影仪把内容投到真实墙壁上"的效果

### 3. NavMesh 寻路

```swift
extension Entity {
    public func navigate(/* ... */) async {
        let navigator = try! NavigationController(entity: self)
        guard let result = await navigator.computePath(from: fromPosition, to: toPosition)
        else {
            return
        }
        if result.isEmpty {
            return
        }
        for node in result {
            switch node.category {
                case .meshPoint:
                    finalPath.append(node.position)
                case .offMeshConnection:
                    // 处理梯子、传送门等网格外连接
            }
        }
    }
}
```

关键点：

- `NavigationController` 是异步 API，路径计算不会阻塞主线程
- 支持区域成本（Area Costs）——不同地形（草地、沼泽、道路）可以设置不同移动成本
- 支持网格外连接（Off-mesh Connections）——梯子、跳跃点、传送门等特殊移动方式
- NavMesh 可以在 Reality Composer Pro 3 中可视化编辑

### 4. 布料模拟

```swift
// 把窗帘固定到锚点
for (pin, pinComponent) in pins {
    let position = pin.position(relativeTo: event.entity)
    let selectionSphere = ClothSphereShape(radius: pinComponent.radius)

    let vertices = clothMesh.vertices(in: .sphere(selectionSphere),
                                    center: position)
    clothBody.motionTypes.set(vertexIndices: vertices, value: .kinematic)
}
```

关键点：

- 布料顶点的 `motionTypes` 可以是 `.dynamic`（受物理影响）或 `.kinematic`（固定不动）
- 通过选择球体范围内的顶点，可以把布料的特定区域"钉"在场景中
- 适合模拟窗帘、旗帜、衣服等效果

### 5. LOD（细节层次）自动切换

**按相机距离切换：**

```swift
let lod0 = [ModelEntity(mesh: lodMesh0)]
let lod1 = [ModelEntity(mesh: lodMesh1)]
let lod2 = [ModelEntity(mesh: lodMesh2)]

let entity = Entity()

LevelOfDetailComponent.addByCameraDistance(to: entity, levels: [
    (entities: lod0, maxDistance: 1.0),  // 1米内用最高精度
    (entities: lod1, maxDistance: 5.0),  // 5米内用中等精度
    (entities: lod2, maxDistance: .infinity), // 更远用最低精度
])
```

**按屏幕占比切换：**

```swift
LevelOfDetailComponent.addByScreenArea(to: entity, levels: [
    (entities: lod0, minArea: 0.2),  // 占屏幕 20% 以上用最高精度
    (entities: lod1, minArea: 0.1),  // 占 10% 以上用中等精度
    (entities: lod2, minArea: 0.01), // 占 1% 以上用最低精度
])
```

### 7. 高斯 Splat 渲染

```swift
let resource = try GaussianSplatResource.BufferResource(
    count: splatCount,
    position: positionBuffer,
    scale: scaleBuffer,
    rotation: rotationBuffer,
    opacity: opacityBuffer,
    sphericalHarmonics: (sphericalHarmonicsBuffer, degree)
)

let splatResource = GaussianSplatResource(resource)
let splatComponent = GaussianSplatComponent(splatResource)
splatEntity.components.set(splatComponent)
```

关键点：

- 高斯 splat 是一种用数百万个模糊粒子重建真实场景的技术
- 适合渲染真实世界扫描的内容，比传统 mesh 更轻量、更真实
- 需要 position、scale、rotation、opacity、spherical harmonics 五个 buffer

### 8. 自定义混响网格

```swift
// 创建鞋盒形状的混响空间
let mesh: ReverbMeshResource = .shoebox(size: [5, 4, 6])
let reverb: Reverb = .simulated(mesh: mesh, materials: [.dryWall])
entity.components.set(ReverbComponent(reverb: reverb))
```

**自定义材质：**

```swift
let thickCarpet: Audio.Material = .carpet.scalingAbsorption { freq in 0.1 }

let bookshelfAbsorption = Audio.Absorption(
    [0.10, 0.15, 0.28, 0.20, 0.15, 0.10, 0.10, 0.07, 0.07, 0.05])

let bookshelf = Audio.Material(absorption: bookshelfAbsorption,
                               scattering: bookshelfScattering)
```

## 最佳实践

- **热状态管理是必修课**：visionOS 设备散热受限，必须监听 `thermalStateDidChange`，在 `.serious`/`.critical` 时主动降低阴影质量和 LOD 级别
- **NavMesh 的异步处理**：`computePath` 返回时 NPC 位置可能已经变化，路径第一个点要平滑过渡，避免瞬移
- **LOD 策略选择**：相机距离适合开放世界，屏幕占比适合密集场景（很多小物体）。可以组合使用
- **光照烘焙优先**：静态场景的间接光照用 Reality Composer Pro 3 的 light baker 生成 lightmap，不要运行时硬算
- **高斯 splat 的适用场景**：适合展示真实环境扫描（如房地产、博物馆），不适合需要精确碰撞检测的游戏场景
