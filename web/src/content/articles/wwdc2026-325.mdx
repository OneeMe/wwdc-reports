## Highlight

> Core AI 的 Python 工具链不仅能转换标准 PyTorch 模型，还允许你在模型里直接内联自定义 Metal kernel——这意味着你可以用 Python 写模型结构、用 Metal Shading Language 写高性能算子，然后一键打包成可在 iPhone 上运行的 .aimodel 文件。

---

## 核心内容

### 1. 这场演讲解决什么问题

"Meet Core AI" 展示了基础转换流程，但真实世界的模型往往有自定义算子、需要量化压缩、或者需要针对特定硬件优化。这场演讲深入 Core AI 的 Python 生态，覆盖：模型仓库和 Agent skills、转换与验证流程、平台感知优化、Core AI Debugger、以及自定义 Metal kernel 的编写。

### 2. Core AI Models 仓库和 Agent Skills

Apple 开源了 `coreai-models` 仓库，包含：

- 预配置的 LLM 运行示例（Swift package）
- 各种用例和约束条件下的模型配置
- 可复用的组件，用于接入你自己的模型
- **Core AI Skills**：可以安装到编码 Agent 中的技能包，让 Agent 从第一天起就按最佳实践帮你部署模型

这些 skills 会询问你的模型类型、目标硬件家族、应用约束，然后生成从 PyTorch 代码修改到转换、优化、运行的完整部署计划。

### 3. 基础转换与优化流程

最简单的流程四步走：导出 → 转换 → 优化 → 保存。

```python
import torch
import torch.nn as nn

# 1. 定义模型
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(256, 512)
        self.fc2 = nn.Linear(512, 10)

    def forward(self, x):
        return self.fc2(torch.relu(self.fc1(x)))

# 2. 导出
model = MLP().eval()
example_input = (torch.randn(1, 256),)
exported_program = torch.export.export(model, example_input)
```

```python
import coreai
import coreai_torch
from coreai.runtime import NDArray

# 3. 转换
converter = coreai_torch.TorchConverter()
converter.add_exported_program(
    exported_program,
    input_names=["features"], output_names=["logits"])
core_ai_program = converter.to_coreai()

# 4. 优化并保存
core_ai_program.optimize()
asset = core_ai_program.save_asset("mlp.aimodel")

# 5. 验证推理
specialized_model = await AIModel.load("mlp.aimodel")
specialized_function = specialized_model.load_function("main")
result = await specialized_function(
    {"features": NDArray(example[0].numpy())}
)
```

`optimize()` 会自动应用平台感知的优化策略，包括算子融合、内存布局优化等。优化后的模型针对 Apple Silicon 的 CPU/GPU/ANE 做了特化。

### 4. Core AI Debugger

转换后的模型如果输出不对，怎么调试？Core AI Debugger 是可视化调试工具，可以：

- 逐层查看模型的计算图结构
- 追踪任意 tensor 的数值，直接回溯到原始 Python 源码位置
- 对比 PyTorch 参考输出和 Core AI 输出的差异
- 分析内存使用和性能瓶颈

这是 Core AI 相比之前 Core ML 工具链的重大改进——你不再需要猜测转换哪里出了问题，Debugger 会告诉你具体是哪个算子、哪一行 Python 代码对应的输出有偏差。

### 5. 自定义 Metal Kernel

当模型包含 PyTorch 没有原生对应的操作，或者你需要极致性能时，可以直接在 Python 模型中内联 Metal kernel。

以自定义 SiLU（Sigmoid Linear Unit）激活函数为例：

```python
import torch
from coreai_torch.dsl import TorchMetalKernel, MetalParameter

# 1. 用 PyTorch 写参考实现（用于验证）
def silu_torch(x):
    return x * torch.sigmoid(x)

# 2. 用 Metal Shading Language 写 GPU 实现
SILU_MSL = """
float val = float(x[gid]);
float sig = 1.0f / (1.0f + exp(-val));
y[gid] = TYPE(val * sig);
"""

# 3. 注册为 Core AI 自定义 kernel
silu_kernel = TorchMetalKernel(
    name="fused_silu",
    input_names=["x"],
    result_names=["y"],
    src=SILU_MSL,
    torch_defn=silu_torch,  # 参考实现，用于数值验证
    metal_params=[MetalParameter("gid", "uint", "thread_position_in_grid")],
    template_dtypes={"x": "TYPE"},
)
```

然后在模型中使用这个 kernel：

```python
class MyModel(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = torch.nn.Linear(256, 256)

    def forward(self, x):
        h = self.linear(x)
        n = h.numel()
        return silu_kernel(
            h,
            threads_per_grid_size=(n, 1, 1),
            threads_per_thread_group=(min(n, 256), 1, 1),
            result_shapes=[h.shape],
        )

# 导出并转换
exported_program = torch.export.export(MyModel(), (torch.randn(1, 256),))

converter = coreai_torch.TorchConverter()
converter.register_custom_kernels([silu_kernel])  # 注册自定义 kernel
converter.add_exported_program(
    exported_program,
    input_names=["x"], output_names=["y"])

deployable = converter.to_coreai()  # MSL 代码被嵌入到 asset 中
```

关键点：

- `torch_defn` 提供 PyTorch 参考实现，转换时自动做数值一致性检查
- `template_dtypes` 让 kernel 支持多种数据类型（float16、float32 等）
- `register_custom_kernels()` 在转换器注册自定义算子，让 TorchConverter 知道如何处理
- 最终生成的 `.aimodel` 包含了完整的 Metal 源码，在设备上直接编译运行

## 最佳实践

- **先用标准转换，再考虑自定义 kernel**：大部分 PyTorch 操作 Core AI 都有原生支持，自定义 kernel 只在性能瓶颈或缺失算子时引入
- **始终提供 torch_defn**：自定义 kernel 的 PyTorch 参考实现是数值验证的基准，不要省略
- **利用 coreai-models 仓库**：不要从零开始配置 LLM，仓库里有经过验证的模型架构和参数
- **安装 Core AI Skills 到编码 Agent**：让 Agent 帮你生成转换代码和优化策略，减少试错
- **用 Debugger 而不是 print 调试**：Core AI Debugger 能定位到具体算子和源码行，比打印 tensor 值高效得多
- **optimize() 不是万能的**：对于已经手动调优过的模型，`optimize()` 的收益可能有限，建议对比优化前后的性能
