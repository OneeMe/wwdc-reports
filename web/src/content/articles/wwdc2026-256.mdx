## Highlight

> AI 生成字幕在设备端实时转写或翻译视频音频，无需你写一行代码。字幕样式预览让用户可以自定义字幕外观，大幅提升视频内容的可访问性。

---

## 核心内容

### 1. 这场演讲解决什么问题

视频内容需要字幕，但手动创建多语言字幕成本高、耗时长。AI 生成字幕用设备端模型实时转写音频或翻译已有字幕，让视频内容对更多人可访问。

字幕对以下人群至关重要：

- 聋人或听力障碍者
- 需要辅助理解对话的人
- 在嘈杂环境中无法听到音频的人

### 2. 两种生成方式

**语音转写（Speech Transcription）**：

- 源音频 → 设备端 Speech-to-Text 模型 → 生成字幕
- 适用于原始内容没有字幕的情况

**语言翻译（Language Translation）**：

- 源字幕（如英文）→ 设备端翻译模型 → 新语言字幕（如意大利文）
- 适用于内容有字幕但缺少目标语言的情况

生成的字幕是补充性的——如果内容提供了人工字幕（Authored subtitles），系统会优先使用人工字幕。

### 3. 零代码开启

好消息：你不需要实现任何东西来开启生成字幕。它们在视频播放时自动可用。

支持的场景：

- HTTP Live Streaming（HLS）内容，包括直播和点播
- 文件内容，如 App 内嵌视频或下载的媒体
- 专业内容（电影、剧集）和用户生成内容（iPhone 拍摄、社交媒体视频）

### 4. 设备和语言支持

从 iOS / macOS / tvOS / visionOS 27 开始：

- 英文音频可生成英文字幕
- 英文字幕可翻译成多种其他语言字幕

### 5. 字幕选择 UI

**方案一：使用系统播放器（推荐）**

`AVPlayerViewController`（iOS）和 `AVPlayerView`（macOS）自带完整的字幕选择和播放器控制，无需额外工作。

**方案二：添加字幕选择菜单**

`AVLegibleMediaOptionsMenuController` 提供字幕选择控制，但不包含播放器控制。适合已有自定义播放器 UI 的 App：

```swift
let menuController = AVLegibleMediaOptionsMenuController(
    player: player
)
```

**方案三：完全自定义**

使用 `AVPlayerItem` 的 `legibleMediaSelectionOptions` 获取可用字幕选项，自己构建 UI。

### 6. 字幕样式预览

用户可以自定义字幕样式（字体、大小、颜色、背景等），并在播放时实时预览效果。

实现字幕样式预览：

```swift
import AVFoundation
import MediaAccessibility

func updateProfileList() {
    subtitleStyleProfileIDs = MACaptionAppearanceCopyProfileIDs() as? [String] ?? []
}

func showPreviewStyle(subtitleStyleProfileID: String) {
    playerLayer.setCaptionPreviewProfileID(
        subtitleStyleProfileID,
        position: .zero,
        text: nil
    )
}

func stopPreviewStyle() {
    playerLayer.stopShowingCaptionPreview()
}

func setSubtitleStyle(subtitleStyleProfileID: CFString) {
    MACaptionAppearanceSetActiveProfileID(subtitleStyleProfileID)
}
```

关键点：

- `setCaptionPreviewProfileID` 在播放器上显示预览字幕
- `position` 参数控制预览文本的位置
- `text: nil` 使用默认预览文本
- 用户确认后，用 `MACaptionAppearanceSetActiveProfileID` 应用样式

### 7. 字幕样式的工作原理

系统维护一组字幕样式 profile，每个 profile 包含：

- 字体和大小
- 文字颜色
- 背景样式（透明、半透明、纯色）
- 边缘样式（描边、阴影）

用户可以在系统设置中创建和编辑样式，你的 App 只需要提供预览和应用接口。

## 最佳实践

- **始终提供字幕选择入口**：即使使用系统播放器，也要确保用户知道字幕功能的存在
- **优先使用系统播放器**：`AVPlayerViewController` 和 `AVPlayerView` 自动处理所有字幕逻辑
- **为自定义播放器使用 AVLegibleMediaOptionsMenuController**：不要从头实现字幕选择 UI
- **测试字幕样式预览**：确保预览位置不会遮挡重要内容
- **提供高质量人工字幕**：对于医疗、法律等对准确性要求高的内容，不要依赖 AI 生成字幕
- **考虑字幕的可达性**：确保字幕对比度足够，字体大小可调整
