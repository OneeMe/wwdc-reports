## Highlight

> WWDC21 发布了 iOS 15、iPadOS 15、macOS Monterey 和 watchOS 8 四大系统更新。对开发者而言，最重要的三个变化是：Swift 原生支持 async/await 并发编程，Xcode Cloud 提供了云端 CI/CD 能力，以及 Object Capture API 让 3D 建模从数周缩短到数分钟。

---

## 核心内容

WWDC21 是 Apple 连续第二年以全线上形式举办开发者大会。Tim Cook 开场时提到，上一届 WWDC 吸引了近 2500 万观众，是有史以来覆盖面最广的一次。今年大会继续免费向所有开发者开放，包含 200+ 场深度 session 和一对一实验室。

Keynote 时长约 1 小时 45 分钟，按产品线逐段展开。下面按主题梳理每个平台的关键变化。

### iOS 15：连接、专注与智能

iOS 15 的更新围绕四个方向：保持连接、减少干扰、智能发现信息、探索世界。

FaceTime 获得了四项重要增强（[05:17](https://developer.apple.com/videos/play/wwdc2021/101/?time=317)）。空间音频（Spatial Audio）让通话中每个人的声音从屏幕中对应位置传出，模拟面对面交谈的声场。语音突显（Voice Isolation）用机器学习过滤环境噪音，只保留人声；宽频谱（Wide Spectrum）则相反，保留所有环境音。人像模式（Portrait Mode）模糊背景，把焦点放在人物上。最关键的是，FaceTime 链接（FaceTime Links）让 Android 和 Windows 用户可以通过浏览器加入通话，且仍然保持端到端加密。

SharePlay 是 FaceTime 的延伸（[09:54](https://developer.apple.com/videos/play/wwdc2021/101/?time=594)）。用户在 FaceTime 通话中可以一起听 Apple Music、一起看视频、共享屏幕。所有参与者的播放进度保持同步，共享播放控制让任何人都可以暂停或切歌。SharePlay 提供了 API，Disney+、Hulu、HBO Max、TikTok、NBA、Twitch 等已经接入。

通知系统重新设计了外观——联系人照片和更大的 App 图标让识别更快捷（[16:52](https://developer.apple.com/videos/play/wwdc2021/101/?time=1012)）。通知摘要（Notification Summary）将非紧急通知打包，在你设定的时间统一推送，按优先级排序。专注模式（Focus）则更进一步：用户可以为工作、个人生活等场景创建不同的专注状态，每个状态可以指定允许通知的 App 和人、甚至可以切换不同的主屏幕页面。

Live Text（实况文本）让用户从任何照片中直接提取文字（[20:08](https://developer.apple.com/videos/play/wwdc2021/101/?time=1208)）。相机对准白板或菜单，点一下指示器，文字就可以选中、复制、翻译。支持七种语言，包括简体中文和繁体中文。同一套视觉识别还能识别物体和场景——狗的种类、花的品种、地标等。

钱包 App 新增了三类钥匙：家门钥匙、公司门禁卡、酒店钥匙（[26:25](https://developer.apple.com/videos/play/wwdc2021/101/?time=1585)）。最重要的是身份证明——美国部分州开始支持将驾照和州 ID 扫描进 Wallet，TSA 将允许在机场安检处使用数字 ID 验证。

### iPadOS 15：生产力升级

iPadOS 15 最大的变化在桌面和分屏（[37:44](https://developer.apple.com/videos/play/wwdc2021/101/?time=2264)）。小组件可以自由放置在主屏幕任意位置（不再限于左侧固定区域），并新增了专为 iPad 大屏幕设计的加大号组件。App 资源库也来到了 iPad，自动分类整理所有 App，并集成在 Dock 栏中。

多任务操作全面改版（[41:02](https://developer.apple.com/videos/play/wwdc2021/101/?time=2462)）。每个 App 顶部新增多任务菜单按钮，点击即可选择全屏、Split View 或 Slide Over。新增的 Shelf 区域管理 App 的所有打开窗口。App 切换器支持拖拽创建分屏。

Quick Note（快速备忘录）是 iPadOS 15 的亮点功能（[44:09](https://developer.apple.com/videos/play/wwdc2021/101/?time=2649)）。从屏幕右下角向内轻扫即可呼出一个浮动笔记窗口。它会感知当前正在使用的 App，自动添加对应链接。在 Safari 中打开的 Quick Note 会自动带上网页链接和高亮文本。

Swift Playgrounds 现在可以开发完整的 App 了（[47:06](https://developer.apple.com/videos/play/wwdc2021/101/?time=2826)）。使用 SwiftUI 编写代码，实时预览运行效果，支持代码补全、完整的 UI 组件库和文档，甚至可以直接提交到 App Store。项目格式与 Xcode 兼容，可以在 Mac 上继续开发。

### 隐私：从应用到网络的全面防护

Mail Privacy Protection 阻止邮件发送者使用隐藏像素追踪你的邮件打开行为和 IP 地址（[49:48](https://developer.apple.com/videos/play/wwdc2021/101/?time=2988)）。Safari 的智能防追踪现在还会隐藏 IP 地址，防止追踪器跨站点关联你的活动。App Privacy Report 是新增的隐私仪表盘（[50:56](https://developer.apple.com/videos/play/wwdc2021/101/?time=3056)），展示每个 App 在过去 7 天内访问敏感权限的频率，以及它们连接了哪些第三方域名。

Siri 现在默认在设备端处理语音识别（[52:10](https://developer.apple.com/videos/play/wwdc2021/101/?time=3130)）。这意味着不需要网络连接就能完成启动 App、修改设置、控制音乐等操作，速度也更快。

iCloud 付费订阅升级为 iCloud+（[54:33](https://developer.apple.com/videos/play/wwdc2021/101/?time=3273)），价格不变。新增两个功能：Private Relay 通过双重中继加密 Safari 流量，连 Apple 都无法同时知道你是谁和你访问了哪些网站；Hide My Email 允许创建随机的唯一邮箱地址，转发到你的个人邮箱，内置在 Mail、Safari 和 iCloud 设置中。

### 健康：数据驱动的洞察

Walking Steadiness（步行稳定性）通过 iPhone 运动传感器测量步速、步幅、双脚同时着地时间等指标（[01:01:02](https://developer.apple.com/videos/play/wwdc2021/101/?time=3662)），评估跌倒风险。数据来自 Apple Heart & Movement Study 的 10 万+ 参与者，是史上最大规模的跌倒风险研究。

Trends 功能长期追踪步数、静息心率、血糖、睡眠等指标的变化趋势（[01:03:20](https://developer.apple.com/videos/play/wwdc2021/101/?time=3800)），发现异常时主动提醒。Health Sharing 让用户可以安全地与家人和医生共享选定的健康数据（[01:04:27](https://developer.apple.com/videos/play/wwdc2021/101/?time=3867)），医生可以直接在电子病历系统中查看。

### macOS Monterey：跨设备协作

macOS Monterey 的核心主题是让 Mac 与 iPad 更无缝地协作（[01:20:10](https://developer.apple.com/videos/play/wwdc2021/101/?time=4810)）。

Universal Control 是这个 Keynote 最惊艳的演示（[01:22:27](https://developer.apple.com/videos/play/wwdc2021/101/?time=4947)）。把 iPad 放在 MacBook 旁边，Mac 的鼠标光标就能自动穿越到 iPad 屏幕上，一套键鼠控制两台设备。支持最多三台设备，可以直接拖拽文件跨设备传输——Craig 现场演示了从 iPad 的 Procreate 拖拽图片到 MacBook 的 Keynote，再到 iMac 的 Final Cut Pro。不需要任何设置。

Shortcuts（快捷指令）终于来到了 Mac（[01:26:26](https://developer.apple.com/videos/play/wwdc2021/101/?time=5186)）。内置丰富的预设快捷指令，编辑器支持拖拽组合操作。快捷指令集成在 Finder、菜单栏、Spotlight 和 Siri 中。Automator 继续得到支持，其工作流可以导入 Shortcuts。这是 Apple 宣布的多年代迁移的第一步。

Safari 重新设计了标签页体验（[01:27:46](https://developer.apple.com/videos/play/wwdc2021/101/?time=5266)）。工具栏被精简，标签页更紧凑，搜索栏与活动标签页合并。标签组（Tab Groups）允许保存一组标签页，跨所有设备自动同步。iPhone 上的标签栏移到了底部拇指可及的位置。Safari Web Extensions 首次来到 iPhone 和 iPad。

### 开发者工具：三项重大更新

**Swift Concurrency** — async/await 成为 Swift 语言的一等公民（[01:37:15](https://developer.apple.com/videos/play/wwdc2021/101/?time=5835)）。搭配 actors 技术，并发代码从复杂的回调地狱变成线性的步骤序列。这是 Swift 社区呼声最高的特性。

**Object Capture** — 一项革命性的 macOS API（[01:35:07](https://developer.apple.com/videos/play/wwdc2021/101/?time=5707)），通过摄影测量（photogrammetry）将一系列 2D 照片转换为照片级真实的 3D 模型，耗时仅数分钟。传统手工建模可能需要数周。Maxon（Cinema 4D）、Unity 和 Wayfair 已经接入。

**Xcode Cloud** — Apple 的云端 CI/CD 服务（[01:41:41](https://developer.apple.com/videos/play/wwdc2021/101/?time=6101)）。提交代码后自动在云端构建、并行运行测试、自动分发到 TestFlight。构建在云端进行，Mac 本地可以继续其他工作。TestFlight 也首次来到了 Mac。Xcode Cloud 从当天开始提供限量测试版，2022 年正式上线。

## 核心启发

### 1. 为你的 App 接入 SharePlay

SharePlay API 让用户可以在 FaceTime 通话中一起使用你的 App。如果你的 App 涉及媒体消费（视频、音乐、播客）或协作场景，这是一个自然的增长点。

开始方式：研究 `GroupActivities` 框架，实现 `GroupActivity` 协议。Apple 提供了 `GroupSessionMessenger` 用于在参与者之间同步数据。

### 2. 迁移异步代码到 async/await

Swift 5.5 的 async/await 是语法级别的改进，不是框架层面的补充。任何有大量异步操作（网络请求、数据库读写、文件操作）的 App 都应该计划迁移。

开始方式：找出项目中回调嵌套最深的代码路径，从那里开始改写。利用 `Task` 和 `TaskGroup` 管理结构化并发。编译器会自动检查 actor 隔离，防止数据竞争。

### 3. 用 Object Capture 生成 3D 内容

如果你的 App 涉及 AR 体验、电商展示、室内设计或游戏开发，Object Capture 可以把 3D 资产制作成本降到几乎为零。

开始方式：用 iPhone 围绕物体拍摄多角度照片（建议 30-200 张），导入 macOS 上的 `PhotogrammetrySession` API 生成 USDZ 模型。然后用 RealityKit 或 AR Quick Look 在 App 中展示。

### 4. 适配 Focus Mode 的通知策略

iOS 15 的 Focus Mode 意味着用户在特定场景下可能完全收不到你的通知。开发者需要思考：哪些通知是"时间敏感的"（time-sensitive），哪些可以等待。

开始方式：为通知设置正确的 `interruptionLevel`（passive、active、time-sensitive、critical）。time-sensitive 级别可以在 Focus Mode 下穿透静默。不要滥用这个级别——系统会监控使用频率。

### 5. 尝试 Xcode Cloud 优化 CI 流程

如果你的团队还在本地机器上手动构建和测试，或者 CI 配置维护成本高，Xcode Cloud 提供了一个零配置的选择。

开始方式：在 Xcode 中创建 Workflow，选择触发条件（每次提交、PR 等），配置测试方案和分发目标。构建在云端并行执行，测试覆盖所有 Apple 平台模拟器。
