## Highlight

> tvOS 27 终于把 iOS 上成熟的 Dynamic Type 搬到了 Apple TV 上。用户可以在设置里选择从 Large 到 Accessibility XXXL 的字体大小，标准 UIKit 和 SwiftUI 组件会自动适配，但你的自定义布局必须跟着调整。好消息是：适配逻辑和 iOS 完全一致，你在 iOS 上的经验可以直接复用。

## 核心内容

### 1. 这场演讲解决什么问题

tvOS 开发者长期习惯了"大屏 = 大固定字号"的思维。但 tvOS 27 引入了 Dynamic Type 后，这种硬编码的做法会导致：

- 文字被截断（truncation）
- UI 元素被裁剪（clipping）
- 布局在字体放大后完全崩坏

而且 Apple 明确表态：光把字放大导致截断是半成品，必须配合空间重构。支持 Larger Text 的 App 还能在 App Store 的 Accessibility Nutrition Labels 里获得标识，触达更多有需求的用户。

### 2. 采用标准文本样式

**SwiftUI**：用语义化字体替代硬编码

```swift
// 错误：硬编码字号
Text("Signup information")
    .font(.system(size: 14))
    .frame(width: 300, alignment: .leading)

// 正确：语义化字体 + 弹性约束
Text("Signup information")
    .font(.caption.bold())
    .lineLimit(1)
    .foregroundStyle(.secondary)
    .frame(maxWidth: .infinity, alignment: .leading)
```

**UIKit**：用 `preferredFont` + `adjustsFontForContentSizeCategory`

```swift
// 错误：硬编码
titleLabel.font = UIFont.boldSystemFont(ofSize: 28)

// 正确：Dynamic Type
titleLabel.font = UIFont.preferredFont(forTextStyle: .headline)
titleLabel.adjustsFontForContentSizeCategory = true
```

### 3. 响应式布局：根据字体大小调整结构

SwiftUI 用 `@Environment(\.dynamicTypeSize)` 读取当前字体级别：

```swift
struct MovieShelf: View {
    @Environment(\.dynamicTypeSize) private var dynamicTypeSize
    var body: some View {
        ScrollView(.horizontal) {
            LazyHStack(spacing: 40) {
                ForEach(Asset.allCases) { asset in
                    Button {
                        // ...
                    } label: {
                        asset.portraitImage
                        Text(asset.title)
                    }
                    .containerRelativeFrame(
                        .horizontal,
                        count: dynamicTypeSize.isAccessibilitySize ? 4 : 6,
                        spacing: 40)
                }
            }
        }
    }
}
```

关键点：
- 标准字体时显示 6 列
- 辅助功能大字体时自动减少到 4 列，给每列更多空间

### 4. 条件布局切换：AnyLayout

当字体变大时，把横向布局切换为纵向：

```swift
struct CardContentView: View {
    @Environment(\.dynamicTypeSize) private var dynamicTypeSize
    var asset: Asset

    var body: some View {
        let layout = dynamicTypeSize.isAccessibilitySize ?
            AnyLayout(VStackLayout(alignment: .leading, spacing: 10)) :
            AnyLayout(HStackLayout(alignment: .top, spacing: 10))
        layout {
            asset.portraitImage
            Text(asset.title)
            Text(asset.description)
        }
    }
}
```

### 5. UIKit 的 Trait Changes 响应

```swift
class AdaptiveLayoutViewController: UIViewController {
    let stackView = UIStackView()

    override func viewDidLoad() {
        super.viewDidLoad()
        updateLayout()

        let sizeTraits: [UITrait] = [UITraitPreferredContentSizeCategory.self]
        registerForTraitChanges(sizeTraits, action: #selector(updateLayout))
    }

    private func updateLayout() {
        if traitCollection.preferredContentSizeCategory.isAccessibilityCategory {
            stackView.axis = .vertical
        } else {
            stackView.axis = .horizontal
        }
    }
}
```

## 最佳实践

- **全局清洗硬编码**：在已有项目中，用正则搜索 `.system(size:` 和 `UIFont.systemFont(ofSize:`，全部替换为 `.font(.body)` 或 `UIFont.preferredFont(forTextStyle: .body)`。同时搜索固定的 `.frame(width: 300)`，改为 `.frame(maxWidth: .infinity)` 让内容自己撑开
- **焦点测试是灵魂**：tvOS 适配大字体后，一定要用 Siri Remote 实际按一按。布局切换时如果焦点跳到了屏幕边缘或者消失，说明你的视图层级在切换时被销毁了，老老实实换回 `AnyLayout`
- **跑马灯兜底**：如果某些电影标题实在太长，大字体下无论怎么调布局都会截断，别硬塞。Apple 建议实现自定义的 Marquee 效果，让文字在焦点停留时滚动显示
- **App Store 标识**：适配完成后，记得在 App Store Connect 里勾选 Accessibility Nutrition Labels 的 Larger Text 支持，这是触达有需求用户的有效方式
