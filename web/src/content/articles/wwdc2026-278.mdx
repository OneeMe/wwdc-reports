## Highlight

> iOS 27 让 iPhone app 变成了可以随意拖拽改变大小的窗口——在 iPad 上、在 Mac 的 iPhone Mirroring 里都一样。这场演讲告诉你怎么把「面向特定设备写死布局」的老代码，改成用 Size Classes 和 Trait Collections 动态适配的现代化 UIKit App。

---

## 核心内容

### 1. 这场演讲解决什么问题

以前写 UIKit App，很多开发者习惯这样干：

- 用 `UIScreen.main.bounds` 获取屏幕尺寸算布局
- 用 `UIDevice.current.userInterfaceIdiom` 判断是 iPhone 还是 iPad
- 用 `interfaceOrientation` 判断横竖屏
- 还没迁移到 `UIScene` 生命周期

iOS 27 彻底打破了这些假设。iPhone app 在 Mac 上可以自由 resize，在 iPad 上也不再是固定比例。继续用老办法，布局会错得一塌糊涂。

### 2. 迁移到 Scene 生命周期

`UIScene` 生命周期是自适应 App 的基础。iOS 27 SDK 下，没迁移的 App 直接无法启动。

```swift
// 检查你的 AppDelegate 是否有 scene configuration
func application(
    _ application: UIApplication,
    configurationForConnecting connectingSceneSession: UISceneSession,
    options: UIScene.ConnectionOptions
) -> UISceneConfiguration {
    return UISceneConfiguration(name: "Default Configuration", sessionRole: connectingSceneSession.role)
}
```

如果还没迁移，参考 WWDC25 的 "Make your UIKit app more flexible" 和文档 "Transitioning to the UIKit scene-based life cycle"。

### 3. 移除 UIScreen.main 引用

`UIScreen.main` 在多屏幕环境下会返回错误信息。正确的做法是从 window scene 动态获取：

```swift
// 用 window scene 获取当前屏幕
let screen = window?.windowScene?.screen

// 需要 screen 的方法，传入本地引用
func generateThumbnail(_ image: UIImage, screen: UIScreen) -> UIImage {
    // 用传入的 screen 替代 UIScreen.main
}
```

**用 trait collection 替代 screen scale：**

```swift
override func layoutSubviews() {
    super.layoutSubviews()

    // 用 traitCollection.displayScale 替代 screen.scale
    let displayScale = traitCollection.displayScale
    // ...
}
```

**监听 trait 变化：**

```swift
// 自动 trait tracking：系统会检测 layoutSubviews 等方法中使用的 trait
// 当对应 trait 变化时自动重新调用这些方法

// 手动注册 trait 变化（自动 tracking 覆盖不到的地方）
let displayScaleTrait: [UITrait] = [UITraitDisplayScale.self]
registerForTraitChanges(displayScaleTrait) {
    (view: GalleryView, previousTraitCollection: UITraitCollection) in
    view.cache.invalidate()
}
```

**监听 effective geometry 变化：**

```swift
// UIWindowSceneDelegate
func windowScene(
    _ windowScene: UIWindowScene,
    didUpdateEffectiveGeometry previousEffectiveGeometry: UIWindowScene.Geometry
) {
    let geometry = windowScene.effectiveGeometry
    let availableSpace = geometry.coordinateSpace.bounds
    // 根据可用空间重新布局
}
```

**用 view bounds 检查可用空间：**

```swift
override func viewDidLayoutSubviews() {
    super.viewDidLayoutSubviews()

    let availableSpace = view.bounds.size
    // 根据 view 的实际大小调整布局
}
```

关键点：

- `traitCollection.displayScale` 替代 `UIScreen.main.scale`，视图不在可见层级时也能提供合理的 fallback
- `registerForTraitChanges` 用于自动 trait tracking 覆盖不到的场景，比如需要手动失效缓存
- `effectiveGeometry` 在窗口大小变化时回调，比监听屏幕旋转更通用

### 4. Tab Bar 和 Navigation Bar 的新 API

**Sidebar 布局（iPad/Mac）：**

```swift
// 让 tab bar 以 sidebar 形式展示
tabBarController.sidebar.preferredPlacement = .sidebar

// 检查 sidebar 是否可用
if tabBarController.sidebar.isAvailable {
    // 可以切换到 sidebar 模式
}
```

**Prominent Tab：**

```swift
// 设置一个突出的 tab（比如购物车的购物车图标）
let tabs = [/* ... */]
let tabBarController = UITabBarController(tabs: tabs)
tabBarController.prominentTabIdentifier = "cart"
```

**Navigation Bar 最小化行为：**

```swift
override init(nibName nibNameOrNil: String?, bundle nibBundleOrNil: Bundle?) {
    super.init(nibName: nibNameOrNil, bundle: nibBundleOrNil)

    navigationItem.barMinimizationBehavior = .always
    navigationItem.barMinimizationSafeAreaAdjustment = .never
}
```

### 5. Core Motion 和 Core Location 的坐标系自动适配

以前处理设备运动数据时，需要根据屏幕方向手动旋转坐标系。现在直接把 View 赋值给 motion manager，系统自动处理：

```swift
override func viewDidLoad() {
    super.viewDidLoad()

    motionManager.deviceMotionBody = view
    locationManager.headingBody = view
}
```

关键点：

- `deviceMotionBody` 和 `headingBody` 接收一个 `UIView`，系统会自动把物理坐标转换到该 view 的坐标系
- 不再需要自己写三角函数根据屏幕方向旋转坐标

### 6. 用 AI Agent 自动现代化代码

Xcode 27 提供了 App Modernization skill，可以自动帮你完成很多迁移工作：

```sh
# 导出 Xcode skill 供其他工具使用
xcrun agent skills export
```

这个 skill 可以：
- 把 `UIScreen.main` 替换为正确的获取方式
- 把 `interfaceOrientation` 检查替换为 Size Classes
- 把 `UIDevice.current.userInterfaceIdiom` 替换为 trait collection 检查

## 最佳实践

- **迁移优先级**：先确认 `UIScene` 生命周期（不迁移 iOS 27 无法启动），然后全局搜索替换 `UIScreen.main`、`UIDevice.current.userInterfaceIdiom`、`interfaceOrientation`
- **布局思维转变**：忘掉"这是 iPhone 还是 iPad"，脑子里只保留"Compact 还是 Regular"。用 `horizontalSizeClass` 和 `verticalSizeClass` 做布局决策
- **测试覆盖**：在可调整大小的 Simulator 中测试各种尺寸比例，特别是 iPhone Mirroring 在 Mac 上的各种窗口大小
- **AI Agent 辅助**：先用 Xcode 27 的 App Modernization skill 自动处理机械替换，再人工审查边界情况
- **CoreMotion 迁移**：把手动坐标旋转代码替换为 `deviceMotionBody`/`headingBody`，减少错误和代码量
