## 概述

本 session 介绍了 Apple Music API 和 MusicKit 框架的核心功能，展示如何将 Apple Music 的强大功能集成到你的应用中。无论你是构建 Web 服务还是 Android 应用，都可以通过这些工具为用户提供丰富的音乐体验。

## Apple Music API 基础

Apple Music API 是一套 RESTful API，允许你访问 Apple Music 的海量内容库。通过这个 API，你可以：

- **搜索和发现内容**：查找歌曲、专辑、艺术家和播放列表
- **获取资源详情**：访问专辑、艺术家、歌曲的详细信息
- **个性化推荐**：为订阅用户提供基于其喜好的推荐内容
- **播放列表管理**：创建和管理用户的播放列表

## MusicKit 框架

MusicKit 是 Apple 提供的客户端框架，支持多个平台：

- **iOS**：原生 iOS 应用集成
- **Android**：Android 应用支持
- **Web**：基于 JavaScript 的 Web 集成

### 主要功能

1. **身份验证和授权**：处理用户订阅状态和权限
2. **内容搜索**：快速搜索 Apple Music 目录
3. **播放控制**：控制音乐播放、暂停、跳转
4. **目录浏览**：浏览排行榜、新发布内容等

## 集成步骤

### 1. 配置开发者账号

首先需要在 [Apple Developer](https://developer.apple.com/) 网站配置你的应用：

- 创建 App ID
- 启用 MusicKit capability
- 配置 JWT 密钥用于服务器端认证

### 2. 选择合适的 SDK

根据你的目标平台选择对应的 SDK：

```bash
# iOS - 通过 CocoaPods 或 Swift Package Manager
pod 'MusicKit'

# Android - 通过 Gradle
implementation 'com.apple.android.sdk:musickit:1.0.0'

# Web - 通过 npm
npm install musickit
```

### 3. 基本集成

初始化 MusicKit 并配置开发者令牌：

```javascript
// Web 示例
const musicKit = await MusicKit.configure({
  developerToken: 'YOUR_DEVELOPER_TOKEN',
  app: {
    name: 'Your App Name',
    build: '1.0.0'
  }
});
```

## 核心功能实现

### 搜索音乐

```javascript
// 搜索歌曲、专辑、艺术家
const searchResults = await musicKit.api.music(
  `/v1/catalog/{storefront}/search`,
  {
    term: 'Swift',
    types: ['songs', 'albums', 'artists'],
    limit: 20
  }
);
```

### 播放控制

```javascript
// 播放歌曲
await musicKit.player.setQueue({ song: 'song-id' });
await musicKit.player.play();

// 暂停
await musicKit.player.pause();

// 跳转到指定时间
await musicKit.player.seekToTime(30);
```

### 个性化推荐

为订阅用户提供个性化内容：

```javascript
// 获取用户偏好推荐
const recommendations = await musicKit.api.music(
  `/v1/me/recommendations`
);
```

## 最佳实践

### 1. 处理订阅状态

始终检查用户的订阅状态，只有订阅用户才能播放完整曲目：

```javascript
const isSubscribed = musicKit.musicSubscriptionStatus === 'subscribed';
if (!isSubscribed) {
  // 显示订阅提示或提供预览版本
}
```

### 2. 错误处理

实现完善的错误处理机制：

```javascript
try {
  const results = await musicKit.api.music(`/v1/catalog/{storefront}/charts`);
} catch (error) {
  if (error.code === 401) {
    // 处理授权错误
  } else if (error.code === 429) {
    // 处理速率限制
  }
}
```

### 3. 缓存策略

合理缓存 API 响应以减少请求次数：

- 缓存不常变化的内容（如专辑信息）
- 对实时数据（如播放进度）不使用缓存
- 实现 Cache-Control 头策略

## 跨平台注意事项

### Web 集成

- 确保你的网站支持 HTTPS
- 处理浏览器的自动播放策略
- 提供备用方案给不支持 Web Audio API 的浏览器

### Android 集成

- 正确配置 Android Manifest 权限
- 处理 Android 生命周期事件
- 处理网络状态变化
