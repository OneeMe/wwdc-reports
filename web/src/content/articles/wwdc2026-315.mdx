## Highlight

> 原生 `select` 元素终于能完全自定义样式了。`appearance: base-select` 配合新的伪元素（`::picker-icon`、`::picker(select)`、`::checkmark`），让你可以用纯 CSS 把下拉菜单融入设计系统。而且 `option` 里可以塞图片和富文本，无障碍和键盘导航完全保留。

---

## 核心内容

### 1. 这场演讲解决什么问题

前端开发者的老痛点：想自定义下拉菜单样式，要么用原生 `select` 被系统样式限制，要么用 `div` 模拟一套，自己处理键盘导航、ARIA 标签、屏幕阅读器兼容。

Customizable Select 解决了这个问题：保留原生 `select` 的无障碍能力和语义，同时开放完整的样式控制。

Safari 27 和 Chrome 135 开始支持。

### 2. 基础用法：从原生到自定义

原生 `select`：

```html
<label for="sort-select">Sort by</label>
<select id="sort-select">
    <option>Newest</option>
    <option>Oldest</option>
</select>
```

加上 `appearance: base-select` 获得可定制基础：

```css
body {
    font-family: Gill Sans, sans-serif;
}

select {
    appearance: base-select;
    background-color: var(--green-10);
    border: none;
    padding: 0.6em 1em;
}

/* 打开状态 */
select:open {
    background-color: var(--green-100);
    color: white;
}
```

关键点：

- `appearance: base-select` 是第一步，它提供了一个最小化的样式基础
- 继承父元素的 `font-family`，与页面其他文字保持一致
- `:open` 伪类在菜单打开时生效

### 3. 自定义下拉箭头

```css
select:open::picker-icon {
    content: url(icons/arrow-white.svg);
}
```

`::picker-icon` 选择器控制下拉箭头图标，可以替换为自定义 SVG 或字体图标。

### 4. 自定义下拉面板

```css
::picker(select) {
    appearance: base-select;
    padding: 4px;
    margin-top: 0.5em;
    border: 1px solid rgba(0,0,0,0.2);
    border-radius: 9px;
    box-shadow: 0 4px 20px rgba(0,0,0,0.2);
}
```

`::picker(select)` 选择下拉面板本身，可以设置边距、边框、阴影等。

### 5. 自定义选项样式

```css
option:checked {
    font-weight: 600;
}

option:not(:checked) {
    color: #777;
}

option::checkmark {
    content: url(checkmark.svg);
    width: 0.65em;
}
```

`::checkmark` 控制选中标记，可以隐藏或替换为自定义图标。

### 6. 富内容选项

`option` 里可以包含图片和其他 HTML 元素：

```html
<select>
    <option value="flower">
        <img src="flowers.svg" alt="">
        <span class="text">Flowers</span>
    </option>
    <option value="buildings">
        <img src="icons/buildings.svg" alt="">
        <span class="text">Buildings</span>
    </option>
</select>
```

### 7. 下拉面板用 Grid 布局

```css
::picker(select) {
    display: grid;
    grid-template: 1fr 1fr / 1fr 1fr 1fr;
    gap: 1rem;
}
```

下拉面板可以用任意 CSS 布局，比如网格布局展示图片选项。

### 8. 自定义选中内容展示

用 `` `selectedcontent` `` 元素控制按钮上显示的选中项内容：

```html
<select>
    <button>
        <selectedcontent><\/selectedcontent>
    </button>
    <option>
        <img src="icons/all.svg" alt="">
        <span class="text">Everything</span>
    </option>
    <option>
        <img src="icons/buildings.svg" alt="">
        <span class="text">Buildings</span>
    </option>
</select>
```

`` `selectedcontent` `` 会自动镜像当前选中 `option` 的内容到按钮上。

## 最佳实践

- **渐进替换**：先从样式问题最多的简单 `select` 开始改造，逐步替换 `div` 模拟的下拉菜单
- **保留键盘导航**：不要拦截上下键和回车键，让浏览器处理无障碍逻辑
- **给图片加 `alt` 属性**：即使只是装饰性图片，也要考虑屏幕阅读器
- **测试层叠上下文**：早期版本在处理带 `box-shadow` 的下拉面板遮挡时可能有 bug
- **用 `:open` 管理状态**：代替 JS 监听展开/收起事件
