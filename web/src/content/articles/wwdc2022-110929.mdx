## Highlight

> WWDC22 第一天发布了 iOS 16 锁屏自定义、M2 芯片、macOS Ventura 台前调度、Metal 3、WeatherKit、Swift Regex 和 Xcode Cloud 全面开放等核心内容。

## 核心内容

### iOS 16：锁屏重新定义

iOS 16 最大的变化是锁屏。用户可以选择字体、颜色、小组件来个性化 iPhone 锁屏界面。这是 iPhone 个性化程度最高的一次升级。

Focus（专注模式）也升级了，支持 Personal Focus，帮用户在工作和生活之间建立边界。信息 App 支持编辑已发送消息和撤回，SharePlay 集成到信息中，可以一边聊天一边看电影。

照片方面，iOS 16 引入了触控抠图功能：长按图片中的主体，系统会自动分离背景，直接分享。iCloud 共享图库让家庭成员之间的照片分享变得更简单。（[00:12](https://developer.apple.com/videos/play/wwdc2022/110929/?time=12)）

### macOS Ventura：台前调度

macOS 的新版本叫 Ventura。核心新功能是 Stage Manager（台前调度），窗口管理方式发生了改变。当前使用的窗口放在屏幕中央，其他窗口缩略排列在左侧，点击即可切换。

Spotlight 增强了图片搜索能力。邮件支持定时发送和撤回发送。Continuity Camera 让用户可以把 iPhone 当作 Mac 的网络摄像头使用，支持人物居中、摄影室灯光等效果。（[01:35](https://developer.apple.com/videos/play/wwdc2022/110929/?time=95)）

### iPadOS 16：首次支持多窗口重叠

iPadOS 16 首次支持多窗口重叠显示，同样引入了 Stage Manager。协作功能跨 App 和跨设备增强，今年晚些时候还会推出一个实时协作的新 App。（[01:59](https://developer.apple.com/videos/play/wwdc2022/110929/?time=119)）

### M2 芯片与新款 Mac

M2 芯片正式发布，采用第二代 5nm 工艺。搭载 M2 的新款 MacBook Air 采用了全新的外观设计，更薄更轻。13 英寸 MacBook Pro 也更新了 M2 版本。（[01:19](https://developer.apple.com/videos/play/wwdc2022/110929/?time=79)）

### 开发者技术更新

开发者层面的核心更新包括：（[02:15](https://developer.apple.com/videos/play/wwdc2022/110929/?time=135)）

- **WeatherKit**：开发者可以接入 Apple 的天气数据
- **Metal 3**：游戏开发能力大幅提升
- **SwiftUI**：更强大更灵活的新 API
- **Swift Charts**：全新的图表框架
- **Swift Regex**：正则表达式正式加入标准库
- **Xcode Cloud**：向所有开发者开放

### Apple Watch 新功能

Apple Watch 新增心率区间等训练视图，支持用药提醒。新表盘包括 Astronomy、Lunar、Playtime、Metropolitan 和 Buddy。（[00:59](https://developer.apple.com/videos/play/wwdc2022/110929/?time=59)）

### 其他更新

- Maps 支持最多 15 个途经点的路线规划
- 新一代 CarPlay 预览，深度整合车辆仪表盘
- Apple Design Awards 揭晓 12 位获奖者

## 详细内容

### 开发者应该关注的技术线

Day 1 的发布可以按优先级分类：

**立刻上手**：
- Swift Regex：字符串处理不再需要 NSRegularExpression
- Swift Charts：数据可视化有了原生方案
- WeatherKit：天气数据 API 直接调用

**持续关注**：
- Metal 3：游戏和图形应用性能提升
- SwiftUI 新 API：布局系统更完善
- Xcode 14：编译速度提升，新特性支持

**长期规划**：
- Passkeys：替代密码的新认证方式
- Managed Device Attestation：设备安全验证

### 平台适配建议

iOS 16 的锁屏小组件是新的用户触点，App 应该考虑提供锁屏小组件。macOS Ventura 的台前调度改变了窗口管理习惯，Mac App 需要测试在这种模式下的表现。iPadOS 16 的多窗口支持意味着 iPad App 需要重新考虑窗口管理逻辑。

## 核心启发

- **锁屏小组件应用**：iOS 16 的锁屏小组件是一个全新的用户接触点。健身 App 可以显示实时心率，天气 App 显示当前温度，待办 App 显示下一个任务。入口 API 是 `WidgetKit` 的锁屏小组件配置。

- **WeatherKit 天气应用**：利用 Apple 官方天气数据构建精致的天气应用，无需自己维护气象数据源。可以结合 Swift Charts 展示温度趋势图。入口 API 是 `WeatherKit` 框架和 `Chart`。

- **Swift Regex 文本处理工具**：用 Swift Regex 构建日志分析、文本提取、格式验证等工具。正则表达式现在是 Swift 原生语法，类型安全且可读性更好。入口 API 是 `Regex` 和 `RegexBuilder`。

- **Continuity Camera 创意应用**：利用 iPhone 作为 Mac 摄像头的特性，开发需要高质量视频输入的 Mac 应用，比如直播工具、扫描应用、AR 预览工具。入口 API 是 `AVFoundation` 和 Continuity Camera 的自动集成。
