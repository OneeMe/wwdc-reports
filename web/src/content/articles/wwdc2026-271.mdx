## Highlight

> SwiftUI 的拖拽排序终于从"List 专属"变成了"任意容器通用"。`reorderContainer` + `reorderable` 组合让跨容器重排变得像写 `ForEach` 一样简单，`dragContainer` 支持批量拖拽多张卡片，`dragConfiguration` 让你精确控制是移动还是复制。纸牌游戏、看板、相册管理——这些以前需要桥接 UIKit 的复杂场景，现在纯 SwiftUI 就能搞定。

---

## 核心内容

### 1. 这场演讲解决什么问题

SwiftUI 之前的拖拽 API（`draggable` + `dropDestination`）有几个局限：

- 只能做简单的跨 App 拖拽，容器内的重排需要自己算坐标
- 不支持批量拖拽（一次拖多张图片/卡片）
- 无法自定义拖拽预览的外观
- 无法区分"移动"和"复制"操作
- 复杂布局（网格、多列看板）需要自己写状态机

今年的新 API 一次性解决了这些问题。

### 2. 基础 Reordering：单个容器内拖拽

最简单的用法，在 Preview 里就能试：

```swift
#Preview {
    @Previewable @State var cards = [
        CardValue(rank: .ace, suit: .clubs),
        CardValue(rank: .ace, suit: .diamonds),
        CardValue(rank: .ace, suit: .hearts),
        CardValue(rank: .ace, suit: .spades)
    ]

    HStack {
        ForEach(cards) { card in
            CardFaceView(card: card)
        }
        .reorderable()  // 让 ForEach 支持拖拽
    }
    .frame(maxWidth: .infinity, maxHeight: .infinity)
    .reorderContainer(for: CardValue.self) { difference in
        cards.apply(difference: difference)  // 更新数据
    }
    .padding()
    .background(.green.gradient)
}
```

关键点：

- `.reorderable()` 加在 `ForEach` 上，标记哪些视图可以拖拽
- `.reorderContainer()` 加在父容器上，接收拖拽完成后的差分数据
- `difference` 包含源位置和目标位置，应用到数据模型即可

### 3. 跨容器 Reordering：纸牌游戏的七列牌堆

Solitaire 的核心需求是把牌在不同牌堆之间移动。用 `collectionID` 标识每个容器：

```swift
struct GameView: View {
    var game: Game

    var body: some View {
        // ...
        HStack(alignment: .top, spacing: spacing) {
            ForEach(0..<7) { index in
                PileView(game: game, index: index)
                    .frame(width: cardWidth)
            }
        }
        .frame(maxHeight: .infinity, alignment: .top)
        .reorderContainer(for: CardValue.self, in: Card.Group.self) { difference in
            game.moveCards(difference: difference)  // 跨牌堆移动
        }
    }
}

struct PileView: View {
    var game: Game
    var index: Int
    @Query var cards: [Card]

    var body: some View {
        ZStack(alignment: .topLeading) {
            CardPlaceholderView()
            PileLayout {
                ForEach(cards[..<firstFaceUpIndex]) { card in
                    CardView(card: card)
                }
                ForEach(cards[index...], id: \.value) { card in
                    CardView(card: card)
                }
                .reorderable(collectionID: Card.Group.pile(index))  // 标识所属牌堆
            }
        }
    }
}
```

关键点：

- `reorderContainer(for:in:)` 的第二个参数是 collection 类型，用于区分不同容器
- `.reorderable(collectionID:)` 标记每个元素属于哪个容器
- 拖拽跨容器时，`difference` 会自动处理源容器和目标容器的 ID

### 4. 批量拖拽：一次拖多张牌

```swift
struct GameView: View {
    // ...
    .reorderContainer(for: CardValue.self, in: Card.Group.self) { difference in
        game.moveCards(difference: difference)
    }
    .dragContainer(for: CardValue.self) { cardID in
        game.cardStack(startingAt: cardID)  // 返回要拖拽的所有卡片
    }
    .dragPreviewsFormation(.stack)  // 拖拽时显示为堆叠效果
}
```

- `.dragContainer()` 自定义拖拽时要移动哪些元素
- `.dragPreviewsFormation(.stack)` 让多张卡片在拖拽时显示为堆叠
- `.dropPreviewsFormation(.stack)` 让目标位置也显示堆叠效果

### 5. 自定义拖拽行为：移动 vs 复制

```swift
struct RemainderView: View {
    @Query var cards: [Card]
    var game: Game

    var body: some View {
        // ...
        ZStack {
            CardPlaceholderView()
            if let currentCard {
                CardFaceView(card: currentCard.value)
                    .draggable(containerItemID: currentCard.value)
            }
        }
        .dragContainer(for: CardValue.self) { cardID in
            [cardID]
        }
        .dragConfiguration(DragConfiguration(allowMove: true))  // 允许移动
    }
}
```

配合 Drop Destination 控制落点：

```swift
.dropDestination(for: CardValue.self) { newCards, session in
    if let destination = session.reorderDestination(
        for: CardValue.self, in: Card.Group.self) {
        game.insertCards(newCards, to: destination)
    }
}
.dropConfiguration { session in
    // 计算落在哪个牌堆
    let alignedX = session.location.x - 0.5 * spacing
    let pile = Int(alignedX / (cardWidth + spacing))
    let destination = ReorderDifference<CardValue, Card.Group>
        .Destination(position: .end, collectionID: .pile(pile))

    // 检查是否允许移动
    let allowed = session.suggestedOperations.contains(.move)
        && game.validateMove(session: session, destination: destination)
    let operation: DropOperation = allowed ? .move : .forbidden

    return DropConfiguration(operation: operation, destination: destination)
}
```

关键点：

- `DragConfiguration(allowMove: true)` 明确这是移动操作
- `session.suggestedOperations.contains(.move)` 检查当前手势是否表示移动
- `DropOperation.forbidden` 在不允许落点时显示禁止图标

## 最佳实践

- **单个 List 内移动继续用 `.onMove`**：简单场景不需要迁移到新 API
- **网格/看板/复杂布局用 `reorderContainer`**：能省掉 30% 以上的状态管理代码
- **数据模型必须先实现 `Identifiable`**：每个可拖拽元素需要全局唯一 ID
- **条件禁用拖拽用 `isEnabled` 参数**：不要在 `reorderable` 外包 `if`，会破坏动画
- **保持视图树结构稳定**：拖拽过程中不要动态增删视图层级
