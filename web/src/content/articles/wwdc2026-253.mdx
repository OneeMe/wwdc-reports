## Highlight

> Music Understanding 框架让你用几行代码就能分析音乐的调性、节奏、结构、速度、乐器活动和响度，全部在设备端完成，不需要信号处理或机器学习背景。

---

## 核心内容

### 1. 这场演讲解决什么问题

想在 App 里做音乐分析？以前你要么自己啃 DSP 算法，要么把音频传到服务器处理。Music Understanding 框架把这一切简化了——你只需要给一个 `AVAsset`，它返回六个维度的分析结果。

Final Cut Pro 团队已经在用这个框架实现节拍检测和自动蒙太奇功能。

### 2. 六个分析维度

框架提供六个核心分析维度：

| 维度 | 说明 | 用途 |
|------|------|------|
| **Key** | 调性（如 C major、A minor） | 音乐分类、DJ 混音 |
| **Rhythm** | 节拍、小节、BPM | 节拍器、舞蹈游戏 |
| **Structure** | 段落结构（intro、verse、chorus） | 视频剪辑对齐 |
| **Pace** | 速度感（不同部分快慢变化） | 自动蒙太奇 |
| **Instrument Activity** | 乐器活动检测 | 音乐可视化 |
| **Loudness** | 响度分析 | 音频均衡 |

### 3. 基础用法

初始化 session 并分析：

```swift
import MusicUnderstanding
import AVFoundation

// 从文件导入音频
.fileImporter(isPresented: $isPresented, allowedContentTypes: [.audio]) { result in
    switch result {
    case .success(let url):
        let asset = AVURLAsset(
            url: url,
            options: [AVURLAssetPreferPreciseDurationAndTimingKey: true]
        )
        let session = try await MusicUnderstandingSession(asset: asset)
        let results = try await session.analyze()
    }
}
```

### 4. 分析结果结构

`SessionResult` 包含所有分析结果：

```swift
public struct SessionResult: Codable, Sendable {
    public let instrumentActivity: InstrumentActivityResult?
    public let key: KeyResult?
    public let loudness: LoudnessResult?
    public let pace: PaceResult?
    public let rhythm: RhythmResult?
    public let structure: StructureResult?
}
```

结果使用两种时间容器：

- **`TimedValue<Value>`**：在特定时间点的值
- **`RangedValue<Value>`**：在某个时间范围内的值

### 5. 调性分析

```swift
public struct KeyResult: Codable, Sendable {
    public let ranges: [MusicUnderstandingSession.RangedValue<KeySignature>]
}

public struct KeySignature: Codable, Hashable, Sendable {
    public let tonic: Tonic      // C, D, E, F, G, A, B 等
    public let mode: Mode        // major 或 minor
}
```

### 6. 节奏分析

```swift
public struct RhythmResult: Codable, Sendable {
    public let beats: [CMTime]       // 每个节拍的时间点
    public let bars: [CMTime]        // 每个小节的时间点
    public let beatsPerMinute: Float? // BPM
}
```

### 7. 结构分析

```swift
public struct StructureResult: Codable, Sendable {
    public let sections: [CMTimeRange]  // 大段落（chorus、verse）
    public let segments: [CMTimeRange]  // 中段
    public let phrases: [CMTimeRange]   // 乐句
}
```

### 8. 乐器活动检测

```swift
public struct InstrumentActivityResult: Codable, Sendable {
    public let ranges: [Instrument: [CMTimeRange]]
    public let activity: [Instrument: [MusicUnderstandingSession.TimedValue<Float>]]
}
```

检测鼓、贝斯、人声等乐器的活动时间。

### 9. 响度分析

```swift
public struct LoudnessResult: Codable, Sendable {
    public let integrated: MusicUnderstandingSession.TimedValue<Float>
    public let momentary: [MusicUnderstandingSession.TimedValue<Float>]
    public let shortTerm: [MusicUnderstandingSession.TimedValue<Float>]
    public let peak: MusicUnderstandingSession.TimedValue<Float>
}
```

### 10. 流式 API

对于实时场景（如音频可视化），可以使用流式 API：

```swift
let audioProvider = AudioProvider()
let session = MusicUnderstandingSession(audioProvider: audioProvider)

await withThrowingTaskGroup(of: Void.self) { group in
    group.addTask {
        for try await result in await session.loudnessResults {
            updateAudioLevel(result.momentary.value)
        }
    }

    group.addTask {
        try await session.analyze(for: [.loudness])
    }
}
```

自定义 `AudioProvider`：

```swift
struct AudioProvider: AsyncSequence, AsyncIteratorProtocol {
    func makeAsyncIterator() -> Self {
        return self
    }

    mutating func next() async -> AVReadOnlyAudioPCMBuffer? {
        // 返回下一个音频 buffer，nil 表示结束
    }
}
```

### 11. 指定分析类型

默认分析所有维度。为提升性能，可以只分析需要的类型：

```swift
let results = try await session.analyze(for: [.rhythm, .structure])
```

### 12. 导出结果

结果可以编码为 JSON：

```swift
let encoder = JSONEncoder()
let jsonData = try encoder.encode(results)
```

---

## 最佳实践

- **指定分析类型提升性能**：如果只需要节奏信息，用 `analyze(for: [.rhythm])` 避免不必要的计算
- **使用流式 API 做实时可视化**：响度分析配合流式 API 可以实现实时音频电平显示
- **后台线程执行分析**：音频分析是 CPU 密集型任务，不要在主线程执行
- **利用时间容器做可视化**：`TimedValue` 和 `RangedValue` 可以直接映射到播放进度条
- **缓存分析结果**：对于同一首歌曲，分析结果可以缓存避免重复计算
