## Highlight

> WWDC25 的欢迎视频是一份全年 Session 的索引：100+ 场内容覆盖新设计 Liquid Glass、Apple Intelligence on-device 大模型、Xcode、Swift、SwiftUI、Metal 与 Gaming，并新增了文字摘要、Xcode 一键拷贝代码与在线 Group Lab 三项观看辅助。

## 核心内容

每年 WWDC 一开场，开发者面对的第一个问题都是：100+ 场 Session 怎么挑、按什么顺序看。漏掉关键 Session 就会错过整年最重要的 API 改动；按 ID 顺序硬啃又会被淹没在细节里。这条 2 分半的欢迎视频，定位就是"今年的 Session 路线图"。

视频开篇就把全年内容压成一句话——「new design、Apple Intelligence、Xcode、Swift、SwiftUI、Metal、Gaming」（[00:06](https://developer.apple.com/videos/play/wwdc2025/364/?time=6)）。随后用三类 Session 的标签把内容分层：Code-along（[00:22](https://developer.apple.com/videos/play/wwdc2025/364/?time=22)）跟着 Apple 工程师逐行写、Foundation（[00:29](https://developer.apple.com/videos/play/wwdc2025/364/?time=29)）补设计与技术基础、Platforms State of the Union（[00:39](https://developer.apple.com/videos/play/wwdc2025/364/?time=39)）拿到所有开发者公告的细节。两条主线被反复强调：一是 Liquid Glass，「broadest design update ever」（[00:48](https://developer.apple.com/videos/play/wwdc2025/364/?time=48)），把玻璃的光学质感和流体感合到一起；二是 on-device LLM，「any app can tap into the intelligence...available even when the user is offline」（[01:19](https://developer.apple.com/videos/play/wwdc2025/364/?time=79)），通过 Foundation Models 框架直接调用 Apple Intelligence 核心的端侧大模型。

视频后半段讲的是观看体验本身的升级。每个 Session 现在都有 written summary（[01:36](https://developer.apple.com/videos/play/wwdc2025/364/?time=96)），可以先扫摘要再决定是否看完整视频；developer.apple.com 上的代码块支持直接拷贝到 Xcode（[01:47](https://developer.apple.com/videos/play/wwdc2025/364/?time=107)）；除了一对一 Lab，今年新增了由 Apple Engineers 和 Designers 主持的 online group lab（[02:01](https://developer.apple.com/videos/play/wwdc2025/364/?time=121)），可提问、可投票、也可以单纯旁听。

## 详细内容

视频本身没有 API 代码，但它把今年 Session 的检索路径梳理成了一条清晰的工作流：

```text
1. 看 Platforms State of the Union（102）拿到全年 API 公告
2. 用每个 Session 的 written summary 快速筛选
3. 命中后看完整视频；代码可一键拷贝到 Xcode
4. 设计与技术基础回到 Foundation 类 Session
5. 想动手 → Code-along；想问问题 → online group lab 或 1:1 lab
6. 后续问题 → Apple Developer Forums
```

**关键点**：
- 第 1 步对应视频中「get the details on all the new developer announcements in the Platforms State of the Union」（[00:39](https://developer.apple.com/videos/play/wwdc2025/364/?time=39)），State of the Union 是技术公告的总入口。
- 第 2 步对应「each session now has a written summary that highlights the essentials」（[01:36](https://developer.apple.com/videos/play/wwdc2025/364/?time=96)），是今年新增的浏览能力。
- 第 3 步对应「you can copy code right from a session into Xcode」（[01:47](https://developer.apple.com/videos/play/wwdc2025/364/?time=107)），Session 页面的代码块带「Copy to Xcode」按钮。
- 第 4 步对应「Foundation sessions to brush up on key design and technical principles」（[00:29](https://developer.apple.com/videos/play/wwdc2025/364/?time=29)），适合在主题 Session 里遇到陌生概念时回看。
- 第 5 步覆盖「Code-along sessions to work line by line with an Apple engineer」（[00:22](https://developer.apple.com/videos/play/wwdc2025/364/?time=22)）和「online group labs hosted by Apple Engineers and Designers」（[02:01](https://developer.apple.com/videos/play/wwdc2025/364/?time=121)）。
- 第 6 步对应「find answers in the Apple Developer Forums」（[02:15](https://developer.apple.com/videos/play/wwdc2025/364/?time=135)），WWDC 周之后还能继续答疑的官方渠道。

视频还点名了两个本届的重头戏，作为优先级最高的 Session：

- **Liquid Glass**：「a new material that combines the optical qualities of glass with a sense of fluidity」（[01:00](https://developer.apple.com/videos/play/wwdc2025/364/?time=60)）。设计语言层面的统一更新，跨 app、跨平台。
- **Foundation Models framework**：「direct access to the on-device large language model at the core of Apple Intelligence」（[01:27](https://developer.apple.com/videos/play/wwdc2025/364/?time=87)）。强调 powerful、fast、privacy、offline 四个特性，是今年 AI 能力的入口框架。

## 核心启发

- **做什么**：用 Platforms State of the Union（Session 102）作为全年 API 阅读起点。
  - **为什么值得做**：欢迎视频明确把它定位为「all the new developer announcements」的总入口，比按 Session 编号扫一遍效率高得多。
  - **怎么开始**：先看 102 一遍，把里面提到的框架名记下来，再去 developer.apple.com 用框架名搜对应 Session。

- **做什么**：把 written summary 作为 Session 看不看的过滤器。
  - **为什么值得做**：100+ 场 Session 没法全看，summary 是 Apple 自己给的一句话定位，比标题更准。
  - **怎么开始**：在 developer.apple.com 的 Session 页面，先读 Overview 段落，确认是自己 app 用得上的 API 再投入完整视频时间。

- **做什么**：在 Xcode 26 上启用 Session 代码一键拷贝。
  - **为什么值得做**：今年所有 Session 页面的 code block 都带 Copy to Xcode，省掉手抄 sample 的时间，避免拼写错误。
  - **怎么开始**：在 Safari 打开 Session 页面，点代码块右上角按钮，Xcode 会自动接收并粘贴到当前文件。

- **做什么**：为具体适配问题申请 online group lab。
  - **为什么值得做**：1:1 lab 名额紧张；group lab 由 Apple 工程师主持，支持投票，看到别人问的同类问题也能受益。
  - **怎么开始**：在 Apple Developer App 里查看 lab 排期，挑与自己 app 技术栈相关的场次报名，提前把问题写好提交。
