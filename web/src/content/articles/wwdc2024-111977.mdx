## Highlight

> WWDC 2024 Platforms State of the Union 的五分钟回顾版，以 Apple Intelligence 为核心，浓缩了生成式模型集成、Xcode 16 AI 编码工具、SwiftUI 改进、Controls API 等关键公告。

## 核心内容

WWDC 每年发布大量新 API 和工具，开发者很难快速判断哪些方向与自己相关。Platforms State of the Union 完整版时长较长，许多开发者需要一个快速入口来筛选关注点。

这个五分钟回顾版把 WWDC 2024 最关键的公告压缩成一段精炼概览。最大的变化是 Apple Intelligence 的登场——Apple 的个人智能系统，将生成式模型带入 iOS、iPadOS 和 macOS，具备对用户个人上下文的感知能力。使用标准 UI 框架渲染文本框的 App 会自动获得 Writing Tools，开发者可以通过新的 TextView delegate API 自定义 Writing Tools 激活时 App 的行为（[00:47](https://developer.apple.com/videos/play/wwdc2024/111977/?time=47)）。Genmoji 提供全新沟通方式，Image Playground API 带来一致且易用的图像生成体验（[00:54](https://developer.apple.com/videos/play/wwdc2024/111977/?time=54)）。

工具链方面，Xcode 16 的代码补全引擎做了重大升级：使用项目符号做本地个性化推荐，不上传代码到云端，离线也能用（[02:14](https://developer.apple.com/videos/play/wwdc2024/111977/?time=134)）。Swift Assist 是运行在云端的更大模型，用自然语言描述需求就能生成代码，适合探索新框架和实验新想法（[02:40](https://developer.apple.com/videos/play/wwdc2024/111977/?time=160)）。Swift 迎来 10 周年，Apple 明确将其定位为 C++ 的继任者，强调安全性、速度和内建的 C/C++ 互操作性（[01:12](https://developer.apple.com/videos/play/wwdc2024/111977/?time=72)）。

## 详细内容

**Apple Intelligence 与 Writing Tools**（[00:24](https://developer.apple.com/videos/play/wwdc2024/111977/?time=24)）

Apple Intelligence 是本次 WWDC 的核心主题。它是一个个人智能系统，把生成式模型集成到 iOS、iPadOS 和 macOS 中，具备对用户个人上下文的感知能力。如果你的 App 使用标准 UI 框架渲染文本框，Writing Tools 会自动生效。通过新的 TextView delegate API，开发者可以自定义 Writing Tools 激活时 App 的行为（[00:47](https://developer.apple.com/videos/play/wwdc2024/111977/?time=47)）。Genmoji 为用户提供了全新的沟通方式，Image Playground API 提供一致、有趣且易用的体验（[00:54](https://developer.apple.com/videos/play/wwdc2024/111977/?time=54)）。

**Swift 与 SwiftUI**（[01:05](https://developer.apple.com/videos/play/wwdc2024/111977/?time=65)）

Swift 迎来 10 周年。Apple 的定位很明确：Swift 的安全性、速度和易用性，加上内建的 C 和 C++ 互操作性，使其成为 C++ 的继任者（[01:17](https://developer.apple.com/videos/play/wwdc2024/111977/?time=77)）。SwiftUI 今年的改进集中在三个方向：预览、定制化和互操作性。预览系统采用了新的动态链接架构，使用与 build-and-run 相同的构建产物（[01:45](https://developer.apple.com/videos/play/wwdc2024/111977/?time=105)）。SwiftUI 还增加了大量定制化选项来微调 App 的外观和手感，所有 UI 框架今年共享更多通用基础（[01:52](https://developer.apple.com/videos/play/wwdc2024/111977/?time=112)）。

**Xcode 16 与 AI 编码工具**（[02:02](https://developer.apple.com/videos/play/wwdc2024/111977/?time=122)）

Xcode 16 的代码补全引擎迎来重大升级：新的引擎能预测你需要的代码，使用项目符号做个性化推荐，在本地运行保护代码隐私，速度极快，离线也能工作（[02:14](https://developer.apple.com/videos/play/wwdc2024/111977/?time=134)）。Swift Assist 是一个运行在云端的更大模型，作为编码任务的伴侣，可以回答编码问题、帮助实验新 API，探索新框架和实验新想法只需一个请求（[02:40](https://developer.apple.com/videos/play/wwdc2024/111977/?time=160)）。Instruments 新增火焰图视图和 backtrace 单一视图，本地化目录也得到增强（[03:03](https://developer.apple.com/videos/play/wwdc2024/111977/?time=183)）。

**Controls API 与视觉更新**（[03:20](https://developer.apple.com/videos/play/wwdc2024/111977/?time=200)）

iOS 18 的 Controls API 让 App 的操作能直接出现在控制中心、锁屏和 Action Button 上。Control 可以切换设置、执行操作或深度链接到特定体验（[03:24](https://developer.apple.com/videos/play/wwdc2024/111977/?time=204)）。App 图标和 Widget 现在支持 Light、Dark、Tinted 三种外观，系统会智能处理以保持设计意图和可读性（[03:40](https://developer.apple.com/videos/play/wwdc2024/111977/?time=220)）。

**游戏与 visionOS**（[03:52](https://developer.apple.com/videos/play/wwdc2024/111977/?time=232)）

Metal 和 Apple Silicon 的持续进步让所有 Apple Silicon Mac、M 系列芯片的 iPad 甚至 iPhone 15 Pro 都能运行以前需要独显的游戏（[03:52](https://developer.apple.com/videos/play/wwdc2024/111977/?time=232)）。Game Porting Toolkit 2 改进了 AVX2 兼容性和光线追踪支持，可以评估更多 Windows 游戏（[04:09](https://developer.apple.com/videos/play/wwdc2024/111977/?time=249)）。visionOS 方面，djay 的例子展示了从 SwiftUI iPad App 重新编译到 visionOS 再扩展空间计算能力的路径（[04:21](https://developer.apple.com/videos/play/wwdc2024/111977/?time=261)）。

## 核心启发

- **做什么：集成 Writing Tools 自动适配**。如果你的 App 使用标准 UI 框架的文本框，Writing Tools 已经自动生效。下一步是用 TextView delegate API 精细控制 Writing Tools 激活时 App 的行为，比如在编辑器场景下限制改写范围、保持格式一致性。为什么值得做：零额外代码就能让用户获得系统级 AI 写作能力，delegate API 让你不丢失对内容的控制。怎么开始：查阅 session 10168 "Get started with Writing Tools"，确认你的文本视图是否走标准渲染路径，再逐步接入 delegate API。

- **做什么：用 Controls API 把核心功能暴露到系统级入口**。控制中心、锁屏、Action Button 是用户高频触达的位置。把 App 最常用的操作（切换状态、快速启动、深度链接）做成 Control，减少用户打开 App 的步骤。为什么值得做：用户不需要进入 App 就能完成关键操作，降低使用门槛。怎么开始：参阅 SwiftUI 新增的 Control 相关 API，从单一功能（如切换开关）开始验证，再扩展到更复杂的交互。

- **做什么：评估 Xcode 16 本地代码补全对日常开发效率的提升**。新的补全引擎使用项目符号做本地推荐，隐私友好、离线可用。在现有项目上实际使用一周，对比补全命中率和接受率。为什么值得做：每天使用的工具哪怕提升 10% 效率，长期累积效果也很大。怎么开始：升级到 Xcode 16，确保项目符号索引完整，在日常编码中观察补全建议的准确性，同时关注 Swift Assist 在探索新 API 时的表现。

- **做什么：为 App 图标和 Widget 准备 Dark / Tinted 变体**。iOS 18 会对所有 App 图标统一应用 Light、Dark、Tinted 处理。如果你希望保持品牌一致性而不是依赖系统自动转换，需要主动提供变体。为什么值得做：系统自动转换可能丢失设计细节，主动提供变体能确保在不同外观模式下都保持品牌辨识度。怎么开始：按 Apple 的图标规范制作 Dark 和 Tinted 版本，用 Xcode Asset Catalog 的变体槽位配置。
