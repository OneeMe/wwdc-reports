## Highlight

> Apple 为汽车厂商和车载系统开发者推出 CarPlay 视觉集成和基础设施升级方案，包括动态屏幕适配、圆角裁剪遮罩、UI 焦点转移、外观模式同步、无线连接简化、HEVC 视频编码支持，以及为下一代 CarPlay 做准备的基础设施要求。

## 核心内容

### 显示屏适配：从矩形到任意形状

现代汽车的显示屏形状各异。有的宽，有的高，有的是非矩形，有的把 CarPlay UI 和车载系统 UI 混在一起。

（[01:22](https://developer.apple.com/videos/play/wwdc2023/10150/?time=82)）CarPlay 用两个概念解决适配问题。视图区域（View Area）定义 CarPlay 绘制 UI 的边界。安全区域（Safe Area）是显示区域内最大的矩形。CarPlay 把交互内容画在安全区域内，确保所有重要 UI 可见。

如果显示屏是非矩形的，把视图区域定义为包围显示屏的最小矩形，安全区域定义为显示屏内的最大矩形。CarPlay 会正确处理超出安全区域的像素。

（[02:55](https://developer.apple.com/videos/play/wwdc2023/10150/?time=175)）新的安全区域标志允许 CarPlay 在安全区域外绘制背景。这样 CarPlay 的背景可以延伸到显示屏边缘，创造更沉浸的视觉效果。这个标志只对主显示屏有效。

### 圆角裁剪遮罩

（[03:59](https://developer.apple.com/videos/play/wwdc2023/10150/?time=239)）CarPlay UI 的圆角默认显示黑色背景。当 CarPlay 以窗口形式显示时，圆角处的黑色三角形会和车载系统的壁纸不协调。

圆角裁剪遮罩解决了这个问题。iPhone 提供一个包含透明度信息的混合遮罩，车载系统把这个遮罩应用到 CarPlay UI 的每个角，去除黑色三角形。然后车载系统的背景可以一直画到 CarPlay 的圆角边缘。

这个特性不能和"在安全区域外绘制"同时使用。

### UI 焦点转移

（[05:09](https://developer.apple.com/videos/play/wwdc2023/10150/?time=309)）支持旋钮或触控板的系统，CarPlay 和车载系统 UI 之间需要无缝切换焦点。

CarPlay 启动时，车载系统决定焦点归属。驾驶员把焦点移向 CarPlay 时，系统释放焦点并提供方向和位置信息。CarPlay 用这些信息在最直观的 UI 元素上显示焦点高亮。

驾驶员把焦点移回车载系统时，CarPlay 提供焦点，系统获取后显示自己的焦点高亮。API 确保同时只有一个焦点高亮。

如果系统以窗口形式展示 CarPlay 且支持旋钮或触控板，应该支持 UI 焦点转移。

### 外观模式同步

（[06:54](https://developer.apple.com/videos/play/wwdc2023/10150/?time=414)）CarPlay 支持亮色和暗色主题。车载系统应该让 CarPlay 的外观和系统 UI 保持一致。

CarPlay 的外观会根据车辆状态、用户设置和时间自动变化。比如系统夜间切换到暗色主题，CarPlay 也会自动切换。地图 UI 有独立的外观设置，需要单独同步。

### 多显示屏内容

（[08:36](https://developer.apple.com/videos/play/wwdc2023/10150/?time=516)）现代车辆有主显示屏、仪表盘显示屏和抬头显示。CarPlay 为每种显示屏提供不同内容：

- 主显示屏：显示 CarPlay 视频流，用 iAP2 元数据驱动车载系统的内置 UI 控件
- 仪表盘：显示 CarPlay 导航 UI 流，支持地图缩放
- 抬头显示：用 iAP2 元数据显示转向提示等信息

如果车载系统有地图小部件，可以在 CarPlay 导航激活时用 CarPlay 导航 UI 流填充小部件，显示 ETA、限速标志和指南针。

### 无线连接改进

（[10:06](https://developer.apple.com/videos/play/wwdc2023/10150/?time=606)）首次配对支持 out-of-band 配对，驾驶员只需把 iPhone 插到车上就能完成无线 CarPlay 配对。这是无线 CarPlay 的标准要求。

（[10:33](https://developer.apple.com/videos/play/wwdc2023/10150/?time=633)）如果系统支持数字车钥匙，iOS 17 支持通过车钥匙连接配对 CarPlay。添加车钥匙后，系统提示配对无线 CarPlay，配对通过车钥匙连接完成。

（[11:20](https://developer.apple.com/videos/play/wwdc2023/10150/?time=680)）简化的连接流程是首选方式。用现有的 iAP2 连接交换 IP 地址和端口信息，不再需要 Bonjour。实现更简单、连接更快，还支持仅 WPA3 网络。兼容 iOS 14 及以上设备。

（[11:55](https://developer.apple.com/videos/play/wwdc2023/10150/?time=715)）数字车钥匙还支持即时连接。驾驶员携带数字车钥匙靠近车辆时，系统提前准备 CarPlay 栈，检查对应配对关系，CarPlay 看起来是即时启动的。

### 音频增强

（[13:42](https://developer.apple.com/videos/play/wwdc2023/10150/?time=822)）增强缓冲音频是流媒体音频的首选平台。iPhone 以快于实时的速度把音频流式传输到车载系统，通信插件包含最长 2 分钟的音频缓冲区。这提高了响应速度，音频可以在短暂断连时继续播放。

系统需要支持同时混合多种音频流：主音频、增强缓冲音频、替代音频和辅助音频。

### 视频编码升级

（[15:48](https://developer.apple.com/videos/play/wwdc2023/10150/?time=948)）CarPlay UI 流以前用 H.264 编码，现在支持 HEVC 编码。HEVC 更高效，支持更高分辨率的显示屏。系统需要继续支持 H.264 以保持向后兼容。

### EV 路由

（[16:24](https://developer.apple.com/videos/play/wwdc2023/10150/?time=984)）Apple Maps 可以规划包含充电站停靠的电动汽车行程。今年新增功能：用户可以选择偏好的充电网络，地图显示实时充电站可用性。

车载系统需要向 Apple Maps 提供电动车辆的特性信息，支持实时电量状态通信。如果有汽车厂商应用，支持 SiriKit intents 让用户在车内或车外都能使用 EV 路由。

## 详细内容

### 视图区域和安全区域配置

（[01:50](https://developer.apple.com/videos/play/wwdc2023/10150/?time=110)）CarPlay 的视图区域定义 UI 绘制边界。系统应该给 CarPlay 尽可能多的空间，CarPlay 会自动创建合适的内边距。

动态屏幕尺寸调整让用户可以在不同布局间无缝切换。比如从全屏 CarPlay 切换到 CarPlay 和系统小部件并排显示时，CarPlay 自动调整大小。

对于非矩形显示屏：
- 视图区域 = 包围显示屏的最小矩形
- 安全区域 = 显示屏内的最大矩形
- CarPlay 交互内容画在安全区域内
- 安全区域外的像素显示为黑色（除非启用安全区域外绘制）

### 焦点转移协议流程

（[06:03](https://developer.apple.com/videos/play/wwdc2023/10150/?time=363)）焦点协调的具体流程：

1. CarPlay 启动，系统决定初始焦点归属
2. 驾驶员把焦点移向 CarPlay，系统释放焦点并提供 heading 和 position
3. CarPlay 接收信息，在合适的 UI 元素上显示焦点高亮
4. 驾驶员把焦点移回系统，CarPlay 提供焦点
5. 系统获取焦点，显示自己的焦点高亮

这个协议确保驾驶员在 CarPlay 和系统 UI 之间切换时，焦点体验连贯。

### 连接性最佳实践

（[12:44](https://developer.apple.com/videos/play/wwdc2023/10150/?time=764)）维持稳定的无线 CarPlay 连接：

1. 检测无线信道上的干扰源
2. 用信道切换通告避开干扰
3. 如果系统支持多个无线射频，用 BSS 过渡管理把 iPhone 导向另一个接入点
4. 优先在 5 GHz 频段运行
5. 短暂断连时不要关闭 CarPlay TCP socket

### 下一代 CarPlay 的准备

（[17:26](https://developer.apple.com/videos/play/wwdc2023/10150/?time=1046)）今年介绍的所有基础设施改进都是为下一代 CarPlay 做准备：

- 视觉集成：动态屏幕适配、圆角遮罩、焦点转移
- 连接性：简化连接流程、即时连接
- 音频：增强缓冲
- 视频：HEVC 编码支持

这些特性在下一代 CarPlay 规范中都是必需的。

## 核心启发

1. **为车载信息娱乐系统添加 CarPlay 支持**
   - 如果开发车载系统软件，按 CarPlay 规范实现视图区域、安全区域和焦点转移
   - 支持简化连接流程和 out-of-band 配对
   - 入口：developer.apple.com/carplay 获取最新规范

2. **优化现有 CarPlay 系统的视觉体验**
   - 启用圆角裁剪遮罩消除黑色三角形
   - 同步 CarPlay 和系统 UI 的外观模式
   - 支持动态屏幕尺寸调整
   - 入口：CarPlay 通信插件中的 corner clipping mask API

3. **为电动汽车添加 CarPlay EV 路由支持**
   - 向 Apple Maps 提供车辆电池特性和实时电量
   - 支持 SiriKit intents 让语音控制 EV 路由
   - 入口：iAP2 电量状态消息 + SiriKit Vehicle intents
