## Highlight

> visionOS 27 让对象追踪从"只能看不能摸"升级到了"手持动态也能稳跟"，还彻底开放了第三方空间配件——有 LED 星座+IMU+蓝牙就能做自定义硬件，医疗测量和赛车模拟的物理交互终于能落地了。

---

## 核心内容

### 1. 这场演讲解决什么问题

visionOS 2.0 的对象追踪有几个明显限制：

- 只能追踪静止物体，手一拿起来或动得快就丢追踪
- 空间配件只有苹果官方认证的几款，开发者没法自己做
- 追踪结果包含显示校正，不适合精密物理测量

visionOS 27 一次性解决了这三个问题。

### 2. 高帧率追踪（High-frame-rate tracking）

```swift
// 创建 reference object 配置
var configuration = ReferenceObject.Configuration()
configuration.highFrameRateTrackingEnabled = true

// 用 ARKit API 加载 reference object
let refObjURL = Bundle.main.url(forResource: "flashlight", withExtension: ".referenceobject")
let refObject = try? await ReferenceObject(from: refObjURL!, configuration: configuration)
```

关键点：

- `highFrameRateTrackingEnabled` 为单个 reference object 启用高帧率追踪
- 适合手持物体、快速移动的物体
- 需要在 Create ML 中用 extended 训练模式生成 reference object

### 3. Extended 训练模式

```sh
# 用命令行创建 extended 模式的 reference object
xrun createml objecttracker \
    --source flashlight.usdz \
    --output flashlight.referenceobject \
    --training-mode extended \
    --all-angles
```

关键点：

- `extended` 训练模式比默认模式采集更多角度和遮挡情况
- `--all-angles` 让模型学习物体在各个旋转角度下的外观
- 训练后的 reference object 对动态遮挡（如手挡住部分物体）更鲁棒
- 可以集成到 CI/CD 流水线，不用每次在 Mac 上点鼠标

### 4. 度量空间姿态（Metric-space poses）

```swift
// 获取带显示校正的渲染姿态
let renderingPose = myObjectAnchor.coordinateSpace(correction: .rendered)

// 获取不带校正的度量空间姿态（用于物理测量）
let metricPose = myObjectAnchor.coordinateSpace(correction: .none)
```

关键点：

- `.rendered` 包含显示校正，适合把虚拟内容叠加到物体上
- `.none` 是纯度量空间姿态，适合物理测量应用（如医疗探针测距）
- 毫米级精度是物理测量应用的基础

### 5. 对象追踪扩展到 iOS

```swift
import ARKit
import RealityKit

class ObjectTrackingARSessionDelegate: NSObject, ARSessionDelegate {
    let arView = ARView(frame: .zero)
    var entities: [UUID: AnchorEntity] = [:]

    func start() throws {
        let stationaryObject = try ARReferenceObject(archiveURL:
            Bundle.main.url(forResource: "stationary", withExtension: "referenceobject")!)
        let movingObject = try ARReferenceObject(archiveURL:
            Bundle.main.url(forResource: "moving", withExtension: "referenceobject")!)

        let configuration = ARWorldTrackingConfiguration()
        configuration.detectionObjects = [stationaryObject]   // 低帧率检测
        configuration.trackingObjects = [movingObject]        // 高帧率追踪

        arView.session.delegate = self
        arView.session.run(configuration)
    }

    func session(_ session: ARSession, didAdd anchors: [ARAnchor]) {
        for case let anchor as ARObjectAnchor in anchors {
            let entity = AnchorEntity(anchor: anchor)
            entities[anchor.identifier] = entity
            arView.scene.addAnchor(entity)
        }
    }

    func session(_ session: ARSession, didUpdate anchors: [ARAnchor]) {
        for case let anchor as ARObjectAnchor in anchors {
            entities[anchor.identifier]?.isEnabled = anchor.isTracked
        }
    }

    func session(_ session: ARSession, didRemove anchors: [ARAnchor]) {
        for case let anchor as ARObjectAnchor in anchors {
            if let entity = entities.removeValue(forKey: anchor.identifier) {
                arView.scene.removeAnchor(entity)
            }
        }
    }
}
```

关键点：

- iOS 上对象追踪使用同样的 `ARReferenceObject` 格式
- `detectionObjects` 用于低帧率检测（物体刚出现时）
- `trackingObjects` 用于高帧率追踪（物体已识别后的持续追踪）
- `isTracked` 表示当前是否成功追踪到物体

### 6. 第三方空间配件

```swift
import ARKit
import GameController

// 发现通用空间配件
if let device = GCSpatialAccessory.spatialAccessories.first {
    // 自动解析 .referenceaccessory bundle
    let accessory = try await Accessory(device: device)
    let provider = AccessoryTrackingProvider(accessories: [accessory])
    try await arkitSession.run([provider])
}

// 热插拔：不重启 session 更新配件
try await provider.updateAccessories([newAccessory])
```

关键点：

- `GCSpatialAccessory` 通过 Game Controller 框架发现配件
- 配件需要 LED 星座（用于视觉追踪）、IMU（惯性测量单元）和蓝牙连接
- `.referenceaccessory` bundle 包含追踪所需的参考数据
- `updateAccessories` 支持热插拔，不需要重启 AR session

## 最佳实践

- **已有项目迁移**：如果追踪手持物体老是丢，用 Create ML 的 `extended` 模式重新训练 `.referenceobject`，并在代码里开启 `highFrameRateTrackingEnabled`
- **物理测量**：涉及测量的务必使用 `.none` 获取 metric pose；涉及渲染的继续用 `.rendered`。不要混用
- **空间配件开发**：别一开始就自己画板子，先买 DFRobot 或 MikroE 的现成参考硬件跑通 `GCSpatialAccessory` 流程
- **CI/CD 集成**：Create ML 支持命令行跑 extended 训练，可以直接塞进自动化构建流水线
- **iOS 复用**：同一个 `.referenceobject` 文件可以在 visionOS 和 iOS 之间复用，不需要分别训练
- **遮挡处理**：extended 训练模式对遮挡更鲁棒，但如果物体被完全挡住超过几帧，追踪仍然会丢失。设计 UI 时考虑丢失后的恢复逻辑
