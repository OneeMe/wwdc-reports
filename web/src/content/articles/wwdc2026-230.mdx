## Highlight

> macOS 27 的 Automatic Assessment Configuration 框架让考试 App 不再需要自己造轮子拦截快捷键、遮挡 Dock 和 Menu Bar——系统直接提供原生 API，一行代码就能锁定整个 Mac 环境，防作弊逻辑从"Hack"变成了"配置"。

---

## 核心内容

### 1. 这场演讲解决什么问题

在 Mac 上做在线考试或认证测试的开发者，过去都有一个共同的噩梦：**防作弊**。

没有系统级支持时，考试 App 要自己处理：

- 拦截 `Cmd+Tab`、 Spotlight 搜索等快捷键
- 用无边框窗口遮住 Dock 和 Menu Bar
- 禁止输入法切换、屏幕截图、字典查询
- 检测是否开启了虚拟机或远程桌面

这些方案脆弱且不可靠。macOS 一更新，`CGEventTap` 可能失效；无边框窗口可能被 Mission Control 绕过；学生用听写功能就能把答案念给另一个设备。

macOS 27 的 **Automatic Assessment Configuration（AAC）** 框架彻底改变了这个局面。Apple 把系统底层的 UI 和进程管控权限开放给开发者，考试环境从"App 自己 Hack 系统"变成了"系统原生支持的安全模式"。

---

### 2. 系统前置检查：确保设备处于硬化状态

考试开始前，先检查设备是否满足安全要求：

```swift
import AutomaticAssessmentConfiguration

func makeAssessmentConfiguration() -> AEAssessmentConfiguration {
    let configuration = AEAssessmentConfiguration()

    // 系统完整性保护必须开启
    configuration.requiresSIP = true

    // 设备必须通过 MDM 管理
    configuration.requiresManagedDevice = true

    // 只能有一个用户登录
    configuration.requiresSingleUser = true

    // 登录账户必须是标准账户（非管理员）
    configuration.requiresUserAccountType = .standard

    // 禁用 Lockdown Mode（避免干扰考试基础设施）
    configuration.allowLockdownMode = false

    // 禁用 iCloud Private Relay
    configuration.allowPrivateRelay = false

    return configuration
}
```

关键点：

- `requiresSIP` —— System Integrity Protection 是 macOS 的核心安全机制，关闭后系统容易被篡改。
- `requiresManagedDevice` —— 确保设备被学校或机构的 MDM 管理，可以远程配置和监控。
- `requiresSingleUser` + `requiresUserAccountType` —— 防止考生切换到管理员账户绕过限制。
- `allowLockdownMode = false` 和 `allowPrivateRelay = false` —— 这两个是隐私功能，但会干扰考试系统的网络监控需求。

如果任何一项检查失败，系统会自动弹窗告诉考生需要修复什么问题，不需要你自己写错误提示。

### 3. 精细控制辅助功能

macOS 内置了大量辅助功能（Accessibility），对残障考生至关重要，但某些功能也可能被滥用：

```swift
configuration.allowsAccessibilityVoiceOver = true
configuration.allowsAccessibilitySwitchControl = false
configuration.allowsAccessibilityAlternativeInputMethods = true
configuration.allowsAccessibilityBackgroundSounds = true
configuration.allowsAccessibilityHoverText = true
configuration.allowsAccessibilityLiveSpeech = true
configuration.allowsAccessibilitySpokenContent = true
configuration.allowsAccessibilityVoiceControl = true
configuration.allowsAccessibilityZoom = true
```

关键点：

- 默认情况下，所有已启用的辅助功能在考试期间继续可用。
- 你可以逐个禁用可能被滥用的功能。比如 `SwitchControl` 可以被用来触发外部脚本，建议关闭。
- 不要一刀切全部禁用——这会让真正需要辅助功能的考生无法参加考试。

---

### 4. 自定义 Menu Bar 和 Dock

考试期间，Menu Bar 和 Dock 默认是隐藏的。但你可以精确控制哪些项目可以显示：

```swift
// 允许显示 Menu Bar，但只显示指定项目
configuration.allowsMenuBar = true
configuration.allowedMenuBarItems = [
    .battery,
    .clock,
    .volume
]

// Apple 菜单里只允许"睡眠"
configuration.allowedAppleMenuItems = [
    .sleep
]

// 允许显示 Dock
configuration.allowsDock = true
```

关键点：

- `allowedMenuBarItems` 是一个白名单，只有列出的系统图标会显示。第三方 App 的 Menu Bar 图标自动隐藏。
- 考生可以看到电量、时间和音量，但不能看到 WiFi 状态（防止发现网络监控）。
- `allowedAppleMenuItems` 控制左上角 Apple 菜单的选项，可以保留"睡眠"但移除"关机"和"重新启动"。

---

### 5. 输入限制

防止通过输入法、自动填充等渠道泄露或获取答案：

```swift
configuration.allowsDictation = false        // 禁用听写
configuration.allowsAutoFill = false         // 禁用自动填充
configuration.allowsStructuralInput = false  // 禁用结构输入
configuration.allowsEmojiKeyboard = false    // 禁用表情键盘
```

关键点：

- `allowsDictation` —— 听写功能可以把语音转成文字，考生可能用它来接收外部提示。
- `allowsAutoFill` —— 防止浏览器或系统密码管理器自动填充内容。
- `allowsEmojiKeyboard` —— 看似无害，但某些作弊方案用 Emoji 编码传递答案。

---

### 6. 文件和进程管控

限制考生能访问的文件和能启动的应用：

```swift
// 只允许访问指定目录
configuration.allowedDirectoriesAndFiles = [
    URL(fileURLWithPath: "~/Documents/")
]

// 只允许考试参与者运行其他应用
configuration.allowOnlyParticipantsToRun = true

// 禁止执行用户脚本
configuration.allowsUserScriptExecution = false
```

关键点：

- `allowedDirectoriesAndFiles` 是白名单模式，超出范围的文件系统访问会被阻止。
- `allowOnlyParticipantsToRun` —— 考试组织者可以预先指定哪些 App 可以在考试期间运行（如监考软件）。
- `allowsUserScriptExecution` —— 防止通过 AppleScript、Shell Script 等自动化工具作弊。

## 最佳实践

- **从 CGEventTap 迁移到 AAC**：如果你还在用 `CGEventTap` 拦截快捷键、用隐藏窗口遮挡 Dock，尽快迁移到 `AEAssessmentConfiguration`。自己造的轮子不仅脆弱，还可能在 macOS 更新后失效，甚至被系统判定为恶意行为。

- **遵循最小限制原则**：不要一上来就把所有 `allows...` 设为 `false`。先跑通一个宽松的版本，再根据实际作弊手段慢慢收紧。过度限制会导致考生设备出现各种诡异的系统级问题。

- **处理好 Session 转换回调**：考试结束或意外中断时，系统会退出 Assessment Mode。你的 App 必须在这个回调里清理状态（如保存答题进度、释放资源），而不是等系统强杀。

- **测试辅助功能的兼容性**：在开启各种辅助功能（VoiceOver、Switch Control 等）的情况下测试考试流程，确保残障考生能正常使用。

- **申请必要的 Entitlement**：使用 AAC 框架需要 `com.apple.developer.automatic-assessment-configuration` entitlement，通过 Apple Developer 网站申请。
