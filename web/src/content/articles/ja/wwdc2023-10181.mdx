## ハイライト

> iOS 17 では ISO HDR 静止画規格の完全サポートが導入され、開発者は複雑なトーン マッピングを手動で処理することなく、SwiftUI、UIKit、Core Graphics を使用して HDR 写真を直接ロード、表示、作成できるようになります。

## 主な内容

SDR (スタンダード ダイナミック レンジ) モニターの明るさの範囲は限られており、シーン内のハイライトは圧縮またはトリミングすることしかできません。 HDR ディスプレイは、より広い輝度範囲を表示できるため、画像を実際のシーンに近づけることができます。

Apple は今年、ISO HDR 標準のサポートを導入しました。この規格 (TS22028-5) は、HDR コンテンツを既存の静止画像形式にエンコードする方法を定義します。主なパラメータには、伝達関数としての HLG または PQ の使用、BT.2020 の広色域、10 ビット以上のビット深度が含まれます。 HEIF は HDR をエンコードできますが、従来の JPEG はエンコードできません (8 ビットのみ)。

開発者にとっての最大の変化は、システム フレームワークがすでに HDR の認識と表示を処理していることです。 SwiftUI`Image`、UIKit`UIImageView`、同様に`CALayer`すべてが自動的に HDR コンテンツを認識し、正しくレンダリングできます。画像メタデータが正しいことを確認するだけで、システムは自動的に EDR (拡張ダイナミック レンジ) を利用して、サポートされているディスプレイ上で SDR 白色点の明るさを超えてコンテンツをレンダリングします。

### HDR の基本概念

([00:40](https://developer.apple.com/videos/play/wwdc2023/10181/?time=40)) HDR ディスプレイの中核はヘッドルームです。 SDR ディスプレイの最も明るい白は基準白と呼ばれ、HDR では基準白よりも明るいコンテンツを表示できます。

EDR パラダイムでは:
- 基準白 = 1.0
- ピーク = モニターが表現できる最大値

ISO HDR標準解像度：
- 黒: 0.0005 cd/m²
-デフォルトの基準白: 203 cd/m²
- 203 を超えるものはヘッドルームです

SDR を比較します。
- sRGB/ディスプレイ P3 の黒: 0.2 cd/m²
- 白: 80 cd/m²

### HDR 画像を識別する

([02:35](https://developer.apple.com/videos/play/wwdc2023/10181/?time=155)) システムには、画像が HDR であるかどうかを判断する複数の方法が用意されています。

**SwiftUI 自動処理:**```swift
import SwiftUI

struct ContentView: View {
    var body: some View {
        Image("sunrise_hdr")
            .resizable()
            .scaledToFit()
    }
}
```

SwiftUI`Image`HDR コンテンツは自動的に認識され、EDR 対応ディスプレイ上で正しくレンダリングされます。

**UIKit の処理:**```swift
import UIKit

let imageView = UIImageView()
imageView.image = UIImage(named: "sunrise_hdr")
imageView.preferredImageDynamicRange = .high
```

キーポイント:
- `preferredImageDynamicRange = .high`この画像を HDR でレンダリングする必要があることをシステムに指示します。
- EDR マッピングはシステムによって自動的に処理されます

### ProRAW/RAW から HDR 画像を作成する

([04:30](https://developer.apple.com/videos/play/wwdc2023/10181/?time=270)) iPhone で撮影した ProRAW にはハイ ダイナミック レンジ データが含まれており、HDR 静止画としてエクスポートできます。

```swift
import CoreImage
import ImageIO

// 从 ProRAW 创建 HDR CGImage
guard let rawImage = CIImage(contentsOf: prorawURL,
                             options: [.rawFilterOptions: true]) else { return }

// 应用色调映射以保留 HDR 数据
let toneMapped = rawImage.applyingFilter("CIToneCurve",
    parameters: [
        "inputPoint0": CIVector(x: 0, y: 0),
        "inputPoint1": CIVector(x: 0.25, y: 0.25),
        "inputPoint2": CIVector(x: 0.5, y: 0.5),
        "inputPoint3": CIVector(x: 0.75, y: 0.75),
        "inputPoint4": CIVector(x: 1, y: 1.2)  // 超白区域保留
    ])

// 导出为 HEIF with HDR
let context = CIContext()
guard let cgImage = context.createCGImage(toneMapped, from: toneMapped.extent) else { return }

let destination = CGImageDestinationCreateWithURL(outputURL,
                                                   UTType.heic.identifier as CFString,
                                                   1,
                                                   nil)
let hdrProperties: [String: Any] = [
    kCGImagePropertyHEICSDRHint as String: true,
    kCGImagePropertyHEICGainMap as String: gainMapData
]
CGImageDestinationAddImage(destination!, cgImage, hdrProperties as CFDictionary)
CGImageDestinationFinalize(destination!)
```

キーポイント:
- ProRAW はセンサーレベルのダイナミックレンジデータを保存します
- HDR メタデータをサポートするには、エクスポート時に HEIF 形式を選択します
-`kCGImagePropertyHEICSDRHint`フラグ画像に HDR コンテンツが含まれています

### CALayer で HDR を表示する

([06:15](https://developer.apple.com/videos/play/wwdc2023/10181/?time=375)) カスタム レンダリング シーンの場合、次を使用できます。`CALayer`EDR サポート:

```swift
import QuartzCore

let layer = CALayer()
layer.contents = hdrCGImage
layer.wantsExtendedDynamicRangeContent = true

// 设置 EDR 头部空间
layer.edrMetadata = .hdrContent(
    luminance: 1000.0  // 内容峰值亮度，单位 nits
)
```

キーポイント:
- `wantsExtendedDynamicRangeContent = true`EDR レンダリングを有効にする
-`edrMetadata`コンテンツの明るさの範囲をシステムに伝え、コンテンツを正しくマッピングするのに役立ちます

### ISO HDR のコア グラフィックス サポート

([08:00](https://developer.apple.com/videos/play/wwdc2023/10181/?time=480)) Core Graphics に ISO HDR イメージの読み取りと書き込みのサポートが追加されました。

```swift
import CoreGraphics

// 读取 HDR 图像的元数据
let source = CGImageSourceCreateWithURL(imageURL as CFURL, nil)
let properties = CGImageSourceCopyPropertiesAtIndex(source!, 0, nil) as? [String: Any]

// 检查 HDR 相关属性
let isHDR = properties?[kCGImagePropertyHDRDictionary as String] != nil
let transferFunction = properties?[kCGImagePropertyHDRTransferFunction as String]
// "HLG" 或 "PQ"

// 写入 HDR 图像
let destination = CGImageDestinationCreateWithURL(outputURL as CFURL,
                                                   UTType.heic.identifier as CFString,
                                                   1, nil)
let hdrProps: [String: Any] = [
    kCGImagePropertyHDRDictionary as String: [
        kCGImagePropertyHDRTransferFunction as String: "HLG",
        kCGImagePropertyHDRReferenceWhite as String: 203.0
    ]
]
CGImageDestinationAddImage(destination!, cgImage, hdrProps as CFDictionary)
```

キーポイント:
- `kCGImagePropertyHDRDictionary`HDR 固有のメタデータが含まれています
- HLGおよびPQ伝達関数をサポート
- ISO HDR の最小要件は 10 ビットのビット深度です

## 重要なポイント

**1.写真編集アプリ用の HDR エクスポート**
- **内容**: ハイライトの詳細を保持しながら、編集した写真を HDR としてエクスポートできるようにします
- **価値がある理由**: iPhone 15 Pro シリーズのユーザーが撮影する写真が HDR で撮影されることが増えています。 SDRを編集してからエクスポートするだけだと、元のデータが無駄になってしまいます。
- **開始方法**: を使用します`CGImageDestination`HEIF のエクスポート、設定`kCGImagePropertyHDRDictionary`メタデータ

**2.ギャラリー/ソーシャル アプリの HDR 表示**
- **内容**: フィードと詳細ページで HDR 写真を自動的に識別し、正しく表示します
- **実行する価値がある理由**: SwiftUI`Image`とUIKit`UIImageView`すでに自動的にサポートされていますが、メタデータを壊さないように注意してください
- **開始方法**: 画像の読み込みプロセスをチェックして、HDR メタデータが失われていないことを確認します。で`UIImageView`設定オン`preferredImageDynamicRange = .high`

**3.カメラ アプリでの HDR 写真のプレビュー**
- **内容**: HDR 効果をリアルタイムでビューファインダーに表示し、ユーザーが最終的な画像を確認できるようにします。
- **価値がある理由**: HDR プレビューは、特に逆光のシーンでショットを構成する際に露出を判断するのに役立ちます。
- **開始方法**: を使用します`AVCaptureVideoPreviewLayer`、設定`wantsExtendedDynamicRangeContent = true`

**4. ProRAW から HDR アルバムをバッチ生成**
- **内容**: ユーザーの ProRAW 写真を共有可能な HDR HEIF にバッチ変換します
- **価値がある理由**: ProRAW ファイルは巨大 (25MB 以上)、HDR HEIF はわずか数 MB なので、共有や保存に適しています。
- **開始方法**: を使用します`CIImage(contentsOf:options:)`ProRAW を読み取る`CGImageDestination`HDR メタデータを含む HEIF へのエクスポート
