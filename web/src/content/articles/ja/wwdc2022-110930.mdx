## ハイライト

> 2 日目では、SwiftUI ナビゲーションの新しい API、Xcode 14 の改善、Unity 用の Apple フレームワーク プラグイン、RoomPlan 3D スキャン、SF Symbols マルチカラー サポート、および iOS Push to Talk フレームワークのリリースに焦点を当てます。

## 主要内容

### SwiftUI ナビゲーションのアップグレード

2 日目は、SwiftUI ナビゲーションの新しいソリューションから始まります。 iOS 16の導入`NavigationStack`そして`NavigationSplitView`これにより、マルチプラットフォーム対応における以前のナビゲーション API の問題点が解決されます。 ([00:09](https://developer.apple.com/videos/play/wwdc2022/110930/?time=9))

`NavigationStack`オリジナルを交換しました`NavigationView`、プログラムによるナビゲーションとディープリンクをサポートします。`NavigationSplitView`iPad および Mac にネイティブの複数列ナビゲーション レイアウトを提供し、自分で使用する必要がなくなりました。`HStack`一緒にします。

### Xcode 14 の改善点

Xcode 14 では、開発者エクスペリエンスがいくつか向上しています。コンパイルが高速になり、特に Swift プロジェクトの増分コンパイルが高速になります。インターフェイスも調整されており、開発者は自分に合った情報密度のレベルを選択できます。 ([00:15](https://developer.apple.com/videos/play/wwdc2022/110930/?time=15))

### Unity + Apple フレームワーク

Apple は、Unity 開発者向けの公式プラグインをリリースしました。これにより、Unity ゲームが Core Haptics、Game Center、ARKit などの Apple フレームワークに接続できるようになります。 Core Haptics プラグインは、ゲームの触覚フィードバックを新たなレベルの没入感に引き上げます。 ([00:22](https://developer.apple.com/videos/play/wwdc2022/110930/?time=22))

### RoomPlan 3D スキャン

RoomPlan は、LiDAR スキャナーを使用して屋内空間の 3D モデルを迅速に作成する新しいフレームワークです。スキャンプロセスは自動化され、3D モデルは USDZ 形式で出力されます。 Appleはこれを「現実世界をアプリに持ち込む強力な新しい方法」と呼んでいる。 ([00:34](https://developer.apple.com/videos/play/wwdc2022/110930/?time=34))

### SF Symbols のマルチカラーのサポート

SF Symbols 4 では、マルチカラー レンダリング モードが導入されており、開発者は色を使用してシンボルのより豊かな意味を表現できるようになります。システムは、シンボルのセマンティクスに基づいて、適切な色のグラデーションを自動的に適用します。 ([00:43](https://developer.apple.com/videos/play/wwdc2022/110930/?time=43))

### プッシュ トゥ トーク フレームワーク

iOS 16 では Push to Talk フレームワークが追加され、アプリがトランシーバー機能を実装できるようになります。ユーザーはボタンを押したままにして発言し、ボタンを放して送信します。このフレームワークはバックグラウンド オーディオと権限を管理するため、開発者はビジネス ロジックを処理するだけで済みます。 ([00:49](https://developer.apple.com/videos/play/wwdc2022/110930/?time=49))

### ナビゲーション API の移行に関する推奨事項

使用している場合`NavigationView`、に移行します`NavigationStack`優先順位はプロジェクトの複雑さによって異なります。新しいプロジェクトは新しい API を直接使用でき、古いプロジェクトは段階的に移行できます。`NavigationSplitView`iPad と Mac でのみ意味があり、iPhone では自動的に折りたたまれます。

## 重要ポイント

- **室内空間測定アプリケーション**: RoomPlan を使用して部屋をスキャンして 3D モデルを生成し、面積を自動的に計算し、家具の配置のプレビューを生成します。不動産、装飾、家具のアプリを直接統合できます。エントリーAPIは`RoomCaptureView`そして`RoomBuilder`。

- **インターコム機能の統合**: 建設現場管理、イベント調整、チーム コラボレーションなどのコラボレーション アプリに Push to Talk 機能を追加します。プレス アンド トーク エクスペリエンスは、従来の音声メッセージングよりも即時的です。エントリーAPIは`PushToTalkManager`。

- **マルチカラー アイコン システム**: SF シンボルのマルチカラー レンダリング モードを使用して、アプリのセマンティック アイコン システムを設計します。インターフェースの情報密度を高めるために、さまざまな状態がさまざまな色レベルで表現されます。エントリーAPIは`Image(systemName:)`協力する`.symbolRenderingMode(.multicolor)`。

- **Unity ゲームの触覚アップグレード**: Unity によって開発された iOS ゲームの場合、Core Haptics プラグインに接続して、さまざまなゲーム イベントの詳細な触覚フィードバックを設計します。射撃の反動、アイテムを拾った時の軽い感触、爆発の衝撃など。エントリ API は Unity の Core Haptics プラグインです。
