## ハイライト

> macOS 14 の ScreenCaptureKit には、Presenter Overlay スピーカー オーバーレイ エフェクト、SCContentSharingPicker システム レベル コンテンツ セレクター、および SCScreenshotManager 高解像度スクリーンショット API が追加されており、これにより、画面共有アプリケーションは、独自に構築した UI を構築することなく、システムで一貫したエクスペリエンスを得ることができます。

## 主な内容

### 画面共有 UI のジレンマ

ビデオ会議ツールや画面録画ツールを作成する場合、コンテンツ選択インターフェイスが面倒になることがあります。すべてのウィンドウとアプリケーションを列挙するには、さまざまなエッジ ケースを処理する選択パネルを描画します。アプリケーションごとに選択インターフェイスの外観が異なるため、ユーザーは毎回それを学び直す必要があります。

SCContentSharingPicker がこの負担を引き継ぎます。これは、macOS ネイティブと一致するウィンドウ/アプリケーション/ディスプレイの選択エクスペリエンスを提供するシステム レベルのシングルトンであり、ユーザーがビデオ メニュー バー、アプリ内ボタン、またはウィンドウを直接クリックすることによってトリガーできます。

### プレゼンター オーバーレイ: 自動スピーカー効果

リモート会議で画面を共有する場合、発言者のポートレートとコンテンツは分離されます。プレゼンター オーバーレイは、高度なセグメンテーション アルゴリズムを通じて共有コンテンツにスピーカーを埋め込みます。

スモール オーバーレイ モードでは、移動可能な円形ウィンドウ内にスピーカーが配置されます。ラージ オーバーレイ モードは、スピーカーを背景から分離し、スピーカーと背景の間に画面コンテンツを配置して、天気予報に似た没入型効果を作り出します。

重要なのは、この効果は ScreenCaptureKit を使用するアプリケーションに対して自動的に有効になるということです。アプリがカメラとスクリーン キャプチャ ストリームの両方を使用している限り、コントロールはビデオ メニュー バーに表示され、ScreenCaptureKit は合成されたフレームをストリームに直接プッシュします。

### ビデオ ストリームからネイティブ スクリーンショットにフレームをキャプチャします

以前は、画面のコンテンツをキャプチャするには、SCStream からフレームを取得するか、CGWindowListCreateImage を使用する必要がありました。前者はストリームを維持する必要がありますが、後者は機能が制限されています。

SCScreenshotManager は、非同期スクリーンショット API を提供し、CGImage と CMSampleBuffer の 2 つの出力形式をサポートし、ScreenCaptureKit のフィルタリングおよび構成機能を再利用します。

### プレゼンターオーバーレイステータス検出

([03:32](https://developer.apple.com/videos/play/wwdc2023/10136/?time=212))

アプリは、UI を調整できるように、プレゼンター オーバーレイがいつ有効になっているかを知る必要があります。

```swift
let stream = SCStream(filter: filter, configuration: config, delegate: self)

// 实现 SCStreamDelegate 回调
func stream(_ stream: SCStream, outputEffectDidStart didStart: Bool) {
    if didStart {
        presentBanner()
        turnOffCamera() // 隐藏本地摄像头 tile
    } else {
        turnOnCamera()
    }
}
```

**キーポイント:**
- `outputEffectDidStart` は、プレゼンター オーバーレイが有効または無効になっているときにトリガーされます
- 有効にすると、カメラがオーバーレイによって直接使用されるため、AVCaptureSession は通常のカメラ ストリームを出力しなくなります
- ビデオ通話アプリケーションはオーディオとビデオの同期を調整し、発言者のローカル カメラ タイルを非表示にする必要があります。
- オーバーレイにはリアルタイムの分割レンダリングが含まれるため、より高いフレーム レートに最適化することをお勧めします。

### システムレベルのコンテンツセレクター

([06:48](https://developer.apple.com/videos/play/wwdc2023/10136/?time=408))

SCContentSharingPicker は、独自に構築されたコンテンツ選択インターフェイスを置き換えます。

```swift
let picker = SCContentSharingPicker.shared()
picker.addObserver(self)
picker.isActive = true

// 应用内按钮触发系统选择器
func showSystemPicker(sender: UIButton) {
    picker.present(for: nil, using: .window)
}

// 选择完成回调
func contentSharingPicker(_ picker: SCContentSharingPicker,
                          didUpdateWith filter: SCContentFilter,
                          for stream: SCStream?) {
    if let stream = stream {
        stream.updateContentFilter(filter)
    } else {
        let newStream = SCStream(filter: filter, configuration: config, delegate: self)
        // 启动新流
    }
}

// 失败和取消回调
func contentSharingPicker(_ picker: SCContentSharingPicker,
                          didCancelFor stream: SCStream?) {
    if let stream = stream {
        resetStateForStream(stream: stream)
    }
}

func contentSharingPickerStartDidFailWithError(_ error: Error) {
    presentNotification(error: error)
}
```

**キーポイント:**
- システムがこのアプリをビデオ メニュー バーに含める前に、`isActive = true` を設定する必要があります
- `contentStyle` または `present(for:using:)` はオプション `.window`、`.application`、`.display`
- コールバックによって返された `SCContentFilter` は、ストリームの作成または更新に直接使用できます。
- セレクターの動作はストリームごとに個別に設定可能

### ストリームごとにセレクターを構成する

([08:41](https://developer.apple.com/videos/play/wwdc2023/10136/?time=521))

```swift
let pickerConfig = SCContentSharingPickerConfiguration()
pickerConfig.allowedPickingModes = [.window, .application]
pickerConfig.excludedBundleIDs = ["com.foo.myApp", "com.foo.myApp2"]
pickerConfig.allowsRepicking = false

picker.setConfiguration(pickerConfig, for: stream)
```

**キーポイント:**
- `allowedPickingModes` は、ユーザーが選択できるコンテンツ タイプを制限します
- `excludedBundleIDs` と `excludedWindowIDs` は機密性の高いアプリやウィンドウを非表示にします
- `allowsRepicking = false` は、ユーザーが選択したコンテンツを変更できないようにします
- 各ストリームは異なる構成を持つことができます

### HD スクリーンショット API

([12:26](https://developer.apple.com/videos/play/wwdc2023/10136/?time=746))

```swift
// 方式一：CGImage 输出
if let screenshot = try? await SCScreenshotManager.captureImage(
    contentFilter: myContentFilter,
    configuration: myConfiguration
) {
    // screenshot 是 CGImage，可直接用于 NSImage/UIImage
}

// 方式二：CMSampleBuffer 输出
if let sampleBuffer = try? await SCScreenshotManager.captureSampleBuffer(
    contentFilter: myContentFilter,
    configuration: myConfiguration
) {
    // 支持更多像素格式，适合视频处理流程
}
```

完全な使用プロセス:

```swift
// 1. 获取可共享内容
let content = try await SCShareableContent.current

// 2. 创建内容过滤器（可用 picker 或手动）
let filter = SCContentFilter(display: content.displays.first!,
                             excludingApplications: [],
                             exceptingWindows: [])

// 3. 配置截图参数
let configuration = SCStreamConfiguration()
configuration.width = 1920
configuration.height = 1080
configuration.showsCursor = true

// 4. 调用截图 API
if let screenshot = try? await SCScreenshotManager.captureImage(
    contentFilter: filter,
    configuration: configuration
) {
    print("截图成功，尺寸: \(screenshot.width) x \(screenshot.height)")
}
```

**キーポイント:**
- `captureImage` は CGImage を返します。直接表示または保存するのに適しています。
- `captureSampleBuffer` は CMSampleBuffer を返し、より多くのピクセル形式をサポートします
- カーソル表示、解像度、色空間などの設定オプションは基本的に SCStream と同じです。
- CGWindowListCreateImageから移行する場合、ウィンドウ階層オプションはSCShareableContentで取得されます。

## 重要なポイント

1. **ワンクリック画面録画ツール**
   - **やること**: メニューバーウィジェットを作成します。クリックすると、システム セレクターがポップアップ表示されます。ウィンドウを選択した後、GIF/ビデオの録画を開始します
   - **䡡値**: SCContentSharingPicker は完全な選択 UI を提供します。自分で構築する必要はありません。わずか数行のコードでプロレベルの画面録画を実現できます。
   - **Hai Haifang**: `SCContentSharingPicker.shared()` を使用してセレクターを取得し、コールバックで `SCStream` を作成し、それを `AVAssetWriter` に出力します。

2. **スマートなスクリーンショットメモアプリケーション**
   - **やること**: アプリケーションによってアーカイブされた、スクリーンショット後のテキストの自動 OCR 認識
   - **䡡値**: `SCScreenshotManager` は特定のウィンドウを正確に傍受し、`excludedBundleIDs` と連携してプライベート コンテンツをフィルタリングできます。
   - **Haikata**: `SCShareableContent` を使用してウィンドウ リストを取得し、`SCContentFilter` を作成してターゲット ウィンドウを指定し、`captureImage` を呼び出します。

3. **リモート コラボレーション ホワイトボード**
   - **やること**: 画面共有時にスピーカーのジェスチャーとレーザー ポインター マークを自動的に重ね合わせます
   - **䡡値**: プレゼンター オーバーレイはすでに話者のセグメンテーションを処理しているため、アプリケーションは受信側でカスタム アノテーション レイヤーをオーバーレイするだけで済みます。
   - **ハイハイカタ**: `outputEffectDidStart` コールバックを検出し、UI レイアウトを調整し、共有画面に CAShapeLayer 描画マーカーをオーバーレイします

4. **アプリケーション使用状況分析ツール**
   - **やること**: ユーザーのアクティブなウィンドウを定期的にインターセプトし、毎日のアプリケーション使用時間の視覚的なレポートを生成します。
   - **䡡値**: スクリーンショット API は、`SCShareableContent` のウィンドウ レベル情報と一致して、アプリケーションごとに正確にフィルタリングできます。
   - **Haikata**: `SCShareableContent.current` を使用してアプリケーション リストを取得し、アプリケーションごとにフィルターを作成し、定期的に `captureSampleBuffer` を呼び出してピクセルの変化を分析し、アクティビティを判断します。
