## ハイライト

> Core Motion は、iOS 17 と watchOS 10 に 3 つの新機能を追加します: macOS 用 AirPods ヘッドトラッキングデータサポート、Apple Watch Ultra 水深と温度モニタリング、運動中の HealthKit 高周波センサーデータストリーミング (800Hz 加速度計 / 200Hz デバイスモーション)。

## 主な内容

スポーツデータは、Apple エコシステムの目に見えないインフラストラクチャです。歩数カウント、衝突検出、空間オーディオ - これらのエクスペリエンスはすべて、加速度計、ジャイロスコープ、気圧計などのセンサーに基づいています。 Core Motion は、開発者がこのデータを使用するための統合ポータルとして機能します。

### AirPods のヘッドトラッキングが macOS に拡張されました

([02:22](https://developer.apple.com/videos/play/wwdc2023/10179/?time=142)) 空間オーディオの動的ヘッド トラッキングは、iPhone や Apple Watch と同じモーション アルゴリズムに依存しています。`CMHeadphoneMotionManager`iOS 14 以降、このデータが公開され、アプリがユーザーの頭の姿勢、加速度、回転を追跡できるようになります。

今年、この機能は macOS 14 に拡張されます。

```swift
import CoreMotion

let headphoneManager = CMHeadphoneMotionManager()
headphoneManager.delegate = self

// 检查设备是否支持
if headphoneManager.isDeviceMotionAvailable {
    headphoneManager.startDeviceMotionUpdates(to: .main) { motion, error in
        guard let motion = motion else { return }

        // 头部姿态（俯仰、偏航、翻滚）
        let attitude = motion.attitude

        // 用户加速度
        let acceleration = motion.userAcceleration

        // 旋转速率
        let rotation = motion.rotationRate

        // 数据来源：左耳还是右耳
        let location = motion.sensorLocation // .left or .right
    }
}
```

キーポイント:
- 空間オーディオダイナミックヘッドトラッキングをサポートするAirPods Proなどのヘッドフォンをサポート
-`sensorLocation`データが左耳から来たのか右耳から来たのかを区別する
- 自動インイヤー検出をオンにした後、片方の耳を取り出すと、自動的にもう一方の耳に切り替わり、送信が継続されます。
- Info.plist での設定が必要です`Motion Usage Description`権限の説明

接続状態の監視:

```swift
extension ViewController: CMHeadphoneMotionManagerDelegate {
    func headphoneMotionManagerDidConnect(_ manager: CMHeadphoneMotionManager) {
        // 耳机已连接，可以开始接收数据
    }

    func headphoneMotionManagerDidDisconnect(_ manager: CMHeadphoneMotionManager) {
        // 耳机断开，停止相关功能
    }
}
```

キーポイント:
- 接続ステータスが変化するとデリゲートメソッドがトリガーされます
- 自動インイヤー検出がオンになっている場合、ヘッドフォンの抜き差しも切断/接続をトリガーします。
- ヘッドフォンの装着検出にも対応

### Apple Watch Ultra 水中データモニタリング

（[07:22](https://developer.apple.com/videos/play/wwdc2023/10179/?time=442)）`CMWaterSubmersionManager`Apple Watch Ultra の気圧計を使用して、シュノーケリングや水泳などのウォーターアクティビティ中に水深と水温を追跡します。

```swift
import CoreMotion

let submersionManager = CMWaterSubmersionManager()
submersionManager.delegate = self
```

デリゲートの実装:

```swift
extension WorkoutManager: CMWaterSubmersionManagerDelegate {
    // 浸没状态变化（入水/出水）
    func waterSubmersionManager(
        _ manager: CMWaterSubmersionManager,
        didUpdate event: CMWaterSubmersionEvent
    ) {
        switch event.state {
        case .notSubmerged:
            // 在水面上
        case .submergedShallow:
            // 水下 1 米以内
        case .submergedDeep:
            // 水下超过 1 米
        case .approachingMaxDepth:
            // 接近 6 米最大深度
        case .pastMaxDepth:
            // 超过 6 米
        case .sensorDepthError:
            // 传感器超出量程
        }
    }

    // 深度、压力、水温测量数据
    func waterSubmersionManager(
        _ manager: CMWaterSubmersionManager,
        didUpdate measurement: CMWaterSubmersionMeasurement
    ) {
        let depth = measurement.depth?.value      // 水深（米）
        let pressure = measurement.pressure?.value // 水压
        let surfacePressure = measurement.surfacePressure?.value // 水面气压
    }

    // 水温更新
    func waterSubmersionManager(
        _ manager: CMWaterSubmersionManager,
        didUpdate temperature: CMWaterTemperature
    ) {
        let waterTemp = temperature.temperature.value // 水温
        let uncertainty = temperature.uncertainty     // 不确定度
    }
}
```

キーポイント:
- Apple Watch Ultraのみでサポートされており、watchOS 9+が必要です
- 「浅い深さと圧力」機能を追加する必要があります
- 水温データは浸漬状態でのみ利用可能です。最初に水に入ったときの不確実性は高く、時間の経過とともに収束します。
- 最大監視深度は6メートルであり、それを超えてから入る`pastMaxDepth`ステータス
- 深さの分割:`notSubmerged` → `submergedShallow`(1m未満) →`submergedDeep`(1m以上)

### 高周波センサー データ ストリーム CMBatchedSensorManager

([11:35](https://developer.apple.com/videos/play/wwdc2023/10179/?time=695)) Apple Watch Series 8 および Ultra は、新しい高周波センサー データ ストリームをサポートします。既存のものと`CMMotionManager`(最大100Hz、サンプルごとにリアルタイムプッシュ)`CMBatchedSensorManager`データは毎秒バッチで転送され、加速度センサーの場合は最大 800 Hz、デバイスの動きの場合は最大 200 Hz で転送されます。

2 つのデータ取得方法の比較:

|特長 | CMMotionManager | CMBatchedSensorManager |
|------|-----------------|----------------------|
|加速度計の周波数 |最大100Hz | 800Hz |
|機器の移動頻度 |最大100Hz | 200Hz |
|送信方法 |サンプルごとのリアルタイム プッシュ | 1 秒あたりのバッチ送信 |
|レイテンシ |低 (1 秒未満レベル) |高 (第 2 レベル) |
|使用シナリオ | UIフィードバック、リアルタイム制御 |動作解析、事後計算 |
|前提条件 |なし |アクティブな HealthKit ワークアウトが必要です |

([13:18](https://developer.apple.com/videos/play/wwdc2023/10179/?time=798)) 講演者は、高周波データの価値を示すために野球のスイングを例として使用しました。約 0.3 秒続くスイング全体で、100Hz のサンプリングでは 30 個のデータ ポイントしか取得できませんが、800Hz では 240 個のデータ ポイントを取得できます。これは、インパクトの瞬間の微妙な振動の違いを区別するのに十分です。

### 高周波データフローの利用プロセス

([16:17](https://developer.apple.com/videos/play/wwdc2023/10179/?time=977))`CMBatchedSensorManager`アクティブな HealthKit Workout セッションが必要です。

```swift
import CoreMotion
import HealthKit

let batchedManager = CMBatchedSensorManager()

// 1. 确认设备支持
guard batchedManager.isAccelerometerSupported else { return }

// 2. 启动 HealthKit Workout
let workoutConfiguration = HKWorkoutConfiguration()
workoutConfiguration.activityType = .baseball
// ... 配置并启动 workout session

// 3. 使用 Swift async 接收批量数据
Task {
    do {
        for try await batch in batchedManager.accelerometerUpdates() {
            processAccelerometerBatch(batch)
        }
    } catch {
        // 处理授权错误或平台不支持
    }
}
```

キーポイント:
- `isAccelerometerSupported`そして`isDeviceMotionSupported`デバイスのサポートを確認する
- Apple Watch Series 8およびUltraでのみサポートされています
- データを取得するには、アクティブな HealthKit Workout 内にある必要があります
- Swift async/await インターフェースを使用してデータをバッチごとに処理します
- 無限ループを避けるために、ループ中にワークアウトが終了したかどうかを確認する必要があります

### スイング分析のアルゴリズム実装

([17:08](https://developer.apple.com/videos/play/wwdc2023/10179/?time=1028)) 講演者は、高周波データを使用して「接触までの時間」を計算する方法を示しました。

**ステップ 1: インパクトの瞬間を検出**

```swift
func detectImpact(from batch: [CMAccelerometerData]) -> TimeInterval? {
    // z 轴垂直于表冠方向，击球时会产生明显振动
    let filteredZ = batch.map { highPassFilter($0.acceleration.z) }

    // 找到滤波后信号的峰值
    guard let maxIndex = filteredZ.enumerated().max(by: { $0.element < $1.element })?.offset else {
        return nil
    }

    // 从原始数据获取对应时间戳
    return batch[maxIndex].timestamp
}
```

キーポイント:
- Z軸方向はApple Watchのリューズに対して垂直です。
- ハイパスフィルターを使用して高周波衝撃信号を分離します。
- ピークは衝撃の瞬間に対応します

**ステップ 2: スイングの開始を検出**

```swift
func detectSwingStart(impactTime: TimeInterval, motionBuffer: [CMDeviceMotion]) -> TimeInterval? {
    // 从 impactTime 向前遍历，寻找旋转速率沿重力方向的分量
    // 从超过阈值变为低于阈值的转折点

    for sample in motionBuffer.reversed() {
        // 只检查 impactTime 之前的样本
        guard sample.timestamp < impactTime else { continue }

        // 挥棒持续时间不应超过合理范围（如 500ms）
        guard impactTime - sample.timestamp < 0.5 else { break }

        // 计算旋转速率沿重力方向的分量
        let rotationAlongGravity =
            sample.rotationRate.x * sample.gravity.x +
            sample.rotationRate.y * sample.gravity.y +
            sample.rotationRate.z * sample.gravity.z

        // 寻找从超过阈值到低于阈值的转变点
        if abs(rotationAlongGravity) < swingThreshold {
            return sample.timestamp
        }
    }

    return nil
}
```

キーポイント:
- ImpactTime からデバイスのモーション データを順方向にトラバースします
- 重力方向に沿った回転速度の成分は、身体の周りの手首の回転を反映します。
- この成分はスイング中は大幅にゼロではなく、静止状態ではゼロに近くなります。
- ノイズをフィルタリングするために適切なスイング継続時間の上限を設定します。

**ステップ 3: 接触時間を計算する**

```swift
func computeTimeToContact(impactTime: TimeInterval, swingStartTime: TimeInterval?) -> TimeInterval? {
    guard let startTime = swingStartTime else { return nil }

    // 验证挥棒期间累计旋转角度在合理范围
    let accumulatedRotation = computeAccumulatedRotation(from: startTime, to: impactTime)
    guard accumulatedRotation > minRotationThreshold && accumulatedRotation < maxRotationThreshold else {
        return nil
    }

    return impactTime - startTime
}
```

キーポイント:
- コンタクト時間 = インパクトの瞬間のタイムスタンプ - スイング開始のタイムスタンプ
- 回転角度を累積することにより、検出されたスイングが有効であるかどうかを検証します
- 誤検出をフィルタリングします（手を振る、姿勢を調整する、その他のスイング以外の動作など）

### ヒットとミスの信号の違い

([20:45](https://developer.apple.com/videos/play/wwdc2023/10179/?time=1245)) 講演者は、打球と外れ球の加速度計信号を比較しました。スイング自体はどちらの場合も似ていますが、インパクト時の振動パターンは著しく異なります。インパクト時には鋭い衝撃のピークがあり、ミス時にはより穏やかな振動になります。 800Hz のデータ ストリームではこの違いが捉えられますが、100Hz では区別できなくなります。

## 重要なポイント

**1.ヘッドトラッキング主導の空間オーディオ ゲーム**

- **内容**: AirPods のヘッド ジェスチャー データを使用して、ゲームの視点やメニューの選択を制御します
- **実行する価値がある理由**: ユーザーはデバイスを保持する必要がなく、頭を回すだけで操作できるため、フィットネスや VR 体験に適しています。
- **開始方法**:`CMHeadphoneMotionManager`得る`attitude`ゲームカメラのオイラー角にマッピングされたデータ

**2.ウォータースポーツ記録アプリ**

- **やるべきこと**: シュノーケリングやフリーダイビング愛好家向けに、水深曲線、水温変化、水中時間を記録します。
- **価値がある理由**: Apple Watch Ultra`CMWaterSubmersionManager`外部センサーを使用せずにネイティブの水深と水温 API を提供します
- **開始方法**: 「浅い深さと圧力」機能を構成し、深さと温度の更新を受信するデリゲートを実装し、それを HealthKit ワークアウトに重ね合わせます。

**3.スポーツ姿勢分析ツール**

- **内容**: 800Hz の加速度計と 200Hz のデバイスのモーション データを使用して、ゴルフ スイングやテニスのサーブなどを分析します。
- **価値がある理由**: 高周波データは、インパクトの瞬間のクラブヘッドスピードや手首のフリップ角度など、100Hz では区別できない動きの微妙な違いを捉えることができます。
- **開始方法**: HealthKit Workout を開始し、使用します。`CMBatchedSensorManager`非同期インターフェイスはデータをバッチで取得し、特定の動きの検出アルゴリズムを設計します。

**4.フィットネスアクションのカウントと品質評価**

- **何をするか**: 腕立て伏せ、スクワット、その他の動作の完了数を自動的に識別し、動作の品質を評価します。
- **実行する価値がある理由**: ヘッドトラッキングデータは体の姿勢を決定し、高周波加速度センサーは動きのリズムと振幅を検出できます。
- **開始方法**: AirPods は頭の姿勢のリファレンスを提供します。`CMBatchedSensorManager`手首の動きの詳細を提供し、その 2 つを組み合わせて全身の動きモデルを構築します
