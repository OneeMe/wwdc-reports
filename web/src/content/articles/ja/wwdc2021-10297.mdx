## Highlight

> Apple 扩展了 Apple Configurator：它可以恢复或救援 Apple silicon 与 T2 Mac，并在 iOS 15 中通过 iPhone 将非官方渠道购买的 Mac 加入 Apple Business Manager 或 Apple School Manager。

## 核心内容

一家学校或公司采购 Mac，理想情况是设备来自 Apple、授权经销商或运营商。这样的 Mac 可以直接分配到 Apple Business Manager（Apple 商务管理）或 Apple School Manager（Apple 校园教务管理），开机后进入自动设备注册（Automated Device Enrollment），再接入 MDM（移动设备管理）服务器。

现实常常没这么整齐。设备可能来自普通零售渠道，也可能是临时补货。只要它没有分配给组织，设置助理里就不会出现组织的 MDM 注册流程。IT 管理员只能手工处理，批量部署会变慢。

Apple Configurator 过去已经能把 iPhone、iPad 和 Apple TV 加入组织。WWDC 2021 的变化是 Mac 也进入这个流程。Apple 推出了 Apple Configurator for iPhone。管理员拿 iPhone 扫描 Mac 设置助理里的动画，就能把 Mac 分配给组织。

这场 session 还讲了另一个现场救援场景：Mac 更新中断后无法启动。对于 Apple silicon Mac 和 T2 Mac，Configurator 可以执行 Revive（救援），更新固件和 recoveryOS，并保留用户数据。准备给新用户使用时，则执行 Restore（恢复），抹掉用户数据并更新系统恢复环境。

### Mac 维修：Restore 和 Revive 的边界

Restore 用于重新交付设备。它会恢复固件，更新 recoveryOS，并抹掉所有用户数据。Apple silicon Mac 还会重新安装最新版本的 macOS。

Revive 用于设备无法启动但还要保留数据的场景。它会更新固件和 recoveryOS，不抹掉用户数据。典型例子是 MacBook Pro 在软件更新过程中电量耗尽。

### Mac 入库：用 iPhone 补上自动设备注册

组织管理 Mac 的关键，不在装应用的那一步，而在设备是否属于组织。只有分配到 Apple Business Manager 或 Apple School Manager，Mac 才能在设置助理中自动注册 MDM。

Apple Configurator for iPhone 解决的是这个入口问题。管理员使用带有设备注册管理员权限的 Managed Apple ID 登录，在 Mac 选择国家或地区的界面靠近设备，用 iPhone 相机扫描动画。配对成功后，Mac 会收到加入组织所需的信息。

加入组织后，还要在 Apple Business Manager 或 Apple School Manager 中把这台 Mac 从 Apple Configurator 2 MDM server 移到真正的 MDM server。下一次重启时，Mac 会下载新的自动设备注册设置，并按组织配置完成注册。

## 详细内容

### Restore：把 Mac 准备给下一个用户

（[01:39](https://developer.apple.com/videos/play/wwdc2021/10297/?time=99)）Apple Configurator 支持两类 Mac 维修动作。Restore 面向重新交付。Apple silicon Mac 执行 Restore 后，会重新安装最新 macOS；T2 Mac 会恢复固件，随后可通过互联网恢复重新安装 macOS。

```text
Restore workflow
1. Connect the Mac to the correct port.
2. Select the Mac in Apple Configurator.
3. Choose Restore.
4. Wait for firmware and recoveryOS to update.
5. For Apple silicon, install the latest macOS automatically.
6. Hand the Mac to the next user.
```

关键点：

- 第 1 行：连接端口是前置条件。Apple 在演讲中强调，MacBook Air、Mac mini、MacBook Pro 和 T2 Mac 的正确端口不同。
- 第 2 行：Configurator 以设备为中心操作，先选中目标 Mac。
- 第 3 行：Restore 用于准备新用户，不适合保留原用户数据的维修。
- 第 4 行：Restore 会更新固件和 recoveryOS。
- 第 5 行：Apple silicon Mac 会重新安装最新版本的 macOS。
- 第 6 行：设备回到可交付状态，用户数据已被抹掉。

### Revive：保留用户数据的 Mac 救援

（[02:01](https://developer.apple.com/videos/play/wwdc2021/10297/?time=121)）Revive 用于 Mac 无法启动但仍要保留用户数据的场景。演讲给出的例子是 MacBook Pro 在软件更新中耗尽电量。管理员在 Configurator 中选中设备，从 Advanced Actions 菜单选择 Revive。

```text
Revive workflow
1. Connect the affected Mac to the correct port.
2. Select the Mac in Apple Configurator.
3. Open Advanced Actions.
4. Choose Revive.
5. Update firmware and recoveryOS.
6. Keep user data in place.
```

关键点：

- 第 1 行：Revive 和 Restore 一样依赖正确端口。
- 第 2 行：目标设备必须在 Configurator 中可见。
- 第 3 行：Revive 位于 Advanced Actions 菜单。
- 第 4 行：这个动作面向恢复可启动状态。
- 第 5 行：系统更新的是固件和 recoveryOS。
- 第 6 行：Revive 的核心边界是保留用户数据。

### 自动设备注册：组织拥有权决定后续管理能力

（[04:05](https://developer.apple.com/videos/play/wwdc2021/10297/?time=245)）从 Apple、授权经销商或运营商购买的 Mac 可以分配到组织。分配完成后，自动设备注册会把 MDM 注册流程嵌入 macOS 设置助理。配合 AutoAdvance，Mac 接上电源和以太网后即可完成无接触配置。

```text
Automated Device Enrollment path
1. Mac is assigned to the organization.
2. Mac starts Setup Assistant.
3. Setup Assistant enrolls the Mac into the MDM solution.
4. MDM applies the organization configuration.
5. Mac is ready for an employee or a student.
```

关键点：

- 第 1 行：设备必须先归属 Apple Business Manager 或 Apple School Manager 中的组织。
- 第 2 行：用户看到的是系统设置助理中的原生流程。
- 第 3 行：注册动作连接到组织的 MDM 方案。
- 第 4 行：配置由 MDM server 下发。
- 第 5 行：设备完成设置后即可交给员工或学生。

### Apple Configurator for iPhone：扫描动画完成 Mac 分配

（[05:41](https://developer.apple.com/videos/play/wwdc2021/10297/?time=341)）Apple Configurator for iPhone 让管理员无需线缆即可分配 Mac。前提是使用 Managed Apple ID 登录，并且这个账号至少拥有设备注册管理员角色。实际操作发生在 Mac 设置助理选择国家或地区时。

```text
Configurator for iPhone assignment
1. Sign in with a Managed Apple ID.
2. Confirm the account has the Device Enrollment Manager role.
3. Start the Mac and select the language.
4. Stop at the country or region screen.
5. Bring the iPhone running Configurator near the Mac.
6. Center the animation in the iPhone camera viewfinder.
7. Wait for "Paired Successfully".
8. Let Configurator send the required organization assignment information.
```

关键点：

- 第 1 行：登录账号必须是 Managed Apple ID。
- 第 2 行：权限至少需要设备注册管理员角色。
- 第 3 行：Mac 从设置助理开始进入分配流程。
- 第 4 行：触发点是选择国家或地区的界面。
- 第 5 行：iPhone 与 Mac 近距离配对，无需线缆。
- 第 6 行：相机扫描的是 Mac 上出现的动画。
- 第 7 行：配对成功后，Mac 会显示成功消息。
- 第 8 行：Configurator 把加入组织所需的信息发送给 Mac。

### Wi-Fi 配置：用 iPhone 网络或配置描述文件

（[06:21](https://developer.apple.com/videos/play/wwdc2021/10297/?time=381)）Configurator for iPhone 的 Settings 按钮用于选择 Mac 入网方式。Mac 已连以太网时可以直接继续。没有以太网时，最简单的做法是共享 iPhone 当前连接的 Wi-Fi。若网络不可共享，可以选择带有 Wi-Fi payload 的 configuration profile（配置描述文件）。

```text
Network configuration options
1. If Ethernet is connected, use Ethernet.
2. Else, try sharing the iPhone current Wi-Fi network.
3. If that network is not shareable, choose a configuration profile.
4. Make sure the profile contains the Wi-Fi payload for the Mac.
```

关键点：

- 第 1 行：以太网连接时，Mac 已具备联网条件。
- 第 2 行：Configurator 可以共享 iPhone 当前 Wi-Fi。
- 第 3 行：部分网络不能共享，需要替代方案。
- 第 4 行：替代方案是包含 Wi-Fi payload 的配置描述文件。

### 分配后处理：把 Mac 移到正确的 MDM server

（[07:51](https://developer.apple.com/videos/play/wwdc2021/10297/?time=471)）Mac 加入组织只是第一步。接下来要登录 Apple Business Manager 或 Apple School Manager，把新分配的 Mac 从 Apple Configurator 2 MDM server 移到负责下发自动设备注册设置的 MDM server。Mac 下次重启时会下载新注册设置，并完成 MDM 注册。

```text
Post-assignment steps
1. Sign in to Apple Business Manager or Apple School Manager.
2. Find the newly assigned Mac.
3. Move it from Apple Configurator 2 MDM server.
4. Select the MDM server that has the correct automated device enrollment settings.
5. Restart the Mac.
6. Let the Mac download enrollment settings and enroll itself.
```

关键点：

- 第 1 行：后续管理在 Apple Business Manager 或 Apple School Manager 中完成。
- 第 2 行：目标是刚通过 iPhone 分配的 Mac。
- 第 3 行：新设备先出现在 Apple Configurator 2 MDM server 下。
- 第 4 行：要移到真正承载组织配置的 MDM server。
- 第 5 行：下一次重启会触发新设置下载。
- 第 6 行：Mac 按指定设置完成自动设备注册。

### 30 天临时期：用户可释放新分配的 Mac

（[08:40](https://developer.apple.com/videos/play/wwdc2021/10297/?time=520)）通过这个功能分配的 Mac 有 30 天 provisional period（临时期）。如果用户在这段时间内从 MDM 注销，Mac 会从组织中释放。这一点与 iOS 设备相同。

```text
Provisional period rule
1. Assign the Mac with Apple Configurator for iPhone.
2. Start the 30-day provisional period.
3. If the user unenrolls from MDM during this period, release the Mac from the organization.
4. If the period passes, keep the Mac assigned to the organization.
```

关键点：

- 第 1 行：规则适用于通过 iPhone Configurator 分配的 Mac。
- 第 2 行：临时期长度是 30 天。
- 第 3 行：临时期内注销 MDM 会释放组织分配关系。
- 第 4 行：演讲只说明了临时期内的释放行为，部署时应把这 30 天纳入交付流程。

## 核心启发

1. **做什么**：建立一套 Mac 救援台账，记录每次 Restore 或 Revive。
   **为什么值得做**：Configurator 已经覆盖 Apple silicon 和 T2 Mac 的恢复与救援，IT 团队可以把无法启动、准备转交两类场景拆开处理。
   **怎么开始**：以 Apple Configurator 的 Restore、Revive 操作为入口，在内部工单中强制记录设备型号、使用端口、动作类型和是否保留数据。

2. **做什么**：给非官方渠道 Mac 增加入库流程。
   **为什么值得做**：Apple Configurator for iPhone 可以把这类 Mac 分配到 Apple Business Manager 或 Apple School Manager，补齐自动设备注册入口。
   **怎么开始**：准备带设备注册管理员角色的 Managed Apple ID，在 Mac 设置助理选择国家或地区时，用 iPhone Configurator 扫描配对动画。

3. **做什么**：为批量 Mac 部署准备专用 Wi-Fi profile。
   **为什么值得做**：部分 Wi-Fi 网络无法从 iPhone 共享，演讲明确给出 configuration profile + Wi-Fi payload 的替代路径。
   **怎么开始**：在 Apple Configurator for iPhone 的 Settings 中测试网络配置，给不可共享网络准备只包含 Wi-Fi payload 的配置描述文件。

4. **做什么**：把“迁移到正确 MDM server”做成入库检查项。
   **为什么值得做**：Mac 通过 iPhone 分配后会先出现在 Apple Configurator 2 MDM server 下，不移动就拿不到正确的自动设备注册设置。
   **怎么开始**：在 Apple Business Manager 或 Apple School Manager 中建立操作步骤：找到新 Mac，移动到目标 MDM server，重启验证注册。

5. **做什么**：为 30 天临时期设置交付提醒。
   **为什么值得做**：用户在临时期内注销 MDM 会释放 Mac 的组织分配，影响后续管理能力。
   **怎么开始**：在设备交付当天创建 30 天检查任务，确认设备仍在 MDM 中注册，并保留 Apple Business Manager 或 Apple School Manager 中的分配记录。
