## ハイライト

> Apple と Box は、リモート勤務下のエンタープライズ アプリケーションに関する 4 つの重要なポイントについて話し合いました。Apple Business Manager のゼロタッチ展開、クラウド コンテンツのコラボレーション、消費者レベルのエクスペリエンス、および従業員がどのデバイスでもより迅速に仕事を開始できるようにする組み込みのセキュリティです。

## 主な内容

2020 年のエンタープライズ アプリケーションの問題は、もはやオフィス プロセスを画面に移動するだけではありません。アーロン・リービー氏は、疫病の影響で多くの企業が当初計画していたデジタル化計画を2年、5年、さらには10年かけて進めていると述べた。 Box 自体も、Web とモバイルのあらゆる部分を 1 秒以内に応答できるようにすることを目標に、アプリケーションのパフォーマンスを向上させています。会議室やホワイトボードで議論しているのは 12 人だけだったかもしれませんが、今では 100 人が Slack チャネルでアイデアを投稿しています。

リモートワークでは、デバイスの配信、アイデンティティ、セキュリティ、コラボレーションがすべて同じ問題に巻き込まれます。 Apple は、Mac を頻繁に使用し、ゼロタッチ導入を望んでいる IBM や Oracle などの企業に注目しています。デバイスは従業​​員に直接発送でき、従業員は会社の構成された環境を起動できます。 Box では、従業員が MacBook、iPhone、または iPad で企業データにアクセスし、ファイルを安全に共有し、クラウドでコラボレーションを継続する必要があるという裏側を見ています。

この会話は、エンタープライズ アプリケーションを判断するための一連の基準を提供するものであり、トピックは単一の API に当てはまりません。エンタープライズ ソフトウェアは、コンシューマー アプリケーションと同じくらい高速、明瞭、スムーズである必要があります。アーキテクチャはクラウド コラボレーションとモバイル ファーストをサポートする必要があります。セキュリティとプライバシーをデータ パス自体に組み込む必要があります。 Box の新しい iPad アプリは、Apple Pencil の注釈をサポートし、Web またはデスクトップ上の共同作業者に注釈を表示できるようにする予定であり、これはこの標準の具体例です。

Apple と Box が示した方向性も明確です。まず、従業員と顧客に届くハイレバレッジのエクスペリエンスを変革し、次に基盤となるレガシー システムに対処します。銀行の顧客は、口座開設時に紙と署名に頼るべきではなくなります。医療、教育、ライフサイエンスも、元のプロセスをデジタルエクスペリエンスに書き直す必要があります。したがって、製品、クラウド サービス、デバイス管理、セキュリティ ポリシーはすべてアプリケーション層で実装する必要があるため、開発者の立場はさらに高度になります。

＃＃詳細

### ゼロタッチ導入では、最初に機器を設置します

([02:10](https://developer.apple.com/videos/play/wwdc2020/10204/?time=130)) Apple は、リモート作業環境において、企業は Apple Business Manager を通じてゼロタッチ展開を行うことを望んでいると述べました。デバイスは新規または既存の従業員に直接発行でき、従業員はデバイスを受け取った後に構成済みの状態に入ることができます。

([07:20](https://developer.apple.com/videos/play/wwdc2020/10204/?time=440)) マイク・アボットは、Apple がゼロタッチ Mac 導入とオートアドバンスを拡張し、組織がコンピュータを注文し、従業員がコンピュータを接続して作業を開始できるようにしているとも述べました。 Aaron Levie 氏の個人的な例としては、Box でリモートワークを開始した後、新しい iMac をセットアップしたところ、約 5 分でビジネスに不可欠なすべてのアプリケーションにアクセスできるようになり、同僚と安全にコラボレーションできるようになったことが挙げられます。

```text
远程设备交付工作流
1. 企业通过 Apple Business Manager 准备设备
2. 设备直接寄给员工
3. 员工开机后进入组织配置好的环境
4. 企业应用、云端内容和安全策略一起到位
5. 员工从任意地点开始访问关键业务应用
```

キーポイント:

- Apple Business Manager のゼロタッチ導入シナリオのステップ 1 のトランスクリプト。
- ステップ 2 と 3 では、リモートの従業員が機器を取りにオフィスに戻ることができないという問題を解決します。
- ステップ 4 エンタープライズ アプリケーションとセキュリティ ポリシーを同じデリバリー チェーンに配置します。
- ステップ 5 は、Aaron Levie が述べた、新しい機器が正常に動作するまでの 5 分間に相当します。

### エンタープライズ アプリケーションは消費者レベルのエクスペリエンスを実現する必要があります

([06:00](https://developer.apple.com/videos/play/wwdc2020/10204/?time=360)) Box は、Apple デバイス、クラウド サービス、エンタープライズ セキュリティを 1 つのエクスペリエンス チェーンとして捉えています。 Aaron Levie 氏は、Box が Apple プラットフォームで iOS ファーストの戦略を採用し、消費者レベルのエクスペリエンスをエンタープライズ環境にもたらすことを明らかにしました。

([10:34](https://developer.apple.com/videos/play/wwdc2020/10204/?time=634)) 開発者に対する彼の最初のアドバイスは、消費者を第一に考えることです。企業の従業員は、私生活において高速で明確なアプリケーション エクスペリエンスに慣れています。ソフトウェアを作業に戻すときは、遅さや複雑さを受け入れるべきではありません。

([05:04](https://developer.apple.com/videos/play/wwdc2020/10204/?time=304)) Box は、Apple Pencil をサポートしてドキュメントにリアルタイムで注釈を付け、これらの注釈を Web またはデスクトップ上の共同作業者に表示できる新しい iPad アプリを開発しています。消費者レベルのエクスペリエンスの価値は、単なる視覚的な変更ではなく、リモート コラボレーションのアクションを短縮することにあります。

```text
企业协作体验检查
1. iPhone 上能快速打开文档、聊天或视频
2. iPad 上能用 Apple Pencil 对文档标注
3. Web 和桌面端能看到同一份协作结果
4. 分享动作默认考虑企业权限和安全边界
```

キーポイント:

- ステップ 1 は、モバイルファースト環境およびリモート環境での iPhone の頻繁な使用に関する記録の説明に対応します。
- ステップ 2 Box の新しい iPad アプリからの Apple Pencil 注釈プログラム。
- ステップ 3 は、Web またはデスクトップ上の共同作業者が見ることができるシーンに注釈を付けることから始まります。
- ステップ 4 は、企業コンテンツの安全な共有に関する Box の立場に対応します。

### セキュリティを製品設計に組み込む必要がある

([11:41](https://developer.apple.com/videos/play/wwdc2020/10204/?time=701)) Aaron Levie は 3 番目のヒントとして、設計によるセキュリティについて言及しました。病院、政府機関、ライフ サイエンス組織、銀行、大学、幼稚園から高等学校までの教育にサービスを提供するエンタープライズ アプリケーションの場合、セキュリティとデータ プライバシーが製品の中核となる必要があります。

([12:39](https://developer.apple.com/videos/play/wwdc2020/10204/?time=759))Box は、iOS デバイスの暗号化、Mac のセキュリティ機能、ネイティブ API エクスペリエンス、MDM などのエンタープライズ管理テクノロジなど、Apple デバイスが提供する基礎的な機能に依存していると述べました。これらの機能はプラットフォームの選択と製品設計に組み込む必要があり、発売前に追加したままにすることはできません。

([15:18](https://developer.apple.com/videos/play/wwdc2020/10204/?time=918)) さらに大きな課題は、責任の境界です。これまで開発者は、データ セキュリティはデバイス、ネットワーク プロバイダー、またはセキュリティ ベンダーに属するものと考えていたかもしれません。 Aaron Levie 氏の主張は、21 世紀のエンタープライズ ソフトウェア開発者は、データを扱うあらゆる方法にセキュリティを組み込む必要があるということです。

```text
企业数据路径检查
1. 设备端：利用平台加密和系统安全能力
2. 应用端：只展示用户有权访问的企业内容
3. 分享端：把合作伙伴、同事和外部人员的权限分开处理
4. 云端：让协作状态在不同设备上保持一致
5. 管理端：接入组织已有的管理和更新节奏
```

キーポイント:

- ステップ 1 は、iOS の暗号化と Mac のセキュリティ機能に対応します。
- ステップ 2 は、トランスクリプトのアクセス境界「アクセスできる企業内のすべてのデータにアクセスする」に由来します。
- 社内外の人々とファイルを安全に共有するという Box の説明のステップ 3。
- ステップ 4 は、クラウド コンテンツのコラボレーションとクロスデバイス アクセスに対応します。
- ステップ 5 は、企業の更新頻度、MDM、およびリモート管理のニーズに対応します。

### クラウドと機器を再分割する必要がある

([16:12](https://developer.apple.com/videos/play/wwdc2020/10204/?time=972)) Aaron Levie 氏は、現代のエンタープライズ ソフトウェアはマイクロサービス (マイクロサービス) と継続的インテグレーション (継続的インテグレーション) を指向すべきであると考えています。 Box は、リリースの頻度を四半期または年次から毎日のリリースに調整し、クラウド サービスを継続的に改善しています。

([17:30](https://developer.apple.com/videos/play/wwdc2020/10204/?time=1050)) デバイスとクラウドの役割分担も再評価する必要があります。どのロジックをクラウドに配置し、どのロジックをデバイスに配置するかは、パフォーマンス、セキュリティ、プライバシー、デバイスの機能に基づいて判断する必要があります。同氏は特に、Core MLがローカルの処理能力とプライバシーの利点を活用して、デバイス上で機械学習を実行できることについて言及した。

([18:29](https://developer.apple.com/videos/play/wwdc2020/10204/?time=1109)) ブラウザと iOS デバイスにも同じ判断が適用されます。最新の HTML5 とデバイス機能により、サーバー上に配置されていた一部の処理ロジックをクライアントに返すことが可能になり、ローカル キャッシュによってエクスペリエンスも高速化されます。

```text
功能拆分工作流
输入：一个新的企业协作功能
判断：
- 对延迟、隐私或离线体验敏感的逻辑，优先放到设备端
- 跨用户共享、权限和同步状态，优先交给云端服务
- 需要高频迭代的能力，拆成独立服务并接入持续集成
输出：设备端响应更快，云端协作保持一致
```

キーポイント:

- 最初の判断は、記録における Core ML、デバイスの処理能力、セキュリティ、プライバシーに関する議論から得られます。
- 2 番目の判断は、クラウド コンテンツ管理とリモート コラボレーションに対する Box の位置付けから来ています。
- 3 番目の判断は、マイクロサービス、毎日のリリース、継続的インテグレーションの開発リズムから得られます。
- 出力目標は、1 秒未満の遅延に関する Box のパフォーマンス目標に対応します。

### リモート コラボレーションは同期と非同期の両方をサポートする必要があります

([19:24](https://developer.apple.com/videos/play/wwdc2020/10204/?time=1164)) Aaron Levie 氏は、将来の仕事では、従業員は場所、デバイス、ネットワークを問わず、組織内の人々とリアルタイムで共同作業する必要があると考えています。新しい機会は、同期作業と非同期作業の組み合わせにあります。

([20:00](https://developer.apple.com/videos/play/wwdc2020/10204/?time=1200)) 彼が挙げた例は非常に具体的です。最初に完全な会議をスケジュールしなくても、数秒でビデオ通話を開始できます。リアルタイムでドキュメントを共同作業します。デバイスとネットワーク間で情報を共有する方法が増えました。新しいエンタープライズ アプリケーションは、これらの小さなアクションから始めて、ワークフローを変革できます。

```text
远程协作动作
1. 从文档直接进入视频或聊天
2. 在文档中留下可追踪的标注和评论
3. 把关键上下文同步到其他设备
4. 让没有参加实时会议的人之后也能继续处理
```

キーポイント:

- トランスクリプトからのステップ 1 数秒でビデオ通話ができるというアイデア。
- ステップ 2 Box のドキュメント コラボレーションと Apple Pencil の注釈シーンを接続します。
- ステップ 3 は、デバイスとネットワーク全体での作業に対応します。
- ステップ 4: 同期作業と非同期作業の組み合わせから機会を判断します。

## 重要なポイント

- **リモート オンボーディング ステータス ページ**
- **やるべきこと**: 新入社員向けのオンボーディング ページを作成し、デバイスが Apple Business Manager に入ったかどうか、主要なアプリケーションが利用可能かどうか、クラウド コンテンツの権限が有効かどうかを表示します。
- **実行する価値がある理由**: リモートの従業員はどこからでも勤務状況を迅速に入力する必要があり、デバイスの配送とアプリケーションへのアクセスを個別に処理することはできないことがセッションで繰り返し述べられています。
- **開始方法**: まず、コンピューターの電源を入れた後に従業員が完了する必要がある 5 つのアクションをリストし、デバイスの状態、アプリケーションのインストールの状態、アカウントの権限を同じチェックリストに作成します。

- **ドキュメント注釈のコラボレーション フロー**
- **対処方法**: iPad 注釈ポートをエンタープライズ ドキュメント アプリに追加して、Apple Pencil で書かれた注釈を Web とデスクトップに同期できるようにします。
- **実行する価値がある理由**: Box が開発中の新しい iPad アプリは、リモート コラボレーション機能として Apple Pencil 注釈を使用しています。これは、スタンドアロンで描画するよりも価値があります。
- **開始方法**: まず 1 つのファイル タイプをサポートし、「ドキュメントを開く、注釈を追加する、クラウドに同期する、共同作業者に通知する」という 4 つの手順を実行します。

- **モバイルセーフ共有パネル**
- **内容**: 同僚、外部コラボレーター、パブリック リンクに対する明確な権限を備えた共有パネルを iPhone および iPad に提供します。
- **実行する価値がある理由**: Box の目標は、リモートおよび分散作業でコンテンツを安全に管理することであり、モバイル共有は高頻度のアクションです。
- **開始方法**: 既存のファイル共有プロセスで最もあいまいなステップを見つけ、受信者の ID、有効期限、アクセス範囲を同じ確認インターフェイスに入力します。

- **クラウドとデバイスのパフォーマンス予算**
- **対処方法**: エンタープライズ アプリケーションのクリティカル パスに 1 秒の応答目標を設定し、項目ごとの判定ロジックをデバイス、ブラウザ、またはクラウド上に配置する必要があります。
- **実行する価値がある理由**: Box は、アプリケーションのすべての部分で 1 秒未満のレイテンシーを達成するよう推進しています。このトランスクリプトでは、ローカル処理、キャッシュ、Core ML、クラウド サービス間の分業についても具体的に説明しています。
- **開始方法**: まず、最も遅い 3 つのユーザー アクションを記録し、次に遅延、プライバシー、共有ステータスの 3 つの側面に基づいて移行の方向を決定します。

- **同期および非同期のコラボレーション ポータル**
- **内容**: ワンクリックでビデオ、チャット、フォローアップ コメント エントリをドキュメント、タスク、または顧客レコードに追加します。
- **実行する価値がある理由**: Session は、将来の作業には同期コラボレーションと非同期コラボレーションが混在するようになり、アプリケーションではユーザーが数秒でコンテンツからコミュニケーションに移行できる必要があると考えています。
- **開始方法**: チームが毎日開くビジネス オブジェクトを選択し、「リアルタイム ディスカッションの開始」と「非同期コンテキストの終了」を同じ画面に配置します。
