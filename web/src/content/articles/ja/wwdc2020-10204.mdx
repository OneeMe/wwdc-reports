## Highlight

> Apple 与 Box 讨论了远程办公下企业应用的四个落点：Apple Business Manager 零接触部署、云端内容协作、消费级体验和内建安全，让员工在任意设备上更快进入工作状态。

## 核心内容

2020 年的企业应用问题，不再只是把办公室里的流程搬到屏幕上。Aaron Levie 说，疫情让许多公司把原本两年、五年甚至十年后的数字化计划提前执行。Box 自己也在改进应用性能，目标是让 Web 和移动端的每个部分都在一秒内响应；原来可能只有十几个人在会议室和白板前讨论，现在有一百个人在 Slack 频道里贡献想法。

远程工作把设备交付、身份、安全和协作都推到了同一个问题里。Apple 看到 IBM、Oracle 等大量使用 Mac 的企业想要零接触部署：设备可以直接寄给员工，员工开机后就进入公司配置好的环境。Box 看到的是另一面：员工需要在 MacBook、iPhone 或 iPad 上访问企业数据，安全地分享文件，并在云端继续协作。

这场对谈给出了一套企业应用判断标准，主题不落在某个单独 API 上。企业软件要像消费者应用一样快、清楚、顺手；架构要支持云端协作和移动优先；安全和隐私要进入数据路径本身。Box 的新 iPad 应用计划支持 Apple Pencil 标注，并让标注能被 Web 或桌面端的协作者看到，这正是这种标准的具体例子。

Apple 和 Box 给出的方向也很明确：先改造触达员工和客户的高杠杆体验，再处理底层遗留系统。银行客户开户不该再依赖纸张和签名，医疗、教育、生命科学也需要把原有流程重写成数字化体验。开发者的位置因此更靠前，因为产品、云服务、设备管理和安全策略都要在应用层一起落地。

## 详细内容

### 零接触部署让设备先到位

（[02:10](https://developer.apple.com/videos/play/wwdc2020/10204/?time=130)）Apple 提到，远程工作环境里，企业希望通过 Apple Business Manager 做零接触部署。设备可以直接发给新员工或现有员工，员工拿到后就能进入配置好的状态。

（[07:20](https://developer.apple.com/videos/play/wwdc2020/10204/?time=440)）Mike Abbott 还提到，Apple 正在扩展零接触 Mac 部署和 auto-advance，让组织订购电脑后，员工插上电就能开始工作。Aaron Levie 的个人例子是，他在 Box 进入远程工作后设置一台新 iMac，大约五分钟就访问到所有关键业务应用，并能安全地和同事协作。

```text
远程设备交付工作流
1. 企业通过 Apple Business Manager 准备设备
2. 设备直接寄给员工
3. 员工开机后进入组织配置好的环境
4. 企业应用、云端内容和安全策略一起到位
5. 员工从任意地点开始访问关键业务应用
```

关键点：

- 第 1 步来自 transcript 中的 Apple Business Manager 零接触部署场景。
- 第 2 步和第 3 步解决的是远程员工不能回到办公室领设备的问题。
- 第 4 步把企业应用和安全策略放在同一条交付链路里。
- 第 5 步对应 Aaron Levie 提到的新设备五分钟进入工作状态。

### 企业应用要达到消费级体验

（[06:00](https://developer.apple.com/videos/play/wwdc2020/10204/?time=360)）Box 把 Apple 设备、云服务和企业安全看作同一条体验链。Aaron Levie 明确说，Box 在 Apple 平台上采用 iOS-first 策略，并把消费级体验带到企业环境里。

（[10:34](https://developer.apple.com/videos/play/wwdc2020/10204/?time=634)）他给开发者的第一条建议是 think consumer first。企业员工在个人生活里已经习惯了快速、清楚的应用体验，回到工作软件后不该接受缓慢和复杂。

（[05:04](https://developer.apple.com/videos/play/wwdc2020/10204/?time=304)）Box 正在开发新版 iPad 应用，支持 Apple Pencil 对文档实时标注，并让 Web 或桌面端协作者看到这些标注。消费级体验的价值在于把远程协作动作做短，而不只停留在视觉修饰。

```text
企业协作体验检查
1. iPhone 上能快速打开文档、聊天或视频
2. iPad 上能用 Apple Pencil 对文档标注
3. Web 和桌面端能看到同一份协作结果
4. 分享动作默认考虑企业权限和安全边界
```

关键点：

- 第 1 步对应 transcript 中移动优先和远程环境里频繁使用 iPhone 的描述。
- 第 2 步来自 Box 新 iPad 应用的 Apple Pencil 标注计划。
- 第 3 步来自标注可被 Web 或桌面端协作者看到的场景。
- 第 4 步对应 Box 对安全分享企业内容的定位。

### 安全要进入产品设计

（[11:41](https://developer.apple.com/videos/play/wwdc2020/10204/?time=701)）Aaron Levie 把 security by design 作为第三条建议。企业应用要服务医院、政府机构、生命科学组织、银行、大学和 K-12 教育，安全和数据隐私必须进入产品核心。

（[12:39](https://developer.apple.com/videos/play/wwdc2020/10204/?time=759)）他提到 Box 依赖 Apple 设备提供的底层能力，包括 iOS 设备上的加密、Mac 上的安全能力、原生 API 体验，以及 MDM 等企业管理技术。这些能力要进入平台选择和产品设计，不能留到上线前补。

（[15:18](https://developer.apple.com/videos/play/wwdc2020/10204/?time=918)）更大的挑战是责任边界。过去开发者可能认为数据安全属于设备、网络供应商或安全厂商。Aaron Levie 的观点是，21 世纪的企业软件开发者必须把安全放进每一种数据处理方式。

```text
企业数据路径检查
1. 设备端：利用平台加密和系统安全能力
2. 应用端：只展示用户有权访问的企业内容
3. 分享端：把合作伙伴、同事和外部人员的权限分开处理
4. 云端：让协作状态在不同设备上保持一致
5. 管理端：接入组织已有的管理和更新节奏
```

关键点：

- 第 1 步对应 iOS 加密和 Mac 安全能力。
- 第 2 步来自 transcript 中“get to all of the data in your enterprise that you have access to”的访问边界。
- 第 3 步来自 Box 对安全分享文件给业务内外人员的描述。
- 第 4 步对应云端内容协作和跨设备访问。
- 第 5 步对应企业更新节奏、MDM 和远程管理需求。

### 云端和设备要重新分工

（[16:12](https://developer.apple.com/videos/play/wwdc2020/10204/?time=972)）Aaron Levie 认为现代企业软件要面向 microservices（微服务）和 continuous integration（持续集成）。Box 已经把发布节奏从季度或年度，调整到每日发布和云服务持续改进。

（[17:30](https://developer.apple.com/videos/play/wwdc2020/10204/?time=1050)）设备端和云端的分工也要重新评估。哪些逻辑放在云端，哪些逻辑放在设备上，要根据性能、安全、隐私和设备能力来判断。他特别提到 Core ML 可以在设备上运行机器学习，利用本地处理能力和隐私优势。

（[18:29](https://developer.apple.com/videos/play/wwdc2020/10204/?time=1109)）同样的判断也适用于浏览器和 iOS 设备。现代 HTML5 和设备性能已经让一些过去放在服务端的处理逻辑可以回到客户端，本地缓存也能让体验更快。

```text
功能拆分工作流
输入：一个新的企业协作功能
判断：
- 对延迟、隐私或离线体验敏感的逻辑，优先放到设备端
- 跨用户共享、权限和同步状态，优先交给云端服务
- 需要高频迭代的能力，拆成独立服务并接入持续集成
输出：设备端响应更快，云端协作保持一致
```

关键点：

- 第一条判断来自 transcript 中对 Core ML、设备处理能力、安全和隐私的讨论。
- 第二条判断来自 Box 对云内容管理和远程协作的定位。
- 第三条判断来自微服务、每日发布和持续集成的开发节奏。
- 输出目标对应 Box 对 sub-second latency 的性能目标。

### 远程协作要同时支持同步和异步

（[19:24](https://developer.apple.com/videos/play/wwdc2020/10204/?time=1164)）Aaron Levie 认为，未来工作会要求员工在任意地点、任意设备、任意网络上与组织内的人实时协作。新的机会在同步工作和异步工作的组合上。

（[20:00](https://developer.apple.com/videos/play/wwdc2020/10204/?time=1200)）他举的例子很具体：几秒内发起视频通话，不必先排完整会议；在文档上实时协作；用更多方式在设备和网络之间分享信息。新的企业应用可以从这些小动作开始改造工作流。

```text
远程协作动作
1. 从文档直接进入视频或聊天
2. 在文档中留下可追踪的标注和评论
3. 把关键上下文同步到其他设备
4. 让没有参加实时会议的人之后也能继续处理
```

关键点：

- 第 1 步来自 transcript 中几秒内进入视频通话的设想。
- 第 2 步连接 Box 的文档协作和 Apple Pencil 标注场景。
- 第 3 步对应跨设备、跨网络的工作方式。
- 第 4 步来自同步和异步工作组合的机会判断。

## 核心启发

- **远程入职状态页**
  - **做什么**：为新员工做一个入职页，显示设备是否已进入 Apple Business Manager、关键应用是否可用、云端内容权限是否生效。
  - **为什么值得做**：session 中反复提到远程员工要从任意地点快速进入工作状态，设备交付和应用访问不能分开处理。
  - **怎么开始**：先列出员工开机后必须完成的五个动作，把设备状态、应用安装状态和账号权限做成同一张检查清单。

- **文档标注协作流**
  - **做什么**：给企业文档 App 增加 iPad 标注入口，让 Apple Pencil 写下的批注同步到 Web 和桌面端。
  - **为什么值得做**：Box 正在做的新版 iPad 应用把 Apple Pencil 标注作为远程协作能力使用，价值超过单机绘图。
  - **怎么开始**：先支持一个文件类型，打通“打开文档、添加标注、同步到云端、通知协作者”四个步骤。

- **移动安全分享面板**
  - **做什么**：在 iPhone 和 iPad 上提供一个分享面板，明确区分同事、外部合作方和公开链接的权限。
  - **为什么值得做**：Box 的目标是在远程和分布式工作里安全管理内容，移动端分享是高频动作。
  - **怎么开始**：从现有文件分享流程中找出权限最模糊的一步，把接收者身份、过期时间和访问范围放到同一个确认界面。

- **云端和设备的性能预算**
  - **做什么**：给企业应用的关键路径设定一秒内响应目标，逐项判断逻辑应放在设备端、浏览器端或云端。
  - **为什么值得做**：Box 正在推动应用各部分达到 sub-second latency，transcript 中还专门讨论了本地处理、缓存、Core ML 和云服务的分工。
  - **怎么开始**：先记录最慢的三个用户动作，再按延迟、隐私、共享状态三个维度决定迁移方向。

- **同步和异步协作入口**
  - **做什么**：在文档、任务或客户记录中加入一键视频、聊天和后续评论入口。
  - **为什么值得做**：session 认为未来工作会混合同步协作和异步协作，应用需要让用户在几秒内从内容进入沟通。
  - **怎么开始**：挑一个团队每天都会打开的业务对象，把“发起实时讨论”和“留下异步上下文”放在同一屏。
