### Swift マクロの実際の形式

マクロには 2 つの形式があります。独立したマクロの場合（自立型）`#`プレフィックス:

```swift
let url = #URL("https://developer.apple.com")
```

アタッチされたマクロに使用されます (Attached)`@`プレフィックスを付けて、既存のステートメントを直接変換します。

```swift
@AddAsync
func fetchContent(completion: @escaping (Result<String, Error>) -> Void) {
    // 原有实现
}

// 宏自动生成 async 版本，可以直接调用：
let content = try await fetchContent()
```

キーポイント:
- `#URL`文字列形式はコンパイル中に検証され、不正な URL は直接コンパイルされてエラーが報告されます。
-`@AddAsync`2 番目の関数を手書きする必要はなく、生成されたコードは Xcode で展開して表示できます。
- デバッグ時、マクロ展開後のコードにステップインでき、動作は完全に透過的です

### SwiftData の最小使用パス

```swift
import SwiftData

@Model
class Backyard {
    var name: String
    var birds: [Bird]
    var foodLevel: Int
}

// 根视图设置容器
.windowStyle(.automatic)
.modelContainer(for: Backyard.self)

// 视图读取数据
@Query var backyards: [Backyard]
```

キーポイント:
- `@Model`代わりの`@Observable`、持続性と観察能力を同時に獲得します。
-`modelContainer`アプリレベルで一度設定します
-`@Query`永続ストレージからデータを自動的にロードし、ウィジェットもアクセスできる
- 元に戻す/やり直しをサポートし、追加のコードは必要ありません

### VisionOS アプリケーションの 3 層空間モデル

|要素 |目的 | SwiftUI シーン タイプ |
|------|------|------|
|ウィンドウ |従来の 2D インターフェイス、3D コンテンツを含めることが可能 |`WindowGroup`|
|ボリューム |あらゆる角度から見える3Dオブジェクトを表示 |`WindowGroup` + `defaultSize`|
|フルスペース |他のアプリケーションを非表示にして、完全に没入型のエクスペリエンスを実現 |`ImmersiveSpace` |

([01:03:22](https://developer.apple.com/videos/play/wwdc2023/102/?time=3802)) SwiftUI は、visionOS 上の RealityKit を介してレンダリングされるため、SwiftUI と RealityKit API を直接混合できます。オーナメントはウィンドウの端に取り付けられ、ホバー効果は視線に自動的に反応し、マテリアルは周囲の照明に基づいて動的に調整されます。

## 重要なポイント

- **マクロを使用してチーム内の重複テンプレートを排除**: チームに同様のボイラープレート コード (ネットワーク リクエストのカプセル化、ロギング、ステート マシン変換など) が大量にある場合は、内部マクロ パッケージを作成し、Swift パッケージを通じて共有できます。これはコード ジェネレーターよりも軽量であり、コンパイラーと統合されています。

- **新しいプロジェクトのデフォルトの永続化ソリューションとして SwiftData を使用します**: iOS 16 以前のバージョンと互換性がある必要のない新しいプロジェクトは、SwiftData を直接使用して Core Data を置き換えることができます。モデル クラスは純粋な Swift で記述されており、.xcdatamodeld ファイルを必要としないため、チーム メンバーが理解しやすくなっています。

- **高頻度の軽量操作をウィジェットに追加**: アプリ内で最もよく使用されるシングルステップ操作 (完了のマーク付け、お気に入りの切り替え、開始タイミングなど) を整理し、ウィジェット内のボタンまたはトグルにします。ユーザーはアプリを開く必要がなく、使用頻度が大幅に向上します。

- **visionOS の「ここでしか起こり得ない」瞬間を見つけてください**: アプリ全体を宇宙プラットフォームに移動しようとしないでください。パノラマ写真閲覧、3Dモデル表示、多人数コラボレーションホワイトボードなど、既存の機能の中から「広い空間で見たほうが衝撃的だろう」シーンを見つけて、その瞬間だけを最適化する。
