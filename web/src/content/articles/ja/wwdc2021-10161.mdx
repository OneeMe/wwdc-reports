## ハイライト

> EDR を使用すると、アプリケーションは HDR をサポートするディスプレイ上で SDR 範囲 (>1.0) を超える輝度値を出力できます。システムは、表示機能に基づいてトーン マッピングを自動的に実行します。 Pro Display XDR では、SDR の最大約 6 倍の明るさに達します。

## 主な内容

レンダリング エンジンは、0 ～ 1 の範囲のカラー値を出力します。これは SDR ディスプレイでは問題ありませんが、HDR ディスプレイではハードウェアの電力を無駄に消費します。 Pro Display XDR は、SDR よりも 6 倍明るいピクセルを表示でき、MacBook Pro は 2 ～ 3 倍明るいピクセルを表示できます。この特別なダイナミックレンジをどのように活用すればよいでしょうか?

EDR (Extended Dynamic Range) は Apple のソリューションです。カラー管理に似ていますが、明るさの範囲を管理します。

＃＃詳細

### EDR とは何ですか?

（[00:50](https://developer.apple.com/videos/play/wwdc2021/10161/?time=50)）

EDR は、次の 2 つのことを同時に指します。

1. **HDR 表現形式**: 1.0 を超えるカラー値を許可します
2. **HDR レンダリング テクノロジ**: ディスプレイ機能に応じてシステムが自動的にマッピングします。

SDR システムでは、白は 1.0 として定義されます。 EDR では、1.0 は依然として SDR 白ですが、1.0 を超える値が許可されます。表示する際は、システムが自動的に決定します。明るいピクセルは HDR 画面に直接表示され、SDR 画面ではトーン マッピングが実行されて 1.0 範囲に圧縮されます。

（[02:30](https://developer.apple.com/videos/play/wwdc2021/10161/?time=150)）

**キーポイント:**
- SDR ホワイト = 1.0
- EDR の許容値 > 1.0
- システムは HDR および SDR ディスプレイのマッピングを自動的に処理します
- モニターが異なれば EDR の上限も異なります

### EDR サポートを追加する 4 つのステップ

（[03:37](https://developer.apple.com/videos/play/wwdc2021/10161/?time=217)）

Apple は、EDR を追加するための 4 つの手順を推奨しています。

1. **EDR サポートの検出**
2. **レンダリング ターゲットの構成**
3. **シェーダーで HDR 値を出力**
4. **トーンマッピングの処理**

### EDR サポートの検出

（[05:00](https://developer.apple.com/videos/play/wwdc2021/10161/?time=300)）

```swift
// 检查屏幕是否支持 EDR
let screen = window.screen
let maxEDR = screen.maximumExtendedDynamicRangeColorComponentValue

if maxEDR > 1.0 {
    // 支持 EDR
    print("EDR max: \(maxEDR)")  // Pro Display XDR 上约 6.0
}
```

（[05:00](https://developer.apple.com/videos/play/wwdc2021/10161/?time=300)）

**キーポイント:**
- `maximumExtendedDynamicRangeColorComponentValue`EDRキャップを返却
- 1.0 は EDR がサポートされていないことを意味します
- 値が大きいほど、モニターの HDR 機能が強化されます。
- 画面ごとに値が異なる場合があります

### CAMetalLayer を構成する

（[17:52](https://developer.apple.com/videos/play/wwdc2021/10161/?time=1072)）

```swift
// 配置 Metal layer 支持 EDR
metalLayer.wantsExtendedDynamicRangeContent = true
metalLayer.pixelFormat = .rgba16Float  // 16-bit float 格式

// 设置 colorspace
if let edrColorSpace = CGColorSpace(name: CGColorSpace.displayP3_PQ) {
    metalLayer.colorspace = edrColorSpace
}
```

（[18:53](https://developer.apple.com/videos/play/wwdc2021/10161/?time=1133)）

**キーポイント:**
- `wantsExtendedDynamicRangeContent = true`EDRを有効にする
- 16 ビット浮動小数点ピクセル形式を使用します (`.rgba16Float`）
- HDR をサポートする色空間を選択します (Display P3 PQ など)
- EDR 機能を最大限に活用するには、全画面表示または別のウィンドウが必要です

### シェーダーで HDR 値を出力する

（[20:30](https://developer.apple.com/videos/play/wwdc2021/10161/?time=1230)）

```metal
fragment float4 hdrFragment(...) {
    // 场景渲染
    float3 sceneColor = computeLighting(...);

    // 场景值可能超过 1.0
    // 比如太阳反射可能达到 4.0 或更高

    // 直接输出，EDR 系统会处理映射
    return float4(sceneColor, 1.0);
}
```

（[21:00](https://developer.apple.com/videos/play/wwdc2021/10161/?time=1260)）

**キーポイント:**
- 1.0を超える値を直接出力
- 手動クランプは不要です
- EDR システムはモニター機能に基づいて自動的にマッピングします
- 線形空間を維持し、ガンマ補正を行わない

### Tone Mapping

（[22:30](https://developer.apple.com/videos/play/wwdc2021/10161/?time=1350)）

SDR ディスプレイの場合、システムは自動的にトーン マッピングを実行します。ただし、マッピング カーブを自分で制御したい場合は、シェーダーで行うことができます。

```metal
float3 toneMap(float3 hdrColor, float maxEDR) {
    // 简单的 Reinhard tone mapping
    float3 mapped = hdrColor / (1.0 + hdrColor);

    // 或者使用 ACES filmic tone mapping
    // mapped = ACESFilm(hdrColor);

    return mapped;
}
```

（[23:30](https://developer.apple.com/videos/play/wwdc2021/10161/?time=1410)）

**キーポイント:**
- システムは SDR ディスプレイのマッピングを自動的に処理します
- カスタム トーン マッピングは、特定のスタイルが必要な場合にのみ使用されます。
-最後のステップまで線形スペースを維持します
- シナリオが異なれば、異なるトーン マッピング カーブが必要になる場合があります

### EDR と AVPlayer

（[16:00](https://developer.apple.com/videos/play/wwdc2021/10161/?time=960)）

AVPlayer は自動的に EDR をサポートします。 HDR コンテンツを再生する場合、モニターの EDR 機能が自動的に利用されます。

```swift
let player = AVPlayer(url: hdrVideoURL)
let playerLayer = AVPlayerLayer(player: player)

// AVPlayer 自动处理 EDR，不需要额外配置
playerLayer.videoGravity = .resizeAspect
```

（[16:00](https://developer.apple.com/videos/play/wwdc2021/10161/?time=960)）

**キーポイント:**
- AVPlayer は HDR コンテンツを自動的に検出します
- EDR 表示機能を自動的に活用
- 手動構成は必要ありません
- SDR ディスプレイでの自動トーン マッピング

## 重要なポイント

1. **ゲームに HDR ハイライト効果を追加**。太陽、爆発、ネオンライトなどの光源は、SDR の 2 ～ 6 倍の輝度を出力できます。入口API：`metalLayer.wantsExtendedDynamicRangeContent = true`。

2. **16 ビット浮動小数点レンダー ターゲットを使用します**。 HDR コンテンツには十分な精度が必要ですが、8 ビットでは十分ではありません。入口API：`pixelFormat = .rgba16Float`。

3. **モニターの EDR 能力調整内容を検出**。モニターごとに EDR の上限が異なり、機能に基づいて HDR コンテンツの強度を調整します。入口API：`screen.maximumExtendedDynamicRangeColorComponentValue`。

4. **SD​​R ディスプレイと HDR ディスプレイの両方で効果をテストします**。システムは自動的にトーン マップを作成しますが、効果は異なる場合があります。両方のモニターで良好なビジュアルを確保します。

5. **プロのビデオ アプリケーション用に EDR ワークフローを構成します**。 P3 PQ カラースペース + 16 ビット浮動小数点 + EDR を有効にして表示します。入口API：`CGColorSpace.displayP3_PQ`。
