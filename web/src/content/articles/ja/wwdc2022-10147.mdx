## ハイライト

> iOS 16 のシステム メディア プレーヤーには、カスタマイズ可能な再生速度メニュー、インタースティシャル広告のより強力なサポート、AVPlayerViewController によって提供されるメタデータ表示の最適化が導入されており、開発者はプレーヤー UI を再構築することなく、システムのネイティブ機能を直接利用してメディア アプリケーションの再生エクスペリエンスを向上させることができます。

---

## 主要内容

iOS 16 より前は、ユーザーがビデオの再生速度を調整したり、インタースティシャルをサポートしたり、再生インターフェイスでより豊富なメタデータを表示したりしたい場合は、プレーヤー UI 全体を書き直すことがほとんど運命にありました。 Apple は長い間 AVPlayerViewController を提供してきましたが、そのカスタマイズ機能は常に制限されていました。開発者は 2 つの選択肢に直面します。システム プレーヤーの固定動作を受け入れるか、完全なプレーヤーを最初から構築するかのいずれかです。独自のものを作成するには、バッファー インジケーター、再生コントロール、時間表示、ピクチャー イン ピクチャー、字幕トラックの選択、オーディオ トラックの選択、AirPlay 共有など、膨大な詳細を扱う必要があり、作成には時間がかかり、バグが発生しやすくなります。 ([00:45](https://developer.apple.com/videos/play/wwdc2022/10147/?time=45))

iOS 16 ではそれが変わります。 Apple は AVPlayerViewController の API を拡張し、開発者が自分で UI を保守しなくてもシステム プレーヤーにカスタム関数を直接マウントできるようにしました。これには、(1.0x、1.25x、1.5x、2.0x の固定オプションだけではなく) 再生速度メニューにカスタム ギアを追加できることが含まれます。 AVPlayerInterstitialEventController を使用して、インタースティシャル広告の再生ロジックを管理できます。 externalMetadata を通じて、プレーヤーにタイトル、サブタイトル、説明情報を表示できます。 ([01:30](https://developer.apple.com/videos/play/wwdc2022/10147/?time=90))

これらの改善の重要性は、「システム プレーヤーの使用」と「カスタマイズされたエクスペリエンスの提供」が、もはや二者択一の関係ではなくなることです。重要なポイントでアプリの特性を具体化しながら、Apple のプレーヤー インタラクションの継続的な最適化 (新しいデバイスへの適応、アクセシビリティのサポート、システム機能との統合を含む) を引き続き利用できます。これはメディア アプリケーションにとって特に重要です。ユーザーはプレーヤーに対して明確な期待を持っており、システムの動作方法に慣れていますが、アプリケーション プロバイダーは独自のブランド情報、広告ロジック、または機能を表示する必要があります。 ([02:15](https://developer.apple.com/videos/play/wwdc2022/10147/?time=135))

このセッションの中心は、過剰なカスタマイズを行わずに、最小限のコードでこれらの一般的なプレーヤー要件を実装する方法を示すことです。スピーカーは、完全なカスタム プレーヤーを作成する方法を教えません (Apple はシステムによって提供されるプレーヤーを使用することを推奨しているため) が、アプリのニーズを満たすようにシステム プレーヤーを拡張する方法を教えます。 ([02:45](https://developer.apple.com/videos/play/wwdc2022/10147/?time=165))

## 詳細

### プレーヤーのメタデータを設定する

([03:30](https://developer.apple.com/videos/play/wwdc2022/10147/?time=210)) AVPlayerViewController を使用して URL を再生する場合、デフォルトでは、プレーヤー インターフェイスには時間や再生ボタンなどの基本的なコントロールのみが表示されます。何を放送しているのか分かりません。 iOS 16 では、externalMetadata を通じて AVPlayerItem のメタデータを設定でき、この情報はプレーヤーの情報パネルに自動的に表示されます。

具体的な方法は、各項目がメタデータの一部を表す AVMutableMetadataItem 配列を作成することです。 Apple は、フィールド タイプを指定するための標準の識別子定数を提供しています。タイトルは次のとおりです。`.commonIdentifierTitle`、字幕用`.iTunesMetadataTrackSubTitle`、説明するために使用されます`.commonIdentifierDescription`。コードは次のとおりです。

```swift
let titleItem = AVMutableMetadataItem()
titleItem.identifier = .commonIdentifierTitle
titleItem.value = "WWDC 2022 Session 10147"

let subtitleItem = AVMutableMetadataItem()
subtitleItem.identifier = .iTunesMetadataTrackSubTitle
subtitleItem.value = "Create a great video playback experience"

let infoItem = AVMutableMetadataItem()
infoItem.identifier = .commonIdentifierDescription
infoItem.value = "学习如何利用 iOS 16 的系统媒体播放器构建优秀的媒体应用体验。"

playerItem.externalMetadata = [titleItem, subtitleItem, infoItem]
```

キーポイント:
- `AVMutableMetadataItem`の`identifier`このメタデータのタイプを決定し、システムによって提供される定数を使用する必要があります。
- `value`メタデータ仕様に準拠する文字列またはその他のタイプを指定できます
- `externalMetadata`配列を受け入れ、さらにフィールドを追加できます (アートワーク、作者情報など)。
- この情報は AVPlayerViewController の情報パネルに自動的に表示されます。追加の UI コードは必要ありません。

### ミッドロール広告を管理する

([17:00](https://developer.apple.com/videos/play/wwdc2022/10147/?time=1020)) インタースティシャル広告は、プレロール広告、エンドオブクレジット広告、プログラム間の広告など、メディア アプリケーションの一般的な要件です。 iOS 16 より前は、再生タイミング、スキップ ロジック、メイン コンテンツとの接続を自分で管理する必要がありました。 AVPlayerInterstitialEventController は、これらのシナリオを処理するための宣言型 API を提供するようになりました。

基本的な考え方は、`AVPlayerInterstitialEventController`、それをメイン プレーヤーにバインドし、挿入イベントを宣言します。それぞれ`AVPlayerInterstitialEvent`オブジェクトは、広告コンテンツ (primaryItem) とトリガー時間 (time) を含む挿入を表します。また、イベントに制限を設定して、早送りの禁止やスキップの禁止など、広告再生中の動作制限を指定することもできます。

```swift
let eventController = AVPlayerInterstitialEventController(primaryPlayer: mediaPlayer)

let event = AVPlayerInterstitialEvent(primaryItem: interstitialItem, time: .zero)
event.restrictions = [
    .requiresPlaybackAtPreferredRateForAdvancement,
    .constrainsSeekingForwardInPrimaryContent
]

eventController.events.append(event)
```

キーポイント:
- `AVPlayerInterstitialEventController`初期化はメイン プレーヤーに渡す必要があります。これにより、挿入イベントがメイン プレーヤーのライフ サイクルに関連付けられます。
- `AVPlayerInterstitialEvent`の`primaryItem`広告コンテンツの AVPlayerItem です。`time`メイン コンテンツのどの時点に挿入するかを指定します (`.zero`広告を最初から開始することを示します）
- `restrictions`動作制約の配列です。`requiresPlaybackAtPreferredRateForAdvancement`ユーザーは続行する前に通常の再生速度で広告を視聴する必要があります。`constrainsSeekingForwardInPrimaryContent`広告再生中のメインコンテンツの早送りを無効にする
- 尋ねることができます`eventController.events`プレロール広告 + プログラム ギャップ広告 + エンドオブクレジット広告など、複数のインタースティシャル イベントを追加します。

([18:20](https://developer.apple.com/videos/play/wwdc2022/10147/?time=1100)) コマーシャル休憩のもう 1 つの一般的なシナリオは、「5 秒後にスキップ可能」です。これには、インタースティシャル イベントの表示ステータスを監視し、UI にスキップ ボタンを表示し、ユーザーがクリックしたときにそれを呼び出す必要があります。`cancelCurrentEvent`。 AVPlayerViewController はデリゲートを通じてコールバックします`playerViewController(_:willPresent:)`休憩の表示が間もなく開始されることを通知します。この時点でタイマーを開始できます。

```swift
func playerViewController(playerViewController: AVPlayerViewController, willPresent interstitial: AVInterstitialTimeRange) {
    showSkipButton(afterTime: 5.0, onPress: {
        eventController.cancelCurrentEvent(withResumptionOffset: CMTime.zero)
    })
}
```

キーポイント:
- `willPresent`コールバックは挿入の開始時にトリガーされ、パラメーターは挿入の時間範囲情報です。
- 自分で実装する必要があります`showSkipButton`5秒のカウントダウンとボタンUIを含むロジック
- `cancelCurrentEvent(withResumptionOffset:)`中断はただちに終了します。`withResumptionOffset`再開するメインコンテンツの時点を指定します (`.zero`ゼロから始めるという意味です）
- スキップ ロジックは自分で処理する必要があります。システムは自動的にスキップ ボタンを提供しません。

### カスタム再生速度

([20:00](https://developer.apple.com/videos/play/wwdc2022/10147/?time=1200)) システム プレーヤーは、デフォルトで 1.0x、1.25x、1.5x、2.0x の 4 つの再生速度を提供します。 iOS 16 では次のことが可能になります`AVPlaybackSpeed`カスタムギアを追加します。これは、長い形式のビデオ アプリケーションに役立ちます。ユーザーが視聴するには 0.5 倍、素早く閲覧するには 3.0 倍が必要な場合があります。

`AVPlaybackSpeed`次の 2 つのプロパティがあります。`rate`実際の再生速度です。`localizedName`UI に表示される名前です。カスタム速度オブジェクトを作成して追加できます。`AVPlayerViewController.speeds`配列：

```swift
let player = AVPlayerViewController()
player.player = mediaPlayer
present(player, animated: true)

let newSpeed = AVPlaybackSpeed(rate: 2.5, localizedName: "Two and a half times speed")
player.speeds.append(newSpeed)
```

キーポイント:
- `AVPlaybackSpeed`の`rate`はい`Double`タイプ、1.0 は通常速度、0.5 は半分の速度、2.0 は 2 倍の速度を意味します
- `localizedName`スピードメニューに表示されます。中国語、英語、その他の言語を使用できます。
- に追加`speeds`配列を選択すると、新しい速度オプションがプレーヤー速度メニューに自動的に表示されます。
- 複数のカスタムギアを追加でき、システムはそれらを配列内の順序で表示します。

([22:00](https://developer.apple.com/videos/play/wwdc2022/10147/?time=1320)) 再生速度機能がまったく必要ない場合 (たとえば、アプリケーションが短いビデオの場合、デフォルトで自動的に再生され、ユーザーが速度を調整する必要はありません)、速度メニューを直接非表示にすることができます。その方法は、`speeds`配列クリア:

```swift
let player = AVPlayerViewController()
player.player = mediaPlayer
present(player, animated: true)

player.speeds = []
```

キーポイント:
- クリア`speeds`Array は速度メニュー全体を削除し、速度コントロールはプレーヤー インターフェイスに表示されなくなります。
- ギアを 1 つずつ取り外すよりも簡単です。
- メディアの種類自体が速度調整を必要としない場合 (音楽、特定のシーンのビデオなど)、非表示にすることで UI を簡素化できます。

## 重要ポイント

iOS 16 プレーヤーのこれらの新機能に基づいて、次の機能を直接実装できます。

1. **教育アプリに「集中視聴モード」と「クイックブラウズモード」を追加**——利用する`AVPlaybackSpeed`0.75x や 0.5x などの集中読書ギア、2.5x や 3.0x などのクイックブラウジングギアを追加し、ユーザーは学習ニーズに応じて自由に切り替えることができます。エントリ ポイントはプレーヤーの速度メニューにあり、追加の UI は必要ありません。実装コードは呼び出すだけで済みます。`player.speeds.append()`ギアをいくつか追加します。

2. **ニュース/ポッドキャスト アプリ向けの「スポンサー付きスニペット」の実装** - 使用`AVPlayerInterstitialEventController`番組間にスポンサー音声を自動挿入、設定`.requiresPlaybackAtPreferredRateForAdvancement`強制的に最後まで聞くか、「15 秒後にスキップ」ボタンを提供してエクスペリエンスを向上させます。インタースティシャル イベントを作成して追加するだけです。`events`アレイでは、システムが再生タイミングとステータス管理を自動的に処理します。

3. **メディア ライブラリ アプリにリッチ コンテンツ情報パネルを追加します** —— を使用します`externalMetadata`各ビデオのタイトル、サブタイトル、説明、カバー画像などの情報を設定すると、ユーザーはリスト ページに戻ることなく、プレーヤー情報パネルで番組の詳細を直接確認できます。これに必要なのは、`AVPlayerItem`メタデータ配列を設定すると、システムが自動的にそれを表示します。

4. **「オーディオ クリップ」インサートをミュージック ビデオ アプリに追加します** - 完全な MV の前に 30 秒のオーディション クリップを自動的に再生し、挿入イベントを使用してオーディションと完全なコンテンツの間の接続を管理します。試用後は、完全なコンテンツが自動的に入力されるか、「今すぐ完全版を購入する」ボタンが表示されます。このロジックは補間イベントを使用して追加できます。`willPresent`コールバックの実装により、再生ステータスの切り替えを手動で管理する必要がなくなります。

5. **子供向けコンテンツ アプリの再生コントロールを簡素化** - 使用します`speeds = []`子供が誤って速度メニューに触れて再生が混乱するのを防ぐために、速度メニューを非表示にします。中断イベントの制限を使用して早送りを禁止し、コンテンツが順番に再生されるようにします。この「誤操作防止」の組み合わせにより、システム プレーヤーを子供のシーンにより適したものにするために必要なコードは 2 行だけです。
