## ハイライト

> 3 日目は、アプリ ショートカットのデザイン、デスクトップ iPad アプリケーション開発、新しい iOS カメラ キャプチャ機能、SwiftUI レイアウトとビューの新機能のリリースに焦点を当てます。

## 主要内容

### アプリのショートカットのデザイン

3 日目は、アプリのショートカットのデザイン ガイドから始まりました。 iOS 16 では、ユーザーが事前にショートカットを設定しなくても、Siri を通じてアプリの機能を呼び出せるようにすることで、ショートカットの使用方法が変更されます。 ([00:09](https://developer.apple.com/videos/play/wwdc2022/110931/?time=9))

開発者は、ユーザーがアプリの機能をトリガーするためにどのような自然言語を使用し、これらのシナリオのパラメーターや意図を設計するかを考慮する必要があります。優れたアプリ ショートカット エクスペリエンスでは、ユーザーが「Siri は私の言っていることを理解している」と感じられるはずです。

### デスクトップ iPad アプリ

iPadOS 16 では真のマルチウィンドウ サポートが実現し、アプリはより多くの機能を UI の最前線に置きながら、コンテンツに最適なレイアウトを表現できるようになります。これは、iPad アプリのデザインパラダイムが「大画面の iPhone」から「デスクトップレベルのエクスペリエンス」に移行したことを意味します。 ([00:17](https://developer.apple.com/videos/play/wwdc2022/110931/?time=17))

主な変更点は次のとおりです。
- サイズ変更可能なウィンドウ、複数のウィンドウの並列サポート
- 高密度の UI レイアウト、大画面に適しています
- キーボード ショートカットとメニュー バーのサポート
- ドキュメントブラウザの改善

### iOS カメラ キャプチャの新機能

カメラ キャプチャ セッションでは、iOS 16 の新しい写真機能を紹介します。これには、低照度でのパフォーマンスの向上、新しい露出制御、フレームのさまざまな領域をクリックしてシーン内のオブジェクトに光を集中できるスポットライト効果が含まれます。 ([00:27](https://developer.apple.com/videos/play/wwdc2022/110931/?time=27))

これらの新機能は、写真アプリ、電子商取引撮影アプリ、AR アプリケーションに直接影響します。

### SwiftUI のレイアウトとビュー

SwiftUI はその構成要素を拡張し続けています。新しいレイアウト ツールとビュー コンポーネントを使用すると、開発者は宣言の単純さを維持しながら、より複雑なインターフェイスを作成できます。 ([00:36](https://developer.apple.com/videos/play/wwdc2022/110931/?time=36))

## 詳細

- キーボードとポインタのサポートの改善

**マルチメディアとカメラ**:
- カメラキャプチャ用の新しい API

- 新しいレイアウトコンテナ

- アニメーションシステムの強化

### デスクトップ iPad アプリのデザイン変更

iPad アプリを「デスクトップグレード」にすることは、いくつかの具体的な変更を意味します。

1. **ウィンドウ管理**: 複数のドキュメント ウィンドウを同時に開くことをサポートし、各ウィンドウは独立して実行されます。
2. **ツールバーの密度**: 画面が大きいほど、メニュー内のすべてのツール ボタンを非表示にする必要がなく、より多くのツール ボタンを表示できます。
3. **キーボード優先度**: 一般的な操作にキーボード ショートカットとポインター ホバー効果を提供します
4. **サイドバー ナビゲーション**: 使用する`NavigationSplitView`下部のタブバーを置き換える

これらの変更により、iPad アプリは Mac アプリのエクスペリエンスに近づきますが、タッチファーストの操作性は維持されます。

## 重要ポイント

- **音声ファーストのアプリ操作**: アプリのショートカットを利用して、ユーザーが自然言語でアプリを制御できるようにします。たとえば、会計アプリでは「Siri、昼食代 35 元を書き留めて」と言うことができ、フィットネス アプリでは「30 分間のランニングを始めて」と言うことができます。エントリーAPIは`AppIntent`そして`AppShortcutsProvider`。

- **iPad プロフェッショナル ツール アプリ**: 既存の iPhone ツール アプリをデスクトップ レベルの iPad アプリに変換します。たとえば、コード エディター、デザイン ツール、プロジェクト管理ツールは、効率を向上させるために複数のウィンドウとキーボード ショートカットを使用します。エントリーAPIは`WindowGroup`そして`NavigationSplitView`。

- **カメラ強化された撮影アプリ**: iOS 16 の新しいカメラ機能を使用して、プロの撮影ツールになります。スポットライト効果は商品撮影に使用でき、新しい露出制御は夜景に適しています。エントリーAPIは`AVCaptureDevice`新しいプロパティと`AVCapturePhotoOutput`。

- **マルチドキュメント ワークフロー アプリ**: iPad 上で複数のドキュメントを Mac のように並行編集できるようにします。たとえば、テキスト エディタでは複数のファイルを同時に開くことができ、画像ブラウザではファイルを並べて比較できます。エントリーAPIは`NSDocument`そして`UIDocument`マルチシーンのサポート付き。
