## Highlight

> Day 3 重点发布了 App Shortcuts 设计、桌面级 iPad 应用开发、iOS 相机捕获新特性，以及 SwiftUI 布局与视图的新能力。

## 核心内容

### App Shortcuts 设计

Day 3 开场是 App Shortcuts 的设计指南。iOS 16 允许用户不预先配置快捷指令就能通过 Siri 调用 App 功能，这改变了快捷指令的使用方式。（[00:09](https://developer.apple.com/videos/play/wwdc2022/110931/?time=9)）

开发者需要考虑用户可能用哪些自然语言触发 App 功能，并为这些场景设计参数和意图。好的 App Shortcuts 体验应该让用户感觉"Siri 本来就懂我在说什么"。

### 桌面级 iPad 应用

iPadOS 16 带来了真正的多窗口支持，App 可以表达最适合内容的布局，同时把更多功能放在 UI 前沿。这意味着 iPad App 的设计范式从"大屏 iPhone"转向了"桌面级体验"。（[00:17](https://developer.apple.com/videos/play/wwdc2022/110931/?time=17)）

关键变化包括：
- 可调整大小的窗口，支持多窗口并行
- 更密集的 UI 布局，适合大屏幕
- 键盘快捷键和菜单栏支持
- 文档浏览器的改进

### iOS 相机捕获新特性

相机捕获 Session 展示了 iOS 16 的新拍照能力。包括更好的弱光性能、新的曝光控制、以及 Spotlight 效果——点击画面不同区域可以聚光照射场景中的物体。（[00:27](https://developer.apple.com/videos/play/wwdc2022/110931/?time=27)）

这些新特性对摄影类 App、电商拍摄 App、AR 应用都有直接影响。

### SwiftUI 布局与视图

SwiftUI 继续扩展其构建模块。新的布局工具和视图组件让开发者可以组合出更复杂的界面，同时保持声明式的简洁。（[00:36](https://developer.apple.com/videos/play/wwdc2022/110931/?time=36)）

## 详细内容

### Day 3 技术专题分类

**自动化与集成**：
- App Shortcuts：无需用户预配置的 Siri 集成
- App Intents：定义 App 可执行的操作

**iPad 体验升级**：
- 多窗口管理：UIScene 和 WindowGroup
- 桌面级布局：更密集的控件和更丰富的工具栏
- 键盘和指针支持完善

**多媒体与相机**：
- 相机捕获新 API
- 照片选择器改进
- 视频编辑能力增强

**SwiftUI 深化**：
- 新布局容器
- 视图状态管理改进
- 动画系统增强

### 桌面级 iPad App 的设计转变

把 iPad App 做成"桌面级"意味着几个具体改变：

1. **窗口管理**：支持同时打开多个文档窗口，每个窗口独立运行
2. **工具栏密度**：大屏幕可以放更多工具按钮，不需要全部收进菜单
3. **键盘优先**：为常用操作提供键盘快捷键，指针悬停效果
4. **侧边栏导航**：用 `NavigationSplitView` 替代底部标签栏

这些改变让 iPad App 更接近 Mac App 的体验，但保持触控优先的交互。

## 核心启发

- **语音优先的 App 交互**：利用 App Shortcuts 让用户用自然语言操控 App。比如记账 App 可以说"Siri，记一笔午餐 35 元"，健身 App 可以说"开始 30 分钟跑步"。入口 API 是 `AppIntent` 和 `AppShortcutsProvider`。

- **iPad 专业工具应用**：把现有的 iPhone 工具类 App 改造成桌面级 iPad 应用。比如代码编辑器、设计工具、项目管理工具，利用多窗口和键盘快捷键提升效率。入口 API 是 `WindowGroup` 和 `NavigationSplitView`。

- **相机增强拍摄应用**：利用 iOS 16 的新相机特性做专业拍摄工具。Spotlight 效果可以用于产品摄影，新的曝光控制适合夜景拍摄。入口 API 是 `AVCaptureDevice` 的新属性和 `AVCapturePhotoOutput`。

- **多文档工作流应用**：在 iPad 上实现类似 Mac 的多文档并行编辑。比如文本编辑器同时打开多个文件、图片浏览器并排对比。入口 API 是 `NSDocument` 和 `UIDocument` 配合多 Scene 支持。
