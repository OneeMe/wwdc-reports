## ハイライト

> WWDC 2022 でのプラットフォーム一般教書では、Xcode Cloud オンライン、Swift 5.7 構文と同時実行拡張機能、SwiftUI の新しいナビゲーションとレイアウト、WidgetKit ロック画面機能、App Intents、Passkeys、Metal 3、WeatherKit、VisionKit がプラットフォームのロードマップにまとめられました。

## 主要内容

チームが 2022 年に Apple プラットフォーム アプリをアップグレードする場合、問題は単に「今年はどの API が登場するのか?」ということではありません。本当の問題は、複数のレベルで同時に変更が加えられることによって発生します。コードは保守しやすくする必要があり、インターフェイスはより多くのデバイスをカバーする必要があり、システムの入口はホーム画面からロック画面、Siri、スポットライト、メッセージにまで拡大され、グラフィックスやマップなどの基礎的な機能も進化しています。

この一般教書演説の目的は、これらの変化を同じ構図に戻すことです。 Susan Prescott 氏は、その日 Xcode Cloud が利用可能になったことを最初に発表し、TestFlight、App Store Connect、主流の Git ソース コード ホスティング、および REST API が統合されていると説明しました。続いて講演は、Swift、SwiftUI、システムインテグレーション、セキュリティ、グラフィックス、地図、天気、視覚認識から始まりました。

開発者が取得できるのは、連結できる一連のパスです。 Swift と SwiftUI は日々の開発コストを削減します。 WidgetKit、ライブ アクティビティ、アプリ インテント、およびメッセージ コラボレーション API は、システム表面に機能をもたらします。パスキー、Metal 3、WeatherKit、VisionKit はそれぞれ、ログイン、グラフィックス パフォーマンス、気象データ、視覚認識などのより具体的な問題を処理します。

### ツールチェーンから始める摩擦の低減

Xcode Cloud の位置付けは簡単です。継続的な統合と配信を Xcode に組み込み、クラウドでホストします。すべての Apple プラットフォームをサポートし、TestFlight および App Store Connect に接続し、REST API を通じてチームの既存のプロセスに接続することもできます。完全な CI/CD インフラストラクチャを持たない小規模チームにとって、これはコードの送信からテスト配布までのパスが短縮されることを意味します。

Swift Playgrounds 4 も同じツールチェーン ストーリーに配置されます。すでにアプリを構築して App Store に直接送信でき、SwiftUI もサポートしています。プロトタイピング、学習、提出は、軽量の閉ループを形成します。

### Swift と SwiftUI が引き続きメインラインになります

Josh Shaffer は、Apple プラットフォームの次世代の組み合わせを Swift、SwiftUI、および Xcode Preview として特定しました。 Swift 5.7 は、非同期アルゴリズム、分散アクター、正規表現、`some`そして`any`一般的な書き込みと Swift パッケージのプラグイン。 SwiftUI は、ナビゲーション、レイアウト、共有シート、UIKit コレクション ビュー セル ホスティングおよびその他の機能を追加します。

フード トラックの例は、いくつかの段落にわたって使用されています。まず、Swift Charts を使用してドーナツの販売データを表示し、次に`ViewThatFits`水平および垂直の画面レイアウトを処理し、新しいナビゲーションの分割ビューを使用し、`NavigationStack`iPad ナビゲーションを作成し、最後に同じ SwiftUI コード セットを使用してアプリを Mac に導入し、メニュー バーを追加します。

### システムの入り口が増え、アプリケーションの機能がさらに見つけやすくなるはずです。

iOS 16 のロック画面は WidgetKit の価値を拡張します。 3 つのロック画面ウィジェット ファミリ、円形、長方形、インラインは、Apple Watch のコンプリケーションのデザイン言語を iPhone にもたらします。 watchOS 9 の複雑さも WidgetKit によって駆動されます。同じウィジェット コードでロック画面とウォッチフェイスをカバーできます。

アプリ インテントは、別のエントリ ポイントの問題に対処します。以前は、Siri またはショートカットに機能を表示するには、ユーザーが手動でショートカットを追加する必要がありました。 iOS 16 では、アプリ インテントとアプリ ショートカットが組み合わされているため、ユーザーは最初に設定しなくても、Siri、ショートカット、スポットライトを使用してアプリの機能を見つけることができます。

### 基礎となるフレームワークにより、より重いシーンの実装が可能になります

Metal 3 はゲームとプロ仕様のグラフィックスに重点を置いています。リソースの高速読み込みにより、Metal IO を介したストレージから GPU への読み込みオーバーヘッドが削減されます。オフライン シェーダ コンパイルでは、GPU シェーダ バイナリをプロジェクト構築フェーズに入れて生成します。 Mesh Shading API は、ジオメトリ生成をより最適化されたレンダリング パイプラインに組み込みます。 MetalFX アップスケーリングでは、低解像度のレンダリングを使用して、一時的なアンチエイリアシングとアップスケーリングを実行します。

WeatherKit、MapKit、および VisionKit は、システム レベルのサービスがアプリケーションに公開されるという別の方向性を示しています。 WeatherKit はネイティブの Swift API と REST API を提供します。 MapKit の 3D City Experience、カメラ制御、リアルな標高により、アプリケーションはより正確な位置を表現できます。 VisionKit の Live Text API と Data Scanner API は、写真、一時停止したビデオ フレーム、ライブ カメラからのテキスト、QR コード、バーコードをアプリケーション プロセスに取り込みます。

Swift Package プラグインは、ビルド プロセスを Swift パッケージに拡張します。コマンド プラグインはオンデマンドで実行でき、ビルド プラグインはプロジェクトのビルド時に実行できます。これらはコマンド ラインまたは Xcode から呼び出すことができ、サンドボックス内のアクセス許可も要求します。フード トラックの例では、コマンド プラグインが SwiftFormat ソート インポートを呼び出し、別の SwiftLint ベースのビルド プラグインが不足しているドキュメントの場所を要求し、ビルド プラグインが Xcode Cloud に移動します。

- リソースを高速にロードするための Metal IO API。
- オフライン シェーダー コンパイルにより、シェーダー バイナリの生成がビルド時間まで進みます。
- メッシュ シェーディング API は、ジオメトリ生成結果をデバイス メモリにラップして戻すことを回避します。
- オブジェクト シェーダは、生成するメッシュの数を決定します。
- メッシュ シェーダは実際のジオメトリを生成し、それをラスタライザに送信します。
- MetalFX アップスケーリングは、最初に低解像度でレンダリングし、次にターゲット解像度にアップスケーリングします。

WeatherKit はネイティブの Swift API と REST API を提供します。フード トラックの例では、アプリケーションはまず Xcode に WeatherKit 機能を追加し、次に Swift Concurrency を通じてそれを呼び出します。`WeatherService`の`weather(for:)`、場所を入力し、状態、処方箋、雲量を考慮して、駐車場所として日当たりの良い場所を推奨します。 Apple はまた、開発者プログラムのメンバーシップには月あたり 500,000 回の参加が含まれると述べました`weather(for:location)` API calls。

```swift
WeatherService
weather(for:)
location
condition
precipitation
cloud cover
weather(for:location)
```

キーポイント:
- WeatherService は、デモで天気をリクエストするためのサービス エントリです。
- `weather(for:)`位置情報を受信します。
- 状態、処方箋、雲量は、フードトラックが駐車ポイントを決定するために使用するデータです。
- `weather(for:location)`は、Apple が使用説明書に記載している API 呼び出し名です。

VisionKit は Live Text API と Data Scanner API を提供します。 Live Text API は、画像および一時停止されたビデオ フレーム内のテキストと QR コードを分析し、迅速なアクションを提供します。データ スキャナ API はリアルタイムのカメラ入力を分析し、QR コード、バーコード、倉庫ピッキング、流通、POS シナリオに適しています。デモでは、フード トラックが追加します`ImageInteraction`、カスタム インセットを通じてボタンの位置を調整します。注文プロセス中に、テキスト、QR コード、またはバーコードを検索するために DataScanner がインスタンス化されます。

```swift
ImageInteraction
Live Text API
Data Scanner API
DataScanner
text
QR codes
barcodes
custom insets
button configuration
```

キーポイント:
- ImageInteraction は、Live Text ボタンとクイック アクションを画像ビューに追加します。
- カスタム インセットは、アプリケーション内の既存のボタンを避けるために使用されます。
- ボタン設定は、アプリケーション UI に一致するようにボタンのスタイルを調整します。
- ライブカメラ入力用の DataScanner。
- テキスト、QR コード、およびバーコードは、DataScanner がデモで検索するコンテンツ タイプです。

## 重要ポイント

- **CI/CD を Xcode クラウドに接続**
- **内容**: iOS、iPadOS、macOS、watchOS プロジェクトのコミットから TestFlight までの自動ビルド プロセスを構築します。
- **実行する価値がある理由**: この講演では、Xcode Cloud が利用可能であり、TestFlight、App Store Connect、Git プロバイダー、および REST API を接続できることを示します。
- **開始方法**: まず既存の Git リポジトリを Xcode Cloud に接続し、次に REST API を使用してチームの既存の通知またはリリース プロセスに接続します。

- **高頻度ステータスをロック画面ウィジェットと Apple Watch コンプリケーションに追加**
- **内容**: 注文の進捗状況、フィットネスの目標、在庫アラート、カウントダウンのスケジュールを円形、長方形、またはインラインのウィジェットに追加します。
- **実行する価値がある理由**: WidgetKit は iOS 16 のロック画面と watchOS 9 のコンプリケーションで同じモデルを再利用しており、プラットフォームの違いはシステムによって処理されます。
- **開始方法**: ゲージ、VStack、システム フォント、および`widgetAccentable`ロック画面とウォッチフェイスに適応します。

- **アプリ内アクションを Siri と Spotlight に公開**
- **やるべきこと**: 「今週の販売傾向を表示する」、「コップ一杯の水を記録する」、「ポモドーロを開始する」などのアクションを Siri から直接呼び出せるようにし、Spotlight 検索にも表示します。
- **価値がある理由**: アプリ インテントとアプリ ショートカットを使用すると、ユーザーは最初に手動でショートカットを構成しなくても、アプリの機能を見つけることができます。
- **開始方法**: AppIntent を使用してアクションを記述し、AppEnum を使用してパラメータを記述し、perform を追加してから、Siri チップをインターフェイスに追加します。

- **アカウント システムのパスキーの移行を計画する**
- **対処方法**: 既存のユーザー名とパスワードのログインの隣に、パスキーの登録とログインを追加します。
- **実行する価値がある理由**: パスキーは公開キー暗号化を使用し、サーバーは公開キーのみを保存するため、パスワードの再利用、フィッシング、漏洩のリスクを軽減できます。
- **開始方法**: バックエンドは最初に公開キーの保存と認証チャレンジの発行をサポートし、次にクライアントがパスキーを作成してパスキーでサインインするための入り口を提供します。

- **WeatherKit と VisionKit によるオフライン プロセスの改善**
- **やるべきこと**: 配布、検査、旅行、アクティビティのアプリに、気象に関する意思決定、画像テキスト抽出、QR コード スキャンを追加します。
- **価値がある理由**: WeatherKit は Swift API と REST API を提供します。 VisionKit の Live Text API と Data Scanner API は、システムレベルの識別機能をカスタム プロセスに組み込むことができます。
- **開始方法**: まず、WeatherKit 機能を気象シーンに追加し、WeatherService を呼び出します。画像シーンに ImageInteraction を追加します。 DataScanner を使用して、リアルタイム コード スキャン シーンでテキスト、QR コード、またはバーコードを処理します。
