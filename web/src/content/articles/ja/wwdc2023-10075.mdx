## ハイライト

> Apple は visionOS の FaceTime に Spatial Personas と shared context を導入し、複数人の SharePlay を「画面を一緒に見る」から「同じ空間にいる」体験へ昇格させました。開発者は適切な空間座席テンプレートを選び、コンテンツ状態を同期する必要があります。

## 主要内容

### 「一緒に見る」から「一緒に遊ぶ」へ

以前、SharePlay で友人と動画を見るとき、各自がスマホ画面を見つめ、小さなアバターしか見えませんでした。コミュニケーションは音声のみで、操作は「誰々が再生を一時停止しました」のようなシステム通知に頼っていました。

visionOS の Spatial Personas はこれを変えます。友人が立体的な姿で周囲に現れ、視線、ジェスチャー、ボディランゲージが見えます。Jay がスマホに気を取られたとき、すぐに分かります（[01:57](https://developer.apple.com/videos/play/wwdc2023/10075/?time=117)）。この自然な非言語コミュニケーションで、リモート協業が対面に近づきます。

### 3つの座席テンプレート

Apple はシーンに応じた3つの Spatial Persona Template を提供します。

**Side-by-side**（肩並び）: 全員が横一列に並び、映画やプレゼンなど共通のコンテンツ注視に適しています（[07:38](https://developer.apple.com/videos/play/wwdc2023/10075/?time=458)）。

**Surround**（囲み）: コンテンツを中央に、全員が円形に配置。ボードゲームや共同ホワイトボードなど、各自の角度から見るシーンに適しています（[07:51](https://developer.apple.com/videos/play/wwdc2023/10075/?time=471)）。

**Conversational**（対話）: 会話が主で、コンテンツは背景に。雑談や集まりなど、全員がコンテンツをはっきり見る必要がないシーンに適しています（[08:13](https://developer.apple.com/videos/play/wwdc2023/10075/?time=493)）。

### shared context のトレードオフ

shared context とは、全員が空間上で同じ位置のコンテンツを見ることです。誰かが右にいれば、あなたは彼の左にいます。この一貫性でジェスチャーや指差しに意味が生まれます。

一方、いつ shared context を破るべきかも知る必要があります。空間写真やパノラマ動画では最適な視聴位置は1つだけ。その場合は各自が自分の Full Space に入る方が適切です（[14:12](https://developer.apple.com/videos/play/wwdc2023/10075/?time=852)）。鍵は、別々に見ても再生進捗を同期し、共有コンテキストを保つことです。

## 詳細

### ウィンドウか Full Space か

SharePlay では、1 つのウィンドウと 1 つの immersive space を同時に共有できます（[03:37](https://developer.apple.com/videos/play/wwdc2023/10075/?time=217)）。

ウィンドウに適するシーン:
- 他 App を同時操作するマルチタスク
- ドラッグ&ドロップが必要なワークフロー
- 共同編集（非公開ウィンドウの曲を共有プレイヤーにドラッグなど）

Full Space に適するシーン:
- ゲーム
- 没入型メディア体験
- ユーザーの注意を独占するコンテンツ

### 起動摩擦の削減

SharePlay 活動を開始するとき、次の原則に従います（[05:34](https://developer.apple.com/videos/play/wwdc2023/10075/?time=334)）。

1. 活動と無関係な追加ウィンドウを出さない
2. 可能ならアカウントログインなしで参加できるようにする
3. 追加手順が必要なら、権限のある人が先に活動を開始し、権限のない人にはプレースホルダーウィンドウを表示
4. プレースホルダーには問題解決の入口を用意し、条件が満たされたら即座に実コンテンツに置き換える

### パーソナライズされたコントロール

shared context ではコンテンツ同期が必要ですが、個人のコントロールは異なって構いません。TV App では各自が音量を設定でき、聴覚障害ユーザーは他者に影響せず字幕をオンにできます（[12:25](https://developer.apple.com/videos/play/wwdc2023/10075/?time=745)）。

協業シーンでも各人の編集ツールはパーソナライズ可能です。あなたは赤でマークし、同僚は青を使えます。共有ビューは一貫し、個人ツールは異なってよいのです。

### UI 通知を非言語コミュニケーションで置き換える

visionOS の FaceTime では、相手の大きな動きを直接見られます。「誰々が動画を一時停止しました」のような通知は不要です。声をかけるか、視線とジェスチャーで伝えられます（[11:00](https://developer.apple.com/videos/play/wwdc2023/10075/?time=660)）。

### インタラクション権限の設計

体験の自然な一部でない限り、複雑な権限システムや順番制は設計しないでください。より寛容なアプローチは、全員が自由に操作し、一貫して予測可能なルールで競合を解決することです。グループは自発的に規範を形成します（[11:45](https://developer.apple.com/videos/play/wwdc2023/10075/?time=705)）。

## 重要ポイント

- **やること**: SharePlay 対応の 3D モデルビューアを作り、デザイナーとクライアントが製品プロトタイプを一緒にレビューする。
- **価値**: Spatial Personas でリモート設計レビューが対面議論に近づき、モデルの部位を直接指差せる。
- **始め方**: GroupActivities フレームワークで共有活動を定義し、Surround テンプレートで参加者が各自の角度からモデルを見られるようにする。

- **やること**: 各人が異なるトラックを制御する多人協業音楽制作 App を開発する。
- **価値**: shared context で全員が同じミックスを聴きつつ、各人がトラック音量とエフェクトを独立調整できる。
- **始め方**: SharePlay で再生状態を同期し、参加者ごとに独立したオーディオ設定を保存する。

- **やること**: SharePlay 対応の没入型フォトアルバムを作り、友人と空間写真を振り返る。
- **価値**: 空間写真は Full Space で最良だが、SharePlay でページめくりと議論を同期できる。
- **始め方**: 写真をウィンドウで共有し、タップ後は各自が自分の Full Space で視聴しつつ、写真インデックスは同期する。

- **やること**: 2〜5 人同時プレイ対応の仮想ボードゲームプラットフォームを開発する。
- **価値**: Surround テンプレートはボードゲームに自然に適し、各自が自分の角度から盤面を見られる。
- **始め方**: Surround テンプレートを選び、5 人が囲んでも UI 要素が見え操作できるようにする。
