## ハイライト

> WWDC21 Friday Recap では、ResearchKit/CareKit、Safari 15 Tab Bar、SwiftUI Mac Apps、CloudKit Console、async/await、Xcode Cloud、SharePlay、Metal、watchOS、Xcode、ゲーム、アクセシビリティなど、週全体のトピックを 70 秒にまとめています。

## 主な内容

WWDC の最終日、開発者はデータの過負荷に直面しました。 5 日間にわたる新しい言語機能、開発ツール、プラットフォーム機能、設計原則、コミュニティ活動。本当の問題は、会議後にどのコンテンツを最初に見るか、どのコンテンツをすぐに検証する必要があるか、そしてどのコンテンツを長期的な学習リストに載せるかということです。

今週金曜日の @WWDC21 の要約では、API の詳細には触れません。今週のキーワードを 1 つのルートに圧縮します。まず、医学研究、Safari デザイン、Mac App、CloudKit などの特定のアプリのシナリオに戻ります。次に、学習キューを async/await、Xcode Cloud、SharePlay、Metal、watchOS、Xcode、ゲーム、アクセシビリティに広げます。

開発者にとって、この短編フィルムの価値は終結です。 WWDC21 の焦点は初日のリリースだけではなく、その後の特別セッションでの実装パスにもあることを思い出させます。たとえば、ResearchKit/CareKit は実際の看護プロセスに対応し、Safari 15 は Web サイトの適応に対応し、CloudKit Console はデータのデバッグに対応し、Swift 同時実行性と Xcode Cloud は日常のエンジニアリング効率に対応します。

＃＃詳細

### ResearchKit/CareKit: 研究とケアのプロセスをアプリに変える

([00:09](https://developer.apple.com/videos/play/wwdc2021/10325/?time=9)) 最初に述べた研究とケア用のアプリの作成を確認してください。このクリップで明らかになった具体的な詳細は、臨床医が教育テキストを提供し、より多くの人々を助ける最先端の研究でした。

これは、ResearchKit と CareKit のワークフローを組み合わせたものを指します。研究アプリは参加者のデータを収集する必要があり、ケアアプリはタスクをスケジュールし、進捗状況に関するフィードバックを提供する必要があります。臨床教育テキストでは医師のガイダンスがアプリに組み込まれているため、ユーザーはフォームに記入するだけでなく、各タスクの背後にある看護の目的も理解できます。

キーポイント:

- `research and care`単なるアンケート回収ではなく、完全なシナリオです。
-`educational text from the clinicians`コンテンツソースはその場限りのコピーライターではなく、臨床スタッフから提供されるべきであることを説明します。
-`cutting-edge research`データ リフロー後の調査価値を指摘するため、アプリはユーザーのタスク、結果、説明を結び付ける必要があります。

### Safari 15: タブバーとビジュアルインテリジェンスの Web エクスペリエンスを再検討する

([00:19](https://developer.apple.com/videos/play/wwdc2021/10325/?time=19)) レビューでは次に、Safari 15 のタブバーのデザインについて言及し、それを視覚的知性と同じ文に入れています。

Safari 15 では、ブラウザ Chrome と Web コンテンツの関係が変わります。 Web サイトや Web アプリの場合、ページが開けるかどうかだけでなく、色、上マージン、スクロール状態、タブ バーの背景、クリック可能領域が調整されているかどうかも適応の焦点となります。ビジュアル インテリジェンスは、画像とページ コンテンツはシステムによって理解されるものであり、Web ページ内のテキスト、画像、コントロールはより明確である必要があることを開発者に思い出させます。

キーポイント:

- `tab bar`これは特定のデザイン オブジェクトであり、最初の画面、スクロール、およびインタラクションの状態から適応をチェックする必要があります。
-`visual intelligence`これは、システムがページのコンテンツの理解に関与し、画像内のテキストとコンテキストもユーザー エクスペリエンスに影響を与えることを意味します。
- Safari 15 は iPhone、iPad、Mac に同時に影響し、Web 製品は 1 つのサイズだけを測定することはできません。

### SwiftUI Mac アプリと CloudKit コンソール: クロスプラットフォーム UI からデータ ワークベンチまで

([00:30](https://developer.apple.com/videos/play/wwdc2021/10325/?time=30)) SwiftUI を使用した Mac アプリの構築に関する言及を確認し、これらの API と概念はすべてのプラットフォームに適用されると追加しました。これにより、SwiftUI の Mac アプリ開発がクロスプラットフォームのコンテキストに組み込まれます。同じ宣言型 UI アイデアのセットが、異なるデバイス上のウィンドウ、メニュー、入力メソッド、およびレイアウトに対応する必要があります。

([00:36](https://developer.apple.com/videos/play/wwdc2021/10325/?time=36)) CloudKit コンソールが表示されます。この短いビデオでは、次回コンソールを開いたときに、最後にアクセスしたコンテナーに直接戻ることが具体的に述べられています。この詳細は小さいですが、実際の開発プロセスを示しています。CloudKit の問題をデバッグするとき、開発者は繰り返し同じコンテナに入り、環境を切り替え、レコードを確認し、ログを読み取ります。

キーポイント:

- `SwiftUI Mac apps`SwiftUI の API と概念を Mac App ワークフローに導入することに重点を置いています。
-`apply to all platforms`説明会終了後、SwiftUI を学習する際には、iOS、iPadOS、macOS を合わせて検討してください。
-`last container I visited`これは、高頻度のデバッグ シナリオに適した CloudKit コンソールの効率の詳細です。

### 毎週の学習キュー: キーワードを会議後のアクションに変える

([00:48](https://developer.apple.com/videos/play/wwdc2021/10325/?time=48)) この短編映画は一連のキーワードで終わります: async/await、Xcode Cloud、SharePlay、Metal、コーディングのためのマインドフル クールダウン、watchOS、ティエラ フレッチャーのスピーチ、Xcode、ゲーム、アクセシビリティ。

このリストは同じ種類のテクノロジーではありません。言語、CI/CD、共有エクスペリエンス、グラフィックス、健康リマインダー、時計、開発ツール、ゲーム、アクセシビリティをカバーしています。ミーティング後のアプローチ方法は、プロジェクトのニーズに応じて階層化する必要があります。最初に現在のコードベースに影響を与えるコンテンツを選択し、次にプロトタイピングが必要なコンテンツをスケジュールし、最後にデザインとコミュニティのトピックをチームのディスカッション資料として保存します。

キーポイント:

- `async/await`既存の非同期コードに影響を与えるため、最初は小規模な移行実験に適しています。
-`Xcode Cloud`ビルド、テスト、配布プロセスに影響を与え、ブランチまたはアプリ ターゲットからのパイロットに適しています。
-`SharePlay`メディア、コラボレーション、共同視聴、協力のシナリオに最適です。
-`Metal`ゲーム、グラフィックス、ゲーム チームと同じリマインダーのグループに配置され、特別セッションを継続して視聴する必要があります。
-`accessibility`クロージングリストに掲載されることは、アクセシビリティがその週全体のテーマであり、機能的なデザインとともに推進する必要があることを示しています。

## 重要なポイント

1. **やるべきこと**: 臨床教育カードをリハビリテーション、フォローアップ、または慢性疾患管理アプリに追加します。
   **実行する価値がある理由**: このレビューでは、臨床医が教育テキストを提供し、ResearchKit/CareKit シナリオではタスクと説明をユーザーに引き継ぐ必要があると明確に述べられています。
   **開始方法**: まず、頻度の高い看護タスクを選択し、医師の指示を短いテキスト、写真、または 3D コンテンツに分割して、完了ステータスとユーザーのフィードバックをケアプランに記録します。

2. **やるべきこと**: Safari 15 のスクロールせずに見える範囲への適応チェックリストを作成します。
   **実行する価値がある理由**: この短いビデオは、Safari 15 のタブ バーと視覚的インテリジェンスを訴えています。ウェブサイトの上部領域、画像テキスト、スクロール状態はユーザーの理解に影響を与える可能性があります。
   **開始方法**: 製品のホームページ、ランディング ページ、記事ページから始めて、タブ バーの背景、上部の安全領域、画像内のテキスト、ダーク モード、iPad/Mac のサイズを 1 つずつ確認します。

3. **やるべきこと**: CloudKit を使用してチーム用のコンテナ デバッグ エントリ ページを作成します。
   **実行する価値がある理由**: CloudKit コンソールは最後にアクセスしたコンテナを記憶しており、Apple が高頻度のコンテナ デバッグ プロセスを最適化していることを示します。
   **開始方法**: チーム メンバーが毎回場所を再検索する必要がないように、開発環境と運用環境のコンテナー リンク、一般的なクエリ、スキーマ デプロイメント手順、およびトラブルシューティング エントリのログをリストします。

4. **やるべきこと**: コールバック ネットワーク プロセスを async/await プロトタイプに変更します。
   **実行する価値がある理由**: async/await が金曜日の終了リストに含まれており、Swift の同時実行性が WWDC21 後に検証する必要がある言語トピックであることを示しています。
   **開始方法**: リスクの低い URLSession リクエストを選択し、古い実装を保持し、非同期バージョンを追加して、エラー処理、キャンセル、読み込みステータス、テストの書き込みを比較します。

5. **やるべきこと**: メディア アプリまたはコラボレーション アプリの SharePlay 候補フローチャートを作成します。
   **実行する価値がある理由**: SharePlay は今週のキーワードに含まれており、共同視聴、共同リスニング、または協力をシステム レベルのエクスペリエンスに変えるのに適しています。
   **開始方法**: まず、どのコンテンツを同期する必要があるか、誰が進行状況を制御できるか、参加者が退席したときに復元する方法を定義してから、グループ アクティビティ関連のセッションを読み続けます。
