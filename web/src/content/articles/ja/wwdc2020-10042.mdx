## ハイライト

> このセッションでは、音楽アプリの例を使用して、tvOS 14 の SwiftUI ボタン スタイル、コンテキスト メニュー、フォーカス API、Lazy Grid をデモンストレーションし、Apple TV アプリでリモコンのフォーカス、長押し操作、および水平シェルフ レイアウトを処理できるようにします。

---

## 主な内容

iPhone や iPad の SwiftUI のアイデアを TV に移す場合、最初の違いは入力方法です。 Apple TV ユーザーは、Siri Remote を使用してフォーカスを移動したり、ボタンを押し続けたり、遠くから大画面インターフェイスを表示したりできます。音楽アプリのアルバムボタンを通常のボタンにしただけでは、リモコンをドラッグした際のフォーカスハイライトや方向移動効果が不足します。

このセッションでは、音楽アプリを使用して 3 つの問題を結び付けます。アルバム カードには TV スタイルのボタンと長押しメニューが必要です。 Now Playing ページでは、どの曲がフォーカスされているかを知る必要があります。また、ログイン ページでは、ユーザー名入力ボックスとログイン ボタンの間のデフォルトのフォーカスを制御する必要があります。すべての例は、tvOS 14 の SwiftUI API を中心に展開しています。

最後の問題はレイアウトです。 Apple TV アプリの共通ホームページは、複数の水平スクロール シェルフで構成されます。 Session は `ScrollView`、`LazyHGrid`、および `CardButtonStyle` を使用してこのレイアウトを組み合わせており、スクロールが必要なときに Lazy Grid が項目を読み込むと説明しています。

### TV スタイルのボタンと長押しメニュー

([01:19](https://developer.apple.com/videos/play/wwdc2020/10042/?time=79)) `CardButtonStyle` はプラッターを作成します。ボタンにフォーカスがあると、プラッターが持ち上がってハイライト表示されます。ユーザーが Siri リモート上でドラッグすると、ボタンがその方向に移動します。```swift
Button(albumLabel, action: playAlbum)
    .buttonStyle(CardButtonStyle())
```キーポイント:

- `Button(albumLabel, action: playAlbum)` はアルバム エントリであり、ユーザーが選択した後に再生アクションが実行されます。
- `.buttonStyle(CardButtonStyle())` は、通常の SwiftUI ボタン​​を tvOS カード ボタン スタイルに置き換えます。
- このスタイルは、ボタンの外側に手書きのアニメーションを必要とせずに、フォーカスの強調表示とリモート コントロールのドラッグ フィードバックを担当します。

([02:20](https://developer.apple.com/videos/play/wwdc2020/10042/?time=140)) デフォルトのハイライト効果とフォーカス効果が適切でない場合は、`ButtonStyle` をカスタマイズできます。セッション コードは構造を表示するだけであり、特定の背景スタイルはアプリ自体によって完成されます。```swift
struct MyNewButtonStyle: ButtonStyle {
    func makeBody(configuration: Configuration) -> some View {
        configuration.label
           .background(configuration.isPressed ? … : …) // Custom styling
    }
}

Button(albumLabel, action: playAlbum)
    .buttonStyle(MyNewButtonStyle())
```キーポイント:

- `MyNewButtonStyle` は `ButtonStyle` プロトコルに準拠します。
- `makeBody(configuration:)` は、さまざまな状態のボタンのビューを返します。
- `configuration.isPressed` はボタンの状態から取得され、押されたときに背景を切り替えるために使用できます。
- `.buttonStyle(MyNewButtonStyle())` を使用すると、同じスタイルを任意のボタンに再利用できます。

([03:04](https://developer.apple.com/videos/play/wwdc2020/10042/?time=184)) アルバムボタンを長押ししてコンテキストメニューを開きます。メニュー項目は通常の「ボタン」として表現されます。```swift
AlbumView()
    .contextMenu {
        Button("Add to Favorites", action: addAlbumToFavorites)
        Button("View Artist", action: viewArtistPage)
        Button("Discover Similar Albums", action: viewSimilarAlbums)
    }
```キーポイント:

- `AlbumView()` はメニューマウントの対象となるビューです。
- `.contextMenu`は長押し後に表示されるショートカット操作領域を宣言します。
- 各「ボタン」はメニュー アクションであり、それぞれコレクションに接続し、アーティスト ページを表示し、類似したアルバムを検索します。

### フォーカス状態に応じてコンテンツ密度を変更する

([05:19](https://developer.apple.com/videos/play/wwdc2020/10042/?time=319)) tvOS 14 では、新しい「isFocused」環境値が追加されています。最も近いフォーカス可能な祖先にフォーカスがある場合、「true」を返します。 [再生中のセッション] ページの説明: フォーカスされている曲の場合はアーティスト名とアルバム名が表示され、フォーカスされていない曲の場合はアーティスト名のみが表示されます。```swift
struct SongView: View {
    var body: some View {
        Button(action: playSong) {
            VStack {
                Image(albumArt)
                DetailsView(...)
            }
        }.buttonStyle(MyCustomButtonStyle())
    }
}

struct DetailsView: View {
    ...
    @Environment(\.isFocused) var isFocused: Bool
    var body: some View {
        VStack {
            Text(songName)
            Text(isFocused ? artistAndAlbum : artistName)
        }
    }
}
```キーポイント:

- `SongView` は `Button` を使用します。ボタン自体はフォーカス可能です。
- `DetailsView` は、それ自体をフォーカス可能なビューにせずに `@Environment(\.isFocused)` を読み取ります。
- `Text(isFocused ? ArtistAndAlbum : ArtistName)` はフォーカス状態に応じて表示情報を切り替えます。
- セッションは、UIKit によってフォーカスが管理されているボタン、リスト、またはビューは、「focusable」修飾子のオーバーレイには適していないことを明確に思い出させます。

### デフォルトのフォーカスを制御し、状態変更後にリセットする

([08:01](https://developer.apple.com/videos/play/wwdc2020/10042/?time=481)) tvOS は初期フォーカスを幾何学的に計算し、通常は画面の上部または最前面のフォーカス可能なビューに当てられます。ログイン ページがデフォルトでユーザー名入力ボックスに重点を置くのは合理的です。ユーザー名とパスワードが入力されている場合、デフォルトのフォーカスはログイン ボタンに置​​かれます。```swift
@Namespace private var namespace
@State private var areCredentialsFilled: Bool

var body: some View {
    VStack {
        TextField("Username", text: $username)
            .prefersDefaultFocus(!areCredentialsFilled, in: namespace)
        SecureField("Password", text: $password)

        Button("Log In", action: logIn)
           .prefersDefaultFocus(areCredentialsFilled, in: namespace)
    }
    .focusScope(namespace)
}
```キーポイント:

- `@Namespace private var namespace` は、フォーカス スコープを識別するために使用される一意の ID を作成します。
- `areCredentialsFilled` は、ユーザー名入力ボックスとログイン ボタンのどちらがデフォルトのフォーカスとして適切であるかを決定します。
- `.prefersDefaultFocus(..., in: namespace)` は設定を表すだけであり、グローバル フォーカス ツリーを直接操作しません。
- `.focusScope(namespace)` は、これらの設定を現在の `VStack` に制限します。

([10:35](https://developer.apple.com/videos/play/wwdc2020/10042/?time=635)) ログインフォームをクリアした後、フォーカスをデフォルトの位置に戻す必要があります。 `resetFocus` 環境アクションは、同じ名前空間によってフォーカスをリセットします。```swift
@Namespace private var namespace
@State private var areCredentialsFilled: Bool
@Environment(\.resetFocus) var resetFocus

var body: some View {
    VStack {
        TextField("Username", text: $username)
            .prefersDefaultFocus(!areCredentialsFilled, in: namespace)
        SecureField("Password", text: $password)

        Button("Log In", action: logIn)
           .prefersDefaultFocus(areCredentialsFilled, in: namespace)

        Button("Clear", action: {
            username = ""; password = ""
            areCredentialsFilled = false
            resetFocus(in: namespace)
        })
    }
    .focusScope(namespace)
}
```キーポイント:

- `@Environment(\.resetFocus)` は、システムによって提供されるリセット フォーカス アクションを取り出します。
- [クリア] ボタンは、最初に「ユーザー名」と「パスワード」をクリアします。
- `areCredentialsFilled = false` は、ユーザー名入力ボックスにデフォルトのフォーカス設定を再度表示します。
- `resetFocus(in: namespace)` は、現在のフォーカス スコープ内でのみリセットを実行します。

### Lazy Grid を使用して TV ホームページの棚を整理する

([12:08](https://developer.apple.com/videos/play/wwdc2020/10042/?time=728)) Apple TV アプリの一般的な水平シェルフ レイアウトは、Lazy Grid を使用して実装できます。 Lazy Grid はオンデマンドで項目を初期化し、水平スクロール領域に多数のカバーを配置するのに適しています。```swift
struct ShelfView: View {
    var body: some View {
        ScrollView([.horizontal]) {
            LazyHGrid(rows: [GridItem()]) {
                ForEach(playlists, id: \.self) { playlist in
                    Button(action: goToPlaylist) {
                        Image(playlist.coverImage)
                            .resizable()
                            .frame(…)
                    }
                    .buttonStyle(CardButtonStyle())
                }
            }
        }
    }
}
```キーポイント:

- `ScrollView([.horizontal])` は水平スクロール領域を作成します。
- `LazyHGrid(rows: [GridItem()])` は、水平棚をグリッド行で編成します。
- `ForEach(playlists, id: \.self)` は、プレイリストを 1 つずつカバー ボタンにマッピングします。
- `Image(playlist.coverImage).resizable().frame(…)` は、カバーがサイズ変更可能であり、サイズがアプリによって指定されることを意味します。
- `.buttonStyle(CardButtonStyle())` は、各カバー ボタンに tvOS カード フォーカス効果を与えます。

## 重要なポイント

1. **アルバム棚のホームページを作成**

**やるべきこと**: 音楽、ビデオ、コース コンテンツを複数の水平の棚に整理し、プレイリストにまとめます。

**実行する価値がある理由**: Session によって表示される `ScrollView([.horizo​​ntal])` と `LazyHGrid` は、Apple TV アプリの一般的なレイアウトです。 Lazy Grid は、スクロールが必要なときに項目を読み込みます。

**開始方法**: まず、`LazyHGrid(rows: [GridItem()])` を使用して棚をレンダリングし、次に各カバーを `Button` にラップし、`CardButtonStyle()` を追加します。

2. **コンテンツカードに長押しショートカット操作を追加**

**作業内容**: アルバム、ビデオ、またはプレイリスト カード上の類似コンテンツの収集、作成者ページの表示、検索などのクイック アクションを提供します。

**実行する価値がある理由**: Session はアルバム ボタンを長押しすることで明示的にコンテキスト メニューを開き、メニュー項目は通常の `Button` を直接使用できます。

**開始方法**: カードビューの後に `.contextMenu` を追加し、各アクションを `Button("Action", action: handler)` として記述します。

3. **Now Playing リストをフォーカスして詳細を展開します**

**対処方法**: 現在フォーカスされている曲にはアーティスト名とアルバム名が表示され、その他の曲にはアーティスト名のみが表示され、TV インターフェース上の情報ノイズが軽減されます。

**実行する価値がある理由**: `isFocused` を使用すると、各詳細ビューに個別のフォーカス ラッパーを追加することなく、サブビューがフォーカス可能な最新の祖先のフォーカス状態を読み取ることができます。

**開始方法**: テキスト領域を `DetailsView` に分割し、その中の `@Environment(\.isFocused)` を読み取り、ブール値に応じて `Text` の内容を切り替えます。

4. **ログイン ページの状態主導型のデフォルト フォーカスを設定します**

**対処方法**: 認証情報が入力されていない場合は、デフォルトでユーザー名入力ボックスがフォーカスされ、認証情報が入力されると、デフォルトでログイン ボタンがフォーカスされます。

**実行する価値がある理由**: tvOS はデフォルトで幾何学的位置に基づいて初期フォーカスを選択します。ログイン プロセスは、フォームのステータスに基づいてフォーカスの入り口を決定するのにより適しています。

**開始方法**: `@Namespace` を作成し、ユーザー名入力ボックスとログイン ボタンにそれぞれ `.prefersDefaultFocus` を追加してから、`.focusScope(namespace)` を使用してスコープを制限します。

5. **フォームのクリアアクションにフォーカスリセットを追加**

**対処方法**: ユーザーが [クリア] をクリックした後、ユーザー名とパスワードをクリアし、フォーカスをユーザー名入力ボックスに戻します。

**実行する価値がある理由**: セッションは、現在の名前空間のデフォルト設定に従ってフォーカスを再計算する `resetFocus(in:)` を公開します。

**開始方法**: `@Environment(\.resetFocus)` を読み取り、Clear ボタン アクションでフォームのステータスを更新してから、`resetFocus(in: namespace)` を呼び出します。
