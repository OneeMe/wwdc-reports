## ハイライト

> Apple Music API 新規`/search/suggestions`、`relate`、`extend`、リレーションシップ ビュー、および Charts API パラメータを使用すると、開発者は検索候補、関連リソース、拡張属性、およびランキング プレイリストを迅速に取得できます。

## 主な内容

音楽検索ページを作りました。ユーザー入力`taylor`、インターフェイスはすぐに提案を提供するはずです。

以前は、電話をかけるのが一般的でした。`/search/hints`提案された言葉を採用します。ユーザーが検索したいものはわかりますが、アーティストや曲などの結果を直接与えることはできません。通常のルートに進む前に、ユーザーが送信するまで待つ必要があります。`/search`。関連付けページに入るには数秒かかります。

Apple が 2021 年に Apple Music API に追加`/search/suggestions`。それは置き換えます`/search/hints`、提案された単語を保持し、上位の結果を返します。アーティストと曲は入力ボックスのすぐ下に表示されます。

検索結果が出た後、2 番目の質問がありました。曲からそのアルバム ページにジャンプしたいだけかもしれません。使用`include`フルアルバムを取得すると、さらに多くのフィールドが得られます。アップルの新製品`relate`の場合、関連付けられたリソースの ID、タイプ、href のみが返されます。ジャンプ力も十分でレスポンスも軽いです。

一部のフィールドはデフォルトでは指定できません。歌など`artistUrl`。これは機能しますが、すべての検索を返すと応答が遅くなったり、オブジェクト モデルが大きくなったりする可能性があります。`extend`リソース タイプごとに名前で拡張属性をリクエストできます。

商品ページには別の種類のデータがあります。アーティスト ページには、人気の曲、人気の MV、シングル リストが必要です。これらはページ モジュールに似ています。 Apple はこのタイプのデータを運ぶために関係ビューを使用しており、開発者は`views`パラメータまたは`/view/{viewName}`パスのリクエスト。

最後に、Charts API はチャート プレイリストを直接取得できます。グローバルデイリーリストと都市リストを渡すことができます`/charts`追加`with`パラメータを取得すると、ディスカバリー ページやローカル トレンド ポータルに適しています。

＃＃詳細

＃＃＃ 使用`/search/suggestions`検索候補に戻る

（[01:25](https://developer.apple.com/videos/play/wwdc2021/10291/?time=85)）

`/search/suggestions`代わりの`/search/hints`。 If you only need the old suggestion word capability, specify this in the request`kinds=terms`。

```http
GET /v1/catalog/us/search/suggestions?term=taylor&kinds=terms
```

**キーポイント:**
- `GET`Apple Music カタログ データの読み取りを表します。
-`/v1/catalog/us`米国のストアフロントにアクセスするためのディレクトリを指定します。
-`/search/suggestions`は新しい検索候補エンドポイントです。
-`term=taylor`は、ユーザーが現在入力している検索語です。
-`kinds=terms`提案された検索語を返すように要求します。

応答には、各提案の種類が示されます。また、検索クエリで使用される単語とユーザーに表示される単語も区別されます。検索ボックスを使用すると、表示コピーをより使いやすくし、クエリ用語を後続の検索リクエストに引き渡すことができます。

### 上位の結果を使用して入力を促進 Lenovo

（[02:09](https://developer.apple.com/videos/play/wwdc2021/10291/?time=129)）

入力の関連付けでは、多くの場合、アーティストと曲を直接表示する必要があります。新しいエンドポイント`kinds=topResults`これを行うには、必要なリソースのタイプも指定します。

```http
GET /v1/catalog/us/search/suggestions?term=taylor&kinds=topResults&types=artists,songs
```

**キーポイント:**
- `kinds=topResults`人気の検索結果が返されるようにリクエストします。
-`types=artists,songs`結果をアーティストと曲に限定します。
- 上位の結果のリソースが応答に配置されます`content`キーを押します。
- このエンドポイントは速度を優先しており、結果は通常のものと同じくらい優れている可能性があります。`/search`違う。
- 通常`/search`まだ完全な検索結果ページに収まります。

このタイプのリクエストは、入力ボックスのドロップダウン レイヤーに適しています。ユーザーは Enter キーを押す前にアーティストまたは曲をクリックできます。

＃＃＃ 使用`relate`関連付けられたリソース識別子のみを取得します

（[03:47](https://developer.apple.com/videos/play/wwdc2021/10291/?time=227)）

Apple Music API のリソース識別子は、ID、type、href で構成されます。`relate`関係をリクエストすると、これらの識別子のみが返されます。

```http
GET /v1/catalog/us/search/suggestions?term=taylor&kinds=topResults&types=artists,albums,songs&relate[songs]=albums
```

**キーポイント:**
- `types=artists,albums,songs`提案された結果にアーティスト、アルバム、曲を含めることができます。
-`relate[songs]=albums`曲リソースのリクエストのみが行われることを示します`albums`関係。
- 返されるアルバム関係には、リソース識別子のみが含まれます。
- 曲をクリックするとアルバムページにジャンプするだけです。`href`十分です。
- この応答は、完全な関係オブジェクトを要求するよりも高速です。

これにより、検索ページの一般的な無駄が解決されます。リスト ページにはジャンプ ターゲットのみが必要で、アルバム名、カバー、その他の属性は必要ありません。

＃＃＃ 使用`extend`拡張属性をリクエストする

（[05:03](https://developer.apple.com/videos/play/wwdc2021/10291/?time=303)）

リソースには、デフォルトで名前やアートワークなどの共通属性が含まれます。一部のプロパティは計算コストが高いか、使用頻度が低いため、デフォルトでは返されません。`extend`これらの拡張属性を名前で要求するために使用されます。

```http
GET /v1/catalog/us/search/suggestions?term=taylor&kinds=topResults&types=artists,albums,songs&relate[songs]=albums&extend[songs]=artistUrl
```

**キーポイント:**
- このリクエストは以前の検索候補を継承し、`relate`。
- `extend[songs]=artistUrl`曲リソースのみをリクエストすることを示します`artistUrl`拡張属性。
-`artistUrl`ユーザーを Apple Music のアーティストのページに誘導するために使用できます。
- 拡張プロパティは、デフォルトの応答が遅くなったり大きくなったりするのを避けるために、オンデマンドで返されます。

実際の使用方法の 1 つは、検索結果の [アーティスト ページを開く] ボタンです。このボタンが存在する場合にのみ要求されます`artistUrl`。

### リレーションシップ ビューを使用してアーティスト ページ モジュールを構築する

（[06:16](https://developer.apple.com/videos/play/wwdc2021/10291/?time=376)）

ビューは製品ページに適しています。これはリレーションシップよりも緩やかで、独自のヘッダーとデータを持つことができます。講演で挙げられた例は、アーティストのトップ ソング ビューです。

```http
GET /v1/catalog/us/artists/159260351?views=top-songs
```

**キーポイント:**
- `/artists/159260351`アーティストのリソースを直接取得します。
-`views=top-songs`リクエストの応答には、トップソングのビューが含まれています。
- ビューは、リソースの直接取得中にのみリクエストできます。
- その他の例には、トップ ミュージック ビデオやシングルが含まれます。
- 特定のリソース タイプがサポートするビューについては、Apple Music API ドキュメントを確認する必要があります。

パスを使用して同じビューをリクエストすることもできます。

```http
GET /v1/catalog/us/artists/159260351/view/top-songs
```

**キーポイント:**
- `/view/top-songs`リソース ID の後に配置します。
- この書き方では 1 つのビューのみを要求します。
- ユーザーが「Hot Songs」領域までスクロールしたときにリクエストを送信するなど、ページ モジュールの遅延読み込みに適しています。

### Charts API を使用してグラフ リストを取得する

（[06:59](https://developer.apple.com/videos/play/wwdc2021/10291/?time=419)）

Apple Music は、世界、店頭、都市レベルのチャート プレイリストをサポートしています。ユーザーはこれらのプレイリストをデータベースに追加でき、プレイリストは自動的に更新されます。開発者は直接アクセスできるようになりました。`/charts`入手してください。

```http
GET /v1/catalog/us/charts?types=playlists&with=dailyGlobalTopCharts,cityCharts
```

**キーポイント:**
- `/charts`リーダーボードのエンドポイントです。
-`types=playlists`返されるプレイリストタイプのランキングリストを指定します。
-`with=dailyGlobalTopCharts,cityCharts`グローバルのデイリーリストと都市リストをリクエストします。
-`with`パラメーターは、コレクションの 1 つだけ、または両方で渡すことができます。
- 返された結果は、音楽検索ページに配置するのに適しています。

## 重要なポイント

1. **やるべきこと**: 音楽アプリのインスタント検索ドロップダウン レイヤーを作成します。
   **実行する価値がある理由**:`/search/suggestions`提案された単語と人気のある結果の両方を返すことができ、先行入力に適しています。
   **開始方法**: 入力ボックス内のテキストの変化を監視し、呼び出します`GET /v1/catalog/{storefront}/search/suggestions?term={text}&kinds=topResults&types=artists,songs`、バンドル`content`以下のアーティストと曲は、クリック可能なアイテムとして表示されます。

2. **やるべきこと**: 曲の検索結果に「アルバムの表示」ショートカットを追加します。
   **実行する価値がある理由**:`relate[songs]=albums`アルバムリソース識別子のみが返されます。`href`ジャンプすることができます。
   **開始方法**: 検索の提案 参加のリクエスト`relate[songs]=albums`、曲の結果でアルバムの関係を読み取ります。`href`をクリックしてアルバム詳細ページのデータを取得します。

3. **やるべきこと**: 検索結果に「Apple Music でアーティストを開く」ボタンを追加します。
   **実行する価値がある理由**:`extend[songs]=artistUrl`すべてのリクエストにデフォルトで拡張属性を持たせる必要がなく、オンデマンドで曲に対応するアーティスト リンクを取得できます。
   **開始方法**: インターフェイスに外部リンク ボタンが必要な場合のみ、リクエストに追加します`extend[songs]=artistUrl`、そしてそれを返します`artistUrl`ボタンにバインドします。

4. **やるべきこと**: アーティスト詳細ページの「Hot Songs」モジュールを作成します。
   **実行する価値がある理由**: リレーションシップ ビューに特化したサービス製品ページ モジュール、`top-songs`このページのニーズを直接表現します。
   **始め方**：アーティストページ入場時のお願い`/v1/catalog/{storefront}/artists/{id}?views=top-songs`、ビューデータを曲リストにレンダリングします。モジュールが最初の画面の外側にある場合は、次を使用できます`/view/top-songs`遅延読み込み。

5. **やるべきこと**: アーバン ミュージックのトレンド ページを作成します。
   **実行する価値がある理由**: Charts API は機能します`with=cityCharts`地元の人気コンテンツを紹介するのに適した都市チャートのプレイリストを入手します。
   **開始方法**: 電話`/v1/catalog/{storefront}/charts?types=playlists&with=cityCharts`、返されたチャート プレイリストを入り口として使用し、クリックしてプレイリストの詳細を入力します。
