## Highlight

> WWDC 2020 首次以线上形式面向 2300 万开发者免费开放，并宣布 Mac 将转向 Apple Silicon，为 iOS、iPadOS 与 macOS 应用共享芯片架构奠定基础。

## 核心内容

2020 年的 Keynote 放在一个特殊背景里开场。Tim Cook 先说明这届 WWDC 会从 Apple Park 直接送到开发者家中，超过 100 场工程视频、开发者论坛和一对一工程咨询会免费开放给全球 2300 万开发者（[04:41](https://developer.apple.com/videos/play/wwdc2020/101/?time=281)）。对开发者来说，这不是简单地把线下会议搬到线上；会议分发方式变了，平台更新的学习节奏也变了。

Keynote 的主线很清楚：用户在手机、平板、手表、客厅和 Mac 之间切换得越来越频繁，系统需要在每个入口上减少打断。iOS 14 的 App Library、Widgets、Picture in Picture 和 App Clips 都在处理这个问题；iPadOS 14 用 sidebar、紧凑搜索和 Scribble 让大屏操作更像生产工具；watchOS 7 把表盘、睡眠和洗手检测变成更贴近日常的入口。

最后的 Apple Silicon 才是这场发布会的结构性变化。Mac 从 Intel 处理器转向 Apple 自研 SoC 后，Apple 可以把 Secure Enclave、高性能 GPU、Neural Engine、统一芯片架构和更高每瓦性能带到 Mac。迁移不是只给硬件团队的新闻，它会影响 Mac 应用的构建方式、测试矩阵、性能假设，以及 iPhone/iPad 应用进入 Mac App Store 的路径。

## 详细内容

### iOS 14：主屏、Widget 和即时 App 入口

（[07:40](https://developer.apple.com/videos/play/wwdc2020/101/?time=460)）App Library 是 iOS 14 对主屏膨胀问题的回应。系统在主屏最后一页放入一个自动整理空间，包含搜索、按字母排序、Suggestions、Recently Added 和智能分类。用户可以隐藏不常用页面，把访问路径收敛到一两次滑动。

关键点：
- App Library 自动分类应用，用户不需要手动维护文件夹。
- Suggestions 使用 on-device intelligence 预测用户下一步可能需要的 App。
- Recently Added 让新下载 App 不必散落在多页主屏上。

（[09:32](https://developer.apple.com/videos/play/wwdc2020/101/?time=572)）Widgets 从 Today View 走到 Home Screen，并增加多种尺寸。Smart Stack 可以手动翻页，也可以根据一天中的情境自动轮换。Keynote 没有展开 WidgetKit 代码，但明确展示了 Widget Gallery、尺寸选择、拖放到主屏和 Smart Stack 自动切换的用户模型。

关键点：
- Widget 变成主屏上的信息卡片，不再只藏在 Today View。
- 三种尺寸让同一类信息可以表达不同密度。
- Smart Stack 让系统在早晨、会议前、晚上等场景里展示不同 Widget。

（[11:43](https://developer.apple.com/videos/play/wwdc2020/101/?time=703)）Picture in Picture 来到 iPhone。用户从视频或 FaceTime 退出到主屏后，画面会浮在当前 App 上方，可以拖动、缩放、收起到屏幕边缘，音频继续播放。

关键点：
- 视频体验不再强占整个 iPhone 屏幕。
- 浮窗位置和大小由用户控制。
- 收起浮窗后音频持续播放，适合听课、会议和长视频场景。

（[29:00](https://developer.apple.com/videos/play/wwdc2020/101/?time=1740)）App Clips 是 Keynote 中最直接面向开发者的新分发入口。它是完整 App 的一小部分，强调轻量、快速、容易发现。用户可以从网页、Messages、Maps place card、NFC 标签、QR 码或 Apple 设计的 App Clip Code 打开它；支付可以用 Apple Pay，登录可以用 Sign in with Apple；为了保证启动速度，App Clip 需要小于 10 MB。

关键点：
- App Clip 适合停车、点咖啡、租车、点餐这类短任务。
- Apple Pay 和 Sign in with Apple 降低第一次使用时的输入成本。
- App Clip 不会长期占据主屏，但最近用过的 App Clip 可以从 App Library 再次打开。
- 多商户平台也可以为不同商家创建不同 App Clip 体验。

### iPadOS 14：大屏控件和 Apple Pencil 输入

（[32:49](https://developer.apple.com/videos/play/wwdc2020/101/?time=1969)）iPadOS 14 把很多系统 App 改成更适合大屏的结构。Photos、Notes、Files 和 Music 都使用 sidebar，把导航集中在左侧；Toolbar 通过下拉菜单收纳操作；Calendar 这类 App 把控件放到统一顶部区域，给内容留出更多空间。

关键点：
- Sidebar 让 iPad App 可以同时显示导航和内容。
- 统一 Toolbar 减少底部和顶部控件分散的问题。
- 紧凑 Siri、紧凑来电和通用搜索都在减少上下文切换。

（[39:14](https://developer.apple.com/videos/play/wwdc2020/101/?time=2354)）Scribble 让 Apple Pencil 可以直接写入任意文本框，系统自动转成文本。演示中，手写可以用于 Safari 搜索框和 Reminders 输入框，还能在同一行识别英文和中文。手写内容也可以像文本一样选择、移动、改变颜色，或通过 Copy as Text 粘贴到 Pages。

关键点：
- 文本框直接支持 Pencil 手写输入，用户不用放下 Pencil 切键盘。
- on-device machine learning 区分手写内容和旁边的绘图。
- Data Detectors 可以识别手写里的电话号码和地址。

### AirPods、watchOS 和隐私：把系统能力放到日常动作里

（[42:52](https://developer.apple.com/videos/play/wwdc2020/101/?time=2572)）AirPods 增加 Automatic Switching，会在 iPhone、iPad 和 Mac 之间自动切换音频。AirPods Pro 的 spatial audio 用方向音频滤波、耳机加速度计和陀螺仪追踪头部运动，并持续比较头部和屏幕的相对运动，让 5.1、7.1 和 Dolby Atmos 内容保持空间定位（[43:22](https://developer.apple.com/videos/play/wwdc2020/101/?time=2602)）。

关键点：
- Automatic Switching 处理用户跨设备切换时的蓝牙管理成本。
- Spatial audio 把头部运动和设备运动都纳入计算。
- 支持的内容格式包括 5.1、7.1 和 Dolby Atmos。

（[46:17](https://developer.apple.com/videos/play/wwdc2020/101/?time=2777)）watchOS 7 允许一个 App 在同一表盘上提供多个 complications，还引入 Face Sharing。开发者可以用 native SwiftUI 构建 rich complications，用户可以从 App Store、网页、朋友消息或社交平台发现预配置表盘。

关键点：
- 多 complication 让同一个 App 可以在表盘上展示多种数据。
- Face Sharing 把表盘从个人配置变成可分发入口。
- 缺少相关 App 时，系统会提示用户安装。

（[51:17](https://developer.apple.com/videos/play/wwdc2020/101/?time=3077)）睡眠功能从目标设置开始，配合 Wind Down、Do Not Disturb、Sleep Mode 和轻柔闹钟引导用户建立睡前流程。Apple Watch 用机器学习模型分析运动和呼吸带来的微小动作，判断清醒和睡眠状态。

关键点：
- 睡眠功能覆盖从睡前到醒来的完整流程，统计页只是其中一部分。
- Wind Down 可以接入快捷指令，例如冥想 App 或放松音乐。
- iPhone 用户即使没有 Apple Watch，也可以使用 Sleep Schedules、Wind Down 和 Sleep Mode。

（[55:29](https://developer.apple.com/videos/play/wwdc2020/101/?time=3329)）隐私部分给开发者列出了四条平台原则：data minimization、on-device intelligence、security、transparency and control。iOS 14 增加 approximate location、麦克风和摄像头状态栏指示、跨 App 和网站追踪前的授权要求，以及 App Store 产品页上的隐私摘要（[57:33](https://developer.apple.com/videos/play/wwdc2020/101/?time=3453)）。

关键点：
- 位置权限可以从精确位置降级到大致位置。
- 麦克风或摄像头当前及近期使用会有系统可见提示。
- App Store 会展示开发者自报的数据收集和共享实践。

### macOS Big Sur 和 Apple Silicon：Mac 的新迁移周期

（[01:09:08](https://developer.apple.com/videos/play/wwdc2020/101/?time=4148)）macOS Big Sur 是 Mac OS X 以来最大的一次设计更新。Dock、App 图标、侧边栏、菜单栏、Control Center、Notification Center 和 Widgets 都被重新设计。Messages 和 Maps 获得与 iOS 14 更接近的功能，Safari 增加 Privacy Report、密码泄露监测、WebExtensions API、扩展权限控制、可定制起始页和内建翻译。

关键点：
- Big Sur 的 UI 更接近 Apple 全平台视觉语言，但保留 Mac 的窗口、菜单栏和多窗口工作方式。
- Control Center 来到 Mac，常用系统控制可以拖到菜单栏。
- Safari 扩展可以按一天、某个网站或长期授予权限。

（[01:26:50](https://developer.apple.com/videos/play/wwdc2020/101/?time=5210)）Apple 宣布 Mac 转向 Apple Silicon。Johny Srouji 把理由讲成三个层次：第一，Apple 已经在 iPhone、iPad 和 Apple Watch 上积累了十年的 SoC 设计经验；第二，Mac 可以获得更高每瓦性能、Secure Enclave、高性能 GPU、Neural Engine、视频显示和图像处理引擎；第三，所有产品线会拥有共同架构，开发者更容易为整个 Apple 生态写和优化软件（[01:28:13](https://developer.apple.com/videos/play/wwdc2020/101/?time=5293)）。

关键点：
- Apple Silicon 迁移的核心指标是每瓦性能。
- Mac 会获得面向本机产品线设计的一族 SoC。
- 统一架构会影响跨 iPhone、iPad、Mac 的代码复用和优化路径。

（[01:34:21](https://developer.apple.com/videos/play/wwdc2020/101/?time=5661)）开发者迁移工具链的关键词是 Universal 2。Xcode 可以构建同时支持 Intel Mac 和 Apple Silicon Mac 的 Universal binary。Apple 表示多数开发者只需打开项目并重新编译，就能在几天内让 App 跑起来。对尚未原生迁移的 App，macOS Big Sur 提供 Rosetta 2，会在安装时翻译现有 Mac App，也能在需要时动态翻译 JIT JavaScript 或 Java 代码（[01:39:21](https://developer.apple.com/videos/play/wwdc2020/101/?time=5961)）。

关键点：
- Universal 2 用单个二进制同时覆盖 Intel Mac 和 Apple Silicon Mac。
- Rosetta 2 让未更新 App 在新 Mac 上继续运行。
- Virtualization 技术支持开发者运行 Linux 和 Docker 等环境。

（[01:42:16](https://developer.apple.com/videos/play/wwdc2020/101/?time=6136)）因为 iPhone、iPad 和新 Mac 都基于 Apple Silicon，iPhone 和 iPad App 可以原生、未修改地运行在新 Mac 上。用户可以从 Mac App Store 下载，多数 App 不需要开发者改动。Apple 同时发布 Quick Start Program 和 Developer Transition Kit，DTK 是一台带 A12Z SoC、16 GB 内存、512 GB SSD、Mac I/O 端口、macOS Big Sur developer beta 和 Xcode 工具的 Mac mini 形态设备（[01:44:02](https://developer.apple.com/videos/play/wwdc2020/101/?time=6242)）。

关键点：
- iPhone 和 iPad App 第一次可以直接进入 Mac App Store 的 Apple Silicon Mac。
- Quick Start Program 提供文档、sample code、论坛、DTS 支持和 labs。
- Tim Cook 给出的迁移节奏是 2020 年底发布首台 Apple Silicon Mac，整轮迁移约两年，同时继续支持 Intel Mac 多年（[01:45:50](https://developer.apple.com/videos/play/wwdc2020/101/?time=6350)）。

## 核心启发

- **把主屏入口改成 glance-first**：做什么：为 App 中最常被快速查看的状态设计 Widget。为什么值得做：iOS 14 把 Widget 放到 Home Screen，Smart Stack 会在合适场景露出信息。怎么开始：先选一个无需交互也有价值的状态，例如包裹进度、课程下一节、账单到期日，再去看 WidgetKit 和 timeline 的实现。

- **为一次性任务拆出 App Clip**：做什么：把停车、点单、预约、扫码领票这类短流程做成 App Clip。为什么值得做：Keynote 明确 App Clip 可以通过 NFC、QR、Maps、Messages 和 App Clip Code 发现，并能接 Apple Pay 与 Sign in with Apple。怎么开始：从完整 App 中切出一个小于 10 MB 的单任务路径，保留支付、登录和完成后的 full app 引导。

- **重新审查 Mac 应用的架构假设**：做什么：为 Apple Silicon 准备 Universal 2 构建和原生测试。为什么值得做：Apple Silicon 带来新的 CPU/GPU/Neural Engine 组合，Rosetta 2 只是过渡层。怎么开始：先用 Xcode 的标准架构设置构建 Universal binary，再检查低层依赖、插件、JIT、虚拟化和性能测试脚本。

- **让 iPad 输入模型覆盖 Pencil、键盘和触控板**：做什么：把 iPad App 的文本输入、搜索、导航和批量操作改成适配多输入设备的结构。为什么值得做：Scribble、紧凑搜索、sidebar 和新 Toolbar 都在把 iPad 推向更长时间的生产工作流。怎么开始：先梳理 App 中最常见的输入场景，确认文本框、搜索框、侧边栏层级和快捷操作在 Pencil 与键盘路径下都能完成。

- **把隐私信息做成产品表面的一部分**：做什么：在功能设计阶段明确精确位置、近似位置、麦克风、摄像头、追踪和数据共享的用户解释。为什么值得做：iOS 14 把这些权限变化放进系统 UI 和 App Store 产品页，用户会在下载前看到更多隐私摘要。怎么开始：为每个敏感权限写清使用目的，减少默认采集，把 on-device 处理作为优先方案。
