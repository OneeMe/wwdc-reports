## ハイライト

> Apple は、WWDC21 の初日に iOS 15、SharePlay、Live Text、Universal Control、Xcode Cloud、Swift 同時実行性、オブジェクト キャプチャ、その他の機能をリリースしました。開発者は、コラボレーション、認識、自動構築、AR コンテンツ制作のための新たな入り口を獲得しました。

## 主な内容

開発者が WWDC 初日を見た後、よくある質問は非常に単純なものでした。つまり、今年最初に何を学ばなければならないのか、どの新機能がアプリに影響を与えるのか、どの機能が単なるシステム機能のアップデートなのかなどです。

この要約では、初日を 2 分強に凝縮しています。 iOS 15 から始まり、マップの 3D 再設計、Safari のクロスプラットフォームの新しい外観、Live Text の写真内のテキスト認識について言及しています。次に、FaceTime、SharePlay、Apple TV、Find My、iCloud+、iPad ホーム画面、Mac への AirPlay、およびユニバーサル コントロールに進みます。

開発者にとって、焦点はいくつかの場所にあります。 SharePlay は単なるシステム ビデオ通話機能ではなく、Apple は開発者に新しい再生起動 API を提供することを明確に述べており、これらの API はアプリの既存のビデオ エクスペリエンスにプラグインできます。 Swift 同時実行性、SwiftUI、Object Capture for ARKit、および Xcode Cloud も、初日から開発者ツールチェーンに組み込まれます。

このセッションの価値は、API の詳細について話すことではありません。その機能は、学習ルートを分類することです。まず基調講演を見てグローバルな視点を確立し、次にプラットフォームの一般教書を見て技術的な入り口を見つけ、最後に、独自のアプリの種類に応じて SharePlay、Swift、Xcode Cloud、ARKit、およびその他の特別なセッションに入ります。

＃＃詳細

### iOS 15: システムエクスペリエンスから始まり、アプリシーンに影響を与える

([00:13](https://developer.apple.com/videos/play/wwdc2021/10321/?time=13)) iOS 15 のファーストクリックを確認してください。トランスクリプトにリストされているシステム機能には、再設計された Maps 3D、Safari の新しい外観、Live Text が含まれます。これらの機能は、ユーザーがアプリの外部でタスクを完了する方法を変更し、アプリへのコンテンツの入力にも影響します。

```text
iOS 15
- Maps: intuitive 3D redesign
- Safari: new look on iPhone, iPad, and Mac
- Live Text: text recognition in images
```

キーポイント:

- `iOS 15`これは、初日のプラットフォーム更新の開始点です。
-`Maps`3D の再設計は、位置情報とナビゲーションのようなエクスペリエンスに影響を与えます。
-`Safari`iPhone、iPad、Mac での同時変更、Web コンテンツとアプリのディープリンクを一緒に確認する必要があります。
-`Live Text`画像内のテキストをインタラクティブな情報に変換し、請求書、メモ、写真の検索などのシナリオに適しています。

### SharePlay: 同期再生を既存のビデオ体験に統合

([00:26](https://developer.apple.com/videos/play/wwdc2021/10321/?time=26)) FaceTime には空間オーディオとポートレート モードが追加されます。さらに、SharePlay は、iPhone、iPad、Mac、Apple TV を対象として、友人との画面、音楽、テレビ番組の同時共有をサポートします。

```text
SharePlay
- share your screen
- listen to music in sync
- watch a TV show in sync
- works across iPhone, iPad, Mac, and Apple TV
- new APIs to start playback inside an existing video experience
```

キーポイント:

- `share your screen`SharePlay はメディア再生だけでなく、共同プレゼンテーションも提供することに注意してください。
-`in sync`これは、参加者が同じ進捗状況を見たり聞いたりするという中核的な制約です。
-`iPhone, iPad, Mac, and Apple TV`エクスペリエンスはデバイス間で一貫している必要があることを説明します。
-`new APIs to start playback`これは開発者ポータルであり、Apple はレビューの中でそれをアプリの既存のビデオ エクスペリエンスと明確に結び付けました。

### ユニバーサル コントロール: マルチデバイス ワークフローがデフォルトの前提となる

([01:05](https://developer.apple.com/videos/play/wwdc2021/10321/?time=65)) この要約では、AirPlay が Mac に導入されることに言及し、次にユニバーサル コントロールを紹介します。ユーザーはデバイス間を移動したり、1 つのデバイスであるかのように操作したり、ファイルをドラッグ アンド ドロップしたりできます。

```text
Universal Control
- move between different devices as if they were one
- drag and drop files between devices
```

キーポイント:

- `different devices`Mac と iPad などのクロスデバイスの組み合わせを指します。
-`as if they were one`入力フォーカスとポインターの移動は連続的である必要があることに注意してください。
-`drag and drop files`それは具体的な相互作用です。ファイル アプリは、ドラッグ アンド ドロップ、インポート、エクスポートのプロセスを確認する必要があります。

### Xcode Cloud、Swift 同時実行性、SwiftUI: 開発ツール チェーンの更新

([01:43](https://developer.apple.com/videos/play/wwdc2021/10321/?time=103)) レビューの後半は開発者のコ​​ンテンツについて説明します。 Transcript では、Xcode Cloud、Focus モード、Swift Playgrounds、Swift 同時実行性、SwiftUI、ハイエンド ゲーム開発ツール、Object Capture for ARKit、および SharePlay API について継続的に言及しています。

```text
Developer tools and frameworks
- Xcode Cloud
- Focus mode
- Swift Playgrounds app building
- Swift concurrency
- SwiftUI
- high-end game development tools
- Object Capture for ARKit
- APIs for SharePlay
```

キーポイント:

- `Xcode Cloud`Apple の開発プロセス内での継続的な統合と配信機能を指します。
-`Focus mode`通知とユーザーの注意管理に影響を与えるため、アプリはユーザーのフォーカス状態を尊重する必要があります。
-`Swift Playgrounds app building`アプリ構築能力を Swift Playgrounds にもたらします。
-`Swift concurrency`これは、Swift 同時実行モデルへの入り口です。特別セッションの続きは後ほどお読みください。
-`Object Capture for ARKit`現実世界のオブジェクトから AR コンテンツを生成するためのワークフローを指します。
-`APIs for SharePlay`SharePlay に開発者 API の入り口があることを再度確認します。

### 健康、ウォレット、Siri: システム サービスが新たなシナリオを切り開く

([01:18](https://developer.apple.com/videos/play/wwdc2021/10321/?time=78)) 中央のセクションでは、ウォーキングの安定性、ヘルスアプリの健康データ共有、太極拳、ピラティス、Apple Watch のマインドフルネス、さらにサードパーティ製デバイスのウォレット、ホームキー、Siri の ID カードについても言及しています。

```text
System services
- Walking Steadiness
- Health data sharing with family and doctors
- Tai Chi, Pilates, and mindfulness on Apple Watch
- ID cards in Wallet
- Home Keys in Wallet
- Siri on third-party devices
```

キーポイント:

- `Walking Steadiness`健康体験に健康リスクのリマインダーを組み込みます。
-`Health data sharing`家族や医師が健康データの利用シナリオになってみましょう。
-`Home Keys`ウォレットをドアロック操作まで拡張します。
-`Siri on third-party devices`これは、音声ポータルがより多くの家庭用デバイスに表示されることを示しています。

## 重要なポイント

1. **やるべきこと**: SharePlay 視聴入り口をビデオ アプリに追加します。
   **実行する価値がある理由**: このレビューでは、Apple が既存のビデオ エクスペリエンスにプラグインできる新しい再生起動 API を提供していると明示的に述べています。
   **開始方法**: まず、グループ アクティビティと SharePlay 特別セッションを見て、同期再生、参加者のステータス、再生制御のフレームワークの入り口を確認します。

2. **やるべきこと**: テキスト認識操作フローを画像アプリまたはスキャン アプリに追加します。
   **実行する価値がある理由**: Live Text は、画像内のテキストをユーザーにとって実用的な情報に変換します。
   **開始方法**: 写真、スクリーンショット、メモ、ホワイトボード画像からテキストを抽出し、コピー、検索、リマインダーの作成などの次のアクションを設計します。

3. **やるべきこと**: iPad と Mac 間のドラッグ アンド ドロップのインポート プロセスを確認してください。
   **価値がある理由**: Universal Control は、デバイス間でのファイルのドラッグ アンド ドロップを、初日に集中したワークフローに変えます。
   **開始方法**: アプリでサポートされているファイルの種類を整理し、ドラッグイン、ドラッグアウト、エラー プロンプト、インポート後の状態回復を確認します。

4. **やるべきこと**: プロジェクトを Xcode Cloud のビルド チェックに接続します。
   **価値がある理由**: Xcode Cloud は開発者ツールチェーンに初日から組み込まれており、ビルド、テスト、配布前チェックの自動化に適しています。
   **開始方法**: マスター ブランチのビルド ワークフローから開始し、徐々にテスト、アーカイブ、TestFlight 配布を追加します。

5. **やるべきこと**: AR 表示アプリ用のオブジェクト キャプチャ マテリアル プロセスを確立します。
   **実行する価値がある理由**: ARKit のオブジェクト キャプチャが初日の開発者機能リストに表示され、Apple が現実のオブジェクトの AR コンテンツへの制作プロセスを最前線に置いていることがわかります。
   **開始方法**: まず小さなオブジェクトを選択し、複数の角度から写真を撮り、オブジェクト キャプチャの特別情報を読み続けて、生成された 3D コンテンツを ARKit に接続して表示します。
