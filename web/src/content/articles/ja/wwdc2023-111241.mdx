## ハイライト

> Vision フレームワークは、ARKit を使用せずに通常の写真から 17 の関節の 3D 位置 (メートル単位) を抽出できる 3D 人間の姿勢検出 (VNDetectHumanBodyPose3DRequest) を追加します。また、深度データの入力と最大 4 人のインスタンスのセグメンテーションもサポートしており、人体の理解を 2D 平面から実空間に移すことができます。

## 主な内容

### 2D から 3D へ: 人間の姿勢検出の進化

Vision フレームワークは、以前は 2D 人間の姿勢検出を提供し、正規化されたピクセル座標を返していました。 WWDC23導入`VNDetectHumanBodyPose3DRequest`、画像から直接 3D 関節位置を抽出します。

3D ポーズは、グループに分類された 17 個のジョイントを返します。

- **頭**: 頭頂部、頭の中心
- **胴体**：左肩、右肩、背骨、股関節中心（根元関節）、左股関節、右股関節
- **左腕**: 左手首、左肩、左肘
- **右腕**: 右手首、右肩、右肘
- **左脚**: 左股関節、左膝、左足首
- **右脚**: 右股関節、右膝、右足首

左と右は、画像の左と右ではなく、検出される人物を基準としたものです。

（[00:51](https://developer.apple.com/videos/play/wwdc2023/111241/?time=51)）

2D 検出とは異なり、3D 関節位置は股関節の中心 (根元関節) を原点としてメートル単位で返されます。これにより、人の手首が地面からどのくらいの高さになるかなど、現実世界の距離を直接測定できます。

### 深度データ: 3D をより正確にする

Vision は深度データを入力として受け入れるようになりました。`VNImageRequestHandler`サポートの追加`AVDepthData`初期化メソッド、適用可能`CVPixelBuffer`そして`CMSampleBuffer`。

画像ファイル自体に深度データ (ポートレート モードの写真など) が含まれている場合、Vision は既存の API を変更せずにそれを自動的に抽出します。

深度データには次のものが含まれます。

- **深度マップ**: 視差または深度形式で保存されます
- **カメラ キャリブレーション データ**: 内部パラメータ、外部パラメータ、レンズ歪みパラメータ

深度データがある場合、`bodyHeight`実際に測定された身長を返します。利用できない場合は、基準値 1.8 メートルを返します。あなたは合格できます`heightEstimation`属性判定はどのような方法で行うのか。

（[10:41](https://developer.apple.com/videos/play/wwdc2023/111241/?time=641)）

### 複数人のインスタンスの分割: 「全員」から「全員」へ

前の`GeneratePersonSegmentation`リクエストは全員を含む 1 つのマスクを返します。新しく導入された人物インスタンスのマスク リクエストでは、最大 4 人の独立した人物のマスクを出力でき、それぞれに信頼度スコアが付けられます。

画像内の人物を個別に選択して抽出できます。背景のみが必要な場合は、インスタンス 0 を選択します。

4 人を超えるシーンの場合は、最初に Vision の顔検出 API を使用してカウントし、4 人を超える場合は従来の 1 人のセグメンテーション リクエストにフォールバックすることをお勧めします。

### 3D 人物姿勢検出のワークフロー

使用`VNDetectHumanBodyPose3DRequest`このプロセスは 2D リクエストの場合と同じです。

```swift
import Vision
import UIKit

func detect3DBodyPose(in image: UIImage) {
    // 1. 创建 3D 人体姿态检测请求
    let request = VNDetectHumanBodyPose3DRequest()
    
    // 2. 初始化图像请求处理器
    guard let cgImage = image.cgImage else { return }
    let handler = VNImageRequestHandler(cgImage: cgImage)
    
    // 3. 执行请求
    do {
        try handler.perform([request])
        
        // 4. 获取结果
        if let observation = request.results?.first as? VNHumanBodyPose3DObservation {
            process3DPose(observation)
        }
    } catch {
        print("3D pose detection failed: \(error)")
    }
}
```

キーポイント:
- `VNDetectHumanBodyPose3DRequest`新しい 3D 姿勢検出リクエスト クラスです
-`VNImageRequestHandler`使用法は 2D リクエストの場合とまったく同じです
-`results`戻る`VNHumanBodyPose3DObservation`配列。現在のバージョンでは、最も著名な人物に対して 1 つの結果のみが返されます。
- エラー処理は標準を使用します`do-catch`モデル

### 関節位置データの取得

```swift
import Vision
import simd

func process3DPose(_ observation: VNHumanBodyPose3DObservation) {
    // 获取特定关节的 3D 位置
    do {
        let leftWrist = try observation.recognizedPoint(.leftWrist)
        print("Left wrist position: \(leftWrist.position)")
        
        // position 是 simd_float4x4 矩阵，第三列包含平移值
        let translation = leftWrist.position.columns.3
        print("Translation - x: \(translation.x), y: \(translation.y), z: \(translation.z)")
    } catch {
        print("Failed to get left wrist point: \(error)")
    }
    
    // 获取一组关节
    do {
        let torsoPoints = try observation.recognizedPoints(.torso)
        for (jointName, point) in torsoPoints {
            print("\(jointName): \(point.position)")
        }
    } catch {
        print("Failed to get torso points: \(error)")
    }
    
    // 获取估计身高
    print("Estimated body height: \(observation.bodyHeight) meters")
    print("Height estimation method: \(observation.heightEstimation)")
}
```

キーポイント:
- `recognizedPoint(_:)`ジョイント名で単一のジョイントを取得して返します`VNHumanBodyRecognizedPoint3D`
- `recognizedPoints(_:)`グループ名でジョイントのグループを取得し、辞書を返します。
-`position`はい`simd_float4x4`ARKit と互換性のある行列。3 番目の列 (columns.3) には、x/y/z 変換値が含まれます。
-`bodyHeight`推定身長 (メートル) を返します。
-`heightEstimation`高さが実測値か参考値かを示します。

### 3D ジオメトリのクラス階層を理解する

Vision では、新しい 3D ジオメトリ基本クラスが導入されています。

- **VNPoint3D**: 基本クラス、定義`simd_float4x4`マトリックスは 3D 位置を保存します
- **VNRecognizedPoint3D**: 位置情報を継承し、識別子(関節名など)を追加
- **VNHumanBodyRecognizedPoint3D**: ローカル位置 (localPosition) と親ジョイント参照を追加します。

```swift
func analyzeJointHierarchy(_ observation: VNHumanBodyPose3DObservation) {
    do {
        let leftWrist = try observation.recognizedPoint(.leftWrist)
        
        // model position: 相对于 root joint（髋部中心）的全局位置
        let globalPosition = leftWrist.position
        print("Global position relative to root: \(globalPosition)")
        
        // local position: 相对于父关节（这里是左肘）的局部位置
        let localPosition = leftWrist.localPosition
        print("Local position relative to parent: \(localPosition)")
        
        // 从 local position 计算关节角度
        let angle = calculateLocalAngleToParent(localPosition)
        print("Joint angle: \(angle)")
        
    } catch {
        print("Error: \(error)")
    }
}

func calculateLocalAngleToParent(_ localPosition: simd_float4x4) -> (pitch: Float, yaw: Float, roll: Float) {
    let pos = localPosition.columns.3
    let vectorLength = sqrt(pos.x * pos.x + pos.y * pos.y + pos.z * pos.z)
    
    // pitch: 90度旋转将几何体从默认朝下的方向调整到骨骼方向
    let pitch = Float.pi / 2
    
    // yaw: 使用反余弦计算
    let yaw = acos(pos.z / vectorLength)
    
    // roll: 使用反正切计算
    let roll = atan2(pos.y, pos.x)
    
    return (pitch, yaw, roll)
}
```

キーポイント:
- `position`常にスケルトンのルート ジョイント (股関節の中心) を基準にします
-`localPosition`親ジョイントを基準にして、体の局所的な動きを解析するのに適しています
-`simd_float4x4`ARKit および SceneKit 座標系との一貫性
- パス`localPosition`関節間の角度（ピッチ/ヨー/ロール）を計算できます

### 3D ジョイントを 2D 画像に投影する

```swift
func projectJointsToImage(_ observation: VNHumanBodyPose3DObservation, imageSize: CGSize) {
    do {
        // 获取 root joint 在 2D 图像中的位置
        let rootJointInImage = try observation.pointInImage(.root)
        print("Root joint in image: \(rootJointInImage)")
        
        // 获取左肩在 2D 图像中的位置
        let leftShoulderInImage = try observation.pointInImage(.leftShoulder)
        print("Left shoulder in image: \(leftShoulderInImage)")
        
        // 将 3D 骨架与原始图像对齐时，需要：
        // 1. 缩放：根据已知关节的 3D 和 2D 距离比例缩放图像平面
        // 2. 平移：使用 root joint 的 2D 位置确定偏移量
        
    } catch {
        print("Projection failed: \(error)")
    }
}
```

キーポイント:
- `pointInImage(_:)`3D ジョイント座標を 2D 画像座標に投影し直す
- 戻り値には、左下を原点とする VNPoint 座標系が使用されます。
- レンダリング環境で画像中心を原点とした座標系に変換する必要がある
- 組み合わせる`cameraOriginMatrix`カメラの視点からシーンをレンダリングする機能

### カメラ原点行列を使用する

```swift
func setupCameraPerspective(_ observation: VNHumanBodyPose3DObservation) {
    // cameraOriginMatrix 包含相机相对于被检测者的位置和旋转
    let cameraMatrix = observation.cameraOriginMatrix
    print("Camera origin matrix: \(cameraMatrix)")
    
    // 使用旋转信息将图像平面朝向相机
    // 只使用旋转部分（3x3 子矩阵），忽略平移（最后一列）
    let rotationMatrix = simd_float3x3(
        columns: (
            simd_float3(cameraMatrix.columns.0.x, cameraMatrix.columns.0.y, cameraMatrix.columns.0.z),
            simd_float3(cameraMatrix.columns.1.x, cameraMatrix.columns.1.y, cameraMatrix.columns.1.z),
            simd_float3(cameraMatrix.columns.2.x, cameraMatrix.columns.2.y, cameraMatrix.columns.2.z)
        )
    )
    
    // 计算逆旋转，让图像平面正对相机
    let inverseRotation = rotationMatrix.inverse
    print("Inverse rotation: \(inverseRotation)")
}
```

キーポイント:
- `cameraOriginMatrix`戻る`simd_float4x4`3D 空間におけるカメラの位置と方向を表す行列
- カメラが被写体の方向を向いていない可能性があります。このマトリックスは相対位置を理解するのに役立ちます
- カメラの視点からレンダリングする場合、マトリックスの回転部分を使用します (移動は無視します)。
- 逆変換により画面をカメラに正しく向けます

### 深度データを使用したリクエスト処理

```swift
import Vision
import AVFoundation

func detectPoseWithDepth(image: CGImage, depthData: AVDepthData) {
    // 使用带深度数据的初始化方法
    let handler = VNImageRequestHandler(
        cgImage: image,
        depthData: depthData,
        options: [:]
    )
    
    let request = VNDetectHumanBodyPose3DRequest()
    
    do {
        try handler.perform([request])
        if let observation = request.results?.first as? VNHumanBodyPose3DObservation {
            // 有深度数据时，bodyHeight 返回实测值
            print("Measured height: \(observation.bodyHeight)")
            print("Estimation: \(observation.heightEstimation)") // .measured
        }
    } catch {
        print("Detection failed: \(error)")
    }
}

// 从人像照片自动提取深度
func detectPoseFromPortraitPhoto(imageURL: URL) {
    // 如果文件包含深度数据，Vision 会自动提取
    let handler = VNImageRequestHandler(url: imageURL)
    let request = VNDetectHumanBodyPose3DRequest()
    
    do {
        try handler.perform([request])
        // 处理结果...
    } catch {
        print("Detection failed: \(error)")
    }
}
```

キーポイント:
- `VNImageRequestHandler`新しい受け入れを追加`AVDepthData`パラメータのオーバーロードされたメソッド
-`AVDepthData`Apple SDKのディープメタデータ用の統合コンテナです
- ポートレート モードの写真には、深度データが自動的に含まれます (視差マップとして保存)
- 深度データがある場合`heightEstimation`戻る`.measured`、それ以外の場合は戻ります`.reference`- LiDAR デバイスは、リアルタイムでキャプチャする際に、より正確なシーン測定を提供します

### 複数人のインスタンスのセグメンテーション

```swift
import Vision

func segmentMultiplePeople(in image: UIImage) {
    guard let cgImage = image.cgImage else { return }
    
    // 创建多人实例分割请求
    let request = VNGeneratePersonInstanceMaskRequest()
    
    // 可选：指定只返回特定实例
    // request.instanceNumber = 1  // 只返回第一个人
    
    let handler = VNImageRequestHandler(cgImage: cgImage)
    
    do {
        try handler.perform([request])
        
        if let observation = request.results?.first as? VNGeneratePersonInstanceMaskObservation {
            // 获取所有可用实例
            let instanceCount = observation.allInstances.count
            print("Detected \(instanceCount) people")
            
            // 提取每个人的 mask
            for instanceIndex in observation.allInstances {
                let mask = try observation.generateMaskedImage(
                    ofInstances: [instanceIndex],
                    from: handler,
                    croppedToInstancesExtent: false
                )
                print("Instance \(instanceIndex) mask generated")
            }
            
            // 提取背景（instance 0）
            let backgroundMask = try observation.generateMaskedImage(
                ofInstances: [0],
                from: handler,
                croppedToInstancesExtent: false
            )
        }
    } catch {
        print("Instance segmentation failed: \(error)")
    }
}

// 处理超过四人的场景
func handleCrowdedScene(image: UIImage) {
    // 先用人脸检测计数
    let faceRequest = VNDetectFaceRectanglesRequest()
    let handler = VNImageRequestHandler(cgImage: image.cgImage!)
    
    do {
        try handler.perform([faceRequest])
        let faceCount = faceRequest.results?.count ?? 0
        
        if faceCount > 4 {
            // 回退到传统的单人分割请求
            let segmentationRequest = VNGeneratePersonSegmentationRequest()
            try handler.perform([segmentationRequest])
            // 处理单一 mask...
        } else {
            // 使用实例分割
            let instanceRequest = VNGeneratePersonInstanceMaskRequest()
            try handler.perform([instanceRequest])
            // 处理独立 mask...
        }
    } catch {
        print("Error: \(error)")
    }
}
```

キーポイント:
- `VNGeneratePersonInstanceMaskRequest`新しいマルチプレイヤー インスタンスの分割リクエストです
- 最大 4 人をサポートし、各人が独立したマスクを持ちます
-`instanceNumber`特定のインスタンスのみを返すようにプロパティを指定できます (0 は背景)
-`allInstances`検出されたすべてのインスタンスのインデックスを返します
-`generateMaskedImage(ofInstances:from:croppedToInstancesExtent:)`指定されたインスタンスのマスク イメージを生成します
- 4 人以上のシーンでは、最初に顔検出とカウントを使用してから、どのセグメンテーション戦略を使用するかを決定することをお勧めします。

## 重要なポイント

- **「姿勢矯正」フィットネス アプリを作成**
  - **何をすべきか**: ユーザーがヨガやフィットネスの動作を行うと、3D 姿勢がリアルタイムで検出され、標準姿勢と比較され、修正提案が表示されます。
  - **実行する価値がある理由**: 3D 関節位置がメートル単位で返されるため、関節角度を正確に測定し、動作が標準であるかどうかを判断できます。
  - **開始方法**: を使用します`VNDetectHumanBodyPose3DRequest`関節位置を取得するには、`localPosition`関節角度（ピッチ/ヨー/ロール）を計算し、あらかじめ設定された標準角度範囲と比較します

- **「身長測定」ツールを作成**
  - **機能**: ポートレート写真から人の身長を自動的に測定します
  - **実行する価値がある理由**: Vision は、深度データが利用可能な場合に測定された高さを返します。ARKit や特殊なハードウェアは必要ありません。
  - **開始方法**: ポートレート モードの写真 (深度データが自動的に含まれる) を読み込み、実行します。`VNDetectHumanBodyPose3DRequest`、 読む`bodyHeight`プロパティ、経由`heightEstimation`実測値であることを確認する

- **「写真背景差し替え」アプリを作成**
  - **作業内容**: 集合写真から人物を個別に抽出し、背景を置き換えるか、新しいシーンに結合します。
  - **実行する価値がある理由**: インスタンス分割 API は最大 4 人を個別に抽出でき、各人は個別のマスクを持ちます。
  - **開始方法**: を使用します`VNGeneratePersonInstanceMaskRequest`各インスタンスマスクを取得し、対象人物のインスタンスインデックスを選択し、`generateMaskedImage`抽出してカスタム背景と組み合わせる

- **「3D人体モデル」プレビューツールを作成**
  - **機能**: 通常の写真から 3D スケルトン視覚化を生成し、回転表示をサポートします。
  - **価値がある理由**: ARKit や深度カメラを使用せずに、通常の写真から 3D 関節の位置を取得します
  - **開始方法**: を使用します`VNDetectHumanBodyPose3DRequest`3D ジョイントを取得するには、次を使用します。`cameraOriginMatrix`カメラの位置を取得し、SceneKit または RealityKit でスケルトンをレンダリングし、視点の切り替えをサポートします。
