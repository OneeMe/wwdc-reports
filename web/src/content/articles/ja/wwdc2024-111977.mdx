## 主要内容

WWDC では毎年大量の新 API とツールが発表され、開発者は自分に関連する方向を素早く判断するのが難しい。Platforms State of the Union 完全版は長く、多くの開発者には関心を絞り込むためのクイックエントリーポイントが必要です。

この 5 分間要約版は WWDC 2024 の最重要発表を簡潔な概観に圧縮しています。最大の変化は Apple Intelligence の登場—Apple のパーソナルインテリジェンスシステムで、生成モデルを iOS、iPadOS、macOS にもたらし、ユーザーの個人コンテキストを認識します。標準 UI フレームワークでテキストフィールドをレンダリングするアプリは Writing Tools を自動的に取得。開発者は新しい TextView delegate API で Writing Tools 有効化時のアプリ動作をカスタマイズできます（[00:47](https://developer.apple.com/videos/play/wwdc2024/111977/?time=47)）。Genmoji は新しいコミュニケーション手段を提供し、Image Playground API は一貫性があり使いやすい画像生成体験を提供します（[00:54](https://developer.apple.com/videos/play/wwdc2024/111977/?time=54)）。

ツールチェーン面では、Xcode 16 のコード補完エンジンが大幅アップグレード：プロジェクトシンボルを使ったローカルパーソナライズ推薦、コードをクラウドにアップロードしない、オフラインでも動作（[02:14](https://developer.apple.com/videos/play/wwdc2024/111977/?time=134)）。Swift Assist はクラウド上のより大きなモデルで、自然言語で要件を記述すればコードを生成。新フレームワークの探索や実験に最適（[02:40](https://developer.apple.com/videos/play/wwdc2024/111977/?time=160)）。Swift は 10 周年。Apple は C++ の後継として明確に位置づけ、安全性、速度、組み込み C/C++ 相互運用性を強調（[01:12](https://developer.apple.com/videos/play/wwdc2024/111977/?time=72)）。

## 詳細

**Apple Intelligence と Writing Tools**（[00:24](https://developer.apple.com/videos/play/wwdc2024/111977/?time=24)）

Apple Intelligence は今回 WWDC の核心テーマです。生成モデルを iOS、iPadOS、macOS に統合するパーソナルインテリジェンスシステムで、ユーザーの個人コンテキストを認識します。標準 UI フレームワークでテキストフィールドをレンダリングするアプリなら、Writing Tools は自動的に有効です。新しい TextView delegate API により、Writing Tools 有効化時のアプリ動作をカスタマイズできます（[00:47](https://developer.apple.com/videos/play/wwdc2024/111977/?time=47)）。Genmoji はユーザーに新しいコミュニケーション手段を提供し、Image Playground API は一貫性があり楽しく使いやすい体験を提供します（[00:54](https://developer.apple.com/videos/play/wwdc2024/111977/?time=54)）。

**Swift と SwiftUI**（[01:05](https://developer.apple.com/videos/play/wwdc2024/111977/?time=65)）

Swift は 10 周年を迎えました。Apple の位置づけは明確：Swift の安全性、速度、使いやすさに加え、組み込み C/C++ 相互運用性により C++ の後継（[01:17](https://developer.apple.com/videos/play/wwdc2024/111977/?time=77)）。SwiftUI の今年の改善は 3 方向に集中：プレビュー、カスタマイズ、相互運用性。プレビューシステムは新しい動的リンクアーキテクチャを採用し、build-and-run と同じビルド成果物を使用（[01:45](https://developer.apple.com/videos/play/wwdc2024/111977/?time=105)）。SwiftUI はアプリの見た目と感触を微調整する大量のカスタマイズオプションを追加。すべての UI フレームワークが今年より多くの共通基盤を共有（[01:52](https://developer.apple.com/videos/play/wwdc2024/111977/?time=112)）。

**Xcode 16 と AI コーディングツール**（[02:02](https://developer.apple.com/videos/play/wwdc2024/111977/?time=122)）

Xcode 16 のコード補完エンジンが大幅アップグレード：新エンジンが必要なコードを予測し、プロジェクトシンボルでパーソナライズ推薦。ローカル実行でコードプライバシーを保護、非常に高速、オフラインでも動作（[02:14](https://developer.apple.com/videos/play/wwdc2024/111977/?time=134)）。Swift Assist はクラウド上のより大きなモデルでコーディングタスクのコンパニオン。コーディング質問に回答し、新 API の実験を支援。1 リクエストで新フレームワークの探索と新アイデアの実験（[02:40](https://developer.apple.com/videos/play/wwdc2024/111977/?time=160)）。Instruments にフレームグラフビューと統一 backtrace ビューを追加。ローカライゼーションカタログも強化（[03:03](https://developer.apple.com/videos/play/wwdc2024/111977/?time=183)）。

**Controls API とビジュアル更新**（[03:20](https://developer.apple.com/videos/play/wwdc2024/111977/?time=200)）

iOS 18 の Controls API により、アプリの操作がコントロールセンター、ロック画面、Action Button に直接表示されます。Control は設定の切り替え、操作の実行、特定体験へのディープリンクが可能（[03:24](https://developer.apple.com/videos/play/wwdc2024/111977/?time=204)）。アプリアイコンと Widget は Light、Dark、Tinted の 3 外観をサポート。システムがインテリジェントに処理し、デザイン意図と可読性を維持（[03:40](https://developer.apple.com/videos/play/wwdc2024/111977/?time=220)）。

**ゲームと visionOS**（[03:52](https://developer.apple.com/videos/play/wwdc2024/111977/?time=232)）

Metal と Apple Silicon の継続的進歩により、すべての Apple Silicon Mac、M シリーズ iPad、さらには iPhone 15 Pro でも以前は専用 GPU が必要だったゲームが動作（[03:52](https://developer.apple.com/videos/play/wwdc2024/111977/?time=232)）。Game Porting Toolkit 2 は AVX2 互換性とレイトレーシングサポートを改善し、より多くの Windows ゲームを評価可能（[04:09](https://developer.apple.com/videos/play/wwdc2024/111977/?time=249)）。visionOS では djay の例が SwiftUI iPad アプリを visionOS 向けに再コンパイルし、空間コンピューティング能力を拡張するパスを示しています（[04:21](https://developer.apple.com/videos/play/wwdc2024/111977/?time=261)）。

## 重要ポイント

- **やること：Writing Tools の自動適応を統合**。標準 UI フレームワークのテキストフィールドを使っているアプリなら、Writing Tools はすでに有効。次に TextView delegate API で Writing Tools 有効化時のアプリ動作を細かく制御—例：エディターシナリオで書き換え範囲を制限、書式の一貫性を維持。**価値**：追加コードなしでユーザーにシステムレベルの AI 執筆能力を提供。delegate API でコンテンツの制御を失わない。**始め方**：セッション 10168「Get started with Writing Tools」を参照し、テキストビューが標準レンダリングパスか確認してから delegate API を段階的に導入。

- **やること：Controls API でコア機能をシステムレベル入口に公開**。コントロールセンター、ロック画面、Action Button はユーザーが頻繁に触れる位置。アプリで最も使う操作（状態切り替え、クイック起動、ディープリンク）を Control にして、アプリを開くステップを削減。**価値**：ユーザーはアプリに入らずに重要操作を完了。**始め方**：SwiftUI の新 Control 関連 API を参照し、単一機能（トグルなど）から検証してからより複雑なインタラクションに拡張。

- **やること：Xcode 16 ローカルコード補完が日常開発効率に与える効果を評価**。新補完エンジンはプロジェクトシンボルでローカル推薦—プライバシーフレンドリー、オフライン対応。既存プロジェクトで 1 週間使用し、補完命中率と受け入れ率を比較。**価値**：毎日使うツールが 10% 向上しても長期的に大きな効果。**始め方**：Xcode 16 にアップグレードし、シンボルインデックスを完全にし、日常コーディングで補完精度を観察。新 API 探索時の Swift Assist も確認。

- **やること：アプリアイコンと Widget 用に Dark / Tinted バリアントを準備**。iOS 18 はすべてのアプリアイコンに Light、Dark、Tinted 処理を統一適用。自動変換に頼らずブランド一貫性を保つには、能動的にバリアントを提供。**価値**：自動変換はデザイン詳細を失う可能性。提供バリアントで各外観モードでブランド識別性を維持。**始め方**：Apple のアイコンガイドラインに従い Dark と Tinted 版を作成し、Xcode Asset Catalog のバリアントスロットで設定。
