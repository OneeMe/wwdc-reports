## ハイライト

> Apple Intelligence が個人向けインテリジェンスシステムとして初登場。端末側モデルがテキストを処理し、拡散モデルが画像を生成。Private Cloud Compute は Apple silicon サーバーで算力を拡張しユーザーデータを保持しない。Siri は画面内容の認識とクロス app 操作を獲得。ChatGPT（GPT-4o）が Siri と Writing Tools に統合。

---

## 主要内容

毎年 WWDC の Keynote は Apple プラットフォームの年間方向性を定めます。2024 年のテーマは明確です：デバイスがあなたを理解する。

OS レベルでは、visionOS 2 が 2D 写真を機械学習で空間写真に変換し、Mac Virtual Display を超ワイド（2 台の 4K ディスプレイを並べた相当）に拡張。Travel Mode に電車シナリオを追加。TabletopKit が卓上協作 app 向けの平面アンカー API を提供。iOS 18 の重点はパーソナライゼーション——Home Screen アイコンの自由配置、ダークモードと着色、完全カスタマイズ可能な Control Center、Lock Screen 下部ボタンの置き換え。Messages に RCS、スケジュール送信、テキストエフェクト。Passwords app が iCloud Keychain から独立し、Windows を含むクロスプラットフォーム同期。

しかし 2024 年を定義するのは Apple Intelligence です。システムに組み込まれた個人向けインテリジェンス層として動作。端末側言語モデルがテキスト要約、書き換え、校正を担当。拡散モデルが画像生成と Genmoji を担当。タスクが端末算力を超える場合、Private Cloud Compute が Apple silicon サーバーでより大きなモデルを実行し、処理後にユーザーデータを保持せず、サーバーソフトウェアイメージは独立専門家が監査可能。Siri のアップグレードも同じアーキテクチャ上：より自然な会話理解、画面内容の認識、クロス app 操作の編成、App Intents フレームワークによるサードパーティ app 連携。

Craig Federighi が演説末尾で ChatGPT（GPT-4o）の Siri と Writing Tools の Compose 機能への統合を発表。ユーザーは登録なしで無料利用可能。ChatGPT サブスクライバーはアカウント接続で有料機能にアクセス。情報共有前に毎回許可を求める。Apple は将来他の AI モデルも統合すると述べた。

## 重要ポイント

1. **App Intents を app に追加**：Apple Intelligence は App Intents フレームワーク経由で app 機能を発見・呼び出す。SiriKit 採用済み app は一部強化を自動取得。新規プロジェクトは App Intents で操作を直接定義し、Siri が「Darkroom で昨日撮った写真にシネマフィルターを適用」のようなコマンドを実行できるようにする。**価値がある理由**：Siri のクロス app 編成能力が登場後、App Intents 対応 app が優先的に発見・呼び出される。**始め方**：app の核心操作を整理し、`AppIntent` プロトコルでラップ。検索、編集、共有系の intent を優先。

2. **Writing Tools と Image Playground API に対応**：標準編集可能テキストビューは追加開発なしで Writing Tools を自動取得。Image Playground は数行で統合。**価値がある理由**：ユーザーは Notes、Mail、サードパーティ app で書き換えと要約に慣れる。未対応 app は機能不足に見える。**始め方**：標準テキストビューを使用していることを確認。画像創作が必要な場所で Image Playground API を呼び出す。

3. **App Lock と選択的連絡先認可に合わせてプライバシー戦略を再構築**：iOS 18 でユーザーは app をロック・非表示にし、連絡先を選択的に認可できる。全連絡先アクセスやバックグラウンドデータ読み取りに依存する app では、実行時権限が不足する可能性。**価値がある理由**：ユーザーが app をロックすると検索と通知から情報が消え、app が依存するデータを受け取れなくなる。**始め方**：連絡先、通知、バックグラウンド読み取りへの依存を監査。部分認可と App Lock 状態向けの降级体験を設計。

4. **visionOS TabletopKit で卓上協作シナリオに参入**：TabletopKit が平面アンカー API を提供。FaceTime spatial Personas と組み合わせ、ボードゲーム、製造ワークステーション、医療トレーニング app の低障壁エントリー。**価値がある理由**：Vision Pro エコシステムはまだ初期段階。卓上シナリオは競争が少なく、TabletopKit が空間アンカー開発の難易度を大幅に下げる。**始め方**：TabletopKit でボードゲームプロトタイプを作成し、平面アンカーと複数 Persona インタラクションを検証。
