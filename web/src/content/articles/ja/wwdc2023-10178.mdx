## ハイライト

> iOS 17 では、デジタル通話シナリオにおける App Clip サイズの上限が 50MB に増加し、デフォルトの App Clip Links 設定不要の通話リンクが追加され、あらゆるアプリが Safari を経由せずに App Clip を直接呼び出せるようになります。

## 主な内容

App Clip を使用すると、ユーザーはアプリ全体をダウンロードしなくても、コア機能を体験できます。 iOS 17 では、3 次元から App Clip を構築して配布するための敷居が低くなります。

### ボリューム制限: デジタル通話の場合は 50MB、物理通話の場合は 15MB

([00:59](https://developer.apple.com/videos/play/wwdc2023/10178/?time=59)) 瞬時に起動できるようにするには、App Clip を小さくする必要があります。ただし、ネットワークの状態は使用シナリオによって大きく異なります。通常、NFC タグと QR コードは屋外の携帯電話ネットワークで使用されますが、メッセージ リンクと Safari ページは Wi-Fi 環境で開かれることがよくあります。

iOS 17 では、2 つの呼び出しメソッドのサイズ制限が区別されます。

|メソッドの呼び出し |サイズ制限 |該当するシナリオ |
|----------|----------|----------|
|物理通話 (NFC、QR コード、アプリ クリップ コード) | 15MB |アウトドア、移動中 |
|デジタル通話 (メッセージ、Safari、Spotlight) | 50MB | Wi-Fi、屋内 |
| iOS 15 以前 | 10MB |古いシステムとの互換性 |

([01:53](https://developer.apple.com/videos/play/wwdc2023/10178/?time=113)) 50MB は、より多くのリソースを配置するのに十分なスペースです。以前にサイズを制御するために実行時にマテリアルをダウンロードしていた場合は、それらを App Clip に直接パッケージ化して、最初の画面エクスペリエンスをより完全なものにすることができます。ゲームのトライアル、オンラインでの食品の注文、コンテンツのプレビューなどのシナリオはすべて有益です。

### デフォルトのアプリクリップリンク: リンクを呼び出すための設定は不要です

([02:19](https://developer.apple.com/videos/play/wwdc2023/10178/?time=139)) 以前は、URL を通じて App Clip を呼び出すには、Apple App Site Association ファイルと関連メタデータを独自の Web サイトでホストする必要がありました。これは、Web サイトを持っていない開発者、または Web サイトの構成を維持したくない開発者にとっては負担です。

iOS 16.4 以降、App Store Connect はデフォルトの App Clip リンクを自動的に生成します。

```
https://appclip.apple.com/id?p=com.example.app.Clip
```

([03:40](https://developer.apple.com/videos/play/wwdc2023/10178/?time=220)) このリンクでは、追加のクエリ パラメーターがサポートされています。ゲームの試用版 App Clip には次からアクセスできます。`?character=wizard`初期ロールを指定すると、食品注文 App Clip が渡すことができます`?restaurant=123`指定レストラン。

App Clip は起動後にパラメータを解析します。

```swift
import SwiftUI

struct ContentView: View {
    @State var parameters: [URLQueryItem] = []

    var body: some View {
        VStack {
            ForEach(parameters, id: \.name) { item in
                Text("\(item.name): \(item.value ?? "")")
            }
        }
        .onContinueUserActivity(NSUserActivityTypeBrowsingWeb) { userActivity in
            guard let inputURL = userActivity.webpageURL else { return }

            let components = NSURLComponents(
                url: inputURL,
                resolvingAgainstBaseURL: true
            )
            guard let queryItems = components?.queryItems else { return }

            self.parameters = queryItems
        }
    }
}
```

キーポイント:
- `onContinueUserActivity`起動時にApp Clipをキャプチャ`NSUserActivity`
- `webpageURL`クエリパラメータを含む完全な呼び出しURLが含まれます。
-`NSURLComponents`パラメータの解析は通常のユニバーサルリンクと同じです

### 任意のアプリから App Clip を呼び出す

([04:20](https://developer.apple.com/videos/play/wwdc2023/10178/?time=260)) iOS 17 より前は、アプリ内で App Clip を呼び出すには、Safari または Safari View Controller を経由する必要がありました。直接呼び出せるようになりました。

**方法 1: リンク プレゼンテーションのリッチ テキスト プレビュー**

```swift
import LinkPresentation

let provider = LPMetadataProvider()
let url = URL(string: "https://appclip.apple.com/id?p=com.example.app.Clip")!

provider.startFetchingMetadata(for: url) { metadata, error in
    guard let metadata = metadata else { return }

    DispatchQueue.main.async {
        let lpView = LPLinkView(metadata: metadata)
        // 添加到视图层级，用户点击即可调起 App Clip
    }
}
```

キーポイント:
- `LPMetadataProvider`リンクメタデータを非同期で取得する
-`LPLinkView`アイコンとタイトルを含むリッチ テキスト カードをレンダリングする
- ユーザーはカードをクリックして、Safari 転送を必要とせずに App Clip を直接起動します。

**方法 2: 直接呼び出す (デフォルトのアプリ クリップ リンク)**

SwiftUI：

```swift
var body: some View {
    let appClipURL = URL(
        string: "https://appclip.apple.com/id?p=com.example.naturelab.backyardbirds.Clip"
    )!

    Link("Backyard Birds", destination: appClipURL)
}
```

UIKit：

```swift
func launchAppClip() {
    let appClipURL = URL(
        string: "https://appclip.apple.com/id?p=com.example.naturelab.backyardbirds.Clip"
    )!

    UIApplication.shared.open(appClipURL)
}
```

キーポイント:
- デフォルトのApp Clip Linkを直接使用できます`Link`または`open(_:)`電話をかける
- 呼び出し後、システムはApp Clipカードを表示し、ユーザーは確認後に入力します。
- 同じ開発者に限定されず、どのアプリでも任意のアプリ クリップを呼び出すことができます

### 数量制限の実際的な影響

([01:10](https://developer.apple.com/videos/play/wwdc2023/10178/?time=70)) 物理通話が 15MB 制限のままである理由は、ユーザーが頻繁に移動しており、ネットワーク状態が不安定であるためです。通話番号を 50MB に増やすと、より充実したエクスペリエンスが可能になります。

- ゲームトライアル: 完全なレベルのリソース、キャラクターモデル、効果音を含めることができます
- オンライン注文: メニューの写真やレストランの環境の写真を含めることができます
- コンテンツのプレビュー: ビデオ クリップや高解像度の画像セットを含めることができます

([02:04](https://developer.apple.com/videos/play/wwdc2023/10178/?time=124)) ターゲット ユーザーに iOS 15 ユーザーが含まれる場合、10MB の制限は引き続き適用されます。処理は、条件付きコンパイルまたはランタイム インストルメンテーションによって区別できます。

### デフォルトの App Clip リンクの生成と使用

([03:13](https://developer.apple.com/videos/play/wwdc2023/10178/?time=193)) App Store Connect が App Clip を公開すると、デフォルトの App Clip リンクが次の固定形式で自動的に生成されます。

```
https://appclip.apple.com/id?p={BundleIdentifier}
```

バンドル識別子は App Clip ターゲットの完全なバンドル ID で、通常は次で終わります。`.Clip`終わり。

パラメータを渡す例:

```
https://appclip.apple.com/id?p=com.example.game.Clip&level=demo&character=knight
```

App Clip での分析:

```swift
.onContinueUserActivity(NSUserActivityTypeBrowsingWeb) { activity in
    guard let url = activity.webpageURL,
          let components = URLComponents(url: url, resolvingAgainstBaseURL: true),
          let items = components.queryItems else { return }

    let level = items.first(where: { $0.name == "level" })?.value
    let character = items.first(where: { $0.name == "character" })?.value

    // 根据参数配置初始界面
}
```

### クロスアプリリコールシナリオ

([04:33](https://developer.apple.com/videos/play/wwdc2023/10178/?time=273)) 講演者はメモ アプリを使用してデモンストレーションを行いました。メモに Backyard Birds App Clip リンクを挿入すると、クリックすると App Clip カードが直接ポップアップします。 Safari がこのプロセスに関与する必要はありません。

実際の応用シナリオ:
- レストラン アプリのクリップをソーシャル アプリで共有し、友達をクリックして直接注文できます
- ナビゲーションアプリで駐車場App Clipを起動し、直接支払いを完了します
- メールアプリでミーティングアプリクリップを起動し、ビデオ会議に直接参加します

## 重要なポイント

**1.フルアプリ用のゲームトライアルアプリクリップを作成します**

- **やるべきこと**: 50MB のサイズ制限を利用して、ゲームの最初のレベルまたはチュートリアルを App Clip としてパッケージ化します。
- **価値がある理由**: ユーザーは、数百 MB の完全なゲームをダウンロードしなくても、核となるゲームプレイを体験でき、コンバージョン率は従来の広告よりもはるかに高くなります。
- **開始方法**: App Clip ターゲットを Xcode のプロジェクトに追加し、レベル リソースとコア ロジックを共有し、Default App Clip Link を通じて配布します。

**2.コンテンツ共有に App Clip を埋め込む**

- **対処方法**: ユーザーがアプリ内のコンテンツを共有すると、関連する App Clip へのデフォルト リンクが添付されます。
- **価値がある理由**: 受信者は、最初にアプリ全体をダウンロードしなくても、リンクをクリックするだけで関連機能を体験できるため、体験のしきい値が下がります。
- **開始方法**: パラメータを使用してデフォルトのアプリ クリップ リンクを生成します (例:`?itemID=123`）、使用`LPLinkView`リッチテキストプレビューを表示

**3.オフラインシナリオでの迅速なサービス**

- **対処法**: NFC タグまたは QR コードを使用して、レストラン、駐車場、ジムなどで 15 MB 以内の軽量 App Clip を起動します。
- **価値がある理由**: ユーザーは、アプリをダウンロードしたり Web ページを開いたりしなくても、携帯電話をラベルに近づけるだけで注文、支払い、チェックインができます。
- **開始方法**: App Clip サイズを 15MB 以内に制御し、物理的な通話エクスペリエンスを設定し、App Store Connect で App Clip コードを生成します。

**4.アプリエコシステム全体にわたるリアルタイムサービス**

- **内容**: App Clip を他のアプリから直接呼び出して、エコシステム内のサービス ノードにできるようにします。
- **実行する価値がある理由**: iOS 17 では、どのアプリでも任意の App Clip を呼び出すことができるため、アプリ間のサービス ネットワークを構築する機会が得られます。
- **開始方法**: シンプルなデフォルト App Clip Link パラメータ プロトコルを設計し、パートナーが簡単に統合できるようにアクティベーション方法を文書化します。
