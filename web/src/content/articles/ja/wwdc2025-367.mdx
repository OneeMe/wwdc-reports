## ハイライト

> これは高度に凝縮された recap です。PSOTU の約1時間の内容を約4分に圧縮し、Liquid Glass、Foundation Models、Xcode 26、Swift 6.2、SwiftUI、Metal 4 など、すべてのコア更新をカバーしています。

## 主要内容

毎年 WWDC の冒頭で、PSOTU（Platforms State of the Union）は約1時間かけてすべてのプラットフォームの技術更新を解説します。開発者にとって最大の課題は、内容が密度高く、情報があまりに速く流れていくため、メモを取りながら見ても漏れが出てしまうこと。後で見返そうとしても、どの Session から切入ればよいかわからない、という点です。

Apple が今年提示した解決策が、この4分間の公式 Recap です。PSOTU の全主軸を早回しのクリップに圧縮し、テーマ別――デザイン、AI、ツールチェーン、言語、UI、グラフィックス、ライトニングラウンドロビン――に切り分けているため、コーヒー一杯の時間で今年の WWDC の全体像を把握できます。この動画を見終わる頃には、どの更新が現在の自分のプロジェクトに関連するのか、どの専門 Session を見るべきかを即座に判断できるようになります。

## 詳細

動画のテンポは非常に緻密で、7つのセグメントですべての要点をカバーしています。

**Liquid Glass（[00:15](https://developer.apple.com/videos/play/wwdc2025/367/?time=15)）** は新しい動的マテリアルで、ガラスの光学特性と流体感を組み合わせ、コンテンツに奥行きとフォーカスをもたらします。付属ツールの Icon Composer は、ブラー、半透明、ハイライトのテスト、および複数のテーマカラーでのアイコンプレビューをサポートします。

**Foundation Models フレームワーク（[00:57](https://developer.apple.com/videos/play/wwdc2025/367/?time=57)）** により、開発者はオンデバイスの基盤モデルを直接呼び出し、テキスト抽出や要約などの日常タスクに集中できます。モデルはデバイス上で実行され、ユーザーデータは外部に送信されず、開発者とユーザーの双方に無料で提供されます。

**Xcode 26（[01:27](https://developer.apple.com/videos/play/wwdc2025/367/?time=87)）** は生成コードモデルのサポートを組み込んでおり、ChatGPT の統合は標準で、他のモデルにも切り替え可能です。ソースコードエディタには新しく Coding Tools が追加され、いわばコード版 Writing Tools として、モデルにプレビューや playground の生成、あるいは issue の修正を依頼できます。

**Swift 6.2（[01:57](https://developer.apple.com/videos/play/wwdc2025/367/?time=117)）** は、パフォーマンス、並行処理、相互運用の3点に注力しています。最も実用的な変更は、モジュールまたは単一のファイルをデフォルトで main actor 上で実行するように設定できることで、冗長な `@MainActor` アノテーションを削減できます。

**SwiftUI（[02:16](https://developer.apple.com/videos/play/wwdc2025/367/?time=136)）** は新しい Web API、3D Charts、およびリッチテキスト編集を導入しました。`TextEditor` の binding を `String` から `AttributedString` に置き換えるだけで、スタイルカスタマイズ可能なリッチテキストエディタが手に入ります。

**Metal 4（[02:45](https://developer.apple.com/videos/play/wwdc2025/367/?time=165)）** は Apple Silicon 専用に設計され、MetalFX フレーム補間とノイズ低減 API を提供。Game Porting Toolkit 3 は Windows アップスケーリングのサポートを追加し、Apple Vision Pro は PlayStation VR2 Sense コントローラのサポートを開始しました。

**ライトニングラウンドロビン（[03:21](https://developer.apple.com/videos/play/wwdc2025/367/?time=201)）** は細かな更新を一気に紹介します。Terminal の24ビットカラー、新テーマ、powerline フォント。visionOS の Apple Projected Media Profile（180/360度没入型メディア）。CarPlay Live Activities。declared age range API。Accessibility Nutrition Labels。Family Sharing と Assistive Access の更新。

動画全体のテンポからわかるのは、今年の WWDC の更新は4分では語り尽くせないほど奥が深く、本編は100以上の Session があるということです。

## 重要ポイント

- **やるべきこと**：まず Recap を見て、どの Session を深掘りするか決める。
  - なぜ価値があるのか：4分で全体像を把握でき、100以上の Session に迷い込んで方向を失うのを防げます。
  - どう始めるか：Keynote → PSOTU → Recap → 専門 Session の順で一周し、Recap を見終わったらすぐに補講すべき3–5本をリストアップする。

- **やるべきこと**：現在の技術スタックに合わせて深掘り方向を選ぶ。
  - なぜ価値があるのか：毎年の更新は広範に及びますが、実際に使うのは1–2分野だけで、分散して手を広げてもリターンはありません。
  - どう始めるか：UI/デザインは Liquid Glass、Design、SF Symbols 7 へ。AI/ML は Foundation Models へ。ツールチェーンは Xcode 26、Swift 6.2 へ。ゲーム/グラフィックスは Metal 4 へ。プラットフォームは watchOS 26、visionOS 26 へ。

- **やるべきこと**：「ライトニングラウンドロビン」セグメントに注目。小粒で美しい変更が隠れています。
  - なぜ価値があるのか：Terminal の24ビットカラー、CarPlay Live Activities、declared age range API、Accessibility Nutrition Labels のような小さな更新は、しばしばあなたの製品要件に直接命中し、導入コストも低いものです。
  - どう始めるか：[03:21](https://developer.apple.com/videos/play/wwdc2025/367/?time=201) で pause して一つ一つ確認し、自製品に関連する API をマーク。一週間以内に最小の試用 demo を作る。

- **やるべきこと**：Recap をチーム内共有の素材として使う。
  - なぜ価値があるのか：4分間の動画は60分の PSOTU より週次ミーティングでの再生に適しており、PM、デザイナー、クライアントサイドの同僚もついてきやすい。
  - どう始めるか：再生終了後に5–10分のディスカッションを用意し、各職能が最も気になる更新を一つ選んで調査を担当する。
