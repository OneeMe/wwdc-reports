## ハイライト

> StoreKit 2 では、プロモーション購入管理 API、Transaction/RenewalInfo データ モデル拡張機能、WWDC2023 の SwiftUI 専用製品表示ビュー (ProductView/StoreView/SubscriptionStoreView)、およびマルチデバイスのオフライン デバッグ、シミュレートされたエラー挿入、カスタム サブスクリプション更新レートをサポートする Xcode 15 の StoreKit テスト ツール チェーンが追加されました。

## 主な内容

### 購入を促進するための完全なリンク

ユーザーが App Store の製品ページでプロモーションされたアプリ内購入アイテムを見てクリックして購入すると、アプリはこのインテントをリッスンしてトランザクションを完了する必要があります。以前は、開発者は受動的に待つことしかできませんでしたが、現在では、プロモーションされた製品の表示順序と可視性を積極的に管理できるようになりました。

ユーザーが App Store からプロモーション製品を購入するとき、アプリはまだ準備ができていない可能性があります (レベルなどで)。 PurchaseIntent は遅延処理をサポートしており、後で完了するためにインテントを保存します。購入した商品を非表示にしたり、ゲームレベルの進行状況の表示順序を動的に調整したりできます。

### データモデルだけでようやく十分

トランザクション モデルでは、storefront (店舗エリア)、storefront CountryCode (国コード)、および理由 (購入理由: ユーザーが積極的に購入した、または自動的に更新した) が追加されます。 RenewalInfo に nextRenewalDate (次回の更新日) が追加されました。

これらのフィールドは、ユーザーがどの地域の店舗から来たのかを判断し、初回購入と更新を区別し、次回の控除時期を事前にユーザーに通知するなど、長期的な問題点を解決します。

### テストはもはやブラックボックスではありません

Xcode 15 の StoreKit テストでは、デバイスがアプリを実行していないときにトランザクションを直接作成し、1 年前のサブスクリプション購入をシミュレートし、自動更新を観察することがサポートされています。ネットワーク エラーや製品の利用不可などの例外を挿入して、アプリケーションのフォールト トレラント ロジックを検証できます。サブスクリプションの更新レートを 1 分に 1 回に調整して、長期サブスクリプションのステータスを迅速に確認できます。

### プロモーションの購入意向を監視する

([01:42](https://developer.apple.com/videos/play/wwdc2023/10140/?time=102))

```swift
import StoreKit

let promotedPurchasesListener = Task {
    for await promotion in PurchaseIntent.intents {
        let product = promotion.product

        do {
            let result = try await product.purchase()
            // 处理购买结果
        } catch {
            // 处理错误，或保存意图稍后重试
        }
    }
}
```

**キーポイント:**
- `PurchaseIntent.intents` は非同期シーケンスであり、ユーザーが App Store でプロモーション購入をクリックするたびに新しい値を生成します
- システムは、アプリが実行されていないときもインテントを保持し、起動直後にインテントを受信します。
- `promotion` オブジェクトを保存し、ユーザーの適切なタイミングで `purchase()` を呼び出すことができます。
- アプリケーションのライフサイクル中、リスナーを実行し続ける必要がある

### プロモーションされた製品の注文と可視性を管理する

([02:57](https://developer.apple.com/videos/play/wwdc2023/10140/?time=177))

```swift
import StoreKit

// 查询当前推广顺序
do {
    let promotions = try await Product.PromotionInfo.currentOrder

    if promotions.isEmpty {
        // 没有本地覆盖，使用 App Store Connect 配置的顺序
    }

    for promotion in promotions {
        let productID = promotion.productID
        let visibility = promotion.visibility
    }
} catch {
    // 处理错误
}

// 设置自定义顺序
let newOrder = ["acorns.individual", "nectar.cup", "sunflowerseeds.pile"]
do {
    try await Product.PromotionInfo.updateProductOrder(byID: newOrder)
} catch { }

// 隐藏特定产品
do {
    try await Product.PromotionInfo.updateProductVisibility(.hidden, for: "acorns.individual")
} catch { }

// 或通过对象修改
var firstPromotion = promotions.first!
firstPromotion.visibility = .hidden
try await firstPromotion.update()
```

**キーポイント:**
- `currentOrder` が空の場合は、ローカル カバレッジがなく、App Store Connect のデフォルト構成が使用されることを意味します。
- `visibility` には 3 つの状態があります: `.visible`、`.hidden`、`.default` (App Store Connect 設定に従います)
- 順序と可視性の変更は、現在のデバイスにのみ影響します
- ゲームの進行状況やユーザーのステータスに基づいてプロモーション表示を動的に調整するのに適しています

### Transaction および RenewalInfo の新しいフィールド

([05:00](https://developer.apple.com/videos/play/wwdc2023/10140/?time=300))

```swift
// Transaction 新增字段
for await result in Transaction.currentEntitlements {
    if case .verified(let transaction) = result {
        let storefront = transaction.storefront
        let countryCode = transaction.storefrontCountryCode
        let reason = transaction.reason // .purchase 或 .renewal

        print("商店: \(storefront), 原因: \(reason)")
    }
}

// RenewalInfo 新增字段
if let subscriptionInfo = product.subscription {
    let renewalInfo = try await subscriptionInfo.status
    for status in renewalInfo {
        if case .verified(let info) = status.renewalInfo {
            if let nextDate = info.nextRenewalDate {
                print("下次续订: \(nextDate)")
            }
        }
    }
}
```

**キーポイント:**
- `storefront` と `storefrontCountryCode` はユーザーの地域を決定するのに役立ちます
- `reason` は、ユーザーによるアクティブな購入 (`.purchase`) と自動更新 (`.renewal`) を区別します。
- `nextRenewalDate` RenewalInfoで次回の更新処理時間を通知します
- Xcode 15 で構築されたアプリが利用可能で、ほとんどのフィールドは古いシステムと上位互換性があります

### 請求に関する問題メッセージの処理

([06:12](https://developer.apple.com/videos/play/wwdc2023/10140/?time=372))

```swift
for await message in Message.messages {
    switch message.reason {
    case .billingIssue:
        // 订阅续订失败，显示账单问题 sheet
        // StoreKit 自动展示，应用可选择推迟或抑制
        await message.display()
    default:
        break
    }
}
```

**キーポイント:**
- `.billingIssue` iOS 16.4で導入され、請求の問題によりサブスクリプションが更新できなかった場合にトリガーされます。
- StoreKit は請求問題シートを自動的に表示するため、ユーザーはアプリを離れることなく問題を解決できます。
- アプリケーションはメッセージを延期したり (ユーザーが対話中である場合)、メッセージを抑制したりできます。
- サンドボックス環境が有効になっており、事前にテストできます

### SwiftUI 製品表示ビュー

([08:32](https://developer.apple.com/videos/play/wwdc2023/10140/?time=512))

```swift
import SwiftUI
import StoreKit

// 单个商品视图
struct BirdFoodShop: View {
    let productID: String

    var body: some View {
        ProductView(id: productID) {
            BirdFoodProductIcon(for: productID)
        }
        .productViewStyle(.large)
    }
}

// 商店视图（多个商品）
struct StorePage: View {
    let productIDs: [String]

    var body: some View {
        StoreView(ids: productIDs) { product in
            BirdFoodIcon(productID: product.id)
        }
    }
}

// 订阅商店视图
struct SubscriptionPage: View {
    let groupID: String

    var body: some View {
        SubscriptionStoreView(groupID: groupID)
    }
}

// 管理订阅 sheet
.manageSubscriptionsSheet(
    isPresented: $showManageSheet,
    subscriptionGroupID: groupID // 直接跳转到指定订阅组
)
```

**キーポイント:**
- `ProductView` は製品情報を自動的にロードし、ローカライズされたタイトル、説明、プロモーション画像を表示します。
- `StoreView` は製品コレクションを表示し、数行のコードで完全なストアを構築します
- `SubscriptionStoreView` は、サブスクリプション グループのすべてのレベルを表示します。`subscriptionGroupID` のみを表示します
- `.manageSubscriptionsSheet` 指定したグループに直接ジャンプするための `subscriptionGroupID` パラメータを追加しました
- すべてのビューは、背景、フォントなどの SwiftUI 標準カスタマイズをサポートしています。

### Xcode トランザクション マネージャーのオフライン デバッグ

([11:12](https://developer.apple.com/videos/play/wwdc2023/10140/?time=672))

Xcode 15 のトランザクション マネージャーは以下をサポートします。
- 接続されているすべてのデバイスとエミュレータにわたる StoreKit アプリのトランザクション履歴を表示
- アプリを実行せずに購入履歴を表示
- Mac から直接新しい購入を作成し、購入パラメータ (数量、割引コード、購入日) を設定します
- 自動更新設定とサブスクリプションの履歴レビューをサポート

操作パス: `Debug > StoreKit > Manage Transactions`

### StoreKit エラーをシミュレートする

([18:54](https://developer.apple.com/videos/play/wwdc2023/10140/?time=1134))

StoreKit 構成ファイルの構成設定で:
- Purchase API の [エラーをシミュレート] オプションをチェックします。
- `.productUnavailable` (ユーザー スイッチ ストア) などのエラー タイプを選択します。
- 構成は自動的に保存され、実行中のデバイスに同期されます
- アプリを再実行せずにテストします

サポートされている API とエラー タイプには、製品の読み込み、購入、受領書検証、トランザクション検証、返金リクエストなどが含まれます。

### 単体テストで購入とバグを模擬する

([21:09](https://developer.apple.com/videos/play/wwdc2023/10140/?time=1269))

```swift
import StoreKit
import StoreKitTest
import XCTest

func testSubscriptionRenewal() async throws {
    let session = try SKTestSession(configurationFileNamed: "Store")

    // 模拟一年前的订阅购买
    let oneYear: TimeInterval = 365 * 24 * 60 * 60
    let transaction = try await session.buyProduct(
        identifier: "birdpass.individual",
        options: [.purchaseDate(Date.now - oneYear)]
    )

    // 验证交易状态
    XCTAssertNotNil(transaction)
}

func testLoadProductsError() async throws {
    let session = try SKTestSession(configurationFileNamed: "Store")

    // 注入网络错误
    session.setSimulatedError(.generic(.networkError), forAPI: .loadProducts)

    do {
        _ = try await Product.products(for: ["product1"])
        XCTFail("应该抛出网络错误")
    } catch StoreKitError.networkError {
        // 预期的错误
    }

    // 清除模拟错误
    session.setSimulatedError(nil, forAPI: .loadProducts)
}

func testFastRenewal() async throws {
    let session = try SKTestSession(configurationFileNamed: "Store")

    // 每分钟续订一次，快速验证长期订阅状态
    session.timeRate = .oneRenewalEveryMinute

    let transaction = try await session.buyProduct(identifier: "birdpass.individual")

    // 等待观察续订行为
}
```

**キーポイント:**
- `SKTestSession` StoreKit 構成ファイルからテスト環境を作成する
- `buyProduct(options:)` は、`purchaseDate` などのテスト固有のオプションをサポートします
- `setSimulatedError(_:forAPI:)` は、指定された API のエラーを挿入します
- `timeRate` はサブスクリプションの更新速度を制御します。`.oneRenewalEveryMinute` が最速です
- 他のテストに影響を与えないように、テスト後にシミュレーション エラーをクリアします。

## 重要なポイント

1. **ダイナミック プロモーション ストア**
   - **やること**: ユーザーのゲームの進行状況に基づいて、App Store で宣伝された製品の表示順序と可視性を動的に調整します
   - **䡡値**: `Product.PromotionInfo` により、プロモーション シーケンスのローカル カバレッジが可能になります。ユーザーがレベルを通過すると、高度な小道具が自動的に表示され、購入した小道具は自動的に非表示になります。
   - **Hai Fang**: `PurchaseIntent.intents` を監視してプロモーション購入を処理し、`updateProductOrder` と `updateProductVisibility` を使用してゲームのステータスに応じて調整します

2. **サブスクリプション ステータス ダッシュボード**
   - **やこと**: 次回更新日、店舗エリア、更新理由など、ユーザーのサブスクリプションの詳細をアプリに表示します
   - **䡡値**: `nextRenewalDate` を使用すると、ユーザーは控除時間を事前に知ることができ、`storefrontCountryCode` は地域の価格設定の問題を特定するのに役立ちます
   - **ハジメスクエア**: `Transaction.currentEntitlements` をトラバースし、`storefront` と `reason` を読み取り、`Product.SubscriptionInfo` から `renewalInfo` を取得します

3. **請求に関する問題のセルフサービス修復**
   - **やること**: サブスクリプションの更新が失敗した場合は、解約を減らすために支払い方法を修復するようにユーザーを積極的に誘導します。
   - **䡡値**: `Message.messages` の `.billingIssue` により、アプリケーションはユーザーが離れる前に問題を解決でき、StoreKit は自動的に修復シートを表示します。
   - **開始パーティー**: `Message.messages`を監視し、`.billingIssue`を受信したらタイミングを判断し、`message.display()`を呼び出すか、適切な時間まで延期します

4. **ゼロコードストアページ**
   - **やること**: StoreKit SwiftUI ビューを使用して、アプリ内購入ページをすばやく構築します
   - **䡡値**: `StoreView` および `SubscriptionStoreView` ロード、表示、購入プロセスを自動的に処理する完全なストアを実装するための数行のコード
   - ** ハジメ **: 製品 ID 配列を渡して `StoreView` を作成するか、`SubscriptionStoreView(groupID:)` を使用してサブスクリプション オプションを表示し、`.productViewStyle` と `.containerBackground` を使用して外観をカスタマイズします
