### PencilKit のシステムレベルのエクスペリエンスは進化し続けます

([01:21](https://developer.apple.com/videos/play/wwdc2020/10107/?time=81)) iOS 14 では PencilKit ドキュメントがスマート選択されます。ユーザーはダブルクリックして単語を選択したり、もう一度ダブルクリックして行を選択したり、グラブ ハンドルを使用して選択範囲を展開したりできます。非連続コンテンツの場合、システムは速度に応じたタップ アンド パン ジェスチャを提供し、ユーザーがブラシ ストロークのような分散したストロークを選択できるようにします。

([01:51](https://developer.apple.com/videos/play/wwdc2020/10107/?time=111)) スペースを挿入すると、手書きメモによくある問題が解決されます。書き終えた後、真ん中の段落が抜けていることに気づきます。ユーザーは空白領域をクリックし、吹き出しバーから [スペースの挿入] を選択し、ハンドルをドラッグしてスペースを作成します。これらの機能はシステムによって提供されるため、既存の PencilKit クライアントは追加のコードを記述する必要はありません。

([02:23](https://developer.apple.com/videos/play/wwdc2020/10107/?time=143)) PencilKit には、新しい UIKit システム カラー ピッカーも搭載されています。ユーザーはスペクトル、スライダー、カスタムカラー、スポイトから選択できます。この講演では、10052 の UIKit ピッカー セッションに関する詳細が明示的に示されています。

### allowedFingerDrawing の代わりに drawingPolicy を使用します

（[05:21](https://developer.apple.com/videos/play/wwdc2020/10107/?time=321)）`allowsFingerDrawing`iOS 14では新しくなりました`PKCanvasViewDrawingPolicy`交換する。開発者は描画ジェスチャ認識機能を直接変更しないでください。`allowedTouchTypes`, 入力意図はキャンバスの描画ポリシーに記述する必要があります。

```swift
var drawingPolicy: PKCanvasViewDrawingPolicy
```

キーポイント:

- `PKCanvasViewDrawingPolicy.anyInput`指と Apple Pencil の両方で描画できます。
-`PKCanvasViewDrawingPolicy.pencilOnly`Apple Pencil による描画のみが許可され、指でスクロールしたり、スマート選択ジェスチャをトリガーしたりできます。
-`PKCanvasViewDrawingPolicy.default`ツールピッカーが表示されている場合、設定またはツールピッカーを介したユーザーの切り替えが尊重されます。`UIPencilInteraction.prefersPencilOnlyDrawing`州。
- ツールピッカーが非表示の場合、デフォルトの戦略では Apple Pencil のみが描画でき、指はスクロールと選択を担当します。

### ツールピッカーの「指で描画」スイッチを制御します。

### 各キャンバスは独自の PKToolPicker を維持できます

([08:40](https://developer.apple.com/videos/play/wwdc2020/10107/?time=520)) iOS 14 が更新されました`PKToolPicker`初期化メソッド。開発者は複数の独立したツール ピッカーを作成でき、各インスタンスには独自の描画ポリシー コントロール、選択されたツール、およびその他の状態があります。講義では、メモ取りモードと色付けモードを使用して、この違いを説明します。

```swift
notesCanvas.drawingPolicy = .default
notesToolPicker.showsDrawingPolicyControls = true
notesToolPicker.selectedTool = PKInkingTool(.pen, color: .black, width: 2)

drawingCanvas.drawingPolicy = .anyInput
drawingToolPicker.showsDrawingPolicyControls = false
drawingToolPicker.selectedTool = PKInkingTool(.marker, color: .purple, width: 20)
```

キーポイント:

- キャンバスを使用してメモを取る`.default`、ユーザーがシステム環境設定を通じて指で描画するかどうかを決定できるようにします。
- メモ取りツール ピッカーには描画ポリシー コントロールが表示され、ユーザーは「指で描画」を直接確認して切り替えることができます。
- カラーキャンバス使用`.anyInput`というのも、このモードでは指と Apple Pencil の両方に色を付けることが明示的に許可されているからです。
- カラーリング ツール ピッカーは、固定ポリシーと競合するスイッチを避けるために描画ポリシー コントロールを非表示にします。
- アプリはそれぞれを保持する必要があります`PKToolPicker`そうしないと、ピッカーの状態とライフサイクルを安定して維持できなくなります。

### ストローク アクセスにより、PencilKit がキャンバスからデータ レイヤーにプッシュされます

- **メモを取ることと色を塗ることが共存するクリエイティブなインターフェイス**: 同じドキュメント内に配置します`notesCanvas`そして`drawingCanvas`、前者は使用します`.default`そして「Draw With Finger」を表示します。`.anyInput`そして紫色のマーカーを修正します。これにより、ユーザーはメモをとるときにスクロールや選択を維持したり、色を塗るときに指で直接色を塗ったりすることができます。
