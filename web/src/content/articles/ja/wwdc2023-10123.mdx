## Highlight

> Apple 发布 Game Porting Toolkit，让开发者无需修改即可在 Mac 上运行 Windows DirectX 游戏，快速评估图形功能兼容性和性能基线，为原生移植做决策。

## 核心内容

### 移植游戏的痛点

把 Windows 游戏带到 Mac 通常要经历漫长流程：重新编译源代码、转换数千个 HLSL 着色器、重新实现图形子系统、处理音频输入显示和 HDR——在能看到第一帧画面之前就要做大量工作。

Game Porting Toolkit 改变了这个流程。它提供一个翻译环境，让未修改的 Windows 游戏直接在 Mac 上运行。

（[00:59](https://developer.apple.com/videos/play/wwdc2023/10123/?time=59)）

### 工具包翻译什么

Game Porting Toolkit 翻译游戏的 Intel x86 指令和 Windows API 调用：

- 键盘、鼠标、手柄输入
- 音频播放
- 网络和文件系统
- 图形 API（DirectX 11/12）

所有现代图形功能都支持：GPU 驱动管线、SIMD 操作、曲面细分、几何着色器。

（[03:06](https://developer.apple.com/videos/play/wwdc2023/10123/?time=186)）

### 实战演示：The Medium

Bloober 团队用 Game Porting Toolkit 评估他们的游戏《The Medium》。步骤如下：

1. 安装工具包
2. 把 Windows 版游戏复制到 Mac
3. 从终端启动游戏

```bash
# 在终端中启动游戏
game-porting-toolkit /path/to/TheMedium.exe
```

终端会显示日志和调试信息。Bloober 的开发者看到游戏运行正常，透明效果、反射、几何着色器、曲面细分、全局光照都被正确翻译到 Metal 3。

（[03:37](https://developer.apple.com/videos/play/wwdc2023/10123/?time=217)）

### 性能评估 workflow

工具包运行时的性能包含了翻译开销，所以看到的数据是基线而非上限。原生移植后性能会显著提升。

推荐的评估 workflow：

1. 启用 Metal Performance HUD 玩游戏
2. 找到帧率下降或掉帧的位置
3. 用 Instruments 捕获 Metal System Trace
4. 分析 GPU 时间线，找到问题根源

增强版 HUD 在标准信息之外，还显示：
- 指令集翻译详情
- Direct3D API 版本
- 渲染编码器数量
- 每帧几何着色器和曲面细分着色器使用次数
- 资源复制和清除操作

（[05:53](https://developer.apple.com/videos/play/wwdc2023/10123/?time=353)）

### 输入、音频和显示

**输入**：Apple 平台的 Game Controller 框架支持手柄、键盘、鼠标、方向盘、摇杆。系统级支持每应用输入重映射、截图、录屏、15 秒高光回放。

**音频**：跨平台音频中间件（Wwise、Unity、FMOD）在 Apple 平台都有原生 Apple Silicon SDK。如果直接使用底层 API，可以用 Spatial Mixer Audio Unit、PHASE、AVAudioEngine。

**显示**：CAMetalLayer 支持扩展动态范围（EDR），可以迁移 HDR 和色调映射逻辑。CAMetalDisplayLink API 提供精细的输入和显示延迟控制。

（[09:42](https://developer.apple.com/videos/play/wwdc2023/10123/?time=582)）

## 详细内容

### Metal Shader Converter

Game Porting Toolkit 包含 Metal Shader Converter，自动将 HLSL GPU 着色器转换为 Metal。这省去了手动重写数千个着色器的工作。

转换后的着色器直接生成 Metal 库文件，可以打包到应用中，避免运行时编译开销。

（[02:03](https://developer.apple.com/videos/play/wwdc2023/10123/?time=123)）

### 使用 Instruments 分析性能

当 HUD 显示某个场景帧率异常时，用 Instruments 捕获 Metal System Trace：

1. 打开 Instruments，选择 Metal System Trace 模板
2. 附加到游戏进程
3. 复现性能问题场景
4. 停止录制，分析 GPU 时间线

常见发现：GPU 时间线出现大段空白，利用率低，某些帧完全没有调度工作。这通常是指令翻译或 API 翻译开销导致的——原生移植后这些问题会消失。

（[06:13](https://developer.apple.com/videos/play/wwdc2023/10123/?time=373)）

## 核心启发

- **做什么**：用 Game Porting Toolkit 快速评估 Windows 游戏在 Mac 上的可行性
  - **为什么值得做**：几小时就能看到游戏在 Mac 上的实际表现，不用等几个月的原生移植
  - **怎么开始**：从 developer.apple.com 下载工具包，按文档配置，直接运行 Windows 游戏可执行文件

- **做什么**：在评估阶段就用 Metal Performance HUD 和 Instruments 建立性能基线
  - **为什么值得做**：工具包运行时的性能数据包含翻译开销，原生移植后会有显著提升，提前知道瓶颈在哪里
  - **怎么开始**：启用 HUD 玩游戏，找到掉帧点，用 Instruments 捕获 Metal System Trace

- **做什么**：利用 MetalFX Upscaling 提升原生版本的帧率
  - **为什么值得做**：Windows 版本通过工具包运行时无法使用 MetalFX，原生移植后可以开启，帧率大幅提升
  - **怎么开始**：评估完成后进入移植阶段，在渲染管线中集成 MetalFX

- **做什么**：为 Mac 版游戏添加手柄震动和触觉反馈
  - **为什么值得做**：Game Controller 框架原生支持这些功能，Windows 游戏的 XInput 逻辑可以直接映射
  - **怎么开始**：用 Game Controller 框架替换 XInput/GameInput 调用
