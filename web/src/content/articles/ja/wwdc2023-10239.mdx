## ハイライト

> SharePlay は、iOS 17 に 3 つの新しい拡張機能を追加します。AirDrop による近距離共有、5 つの新しいアクティビティ タイプ (ワークアウト/ショッピング/読書/学習/一緒に作成)、クロスプラットフォームおよびクロスシナリオの継続性エクスペリエンスで、どのアプリでも 1 人のアクティビティを複数人のコラボレーションに変えることができます。

## 主な内容

### リモートから対面へ: AirDrop が SharePlay を起動

SharePlay は当初、FaceTime 通話でのみ利用可能でしたが、後にメッセージにも拡張されました。しかし、多くの場合、友人はあなたのそばにいます。地下鉄で一緒に音楽を聴いたり、レストランで一緒に食べ物を注文したり、ショッピングモールで一緒に家具を選んだりすることです。

([03:02](https://developer.apple.com/videos/play/wwdc2023/10239/?time=182)) iOS 17 では、AirDrop 経由の SharePlay が追加されます。 SharePlayは、ユーザー名やメールアドレスを交換することなく、2台のデバイスを近づけると開始できます。これにより、SharePlayの適用シーンが「リモートプレイ」から「対面コラボレーション」まで広がります。

さらに良いのは、体験の継続性です。 SharePlay は AirDrop から開始され、その後友達が離れた場合は、シームレスにメッセージに切り替えて続行できます。ボイスチャットをしたい場合は、ワンクリックでFaceTime通話にジャンプできます。 tvOS 17 は大画面での FaceTime もサポートし、SharePlay を起動します。

### 豊富なアクティビティ タイプ

([04:45](https://developer.apple.com/videos/play/wwdc2023/10239/?time=285)) 既存の「Watching Together」、「Listening Together」、「Playing Together」、「Generic」に加えて、今年はワークアウト、ショッピング、読書、学習、作成の 5 つの新しいアクティビティ タイプが追加されました。これらのタイプは、システム HUD に表示されるアイコンとテキストを決定し、ユーザーが現在何をしているかを一目で識別できるようにします。

### あなたがイベントをリードし、Apple が群衆をリードします

SharePlay の核となるコンセプトは、「あなたがイベントをもたらし、Apple が観客をもたらす」です。アプリケーションはアクティビティ コンテンツと同期ロジックを定義するだけで済み、残りは GroupActivities フレームワークが行います。クラウド ディスカバリ、招待状の送信、エンドツーエンドの暗号化されたデータ チャネル、グループ管理 UI (個人セレクター、通知、ステータス変更) はすべて組み込まれています。

([01:06](https://developer.apple.com/videos/play/wwdc2023/10239/?time=66)) データ チャネルでは FaceTime と同じエンドツーエンド暗号化が使用されており、Apple はアプリ データを確認できません。これはユーザーのプライバシーを強力に保証します。

### グループアクティビティを定義する

([04:15](https://developer.apple.com/videos/play/wwdc2023/10239/?time=255)) SharePlay アクティビティを実装する必要があります`GroupActivity`プロトコル：

```swift
import GroupActivities

struct OrderTogether: GroupActivity {
    // 唯一标识符，供系统引用
    static let activityIdentifier = "com.example.TacoTruck.OrderTogether"

    // 应用特定数据，用于在其他设备上启动活动
    let orderUUID: UUID
    let truckName: String

    var metadata: GroupActivityMetadata {
        var metadata = GroupActivityMetadata()
        metadata.title = "Order Tacos Together"
        metadata.subtitle = truckName
        metadata.previewImage = UIImage(named: "ActivityImage")?.cgImage
        metadata.type = .shopTogether
        return metadata
    }
}
```

キーポイント:
- `activityIdentifier`グローバルに一意な逆ドメイン名形式である必要があります
-`metadata.title`アクティビティの名前です (アプリ名ではありません)
-`subtitle`追加のコンテキスト情報を提供する
-`previewImage`イベント固有の画像です (アプリアイコンではありません)
-`type`システム UI 表示に影響を与える最も一致するアクティビティ タイプを選択します

### メタデータ構成例

([04:15](https://developer.apple.com/videos/play/wwdc2023/10239/?time=255)) 基本的なメタデータ設定:

```swift
var metadata: GroupActivityMetadata {
    var metadata = GroupActivityMetadata()
    metadata.title = "Order Tacos Together"
    metadata.type = .generic
    return metadata
}
```

キーポイント:
- アプリに複数のアクティビティがある場合は、各アクティビティのタイトルとアイコンが共通でないことを確認してください
- システムは、`type`HUD に対応するアイコンを表示します (Watch、Listen、Game、または General)
- 新しいタイプ (ワークアウト、ショップ、読み取り、学習、作成) が iOS 17、iPadOS 17、macOS Sonoma、tvOS 17 で利用可能

### シーン間の連続性

([03:36](https://developer.apple.com/videos/play/wwdc2023/10239/?time=216)) SharePlay は 3 つの開始方法をサポートし、シームレスに切り替えることができるようになりました。

1. **FaceTime**: 通話中に [共有] ボタンをクリックすると、システムは SharePlay をサポートするアプリのリストを表示します。
2. **メッセージ**: 電話する必要はありません。メッセージで直接共有アクティビティを開始できます。
3. **AirDrop**: デバイスが近づくと開始でき、対面のシナリオに適しています。

([08:35](https://developer.apple.com/videos/play/wwdc2023/10239/?time=515)) SharePlay セッションに入ると、参加者はグループを再構成することなく、いつでもアクティビティ タイプを切り替えることができます。たとえば、「一緒に曲を聴く」から「一緒にビデオを見る」に切り替えると、グループ全体もそれに応じて切り替わります。

### アプリケーションの検出とインストール

([08:54](https://developer.apple.com/videos/play/wwdc2023/10239/?time=534)) グループ内の誰かが SharePlay をサポートするアプリをインストールしていない場合、システムはそのユーザーを自動的に App Store に誘導してダウンロードします。これにより、新規ユーザーが参加する障壁が低くなります。
