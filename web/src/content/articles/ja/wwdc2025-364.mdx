## Highlight

> WWDC25 のウェルカムビデオは、全年のセッション索引です。100 以上のセッションが新デザイン「Liquid Glass」、Apple Intelligence のオンデバイス大規模モデル、Xcode、Swift、SwiftUI、Metal、Gaming をカバーし、テキスト要約、Xcode へのワンクリックコピーオンライングループラボという3つの視聴補助機能が新たに追加されました。

---

## コア内容

毎年 WWDC の幕を開けると、開発者が最初に直面する問題は「100 以上のセッションをどう選び、どの順番で見るべきか」です。重要なセッションを見逃せば、その年で最も重要な API 変更を逃すことになります。一方、ID 順に機械的に見ても詳細に埋もれてしまいます。この2分半のウェルカムビデオは、「今年のセッションロードマップ」という位置づけです。

ビデオの冒頭で、全年の内容を一言に凝縮しています。「new design、Apple Intelligence、Xcode、Swift、SwiftUI、Metal、Gaming」（[00:06](https://developer.apple.com/videos/play/wwdc2025/364/?time=6)）。その後、3種類のセッションラベルで内容を階層化しています：Code-along（[00:22](https://developer.apple.com/videos/play/wwdc2025/364/?time=22)）は Apple のエンジニアと一行ずつコードを書く、Foundation（[00:29](https://developer.apple.com/videos/play/wwdc2025/364/?time=29)）はデザインと技術の基礎を補強する、Platforms State of the Union（[00:39](https://developer.apple.com/videos/play/wwdc2025/364/?time=39)）はすべての開発者告知の詳細を把握する。二つの柱が繰り返し強調されています。一つは Liquid Glass、「broadest design update ever」（[00:48](https://developer.apple.com/videos/play/wwdc2025/364/?time=48)）。これはガラスの光学特性と流動感を融合させたもの。もう一つはオンデバイス LLM、「any app can tap into the intelligence...available even when the user is offline」（[01:19](https://developer.apple.com/videos/play/wwdc2025/364/?time=79)）。Foundation Models フレームワークを通じて、Apple Intelligence のコアとなるオンデバイス大規模モデルを直接呼び出せます。

ビデオの後半は、視聴体験そのもののアップグレードについてです。各セッションには now has a written summary（[01:36](https://developer.apple.com/videos/play/wwdc2025/364/?time=96)）が付属し、要約を先にチェックしてから完全な動画を見るかどうかを決められます。developer.apple.com のコードブロックは Xcode への直接コピーをサポート（[01:47](https://developer.apple.com/videos/play/wwdc2025/364/?time=107)）。1対1の Lab に加え、今年は Apple のエンジニアとデザイナーが主催する online group lab（[02:01](https://developer.apple.com/videos/play/wwdc2025/364/?time=121)）が新たに追加されました。質問投稿、投票、あるいは単に聴講のみも可能です。

## 詳細内容

このビデオ自体に API コードはありませんが、今年のセッション検索パスを明確なワークフローとして整理しています：

```text
1. Platforms State of the Union（102）を見て全年の API 公告を把握
2. 各セッションの written summary で素早いフィルタリング
3. ヒットしたら完全な動画を視聴。コードは Xcode にワンクリックでコピー
4. デザインと技術の基礎は Foundation クラスのセッションへ
5. 手を動かしたい → Code-along。質問したい → online group lab または 1:1 lab
6. 後続の質問 → Apple Developer Forums
```

**重要ポイント**：
- ステップ1は、ビデオ内の「get the details on all the new developer announcements in the Platforms State of the Union」（[00:39](https://developer.apple.com/videos/play/wwdc2025/364/?time=39)）に対応します。State of the Union は技術公告の総入り口です。
- ステップ2は「each session now has a written summary that highlights the essentials」（[01:36](https://developer.apple.com/videos/play/wwdc2025/364/?time=96)）に対応し、今年新たに追加された閲覧機能です。
- ステップ3は「you can copy code right from a session into Xcode」（[01:47](https://developer.apple.com/videos/play/wwdc2025/364/?time=107)）に対応します。セッションページのコードブロックには「Copy to Xcode」ボタンが付いています。
- ステップ4は「Foundation sessions to brush up on key design and technical principles」（[00:29](https://developer.apple.com/videos/play/wwdc2025/364/?time=29)）に対応し、テーマセッションで未知の概念に遭遇した際の復習に適しています。
- ステップ5は「Code-along sessions to work line by line with an Apple engineer」（[00:22](https://developer.apple.com/videos/play/wwdc2025/364/?time=22)）と「online group labs hosted by Apple Engineers and Designers」（[02:01](https://developer.apple.com/videos/play/wwdc2025/364/?time=121)）をカバーします。
- ステップ6は「find answers in the Apple Developer Forums」（[02:15](https://developer.apple.com/videos/play/wwdc2025/364/?time=135)）に対応し、WWDC ウィーク後も継続して答疑を受けられる公式チャネルです。

ビデオでは、さらに2つの今年の目玉セッションが名指しされ、最優先で視聴すべきセッションとして位置づけられています：

- **Liquid Glass**：「a new material that combines the optical qualities of glass with a sense of fluidity」（[01:00](https://developer.apple.com/videos/play/wwdc2025/364/?time=60)）。デザイン言語レベルでの統一アップデートで、アプリ横断、プラットフォーム横断。
- **Foundation Models framework**：「direct access to the on-device large language model at the core of Apple Intelligence」（[01:27](https://developer.apple.com/videos/play/wwdc2025/364/?time=87)）。powerful、fast、privacy、offline という4つの特性を強調し、今年の AI 能力の入り口となるフレームワークです。

## コアインサイト

- **すること**：Platforms State of the Union（Session 102）を全年 API 読解の起点にする。
  - **なぜ価値があるか**：ウェルカムビデオがこれを「all the new developer announcements」の総入り口と明確に位置づけており、セッション番号順に一周するよりはるかに効率的です。
  - **どう始めるか**：まず 102 を一回見て、言及されたフレームワーク名をメモし、その後 developer.apple.com でフレームワーク名を使って関連セッションを検索します。

- **すること**：written summary をセッションを見るかどうかのフィルターにする。
  - **なぜ価値があるか**：100 以上のセッションを全部見ることはできません。summary は Apple 自身による一句话の位置づけで、タイトルよりも正確です。
  - **どう始めるか**：developer.apple.com のセッションページで、まず Overview 段落を読み、自分のアプリで使える API かを確認してから完全な動画時間を投入します。

- **すること**：Xcode 26 でセッションコードのワンクリックコピーを有効にする。
  - **なぜ価値があるか**：今年すべてのセッションページのコードブロックには Copy to Xcode が付いており、サンプルの手書き転写時間を節約し、スペルミスを回避できます。
  - **どう始めるか**：Safari でセッションページを開き、コードブロック右上のボタンをクリックすると、Xcode が自動的に受け取って現在のファイルにペーストします。

- **すること**：具体的な適用問題について online group lab に申請する。
  - **なぜ価値があるか**：1:1 lab は枠が限られている。一方、group lab は Apple エンジニアが主催し、投票をサポートしており、他人が尋ねた同類の問題を見ても有益です。
  - **どう始めるか**：Apple Developer App で lab スケジュールを確認し、自分のアプリ技術スタックに関連するセッションを選んで申し込み、事前に質問を書いて提出します。
