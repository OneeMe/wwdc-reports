## ハイライト

> App Store サーバー API は、トランザクション履歴、サブスクリプション ステータス、返金情報のアクティブなクエリをサポートします。 Server Notices V2 は 20 以上のイベント タイプをカバーします。新しいファミリー共有のサポートとサンドボックス環境の改善が追加されました。

## 主な内容

アプリにはアプリ内購入があります。ユーザーが購入した後、クライアントは検証のためにレシートをサーバーに送信します。ただし、ユーザーがオフライン中に購入したり、クライアントのリクエストが失敗したりする可能性があります。サーバー上の購入記録が完全であることをどのように確認しますか?

App Store サーバー API とサーバー通知 V2 を使用すると、クライアントからの報告を受動的に待つのではなく、アクティブにデータを取得できます。

＃＃詳細

### App Store Server API

（[01:14](https://developer.apple.com/videos/play/wwdc2021/10174/?time=74)）

サーバー API は、サーバーが JWT 認証後に呼び出すことができる RESTful インターフェイスのセットです。

**トランザクション履歴のクエリ:**

```
GET https://api.storekit.itunes.apple.com/inApps/v1/history/{originalTransactionId}
```

すべての更新、アップグレード、ダウングレード、返金を含む、ユーザーの完全なトランザクション履歴を返します。

**サブスクリプションステータスを確認してください:**

```
GET https://api.storekit.itunes.apple.com/inApps/v1/subscriptions/{originalTransactionId}
```

有効期限、自動更新ステータス、割引タイプなど、現在のサブスクリプションの詳細なステータスを返します。

（[02:30](https://developer.apple.com/videos/play/wwdc2021/10174/?time=150)）

**キーポイント:**
- 使用`originalTransactionId`クエリではなく`transactionId`
- `originalTransactionId`サブスクリプションのライフサイクル全体を通じて変更されない
- 署名データを JWS (JSON Web Signature) 形式で返します
- データが Apple からのものであることを確認するために署名を検証する必要がある

### Server Notifications V2

（[04:00](https://developer.apple.com/videos/play/wwdc2021/10174/?time=240)）

V2 の通知タイプは、V1 の 10 から 20 以上に拡張され、サブスクリプション ライフ サイクルのすべての主要イベントをカバーします。

|通知タイプ |説明 |
|---------|------|
| `SUBSCRIBED`|新規購読 |
| `RENEWAL`|自動更新が成功しました |
| `DID_CHANGE_RENEWAL_STATUS`|ユーザーが自動更新をオン/オフにする |
| `DID_CHANGE_RENEWAL_PREF`|ユーザーのアップグレード/ダウングレード サブスクリプション |
| `EXPIRED`|サブスクリプションの有効期限が切れました |
| `REFUND`|払い戻し |
| `REFUND_DECLINED`|返金が拒否されました |
| `CONSUMPTION_REQUEST`|消費データのリクエスト |
| `REVOKE`|ホームシェアリングが取り消されました |

（[05:15](https://developer.apple.com/videos/play/wwdc2021/10174/?time=315)）

**キーポイント:**
- V2 通知にはより豊富な情報が含まれます
- すべての通知は JWS 形式です
- 署名を検証する必要がある
- 200 以外が返された場合、Apple は数日以内に再試行します

### JWS 署名を検証する

（[06:30](https://developer.apple.com/videos/play/wwdc2021/10174/?time=390)）

サーバー API と通知によって返されるデータは JWS 形式であり、署名を検証する必要があります。

```swift
import CryptoKit

func verifyJWS(_ jwsString: String) throws -> Transaction {
    // 1. 分离 JWS 的三个部分
    let parts = jwsString.split(separator: ".")
    guard parts.count == 3 else { throw VerificationError.invalidFormat }

    // 2. 解析 header，获取证书
    let headerData = base64Decode(String(parts[0]))
    let header = try JSONDecoder().decode(JWSHeader.self, from: headerData)

    // 3. 从 Apple 获取公钥并验证证书链
    let certificate = try validateCertificateChain(header.x5c)

    // 4. 验证签名
    let signedData = Data((parts[0] + "." + parts[1]).utf8)
    let signature = base64Decode(String(parts[2]))
    let isValid = certificate.publicKey.isValidSignature(signature, for: signedData)

    guard isValid else { throw VerificationError.invalidSignature }

    // 5. 解析 payload
    let payloadData = base64Decode(String(parts[1]))
    return try JSONDecoder().decode(Transaction.self, from: payloadData)
}
```

（[07:45](https://developer.apple.com/videos/play/wwdc2021/10174/?time=465)）

**キーポイント:**
- JWS には、ヘッダー、ペイロード、署名の 3 つの部分が含まれています。
- Apple からルート証明書検証証明書チェーンを取得します。
- 署名を検証してデータが改ざんされていないことを確認します
- ペイロードを解析してトランザクション情報を取得します

### Family Sharing

（[09:00](https://developer.apple.com/videos/play/wwdc2021/10174/?time=540)）

iOS 15 では、アプリ内購入によるファミリー共有がサポートされています。ユーザーが購入すると、家族は追加料金なしで自動的にアクセスできるようになります。

サーバー API では、次のように渡すことができます。`inAppOwnershipType`フィールドの区別:

- `PURCHASED`:ユーザーが自分で購入する
- `FAMILY_SHARED`：ホームシェアリングで入手

ホームシェアリングが取り消されると、サーバーは`REVOKE`通知します。

（[10:15](https://developer.apple.com/videos/play/wwdc2021/10174/?time=615)）

**キーポイント:**
- `inAppOwnershipType`購入と共有を区別する
- `REVOKE`共有が取り消されたことを示す通知
- 共有ユーザーのアクセス権を処理する必要がある
- サブスクリプションや非消費型のアプリ内購入に適しています

### サンドボックス環境の改善

（[11:30](https://developer.apple.com/videos/play/wwdc2021/10174/?time=690)）

サンドボックス環境の新機能:

- **テスト サブスクリプション アクセラレーション**: サンドボックスのサブスクリプション期間が短縮されます (1 年 = 1 時間)
- **テスト返金**: 返金プロセスはサンドボックスでシミュレートできます。
- **ファミリー共有のテスト**: ファミリー共有はサンドボックスでテストできます。
- **テストオファー**: サンドボックスで紹介オファーとプロモーションオファーをテストできます

（[12:45](https://developer.apple.com/videos/play/wwdc2021/10174/?time=765)）

**キーポイント:**
- サンドボックスのサブスクリプション サイクルが加速され、テストと更新が容易になります。
- サンドボックスは返金テストをサポートします
- サンドボックスはファミリー共有テストをサポートします
- 测试账号在 App Store Connect 中管理

## 重要なポイント

1. **サーバー API を使用して購入ステータスをアクティブに同期します**。クライアントのレポートだけに依存するのではなく、サーバーはデータの一貫性を確保するために定期的にレポートを取得します。入口API：`GET /inApps/v1/history/{originalTransactionId}`。

2. **サーバー通知 V2 を使用してステータスの変更にリアルタイムで対応します**。 20 を超えるイベント タイプがサブスクリプションのライフ サイクル全体をカバーします。入口 API: JWS 通知を受信するようにサーバー URL を構成します。

3. **Verify the signature of all JWS data**.中間者攻撃やデータ改ざんを防ぎます。入口 API: Apple ルート証明書 + JWS 署名検証。

4. **Support Family Sharing**.区別する`PURCHASED`そして`FAMILY_SHARED`、対処する`REVOKE`通知します。入口API：`inAppOwnershipType` + `REVOKE`通知します。

5. **サンドボックスで完全な購入プロセスをテストします**。サブスクリプション サイクルを加速して、更新、アップグレード、ダウングレード、返金を迅速にテストします。入口 API: App Store Connect サンドボックス テスト アカウント。
