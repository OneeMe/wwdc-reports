## ハイライト

> watchOS 10 は、SwiftUI をコアとして Apple Watch インターフェイスを再設計し、2 つの新しいナビゲーション パラダイム、NavigationSplitView と TabView の垂直ページめくりを導入し、全画面の背景素材、鮮やかな塗りつぶし、テキスト ラベルと組み合わせて、アプリケーションが最小の画面で最も焦点を絞った情報を表示できるようにします。

## 主な内容

### 10秒ルール

Apple Watch ユーザーが手首を上げると、わずか 10 秒しかかかりません。天気アプリを開くと、その日の現地の天気が直接表示されます。 Digital Crown を回すと次の数時間が表示され、次に回すと次の数日間が表示されます。 iPhone のニュースは、複数のタブ、複数レベルのリッチ コンテンツです。ウォッチには 5 つの見出しのみが表示され、クリックするとインラインで展開されます。

このデザインアイデアは「Apple Watch Moment」と呼ばれています。ユーザーが手首を上げた瞬間に最も関連性のある情報は何ですか? [心拍数] には、まず現在の心拍数の値が表示され、次に全画面アニメーションを使用して傾向が表示されます。アクティビティは、複雑なデータを単一の焦点を絞ったビューに分割します。時計アプリをデザインするときは、次のことを自問してください: 時間が 10 秒しかなかったら、何を表示するでしょうか?

### Digital Crown 優先ナビゲーション

2014 年に Apple Watch が発売されたとき、Digital Crown は画面を遮らない高精度の入力デバイスとして定義されていました。 watchOS 10 では、このアイデアを極限まで取り入れています。スクロール、ページング、正確な調整はすべてリューズに固定されており、タッチはバックアップとして機能します。

スマートスタックはこのアイデアを具現化したものです。 Digital Crown を回すと、スマートに分類されたウィジェットが次々と表示されます。アプリケーションを設計するときは、まずどの情報がスマート スタック ウィジェットに最適であるかを考えてから、これらの「現在関連性のある」エクスペリエンスを中心にアプリケーション アーキテクチャを構築します。

### 3 つのナビゲーション パラダイム

NavigationSplitView は、詳細ビューの下にソース リストを非表示にし、ワンクリックでアクセスできるようにします。天気 その日の天気の詳細を直接入力し、リストアイコンをクリックして都市を切り替えます。ソース リストにはタイトル、閉じるボタン、ナビゲーション コントロールは必要なく、より対照的なデータを表示するために短いナビゲーション バーを使用します。

TabView では、新しい垂直方向のページめくりスタイルが追加され、スクロールするコンテンツに合わせて 1 つのタブを拡張できます。アクティビティの 3 つのエクササイズ リングはそれぞれタブになっており、最後までスクロールするとエクササイズ履歴のリストが表示されます。タブ切り替え時の matchedGeometryEffect アニメーションをサポートし、アクティビティ リングが TabView から左上隅までスケールします。

NavigationStack は、ワークアウト、カレンダー、音楽などの深いレベル用に予約されています。プッシュ アニメーションが更新され、選択した項目が強調表示されて移動し、ナビゲーション関係がより明確に表現されます。

### NavigationSplitView の実装

([05:56](https://developer.apple.com/videos/play/wwdc2023/10138/?time=356))

```swift
NavigationSplitView {
    List(cities, selection: $selectedCity) { city in
        Text(city.name)
    }
} detail: {
    WeatherDetailView(city: selectedCity)
}
```

**キーポイント:**
- API は他のプラットフォームと一致していますが、watchOS ではソース リストが詳細ビューの下に表示されません。
- `selectedCity` はデフォルト値に初期化する必要があり、アプリケーションは起動時に直接詳細ビューに入ります。
- 詳細ビューにはタイトルは必要ありません。情報自体が一目で明確である必要があります
- ソースリストには閉じるボタンは必要ありません。リストアイコンをクリックするか、スライドして切り替えます。

### TabView の垂直方向のページめくりと展開

([07:53](https://developer.apple.com/videos/play/wwdc2023/10138/?time=473))

```swift
TabView {
    MoveRingView()
    ExerciseRingView()
    StandRingView()
    RecentWorkoutsList() // 自动检测滚动内容并展开
}
.tabViewStyle(.verticalPage(transitionStyle: .blur))
.containerBackground(.green.gradient, for: .navigation)
```

**キーポイント:**
- `.verticalPage` は、watchOS 10 で追加された新しいタブ ビュー スタイルです。
- `.blur` トランジションにより、タブ間のぼやけた切り替え効果が作成されます
- `containerBackground` 全画面のグラデーション背景をナビゲーション コンテナーに追加します
- TabView は、`List` などのスクロール コンテンツを自動的に検出し、それに合わせて展開します。

### 一致したジオメトリ エフェクトによるアニメーション

([09:12](https://developer.apple.com/videos/play/wwdc2023/10138/?time=552))

```swift
@Namespace private var animationNamespace
@State private var selectedTab = 0

TabView(selection: $selectedTab) {
    MoveRingView()
        .matchedGeometryEffect(id: "rings", in: animationNamespace)
}
.toolbar {
    ToolbarItem(placement: .topBarLeading) {
        ActivityRingsView()
            .matchedGeometryEffect(id: "rings", in: animationNamespace)
            .opacity(selectedTab == 0 ? 0 : 1)
    }
}
```

**キーポイント:**
- `matchedGeometryEffect` は 2 つのビューを接続し、SwiftUI は位置アニメーションを自動的に処理します
- [移動] タブまでスクロールすると、リングがツールバーから TabView 内の位置に合わせて拡大縮小されます。
- `opacity` を通じてターゲット ビューの表示/非表示を制御し、レンダリングの繰り返しを回避します
- このアニメーションは、主要な情報を常に表示しながら、インタラクションを Digital Crown に固定します。

### ダイヤルベースのレイアウト

([13:26](https://developer.apple.com/videos/play/wwdc2023/10138/?time=806))

```swift
struct DialBasedView: View {
    var body: some View {
        ZStack {
            Rectangle()
                .foregroundStyle(Color.clear)

            Circle()
                .foregroundStyle(Color.red)
                .scenePadding(.horizontal)
        }
        .edgesIgnoringSafeArea(.vertical)
    }
}
```

**キーポイント:**
- `scenePadding(.horizontal)` ダイヤル レイアウト グリッドに基づいて正しい余白を計算します。
- `edgesIgnoringSafeArea(.vertical)` ビューを下部の安全領域まで拡張してダイヤルを中央に配置します
- 透明な長方形により、ZStack が利用可能な幅を埋めることができるため、円を正しく配置できます。
・緻密な情報表示に適したダイヤルレイアウト、四隅に操作ボタンを追加可能

### ツールバーの新しい配置場所

([13:30](https://developer.apple.com/videos/play/wwdc2023/10138/?time=810))

```swift
.toolbar {
    ToolbarItem(placement: .topBarTrailing) {
        Button(action: {}) {
            Image(systemName: "ellipsis")
        }
    }
    ToolbarItem(placement: .bottomBar) {
        Button(action: {}) {
            Image(systemName: "pause.fill")
        }
        .controlSize(.large)
    }
}
```

**キーポイント:**
- `.topBarTrailing` ボタンを右上隅に配置すると、時間が自動的に中央に表示されます。
- `.topBarLeading` 左上のボタンを配置します
- `.bottomBar` 下部のコントロール ボタンを配置すると、SwiftUI がレイアウト グリッドに従ってそれらを自動的に配置します。
- `.controlSize(.large)` 主要な操作に適したボタンを大きく目立つようにします。

### 全画面背景素材

([17:01](https://developer.apple.com/videos/play/wwdc2023/10138/?time=1021))

```swift
.containerBackground(.green.gradient, for: .navigation)
```

**キーポイント:**
- `containerBackground` は watchOS 10 の新しい修飾子です
- `.ultraThinMaterial`、`.thinMaterial`、`.regularMaterial`、`.thickMaterial` をサポート
- `.green.gradient` などのカラー グラデーションもサポートします
- システム ポップアップは、階層コンテキストを提供するためにデフォルトで全画面の薄いマテリアルを使用します。

### 鮮やかな前景スタイル

([16:22](https://developer.apple.com/videos/play/wwdc2023/10138/?time=982))

```swift
Text("Decibels")
    .foregroundStyle(.secondary)

Text("85 dB")
    .foregroundStyle(.primary)

Chart { ... }
    .foregroundStyle(.secondary) // 未填充部分
```

**キーポイント:**
- `.primary`、`.secondary`、`.tertiary`、`.quaternary` は 4 つのレベルの情報階層を提供します
- これらのスタイルには鮮やかな効果があり、背景色が透けて見えるようになります。
- フルスクリーンの背景でも読みやすいように、システムカラーには鮮やかなバージョンも用意されています
- リストのコンテンツとコントロールが更新され、マテリアルの背景に適切に表示されるようになりました。

## 重要なポイント

1. **手首のリフトで天気アプリを利用可能**
   - **やること**: ミニマリストな時計天気アプリケーションを作成し、それを開いて現在の場所の天気を直接表示し、デジタル クラウンを回して時間ごとに表示し、次に回して次の 5 日間を表示します。
   - **䡡Value**: NavigationSplitView を使用すると、戻るボタンを必要とせずにワンクリックで都市リストにアクセスできるようになり、情報密度が最大化されます。
   - **開始側**: `NavigationSplitView` で構築され、詳細ビューは温度と風速を表示するためにダイヤル レイアウトを使用し、ソース リストは `List(selection:)` を使用します。

2. **スポーツ データ ダッシュボード**
   - **やること**: TabView を使用してページを縦にめくると、心拍数、歩数、カロリーの 3 つの指標が表示されます。各タブは、全画面のグラデーションの背景によって区別されます。
   - **䡡値**: `matchedGeometryEffect` を使用すると、タブを切り替えるときに主要なインジケーターで視覚的な連続性を維持できます。`.verticalPage` を使用すると、ナビゲーションを Digital Crown によって完全に駆動できます。
   - **Haigata**: `@Namespace` を定義し、同じ `matchedGeometryEffect` ビューを TabView とツールバーに配置し、`containerBackground` を使用して異なるグラデーションを設定します。

3. **フォーカスタイマー**
   - **やること**: ポモドーロ アプリケーション、全画面の背景色がタイミング ステータスに応じて変化します - 集中時は落ち着いた青、休憩時は柔らかい緑、終了時は明るいオレンジ色に変わります。
   - **䡡価値**: watchOS 10 の全画面背景素材と鮮やかなテキストにより、ステータスの変化が一目でわかります。現在の段階を知るために数字を見る必要はありません。
   - **Haigata**: `containerBackground` を使用して動的カラーを設定し、`.primary`/`.secondary` を使用してテキスト レベルを制御し、デジタル クラウンを使用してタイミングの長さを調整します

4. **スマートスタッキングウィジェット**
   - **やること**: 既存の iOS アプリ用の watchOS スマート スタック ウィジェットを設計して、最も関連性の高いリアルタイム データを表示します。
   - **䡡価値**: スマート スタックは、watchOS 10 の中心的な入り口です。ユーザーは、アプリケーションを開くよりも速く、Digital Crown に目を向けることでそれを確認できます。
   - **Hajime**: 「スマート スタックのウィジェットのデザイン」セッションを参照し、WidgetKit を使用して `accessoryRectangular` または `accessoryCircular` スタイルのウィジェットを作成します。
