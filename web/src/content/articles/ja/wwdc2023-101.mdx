## ハイライト

> WWDC 2023 は Apple Vision Pro と visionOS を発表し、M2 Ultra Mac で Apple Silicon 移行を完了するとともに、iOS 17、iPadOS 17、macOS Sonoma、watchOS 10 の大型アップデートを届けました。

## 主要内容

WWDC 2023 は Apple にとって過去 10 年で最も重要な開発者会議でした。3 つの大きな出来事が同時に起きました。Mac 製品ラインの Apple Silicon 移行完了、6 つのソフトウェアプラットフォームの年次大型アップデート、そして全く新しいハードウェアプラットフォーム Apple Vision Pro の誕生です。開発者が注目すべきは新 API だけでなく、デスクトップからモバイル、そして空間コンピューティングへの計算パラダイムの転換です。

### Mac：Apple Silicon 全製品ライン完成

Mac の Apple Silicon 移行は 2020 年の M1 から始まりました。3 年後、最後のピース Mac Pro がついに自社チップを搭載しました。

（[04:55](https://developer.apple.com/videos/play/wwdc2023/101/?time=295)）**15 インチ MacBook Air**。MacBook Air 初の 15 インチモデル。厚さ 11.5mm、重量約 3 ポンド、M2 チップ、18 時間バッテリー。15.3 インチ Liquid Retina ディスプレイ、輝度 500 nits、10 億色対応。$1299 から、13 インチモデルは $1099 に値下げ。

（[09:49](https://developer.apple.com/videos/play/wwdc2023/101/?time=589)）**Mac Studio アップデート**。M2 Max と M2 Ultra の 2 オプションを追加。M2 Max 版は M1 Max より 25% 高速、After Effects レンダリングは 50% 高速。

（[10:42](https://developer.apple.com/videos/play/wwdc2023/101/?time=642)）**M2 Ultra チップ**。UltraFusion アーキテクチャで 2 つの M2 Max チップを接続。24 コア CPU（M1 Ultra より 20% 高速）、76 コア GPU（30% 高速）、32 コア Neural Engine（40% 高速）、最大 192GB ユニファイドメモリ。単一マシンで大型 transformer モデルをトレーニング可能。

（[13:35](https://developer.apple.com/videos/play/wwdc2023/101/?time=815)）**Apple Silicon 搭載 Mac Pro**。M2 Ultra 搭載、PCIe Gen 4 拡張スロット 6 基、Thunderbolt ポート 8 基。内蔵 Media Engine は Afterburner カード 7 枚相当の動画処理能力。$6999 から。

### iOS 17：コミュニケーション、共有、インテリジェント入力

（[18:24](https://developer.apple.com/videos/play/wwdc2023/101/?time=1104)）**Contact Posters**。ユーザーは着信時に表示されるアバター、フォント、色をカスタマイズ可能。CallKit 経由でサードパーティ VoIP アプリも利用可能。

（[19:39](https://developer.apple.com/videos/play/wwdc2023/101/?time=1179)）**Live Voicemail**。留守番電話の録音中にリアルタイム文字起こしを画面表示。ユーザーはいつでも応答可能。文字起こしは完全にデバイス上で実行。

（[21:01](https://developer.apple.com/videos/play/wwdc2023/101/?time=1261)）**Messages アップデート**。検索は複数条件フィルタに対応。音声メッセージは自動文字起こし。Check In で家族に安全到着を自動通知。すべての Emoji がステッカーに。写真から被写体を抽出して Live Stickers を作成し、システム全体で利用可能。

（[25:43](https://developer.apple.com/videos/play/wwdc2023/101/?time=1543)）**NameDrop**。2 台の iPhone を近づけるだけで連絡先情報を交換。iPhone と Apple Watch 間でも利用可能。

（[26:08](https://developer.apple.com/videos/play/wwdc2023/101/?time=1568)）**AirDrop アップグレード**。2 台のデバイスを近づけると転送または SharePlay を開始。AirDrop 範囲を超えた後も、大容量ファイルはインターネット経由で転送継続可能。

（[27:25](https://developer.apple.com/videos/play/wwdc2023/101/?time=1645)）**キーボードとディクテーション**。自動修正が Transformer 言語モデルにアップグレード、文レベルの文法修正に対応。入力予測はインライン表示、スペースキーで単語や文を完了。ディクテーションも Transformer ベースの音声認識モデルにアップグレード。

（[29:45](https://developer.apple.com/videos/play/wwdc2023/101/?time=1785)）**Journal アプリ**。新アプリ。デバイス上の機械学習で写真、位置、音楽などから執筆提案をインテリジェントに生成。サードパーティアプリ向け Suggestions API を提供。

（[32:05](https://developer.apple.com/videos/play/wwdc2023/101/?time=1925)）**StandBy**。iPhone を横向きに充電すると自動的に入るフルスクリーン表示モード。時計、写真スライドショー、ウィジェットに対応。

### iPadOS 17：パーソナライゼーションと生産性

（[35:49](https://developer.apple.com/videos/play/wwdc2023/101/?time=2149)）**インタラクティブウィジェット**。ウィジェットが直接インタラクション可能に — リマインダー完了、HomeKit デバイス操作、音楽再生をアプリを開かずに実行。サードパーティアプリもインタラクション機能を追加可能。

（[36:50](https://developer.apple.com/videos/play/wwdc2023/101/?time=2210)）**ロック画面のパーソナライゼーション**。iPad が iPhone と同じロック画面カスタマイズ体験を獲得。壁紙、フォント、色、ウィジェット。Live Activities も iPad ロック画面に登場。

（[39:11](https://developer.apple.com/videos/play/wwdc2023/101/?time=2351)）**Health アプリが iPad に**。HealthKit 同期が iPad に拡張。開発者は大画面向けの健康・フィットネスアプリを構築可能。

（[40:27](https://developer.apple.com/videos/play/wwdc2023/101/?time=2427)）**PDF 強化**。システムが PDF フォームフィールドを自動認識し、AutoFill 自動入力に対応。Notes アプリ内で PDF の表示、注釈、共同編集が可能。

### macOS Sonoma：ウィジェット、ゲーム、生産性

（[45:11](https://developer.apple.com/videos/play/wwdc2023/101/?time=2711)）**デスクトップウィジェット**。ウィジェットは通知センターに限定されず、デスクトップに直接配置可能。Continuity 経由で Mac は iPhone のウィジェットにアクセスでき、Mac に対応アプリをインストールする必要はありません。

（[48:15](https://developer.apple.com/videos/play/wwdc2023/101/?time=2895)）**ゲームモード**。ゲームに最高の CPU/GPU 優先度を自動割り当て。AirPods のオーディオ遅延が大幅に低減。Xbox/PlayStation コントローラーの Bluetooth サンプルレートが 2 倍に。

（[49:03](https://developer.apple.com/videos/play/wwdc2023/101/?time=2943)）**Game Porting Toolkit**。Metal の新ツール。他プラットフォームのゲームを Mac に迅速に評価・移植。数ヶ月かかっていた評価プロセスが数日に短縮。

（[51:54](https://developer.apple.com/videos/play/wwdc2023/101/?time=3114)）**ビデオ会議強化**。Presenter Overlay で発表者を共有コンテンツの上に重ね表示。Reactions ビデオエフェクトはジェスチャでトリガー。

（[53:15](https://developer.apple.com/videos/play/wwdc2023/101/?time=3195)）**Safari アップデート**。プライベートブラウジングウィンドウは自動ロック。既知のトラッカーをブロック。URL トラッキングパラメータを除去。パスワードと passkey のグループ安全共有に対応。Profiles で仕事用と個人用のブラウジングデータを分離。Web App で任意のウェブサイトを Dock に追加可能。

### オーディオとホーム

（[57:50](https://developer.apple.com/videos/play/wwdc2023/101/?time=3470)）**AirPods Adaptive Audio**。ノイズキャンセリングと外部音取り込みを動的にブレンド。Conversation Awareness で話し始めると音楽音量を自動低下。

（[01:03:05](https://developer.apple.com/videos/play/wwdc2023/101/?time=3785)）**Apple TV での FaceTime**。Continuity Camera で iPhone/iPad カメラを Apple TV にワイヤレス接続。Continuity Camera API が開発者に開放。Zoom と Webex は年末までに tvOS に登場予定。

### watchOS 10：インタラクションの再定義

（[01:07:00](https://developer.apple.com/videos/play/wwdc2023/101/?time=420)）**Smart Stack**。任意の文字盤からデジタルクラウンを回すとウィジェットスタックが表示。機械学習が適切なタイミングで関連情報を表示。

（[01:10:27](https://developer.apple.com/videos/play/wwdc2023/101/?time=4227)）**サイクリング機能**。Apple Watch が Bluetooth 自転車センサーに接続。FTP を自動推定し、Power Zones トレーニングデータを提供。サイクリングワークアウトは iPhone に Live Activity として自動表示。

（[01:13:37](https://developer.apple.com/videos/play/wwdc2023/101/?time=4417)）**ゴルフ/テニスワークアウト API**。Apple Watch Series 8 と Ultra の高頻度モーションセンサーが急速な方向・加速度変化を検出。開発者は API 経由でデータを取得。

（[01:15:02](https://developer.apple.com/videos/play/wwdc2023/101/?time=4502)）**メンタルヘルス**。マインドフルネスアプリで感情と気分を記録。Health アプリで標準化されたうつ病・不安評価尺度を提供。

（[01:17:04](https://developer.apple.com/videos/play/wwdc2023/101/?time=4624)）**視力の健康**。Apple Watch が屋外の日光時間を測定。Screen Distance は TrueDepth カメラでデバイスが目に近すぎないか検出。

### Apple Vision Pro：空間コンピューティングプラットフォーム

（[01:21:05](https://developer.apple.com/videos/play/wwdc2023/101/?time=4865)）Keynote 全体の核心となる発表。Apple Vision Pro はスタンドアロンの空間コンピューターで、$3499 から、2024 年初頭に米国で発売。

（[01:24:22](https://developer.apple.com/videos/play/wwdc2023/101/?time=5062)）**インタラクション**。3 つの入力：目での閲覧（注視で選択）、指のピンチで選択、音声ディクテーションと Siri。コントローラー不要。

（[01:48:16](https://developer.apple.com/videos/play/wwdc2023/101/?time=6496)）**ディスプレイシステム**。2 つの micro-OLED パネル、各切手サイズ、片眼あたり 4K テレビを超えるピクセル数（合計 2300 万ピクセル）。各ピクセルはわずか 7.5 マイクロン幅。

（[01:51:04](https://developer.apple.com/videos/play/wwdc2023/101/?time=6664)）**デュアルチップアーキテクチャ**。M2 が計算を担当、新 R1 チップがセンサーデータを専門処理。R1 は 12 ミリ秒で新画像をディスプレイに送信 — まばたきの 8 倍速。

（[01:28:25](https://developer.apple.com/videos/play/wwdc2023/101/?time=5305)）**EyeSight**。外側の曲面 OLED が周囲の人に装着者の目を表示。完全没入時は光のエフェクトで示唆。

（[01:52:50](https://developer.apple.com/videos/play/wwdc2023/101/?time=6770)）**Digital Persona**。エンコーダー・デコーダーニューラルネットワークがユーザーのデジタル形象を生成し、顔と手の動きを動的に一致。10 億台以上の FaceTime デバイスと通信可能。

（[01:53:28](https://developer.apple.com/videos/play/wwdc2023/101/?time=6808)）**visionOS**。macOS/iOS/iPadOS 上に構築。リアルタイム実行エンジン、動的フォベーテッドレンダリングパイプライン、初のマルチアプリ 3D エンジンを追加。

（[01:54:51](https://developer.apple.com/videos/play/wwdc2023/101/?time=6891)）**開発者エコシステム**。Xcode、SwiftUI、RealityKit、ARKit など馴染みのツールで構築。Reality Composer Pro で 3D シーンを組み立て。数十万の iPad/iPhone アプリが発売時に動作。Unity との深い統合。

（[01:58:46](https://developer.apple.com/videos/play/wwdc2023/101/?time=7126)）**プライバシー**。Optic ID は虹彩認証を使用。視線追跡データはアプリから隔離 — アプリはクリック結果のみ取得し、視線軌跡は取得不可。カメラデータはシステムレベルで処理。

## 詳細

### visionOS 開発フレームワークスタック

Apple Vision Pro の開発者ツールチェーンは既存技術の上に構築されています。

| レイヤー | 技術 | 用途 |
|------|------|------|
| UI フレームワーク | SwiftUI | ウィンドウ、ボリューム、空間インターフェース |
| 3D フレームワーク | RealityKit | 3D レンダリング、アニメーション、物理、オーディオ |
| 空間認識 | ARKit | ハンドトラッキング、シーン理解、平面検出 |
| 低レベルレンダリング | Metal / CompositorServices | カスタムレンダリングパイプライン、完全没入体験 |
| コンテンツツール | Reality Composer Pro | 3D シーンの組み立て、編集、プレビュー |
| ゲームエンジン | Unity | 既存 Unity VR/3D ゲームの移植 |

キーポイント:
- SwiftUI は `WindowGroup`、`Volume`、`ImmersionSpace` シーンタイプを拡張
- RealityKit の `RealityView` は 3D コンテンツを SwiftUI ビュー階層に埋め込む
- ARKit のハンドトラッキングとシーン理解には Full Space 権限が必要
- 既存 iPad/iPhone アプリは互換レイヤー経由で visionOS 上で動作

### visionOS プライバシーアーキテクチャ

```
┌─────────────────────────────────────────┐
│  App Process                            │
│  - クリック結果のみ受信                  │
│  - 視線軌跡にアクセス不可                │
│  - 生カメラデータにアクセス不可          │
└─────────────────────────────────────────┘
                    ↑
┌─────────────────────────────────────────┐
│  System Process (isolated)              │
│  - 視線追跡データ処理                    │
│  - カメラデータ処理                      │
│  - Optic ID 虹彩認識                     │
└─────────────────────────────────────────┘
```

キーポイント:
- 視線追跡データは独立したシステムプロセスで処理
- アプリは「ユーザーがこの要素をタップした」結果のみ取得
- カメラデータはシステムレベルで処理され、アプリは周囲を見られない
- Optic ID データは Secure Enclave に暗号化保存

## 重要ポイント

**1. visionOS 向けアプリ準備の 3 つの戦略**

アプリに適した visionOS 形態を評価 — ウィンドウ化（Windows）、ボリューム化（Volumes）、全空間（Spaces）。iPad/iPhone アプリは Vision Pro 発売日に動作しますが、visionOS 対応アプリのみが空間コンピューティングの利点を発揮できます。入口：SwiftUI の `WindowGroup` と `Volume` シーンタイプから。`RealityView` と `Model3D` などの新ビューを学ぶ。

**2. インタラクティブウィジェットでユーザーエンゲージメントを向上**

既存ウィジェットにインタラクション能力を追加 — 情報表示だけでなく、ユーザーが直接操作できるように。iPad と Mac のウィジェットは両方インタラクション対応。アプリを開かずにタスクを完了できます。入口：SwiftUI の `Button` と `Toggle` でウィジェット内で直接応答。App Intents でバックグラウンド操作を実行。

**3. Mac ゲーム移植の準備**

ゲームの macOS 移植可能性を評価し、Game Porting Toolkit で迅速に検証。ゲームモードはすべての Mac ゲームに開箱即用的なパフォーマンス最適化を提供。入口：Game Porting Toolkit をダウンロードし評価ツールを実行。Metal Shader Converter の使い方を学ぶ。

**4. 空間コンピューティングプロトタイプを構築**

Xcode の visionOS テンプレートとシミュレーターで空間コンピューティングプロトタイプを迅速に構築。メインアプリが 2D でも、回転可能な製品モデルなどの簡単な 3D 要素を試せます。入口：Xcode 15 の visionOS テンプレート + Reality Composer Pro + シミュレータープレビュー。
