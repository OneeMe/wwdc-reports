## ハイライト

> Apple は、自動車メーカーと車載システム開発者向けに、動的画面適応、角丸クロップマスク、UI フォーカス移動、外観モード同期、ワイヤレス接続の簡素化、HEVC ビデオ エンコーディングのサポート、次世代 CarPlay に備えるためのインフラストラクチャ要件など、CarPlay のビジュアル統合とインフラストラクチャのアップグレードを導入します。

## 主な内容

### ディスプレイの適応: 長方形から任意の形状まで

現代の自動車のディスプレイにはさまざまな形状があります。幅が広いものもあれば、縦長のものもあり、非長方形のものもあり、CarPlay UI と車載システム UI が混在しているものもあります。

([01:22](https://developer.apple.com/videos/play/wwdc2023/10150/?time=82)) CarPlay は 2 つの概念を使用して適応問題を解決します。表示領域は、CarPlay が描画する UI の境界を定義します。安全領域は、表示領域内の最大の長方形です。 CarPlay は、すべての重要な UI が確実に表示されるように、安全な領域内にインタラクティブ コンテンツを描画します。

ディスプレイが長方形でない場合は、表示領域をディスプレイを囲む最小の長方形として定義し、安全領域をディスプレイ内の最大の長方形として定義します。 CarPlay は安全領域外のピクセルを正しく処理します。

([02:55](https://developer.apple.com/videos/play/wwdc2023/10150/?time=175)) 新しい安全エリア フラグにより​​、CarPlay が安全エリアの外側に背景を描画できるようになります。これにより、CarPlay の背景がディスプレイの端まで拡張され、より没入感のある視覚効果が得られます。このフラグはメインディスプレイに対してのみ有効です。

### 角丸トリミングマスク

([03:59](https://developer.apple.com/videos/play/wwdc2023/10150/?time=239)) CarPlay UI の丸い角には、デフォルトで黒い背景が表示されます。 CarPlay がウィンドウに表示されると、角の丸い黒い三角形が車のシステムの壁紙と一致しません。

丸い角のクリッピング マスクは、この問題を解決します。 iPhone は透明度情報を含むブレンド マスクを提供し、自動車システムはこのマスクを CarPlay UI の各隅に適用して、黒い三角形を削除します。これにより、自動車システムの背景を CarPlay の丸い端まで描画できます。

この機能は「安全領域外描画」と併用することはできません。

### UI フォーカスの転送

([05:09](https://developer.apple.com/videos/play/wwdc2023/10150/?time=309)) ノブまたはトラックパッドをサポートするシステムの場合、CarPlay と車載システム UI 間のシームレスなフォーカス切り替えが必要です。

CarPlay が開始されると、車のシステムがフォーカスを決定します。ドライバーが CarPlay にフォーカスを移動すると、システムはフォーカスを解放し、方向と位置情報を提供します。 CarPlay はこの情報を使用して、最も直感的な UI 要素にフォーカスを強調表示します。

ドライバーがフォーカスを車載システムに戻すと、CarPlay がフォーカスを提供し、システムはフォーカスを取得した後に独自のフォーカス ハイライトを表示します。 API は、一度に 1 つのフォーカス ハイライトのみが発生することを保証します。

システムが CarPlay をウィンドウとして表示し、ノブまたはトラックパッドをサポートしている場合は、UI フォーカス転送をサポートする必要があります。

### アピアランスモードの同期

([06:54](https://developer.apple.com/videos/play/wwdc2023/10150/?time=414)) CarPlay は明るいテーマと暗いテーマをサポートしています。車載システムは、CarPlay のルック アンド フィールとシステム UI の一貫性を保つ必要があります。

CarPlay の外観は、車両のステータス、ユーザー設定、時刻に基づいて自動的に変化します。たとえば、夜間にシステムがダークテーマに切り替わると、CarPlay も自動的に切り替わります。マップ UI には、個別に同期する必要がある個別の外観設定があります。

### マルチディスプレイコンテンツ

([08:36](https://developer.apple.com/videos/play/wwdc2023/10150/?time=516)) 最近の車両には、メイン ディスプレイ、ダッシュボード ディスプレイ、ヘッドアップ ディスプレイが装備されています。 CarPlay はディスプレイごとに異なるコンテンツを提供します。

- メイン ディスプレイ: 車載システムの内蔵 UI コントロールを駆動する iAP2 メタデータを使用して、CarPlay ビデオ ストリームを表示します。
- ダッシュボード: CarPlay ナビゲーション UI フローを表示し、地図のズームをサポートします
- ヘッドアップ ディスプレイ: iAP2 メタデータを使用して方向転換プロンプトなどの情報を表示します

車載システムに地図ウィジェットがある場合は、CarPlay ナビゲーションがアクティブ化されているときにウィジェットに CarPlay ナビゲーション UI フローを設定し、ETA、速度制限標識、コンパスを表示できます。

### ワイヤレス接続の改善

([10:06](https://developer.apple.com/videos/play/wwdc2023/10150/?time=606)) 初回ペアリングは帯域外ペアリングをサポートしており、ドライバーは iPhone を車に接続するだけでワイヤレス CarPlay ペアリングを完了できます。これはワイヤレス CarPlay の標準要件です。

([10:33](https://developer.apple.com/videos/play/wwdc2023/10150/?time=633)) iOS 17 は、システムがデジタル車のキーをサポートしている場合、車のキー接続を介した CarPlay のペアリングをサポートします。車のキーを追加すると、システムはワイヤレス CarPlay をペアリングするように要求し、車のキーの接続を通じてペアリングが完了します。

([11:20](https://developer.apple.com/videos/play/wwdc2023/10150/?time=680)) 簡略化された接続プロセスが推奨されます。既存の iAP2 接続を使用して IP アドレスとポート情報を交換します。Bonjour はもう必要ありません。実装が簡単になり、接続が高速になり、WPA3 のみのネットワークがサポートされます。 iOS 14以降のデバイスと互換性があります。

([11:55](https://developer.apple.com/videos/play/wwdc2023/10150/?time=715)) 車のデジタルキーもインスタント接続をサポートしています。ドライバーがデジタル車のキーを持って車両に近づくと、システムは事前に CarPlay スタックを準備し、対応するペアリング関係を確認します。 CarPlay は即座にアクティベートされるようです。

### オーディオの強化

([13:42](https://developer.apple.com/videos/play/wwdc2023/10150/?time=822)) 拡張バッファー オーディオは、ストリーミング オーディオに最適なプラットフォームです。 iPhone はリアルタイムよりも高速にオーディオを車のシステムにストリーミングし、通信プラグインには最大 2 分のオーディオ バッファーが含まれています。これにより応答性が向上し、短時間の切断でもオーディオの再生を継続できるようになります。

システムは、複数のオーディオ ストリーム（プライマリ オーディオ、拡張バッファ オーディオ、代替オーディオ、および補助オーディオ）の同時ミキシングをサポートする必要があります。

### ビデオエンコーディングのアップグレード

([15:48](https://developer.apple.com/videos/play/wwdc2023/10150/?time=948)) 以前は H.264 でエンコードされていた CarPlay UI ストリームが HEVC エンコードをサポートするようになりました。 HEVC はより効率的で、高解像度のディスプレイをサポートします。下位互換性を維持するには、システムが H.264 をサポートし続ける必要があります。

### EV ルーティング

([16:24](https://developer.apple.com/videos/play/wwdc2023/10150/?time=984)) Apple マップでは、充電ステーションでの停車を含む電気自動車での旅行を計画できます。今年の新機能: ユーザーは好みの充電ネットワークを選択でき、地図には充電ステーションの空き状況がリアルタイムで表示されます。

車載システムは、Apple Maps に電気自動車の特性情報を提供し、リアルタイムの電力状態通信をサポートする必要があります。自動車メーカーのアプリがある場合、SiriKit インテントのサポートにより、ユーザーは車内または車外で EV ルーティングを使用できます。

### ビューエリアとセキュリティエリアの構成

([01:50](https://developer.apple.com/videos/play/wwdc2023/10150/?time=110)) CarPlay のビュー領域は UI 描画の境界を定義します。システムは CarPlay にできるだけ多くのスペースを与える必要があり、CarPlay は自動的に適切なパディングを作成します。

動的な画面サイズ変更により、ユーザーは異なるレイアウトをシームレスに切り替えることができます。たとえば、全画面 CarPlay から CarPlay とシステム ウィジェットを並べて表示するように切り替えると、CarPlay のサイズが自動的に変更されます。

非長方形ディスプレイの場合:
- 表示領域 = ディスプレイを囲む最小の長方形
- 安全領域 = ディスプレイ内の最大の長方形
- CarPlay インタラクティブ コンテンツは安全な領域に描画されます
- 安全領域外のピクセルは黒く表示されます (安全領域外の描画が有効になっていない限り)

### フォーカス転送プロトコルのプロセス

([06:03](https://developer.apple.com/videos/play/wwdc2023/10150/?time=363)) 焦点調整の具体的なプロセス:

1. CarPlay が開始され、システムが初期フォーカスを決定します。
2. ドライバーがフォーカスを CarPlay に移動すると、システムがフォーカスを解放し、方位と位置を提供します。
3. CarPlay は情報を受信し、適切な UI 要素にフォーカスを強調表示します。
4. ドライバーがシステムにフォーカスを戻し、CarPlay がフォーカスを提供します。
5. システムはフォーカスを取得し、独自のフォーカス ハイライトを表示します。

このプロトコルにより、ドライバーは CarPlay とシステム UI を切り替える際に一貫したフォーカス エクスペリエンスを確保できます。

### 接続のベストプラクティス

([12:44](https://developer.apple.com/videos/play/wwdc2023/10150/?time=764)) 安定したワイヤレス CarPlay 接続を維持します。

1. 無線チャネル上の干渉源を検出する
2. チャンネル切り替え通知を使用して干渉を回避する
3. システムが複数のワイヤレス無線をサポートしている場合は、BSS 移行管理を使用して iPhone を別のアクセス ポイントに転送します。
4. 5GHz帯での動作を優先する
5. 一時的に切断された場合は、CarPlay TCP ソケットを閉じないでください。

### 次世代 CarPlay の準備

([17:26](https://developer.apple.com/videos/play/wwdc2023/10150/?time=1046)) 今年導入されたインフラストラクチャの改善はすべて、次世代の CarPlay に備えたものです。

- ビジュアル統合: 動的な画面適応、丸みを帯びたコーナーマスク、フォーカスシフト
- 接続性: 簡素化された接続プロセス、即時接続
- オーディオ: 強化されたバッファリング
- ビデオ: HEVC エンコードのサポート

これらの機能は、次世代の CarPlay 仕様で必要となります。

## 重要なポイント

1. **車両インフォテインメント システムに CarPlay サポートを追加**
   - 車両システム ソフトウェアを開発する場合は、CarPlay 仕様に従ってビュー エリア、セーフティ エリア、およびフォーカス移動を実装します。
   - 簡素化された接続プロセスと帯域外ペアリングをサポート
   - 入口: 最新の仕様を入手するには、developer.apple.com/carplay にアクセスしてください。

2. **既存の CarPlay システムの視覚体験を最適化**
   - 丸いクロッピングマスクを有効にして黒い三角形を除去します
   - CarPlay の外観モードとシステム UI を同期します
   - 動的な画面サイズ調整をサポート
   - エントリ: CarPlay 通信プラグインのコーナー クリッピング マスク API

3. **電気自動車用の CarPlay EV ルーティング サポートを追加**
   - 車両のバッテリー特性とリアルタイムの充電レベルを Apple Maps に提供します
   - EV ルーティングの音声制御のための SiriKit インテントをサポート
   - 入り口: iAP2 バッテリー ステータス メッセージ + SiriKit Vehicle Intent
