## ハイライト

> SwiftUI は、WWDC21 で SF シンボルのバリアントと 4 つのレンダリング モードをサポートし、開発者は使用できます`Image`、`Label`、`foregroundStyle`、`symbolVariant`そして`symbolRenderingMode`シンボルのセマンティクス、サイズ、色を制御します。

## 主な内容

多くの場合、カード アプリにはハート、スペード、ルールブック、個人情報、元に戻すボタンなどの小さなアイコンが多数あります。これらは単なる装飾のように見えますが、実際にはアクセシビリティ、ダイナミック フォント、ダーク モード、クロスプラットフォームの外観に影響を与えます。

以前は、開発者はシンボル名を手作業で選択することがよくありました。 iOS タブ バーの塗りつぶしバージョンを使用するには、次のようにします。`person.circle.fill`コードを書きます。 macOS にはアウトライン バージョンと別の名前が必要です。カスタム シンボルには、VoiceOver テキストの追加処理も必要です。色はもっと面倒です。 「元に戻す」ボタンには、白い矢印と赤い背景の両方が必要です。単色の色合いだけで表現するのは難しいです。

Apple は SF Symbols 3 と SwiftUI でこのリンクを完成させました。システムシンボルとカスタムシンボルの両方を渡すことができます`Image`そして`Label`現在。シンボルを埋め込むことができる`Text`、その後にテキストの改行が続きます。 SwiftUI コンポーネントは、適切なシンボル バリアントを自動的に選択します。開発者も使用できます`symbolVariant`、`symbolRenderingMode`そして`foregroundStyle`ビューツリー全体を明示的に制御します。

これにより、コードがビジネス上の意味に戻ります。ラベルバーに基本的なシンボル名を書き込むと、プラットフォームは塗りつぶしまたはアウトラインを選択できます。リストに入力する必要がある場合は、外側のレイヤーに修飾子を追加します。ボタンに複数の色のレイヤーが必要な場合は、`foregroundStyle`複数のスタイルを渡します。シンボルは引き続きフォント、動的タイピング、ダーク モード、およびプラットフォームのルールに従います。

### アクセシビリティはシンボルの作成から始まります

`Label`タイトルとアイコンを結合します。多くの SwiftUI 組み込みコンポーネントは、コンテキストに応じてタイトル、アイコン、またはその両方を表示します。 VoiceOver では、タイトルをテキスト説明として直接使用することもできます。

画像のシンボルのみ追加のチェックが必要です。システム シンボルにはデフォルトのアクセシビリティの説明が含まれている場合がありますが、同じアイコンが異なるアプリで同じ意味を持つとは限りません。カスタムシンボルは次の方法でも作成できます。`Localizable.strings`画像名にローカライズされたテキストを指定すると、SwiftUI はそれをアクセシビリティ ラベルに使用します。

### バリアントを使用すると、コードでプラットフォームの詳細を少なく書くことができます

iOS のタブ バーでは、塗りつぶし記号がよく使用されます。以前は、開発者は選択する必要がありました`.fill`終了シンボルの場合は、特定のシンボルに塗りつぶしバージョンがあるかどうかも知る必要があります。

WWDC21 の SwiftUI では、タブ バーなどのビューで特定のバリアントを自動的に選択できるようになります。開発者は、ベース名を使用して、さまざまなプラットフォーム上のコンポーネントに適切な外観を選択します。同じルールを独自のコンポーネントに適用したい場合は、次のようにします。`symbolVariant(.fill)`親ビュー上に配置します。

### レンダリング モードでは、カラー ルールはシンボル レベルに残ります。

SF Symbols は、モノクロ (単色)、マルチカラー (多色)、階層 (レイヤード)、およびパレット (パレット) の 4 つのレンダリング モードをサポートしています。

モノクロは、複数のアイコンの色を統一するのに適しています。マルチカラーでは、色が組み込まれたシンボルを使用します。これは、カード スートなど、固有の色の意味を持つアイコンに適しています。レイヤー化では、前景スタイルを使用してさまざまな不透明度を生成し、シンボルの重要な部分を強調表示します。パレットでは、最大 3 つのスタイルで異なるレベルを制御でき、前景と背景を持つボタンに適しています。

### システム シンボルとカスタム シンボルを作成する

([00:45](https://developer.apple.com/videos/play/wwdc2021/10349/?time=45)) SwiftUI は使用します`Image(systemName:)`システム シンボルを表示するには、次を使用します。`Label(_:systemImage:)`タイトルとシステムシンボルを組み合わせます。カスタム シンボルはリソース名を使用します。`Image`そして`Label`対応する初期化子があります。

```swift
import SwiftUI

struct SymbolBasicsView: View {
    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            Image(systemName: "heart")

            Label("Heart", systemImage: "heart")

            Image("queen.heart")

            Label("Queen of Hearts", image: "queen.heart")
        }
        .padding()
    }
}
```

キーポイント:
- `import SwiftUI`導入`Image`、`Label`、`VStack`そして`View`。
- `SymbolBasicsView`は、SwiftUI アプリに直接ドロップできるビューです。
-`Image(systemName: "heart")`システムが提供するハートマークを表示します。
-`Label("Heart", systemImage: "heart")`タイトルとシンボルの両方を入力してください。
-`Image("queen.heart")`アプリのリソースからカスタム シンボルを読み込みます。
-`Label("Queen of Hearts", image: "queen.heart")`カスタムシンボルをタイトルにバインドします。
-`.padding()`プレビューしやすいように、サンプルコンテンツには余白を残してください。

### 画像のみのシンボルにアクセシビリティ テキストを追加する

（[02:33](https://developer.apple.com/videos/play/wwdc2021/10349/?time=153)）`Label`テキストによる説明が自然に提供されます。のみ`Image`このシナリオでは、開発者は、VoiceOver によって読み取られたコンテンツがビジネス上の意味を満たしているかどうかを確認する必要があります。システムシンボルを追加可能`accessibilityLabel`、カスタムシンボルは次の場所にあります。`Localizable.strings`画像名にローカライズされたテキストを提供します。

```swift
import SwiftUI

struct AccessibleSymbolsView: View {
    var body: some View {
        VStack(spacing: 12) {
            Image(systemName: "heart")
                .accessibilityLabel("Ace of Hearts")

            Image(systemName: "person.circle")
                .accessibilityLabel("Profile")

            Image("queen.heart")
        }
        .padding()
    }
}

// Localizable.strings
// "queen.heart" = "Queen of Hearts";
```

キーポイント:
- `Image(systemName: "heart")`アイコンのみが表示され、タイトルは表示されません。
-`.accessibilityLabel("Ace of Hearts")`現在のアプリのトランプの意味としてハートのアイコンを説明します。
-`Image(systemName: "person.circle")`プロフィール画像のシンボルを使用します。
-`.accessibilityLabel("Profile")`VoiceOver で「プロフィール」を読み上げてもらいます。
-`Image("queen.heart")`カスタムシンボルを使用します。
-`Localizable.strings`内部`"queen.heart"`カスタム画像名にデフォルトのアクセシビリティテキストを提供します。

### テキストに記号を挿入する

([02:59](https://developer.apple.com/videos/play/wwdc2021/10349/?time=179)) SwiftUI で文字列補間が可能`Image(systemName:)`埋め込む`Text`。この方法は、連絡先リストの前向き矢印など、テキストで折り返されるシンボルに適しています。

```swift
import SwiftUI

struct InlineSymbolTextView: View {
    var body: some View {
        Text("""
            Thalia, Paul, and
            3 others \(Image(systemName: "chevron.forward"))
        """)
        .font(.body)
        .padding()
    }
}
```

キーポイント:
- `Text(""" ... """)`2 行のテキストを表示するには、複数行の文字列を使用します。
-`\(Image(systemName: "chevron.forward"))`システム矢印記号をテキスト フローに挿入します。
-`.font(.body)`テキストとインライン シンボルに本文のテキスト スタイルを使用させます。
-`.padding()`サンプルプレビューで行折り返し効果を見やすくします。

### 前景のスタイル、フォント、スケーリングで外観を調整する

（[03:14](https://developer.apple.com/videos/play/wwdc2021/10349/?time=194)）`foregroundStyle`シンボルとテキストの色を制御します。具体的な色、または現在の色合いやセカンダリなどのセマンティック スタイルのいずれかを受け取ることができます。`font`タイトルとシンボルの両方のサイズに影響します。`imageScale`テキストに対するシンボルのサイズのみを変更します。

```swift
import SwiftUI

struct SymbolStylingView: View {
    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            Label("Heart", systemImage: "heart")
                .foregroundStyle(.red)

            Label("Heart", systemImage: "heart")
                .foregroundStyle(.tint)

            Label("Heart", systemImage: "heart")
                .foregroundStyle(.secondary)

            Label("Heart", systemImage: "heart")
                .font(.caption)

            Label("Heart", systemImage: "heart")
                .imageScale(.large)
        }
        .padding()
    }
}
```

キーポイント:
- 最初の段落`Label`システムのハートマークを使用します。
-`.foregroundStyle(.red)`テキストと記号を赤で描画します。
-`.foregroundStyle(.tint)`現在の環境のアクセントカラーを使用します。
-`.foregroundStyle(.secondary)`2 番目の前景スタイルを使用します。
-`.font(.caption)`テキストとシンボルの両方でキャプション テキスト スタイルを使用し、動的なタイプ スケーリングに従います。
-`.imageScale(.large)`テキストに対するシンボルの比率のみが変更されます。

### コンポーネントに自動または手動でシンボル バリアントを選択させます

([04:23](https://developer.apple.com/videos/play/wwdc2021/10349/?time=263)) SwiftUI のタブ バーは、それ自体に適したシンボルのバリアントを自動的に選択します。開発者`tabItem`ここでは基本シンボル名が使用され、システムは必要に応じてパディングなどのバリエーションを適用します。

```swift
import SwiftUI

struct CardsTabView: View {
    var body: some View {
        TabView {
            Text("Cards").tabItem {
                Label("Cards", systemImage: "rectangle.portrait.on.rectangle.portrait")
            }
            Text("Rules").tabItem {
                Label("Rules", systemImage: "character.book.closed")
            }
            Text("Profile").tabItem {
                Label("Profile", systemImage: "person.circle")
            }
            Text("Magic").tabItem {
                Label("Magic", systemImage: "sparkles")
            }
        }
    }
}
```

キーポイント:
- `TabView`タブ付きナビゲーションを作成します。
- それぞれ`Text`タブページのコンテンツです。
-`.tabItem`タブのタイトルとシンボルを定義します。
-`Label("Cards", systemImage: ...)`基本的なシンボル名を使用し、コードは記述されません`.fill`サフィックス。
-`sparkles`パディングなしでも、システムは利用可能なバリアントを処理できます。

([05:12](https://developer.apple.com/videos/play/wwdc2021/10349/?time=312)) 独自のリストも使用できます`symbolVariant(.fill)`。この修飾子はバリアントを環境に書き込み、ビュー階層全体のシンボルに適用します。

```swift
import SwiftUI

struct FilledCardListView: View {
    var body: some View {
        List {
            Label("Ace of Hearts", systemImage: "suit.heart")
            Label("Ace of Spades", systemImage: "suit.spade")
            Label("Ace of Diamonds", systemImage: "suit.diamond")
            Label("Ace of Clubs", systemImage: "suit.club")
            Label("Queen of Hearts", image: "queen.heart")
        }
        .symbolVariant(.fill)
    }
}
```

キーポイント:
- `List`一連のカード エントリを表示します。
- 最初の 4 つ`Label`システムスーツのシンボルを使用します。
-`Label("Queen of Hearts", image: "queen.heart")`カスタムシンボルを使用します。
-`.symbolVariant(.fill)`リスト内のシンボルがパディング バリアントを使用するように要求します。
- この修飾子は、システム シンボルと、命名規則に従うカスタム シンボルの両方に影響を与える可能性があります。

### マルチカラーおよびレイヤードレンダリングモードを使用する

（[06:41](https://developer.apple.com/videos/play/wwdc2021/10349/?time=401)）`symbolRenderingMode(.multicolor)`シンボルに付属のマルチカラー定義を使用します。ハート、スペード、ダイヤ、クラブなど、色が意味をダイレクトに表現するシンボルに適しています。シンボルにマルチカラー バージョンがない場合、システムはモノクロ レンダリングに戻ります。

```swift
import SwiftUI

struct MulticolorCardListView: View {
    var body: some View {
        List {
            Label("Ace of Hearts", systemImage: "suit.heart")
            Label("Ace of Spades", systemImage: "suit.spade")
            Label("Ace of Diamonds", systemImage: "suit.diamond")
            Label("Ace of Clubs", systemImage: "suit.club")
            Label("Queen of Hearts", image: "queen.heart")
        }
        .symbolVariant(.fill)
        .symbolRenderingMode(.multicolor)
    }
}
```

キーポイント:
- `List`同じカード タグのセットを引き続き使用します。
-`.symbolVariant(.fill)`まず塗りつぶしバリアントをリクエストします。
-`.symbolRenderingMode(.multicolor)`シンボルの組み込み色の使用をリクエストします。
- マルチカラー定義のないシンボルはモノクロ モードに戻ります。
- SF Symbols アプリは、システム シンボルがマルチカラーをサポートしているかどうかを確認し、カスタム シンボルにマルチカラー サポートを追加することもできます。

（[07:10](https://developer.apple.com/videos/play/wwdc2021/10349/?time=430)）`symbolRenderingMode(.hierarchical)`現在の前景スタイルを使用してシンボルを描画し、シンボル内の異なるレベルに異なる不透明度レベルを適用します。複雑なアイコンの重要な部分を強調するのに適しています。

```swift
import SwiftUI

struct HierarchicalButtonsView: View {
    var body: some View {
        HStack(spacing: 16) {
            Button(action: {}) {
                Image(systemName: "square.3.stack.3d.top.fill")
            }
            Button(action: {}) {
                Image(systemName: "square.3.stack.3d.bottom.fill")
            }
        }
        .symbolRenderingMode(.hierarchical)
        .font(.largeTitle)
        .padding()
    }
}
```

キーポイント:
- `HStack`2つのボタンを横に並べます。
-`Button(action: {})`クリック アクションを定義します。この例では空です。
- 初め`Image`トップデッキのシンボルを使用します。
- 2番目`Image`下部デッキのシンボルを使用します。
-`.symbolRenderingMode(.hierarchical)`両方のシンボルでレイヤード モードを使用します。
-`.font(.largeTitle)`ボタンのシンボルを拡大すると、レベルの透明度が確認しやすくなります。

### パレット レンダリングを使用してマルチレイヤー カラーを制御する

（[07:50](https://developer.apple.com/videos/play/wwdc2021/10349/?time=470)）`foregroundStyle`複数のスタイルを受信できます。 SwiftUI はパレット レンダリング モードを使用して、これらのスタイルをさまざまなレベルのシンボルに割り当てます。講義での「元に戻す」ボタンの使用`.circle.fill`バリエーションを選択し、矢印、円形の背景、3 番目のレイヤーの色を設定します。

```swift
import SwiftUI

struct PaletteUndoButtonView: View {
    var body: some View {
        Button(action: {}) {
            Image(systemName: "arrow.uturn.backward")
        }
        .symbolVariant(.circle.fill)
        .foregroundStyle(.white, .yellow, .red)
        .font(.largeTitle)
        .padding()
    }
}
```

キーポイント:
- `Button(action: {})`クリック可能なボタンを作成します。
-`Image(systemName: "arrow.uturn.backward")`元に戻す矢印を表示します。
-`.symbolVariant(.circle.fill)`ボタンの背景を生成するための円塗りつぶしバリアントをリクエストします。
-`.foregroundStyle(.white, .yellow, .red)`3 つの前景スタイルが利用可能です。
- シンボルに 1 次コンテンツと 3 次コンテンツしかない場合は、1 番目と 3 番目のスタイルが使用されます。
-`.font(.largeTitle)`シンボルをより大きなサイズで表示します。

（[09:00](https://developer.apple.com/videos/play/wwdc2021/10349/?time=540)）`foregroundStyle`受信したのは`ShapeStyle`。カラー以外にもこんな使い方ができます`.secondary`または`.regularMaterial`。これにより、シンボルは、ぼやけた背景や物質的な背景の前でも体系的な外観を維持できます。

```swift
import SwiftUI

struct AdvancedForegroundStylesView: View {
    var body: some View {
        VStack(spacing: 20) {
            Button(action: {}) {
                Image(systemName: "arrow.uturn.backward")
            }
            .symbolVariant(.circle.fill)
            .foregroundStyle(.white, .red)

            Button(action: {}) {
                Image(systemName: "arrow.uturn.backward")
            }
            .symbolVariant(.circle.fill)
            .foregroundStyle(.white, .secondary)

            Button(action: {}) {
                Image(systemName: "arrow.uturn.backward")
            }
            .symbolVariant(.circle.fill)
            .foregroundStyle(.red, .regularMaterial)
        }
        .font(.largeTitle)
        .padding()
    }
}
```

キーポイント:
- `VStack`3 つのボタンを縦に並べた例。
- 最初のボタンを使用します`.white`そして`.red`2つの色のレイヤーを設定します。
- 2番目のボタンを使用します`.secondary`スタイルの 2 番目のレイヤーとして、環境の視覚的な階層に従うのに適しています。
- 3番目のボタンは`.regularMaterial`スタイルの 2 番目のレイヤーとして、マテリアル効果をシンボル レベルで表示させることができます。
-`.font(.largeTitle)`全体的に行動する`VStack`上では 3 つのシンボルを均一に拡大しています。

## 重要なポイント

1. **やるべきこと**: 設定ページまたはアカウント ページのすべての項目を意味のあるものにします`Label`。
   **実行する価値がある理由**:`Label`タイトルとシンボルはバインドされ、SwiftUI コンポーネントはアイコン、タイトル、またはその両方を状況に応じて表示し、VoiceOver のテキスト ソースを提供できます。
   **開始方法**:`HStack { Image(...); Text(...) }`に変更します`Label("Profile", systemImage: "person.circle")`、必要に応じて追加します`.labelStyle(...)`。

2. **対処方法**: タブ バーとサイドバーには基本的なシンボル名を使用します。
   **実行する価値がある理由**: SwiftUI はタブ バーなどのコンポーネントで適切なバリアントを自動的に選択するため、コードを手動で記述する必要はありません。`.fill`サフィックスはプラットフォーム間で適応させることもできます。
   **開始方法**:`tabItem`で使用される`Label("Cards", systemImage: "rectangle.portrait.on.rectangle.portrait")`、直接書くことは避けてください。`rectangle.portrait.on.rectangle.portrait.fill`。

3. **作業内容**: カテゴリ リストに複数色のシンボルを追加します。
   **実行する価値がある理由**:`symbolRenderingMode(.multicolor)`You can use SF Symbols built-in colors to let symbols such as health, weather, and card suits retain their meaning.
   **開始方法**: リストの外に追加します`.symbolRenderingMode(.multicolor)`、SF シンボル アプリを使用して、ターゲット シンボルがマルチカラーをサポートしているかどうかを確認します。

4. **対処方法**: 複雑なツール ボタンにはレイヤード モードを使用します。
   **実行する価値がある理由**:`symbolRenderingMode(.hierarchical)`前景スタイルを使用して、デッキ、レイヤー、機器などの複数の視覚レベルを持つアイコンに適したマルチレベルの透明度を生成します。
   **開始方法**: ボタングループの外に追加します`.symbolRenderingMode(.hierarchical)`、次に使用します`.foregroundStyle(.tint)`または`.foregroundStyle(.secondary)`全体的な配色を制御します。

5. **手順**: 背景の形状を使用して、「元に戻す」、「削除」、または「確認」ボタンを作成します。
   **実行する価値がある理由**: パレット レンダリングでは、シンボルの前景と背景のスタイルを個別に指定できるため、モノクロの色合いよりも実際のボタンのデザインに近くなります。
   **開始方法**: を使用します`Image(systemName: "arrow.uturn.backward")`、に追加`.symbolVariant(.circle.fill)`、次に使用します`.foregroundStyle(.white, .red)`または`.foregroundStyle(.white, .yellow, .red)`レベルの色を指定します。
