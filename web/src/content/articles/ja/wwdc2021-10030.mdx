## ハイライト

> Safari 15 では、JavaScript、WebAssembly、プライベート クラス フィールドを含む Web API、WeakRef、WebGL2、MediaRecorder、音声認識 API の 3 方向で大規模なアップデートが行われました。

## 主な内容

Web 開発者は長い間、Safari の問題点に直面してきました。それは、新機能のサポートが常に遅いということです。今回のWWDC2021は、多くのギャップを一気に埋めた。

JavaScript エンジンに関しては、プライベート クラス フィールドがついに実装されました。以前はアンダースコアが接頭辞として付けられていました`_startTime`これは単なる慣例であり、外部コードは引き続きアクセスできます。今すぐ使用`#startTime`、カプセル化は言語レベルで強制され、アクセスするとエラーがスローされます。

WeakRef と FinalizationRegistry により、メモリ管理がより細分化されます。ガベージ コレクションを妨げることなく、オブジェクトへの弱い参照を保持できます。オブジェクトがリサイクルされるときに、オブジェクトをクリーンアップするための通知を受け取ることもできます。これは、システムのキャッシュやフレームワークのテストに役立ちます。

WebAssembly エンジンには、メモリ命令、i64/BigInt 相互変換、参照型、ストリーミング コンパイルがアップグレードされています。C++/Rust を Web にコンパイルすると、パフォーマンスがさらに一歩近づきます。

Web API に関しては、WebGL2 はすべてのプラットフォームで利用でき、MediaRecorder はオーディオとビデオを記録でき、音声認識は Siri と同じエンジンを使用して音声をテキストに変換し、Web Share はファイルの共有をサポートします。

### JavaScript プライベート クラス フィールド

以前は、クラスを作成するとき、プライベート メンバーは規約に依存していました。

```javascript
class StopwatchWithOneButton {
    constructor() {
        this._startTime = null;  // 只是约定，外部仍能访问
    }

    click() {
        if (this._startTime === null) {
            this._startTime = Date.now();
        } else {
            const duration = Date.now() - this._startTime;
            this._startTime = null;
            return duration;
        }
    }
}
```

今すぐ使用`#`プレフィックス、言語はプライベートに適用されます:

```javascript
class StopwatchWithOneButton {
    #startTime = null;  // 真正的私有字段

    click() {
        if (this.#startTime === null) {
            this.#startTime = Date.now();
        } else {
            const duration = Date.now() - this.#startTime;
            this.#startTime = null;
            return duration;
        }
    }

    // 私有方法
    #start() { this.#startTime = Date.now(); }
    #stop() {
        const duration = Date.now() - this.#startTime;
        this.#startTime = null;
        return duration;
    }

    // 静态私有字段
    static #startedCount = 0;
    // 公共静态字段
    static totalCreated = 0;
}
```

キーポイント:
- `#field`言語レベルのプライベートであるため、外部アクセスは TypeError をスローします (01:49)
- プライベートメソッドも使用されます`#`プレフィックス、クラス内でのみ呼び出すことができます (03:15)
- 静的プライベートフィールドをサポート`#staticField`およびパブリック静的フィールド`staticField`（03:39）
- プライベート プロパティを実装するために WeakMap ハックは必要ありません

### WeakRef と FinalizationRegistry

オブジェクトのバッチを追跡する必要があるが、それらがガベージ コレクションされるのを防ぎたくない場合:

```javascript
const allStopwatches = new Set();
const registry = new FinalizationRegistry((id) => {
    // 对象被回收时自动清理
    for (const ref of allStopwatches) {
        if (ref.id === id) {
            allStopwatches.delete(ref);
            break;
        }
    }
});

function addStopwatch(sw) {
    const id = generateId();
    const ref = new WeakRef(sw);
    ref.id = id;
    allStopwatches.add(ref);
    registry.register(sw, id);  // sw 被回收时触发回调
}

function clickAllStopwatches() {
    for (const ref of allStopwatches) {
        const sw = ref.deref();  // 获取对象，可能返回 undefined
        if (sw) sw.click();
    }
}
```

キーポイント:
- `WeakRef`弱い参照を保持し、ガベージ コレクションを妨げない (04:19)
- `deref()`オブジェクトを取得し、リサイクルされている場合は返します`undefined`（05:56）
- `FinalizationRegistry`オブジェクトがリサイクルされるときにクリーンアップするコールバックをトリガーする (06:21)
- ガベージ コレクションのタイミングは不確実なので、主要なロジックに依存しないでください。

### MediaRecorder はオーディオとビデオを記録します

```javascript
let mediaRecorder;
let recordedChunks = [];

async function startRecording() {
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
    mediaRecorder = new MediaRecorder(stream, {
        mimeType: 'audio/webm',
        audioBitsPerSecond: 128000
    });

    mediaRecorder.ondataavailable = (event) => {
        if (event.data.size > 0) recordedChunks.push(event.data);
    };

    mediaRecorder.onstop = () => {
        const blob = new Blob(recordedChunks, { type: 'audio/webm' });
        const url = URL.createObjectURL(blob);
        document.querySelector('audio').src = url;
    };

    mediaRecorder.start();
}

function stopRecording() {
    mediaRecorder.stop();
}
```

キーポイント:
- `MediaRecorder`メディア要素または MediaStream からのデータのキャプチャ (25:23)
- 指定可能なMIMEタイプとビットレート(25:39)
- `ondataavailable`断片的なデータを収集し、`onstop`BLOB への組み立て (26:52)
- マイク、カメラ、または画面からの録画をサポート

### Audio Worklet リアルタイム オーディオ処理

```javascript
// distortion-processor.mjs
class DistortionProcessor extends AudioWorkletProcessor {
    process(inputs, outputs, parameters) {
        const input = inputs[0];
        const output = outputs[0];
        for (let channel = 0; channel < input.length; channel++) {
            const inputChannel = input[channel];
            const outputChannel = output[channel];
            for (let i = 0; i < inputChannel.length; i++) {
                outputChannel[i] = this.distort(inputChannel[i]);
            }
        }
        return true;  // 保持活跃
    }

    distort(x) {
        return x > 0 ? Math.min(x * 2, 1) : Math.max(x * 2, -1);
    }
}

registerProcessor('distortion', DistortionProcessor);
```

```javascript
// main.js
async function startRecordingWithEffect() {
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
    const audioContext = new AudioContext();
    await audioContext.audioWorklet.addModule('./distortion-processor.mjs');

    const source = audioContext.createMediaStreamSource(stream);
    const effectNode = new AudioWorkletNode(audioContext, 'distortion');
    const destination = audioContext.createMediaStreamDestination();

    source.connect(effectNode).connect(destination);

    // 录制处理后的音频
    mediaRecorder = new MediaRecorder(destination.stream);
    mediaRecorder.start();
}
```

キーポイント:
- オーディオ ワークレットはオーディオ レンダリング スレッドで実行され、メイン スレッドとレンダリング スレッド間の切り替えを減らします (27:37)
- 古い ScriptProcessorNode よりも低いレイテンシ (27:49)
- プロセッサは継承する必要があります`AudioWorkletProcessor`そして実装する`process()`メソッド (29:01)
- 使用`registerProcessor()`登録後にのみメインスレッドに渡すことができます。`AudioWorkletNode`使用する(29:38)

```javascript
async function shareAudio(blob, filename) {
    const file = new File([blob], filename, { type: 'audio/webm' });
```

### 音声認識 音声認識

```javascript
const recognition = new webkitSpeechRecognition();
recognition.continuous = true;
recognition.interimResults = false;

recognition.onresult = (event) => {
    let transcript = '';
    for (let i = event.resultIndex; i < event.results.length; i++) {
        if (event.results[i].isFinal) {
            transcript += event.results[i][0].transcript;
        }

};

recognition.onend = () => {

function startRecognition() {
    recognition.start();
}

function stopRecognition() {
```

## 重要ポイント

1. **WeakMap のカプセル化をプライベート クラス フィールドに置き換えます**。`#field`構文は WeakMap ソリューションよりもシンプルで直感的であり、プライバシーは言語レベルで保証されます。
2. **Web Share ファイル共有により、Web アプリがよりネイティブに近くなります**。数行のコードでシステム共有パネルを呼び出してファイルを送信でき、ユーザー エクスペリエンスはネイティブ アプリと一致します。
3. **MediaRecorder + Audio Worklet を組み合わせてオーディオ アプリケーションを作成します**。録音、リアルタイム処理、共有はすべて 1 つのリンクを通じて接続されており、完全なオーディオ編集ツールを Web 上に実装できます。
4. **音声認識により、音声対話のしきい値が下がります**。Siri エンジンを使用して音声をテキストに変換するには、独自のモデルをトレーニングしたり、サードパーティ API を呼び出したりする必要はありません。
5. **モジュール ワーカーは、重い計算をバックグラウンドに移動します**。ES モジュールの依存関係管理と動的インポートにより、複雑な計算がメインスレッドをブロックすることがなくなりました。
