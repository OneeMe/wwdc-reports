## Highlight

> Xcode 13 让 Interface Builder 直接配置 iOS 15 的按钮样式、Table View Cell content configuration、SF Symbols 分层渲染和辅助功能预览，开发者可以在画布里完成样式迭代并发现动态字体布局问题。

## 核心内容

很多 UIKit 项目里，Storyboard 和 XIB 仍然承担大量界面搭建工作。问题在于，现代 iOS 界面越来越依赖系统样式：按钮要支持 Dynamic Type、多行标题、状态变化和 Mac Catalyst；列表单元格要有清晰的标题、副标题和图标；符号要跟随 tint color 呈现层次；辅助功能设置还会改变文字尺寸、颜色和布局边界。

过去做这些事，经常要在 Interface Builder 和代码之间来回切换。设计一个预订按钮，先在画布里摆位置，再写代码处理背景色、圆角、图标间距。调整一个 Table View Cell，先改 prototype cell，再运行到模拟器里确认 Dynamic Type。发现文字被裁切后，又回到约束和 label 属性里修。

这场 session 用一个酒店 App 贯穿全程。Booking Scene 里有 Book Room、Check in、Check out、Get Help 和 Guests 选择按钮；Promotions Scene 里有一组可选优惠按钮；Amenities Table View 里有餐厅等设施列表；菜单详情页则用来测试大字号下的文本换行。Xcode 13 的重点，是把这些高频界面迭代直接放回 Interface Builder。

Apple 做了四类改进。画布底部工具栏更紧凑，outline view 支持拖拽重排 scene 和批量选择 constraint group。Button inspector 支持 Plain、Gray、Tinted、Filled 样式，并暴露 subtitle、image placement、corner style、button size 等属性。Table View Cell inspector 支持新的 content configuration styles。画布还能直接打开辅助功能覆盖项，预览 Dynamic Type、Increase Contrast 等设置下的界面表现。

## 详细内容

### 画布和文档大纲更适合整理大型 Storyboard

（[00:51](https://developer.apple.com/videos/play/wwdc2021/10196/?time=51)）

Xcode 13 重新设计了 Interface Builder 的 canvas bottom bar。设备选择、scene layout、orientation、appearance 和 accessibility options 都被收进更紧凑的控件里，给画布留下更多空间。Outline view 的变化更直接：可以拖拽移动一个或多个 scene，也可以选中 Constraints 这类 group 后统一修改或删除。

```text
Booking Scene
Promotions Scene
Constraints
  Top
  Leading
  Trailing
  Bottom
```

关键点：
- `Booking Scene` 可以拖到 `Promotions Scene` 附近，Storyboard 结构和 segue 关系更容易对应。
- 选中 `Constraints` group 等同于选中组内所有约束，适合批量改 constant 或一次性删除。
- 按住 Option 拖拽 scene 可以复制整个 scene，适合从相似页面开始迭代。

（[02:53](https://developer.apple.com/videos/play/wwdc2021/10196/?time=173)）

Xcode 13 的 Button inspector 增加了 Style 属性。选择 Filled、Tinted 或 Gray 后，按钮会进入 iOS 15 的新按钮系统，自动获得 Dynamic Type、多行标题和辅助功能支持。视频里的 Book Room 使用 Filled，Check in 和 Check out 使用 Tinted，Get Help 使用 Gray。

Amenities Table View 的问题是标题和副标题层级不够清楚，图标也缺少色彩。Xcode 13 的 Table View Cell inspector 可以选择新的 content configuration styles，比如 Subtitle Cell、Value Cell、Grouped Header 和 Grouped Footer。随后，SF Symbols 的 Render Mode 可以切到 Hierarchical，用 tint color 给符号主层级加重点。

### 在画布里预览辅助功能设置

（[15:42](https://developer.apple.com/videos/play/wwdc2021/10196/?time=942)）

菜单详情页的 Description Label 使用 subhead text style，支持 Dynamic Type。把 Dynamic Type slider 拉大后，视频中这个 label 超出了 view bounds。修复方式很具体：补一个 trailing constraint，并把 number of lines 改成 0，让文本可以按需要换行。

| 时间 | 画布对象 | 操作 | 结果 |
|------|----------|------|------|
| [16:16](https://developer.apple.com/videos/play/wwdc2021/10196/?time=976) | Accessibility popover | 点击 canvas bottom bar 的 Accessibility button | 打开设计时辅助功能覆盖项 |
| [16:39](https://developer.apple.com/videos/play/wwdc2021/10196/?time=999) | Dynamic Type slider | 激活设置并拖动 slider | Description Label 超出 view bounds |
| [16:53](https://developer.apple.com/videos/play/wwdc2021/10196/?time=1013) | Description Label | 打开 Constraint popover 并添加 trailing constraint | 右侧边界被约束住 |
| [17:00](https://developer.apple.com/videos/play/wwdc2021/10196/?time=1020) | Description Label | 在 Attributes inspector 把 number of lines 设为 0 | 文本按需要换行 |
| [17:15](https://developer.apple.com/videos/play/wwdc2021/10196/?time=1035) | Dynamic Type slider | 再次拖动 slider 验证 | Label 在各个字号下都能完整显示 |

关键点：
- number of lines 设为 0 对应 inspector 里的属性修改，允许 label 占用多行。
- trailing constraint 解决大字号下文字向右溢出的问题。
- Accessibility popover 能在设计时打开 Dynamic Type、Increase Contrast 等覆盖项，减少运行模拟器后才发现布局问题的次数。
- 这个流程适合 Storyboard 项目做快速辅助功能巡检。

## 核心启发

### 1. 给旧 Storyboard 做一次按钮样式迁移

**做什么**：把主要操作按钮改成 Filled，把次要操作改成 Tinted，把工具型按钮改成 Gray 或 Plain。

**为什么值得做**：这场 session 展示了按钮样式直接支持 Dynamic Type、多行标题、corner style 和 Mac Catalyst 映射，迁移成本集中在 inspector。

**怎么开始**：先选一个结账、预订或提交页面，列出 primary、secondary、utility 三类按钮，再分别套用 Filled、Tinted、Gray 或 Plain，并检查大字号。

### 2. 把筛选项改成 pop-up button

**做什么**：把人数、排序方式、日期范围这类单选设置做成 pop-up button。

**为什么值得做**：视频中的 Guests 按钮说明了 pop-up button 可以把菜单和当前选择合在一个控件里，特别适合表单里的紧凑选择。

**怎么开始**：在 object library 拖入 Pop Up Button，用 Option-drag 复制 menu items，把候选值配置完整，并确认每个 menu item 已连接 action。

### 3. 用 content configuration 翻新设置页或详情页列表

**做什么**：把静态 Table View 里的设施、设置、账户信息改成系统 content configuration styles。

**为什么值得做**：Amenities Table View 的例子显示，标题、副标题、图片间距和 Dynamic Type 可以交给系统样式维护。

**怎么开始**：从 Subtitle Cell 开始，批量选择静态 cell，调整 Styles、Image Padding 和 symbol Render Mode，再用画布检查标题、副标题和图标层级。

### 4. 建一个辅助功能画布检查清单

**做什么**：每次改 Storyboard 后，在 Interface Builder 里检查 Dynamic Type、Increase Contrast 和不同 appearance。

**为什么值得做**：视频中 Description Label 的溢出问题是在画布里直接暴露出来的，修复只需要补 trailing constraint 和多行设置。

**怎么开始**：选出 App 里 5 个文本密集页面，把 Dynamic Type slider 拉到较大字号，逐个记录 clipping、overlap 和 contrast 问题。
