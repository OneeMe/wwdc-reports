## Highlight

> Apple Games 是预装在 iPhone、iPad、Mac 上的全新游戏入口，把分类、Game Center、In-App Events 串成一个面向玩家的 daily hub。

---

## 核心内容

iOS 上的游戏一直处在一种尴尬位置。玩家想找游戏要去 App Store，想看自己玩到哪了要打开游戏，想跟朋友比分要去 Game Center 的角落，想知道有没有新活动要刷推送。入口太散，结果就是大多数玩家下载完一个游戏就再也不会回到 Apple 提供的"游戏空间"里。

WWDC 2025 上，App Store Connect 团队的工程师 Logan Pratt 介绍了 Apple Games App。这是一个预装在 iPhone、iPad 和 Mac 上的独立 App，分四个 tab：Home 显示朋友动态和事件、Play Together 集中处理多人邀请、Library 管理已安装游戏、Search 用来发现新游戏。原本散落在 App Store、Game Center、推送通知里的信号，现在汇到一个地方。

对开发者来说，Apple Games 是已有能力的整合渠道。把游戏的 Primary 或 Secondary Category 设成 Games 是基本门槛（[02:31](https://developer.apple.com/videos/play/wwdc2025/215/?time=151)）；接入 Game Center（成就、排行榜、挑战、活动）让游戏在 Home tab 和 Play Together tab 多次出现（[06:00](https://developer.apple.com/videos/play/wwdc2025/215/?time=360)）；配置 In-App Events 把限时内容推到玩家面前（[16:48](https://developer.apple.com/videos/play/wwdc2025/215/?time=1008)）。覆盖面越广，曝光机会越多。

## 详细内容

**游戏页面的基础信息**：图标、名字、副标题、年龄分级、子分类（Action、Puzzle 等）会出现在 Apple Games 的多个位置（[02:46](https://developer.apple.com/videos/play/wwdc2025/215/?time=166)）。背景颜色由系统根据图标自动派生。如果游戏支持手柄，要在 Xcode 里开 Game Controller Capability，Apple Games 和 App Store 上才会显示手柄徽章，玩家在 Library 里可以按"controller support"过滤（[04:17](https://developer.apple.com/videos/play/wwdc2025/215/?time=257)）。视频预览、截图、描述、关键词全部在 App Store Connect 配置，搜索结果也用同一份资源。

**Pre-order**：游戏正式上线前可以开预购，Apple Games 会把它列入 Upcoming Releases，玩家选择"自动下载"后，发布日就会被推到设备上（[05:23](https://developer.apple.com/videos/play/wwdc2025/215/?time=323)）。这是把"等待发布"变成"已经预订"的机制。

**Game Center 四件套**：

- **Achievements**：完成时显示本地化图片、显示名、获得描述。Apple Games 会列出已完成、进行中、朋友已获得三类（[07:54](https://developer.apple.com/videos/play/wwdc2025/215/?time=474)）。
- **Leaderboards**：今年新增了 Description 字段，必须给所有新建和已有的排行榜补上（[09:04](https://developer.apple.com/videos/play/wwdc2025/215/?time=544)）。recurring leaderboard 会显示距离重置的剩余时间。
- **Challenges**：基于排行榜，把单人玩法变成限时社交对战。玩家可以选择尝试次数、持续时长、邀请朋友（[10:38](https://developer.apple.com/videos/play/wwdc2025/215/?time=638)）。Home tab 会高亮挑战结果。
- **Activities**：定义游戏内的目的地（关卡、模式、活动），通过 deep link 把玩家直接送进去。可以挂一个排行榜，让"Play"按钮直达对应关卡（[14:04](https://developer.apple.com/videos/play/wwdc2025/215/?time=844)）。Multiplayer Activity 还能生成 party code，跨平台分享给朋友。

**In-App Event 的 deep link 配置**：演讲里 Logan 给 Lobster Bash 事件的深链加上了 `event=lobsterbash` 参数，让游戏内的 handler 能识别玩家是从哪个事件跳进来的（[19:55](https://developer.apple.com/videos/play/wwdc2025/215/?time=1195)）。一个典型的 In-App Event deep link 长这样：

```
thecoast://activity/race-at-sea?event=lobsterbash
```

关键点：

- `thecoast://` 是游戏注册的 Custom URL Scheme，需要在 Info.plist 里声明 `CFBundleURLTypes`，否则点 Play 会失败。
- `/activity/race-at-sea` 是 Activity 的 deep link 路径，与 App Store Connect 里 Multiplayer Activity 配置的 deep link 保持一致，确保点 Leaderboard、Challenge、Event 的 Play 都能落到同一个目的地。
- `event=lobsterbash` 是事件来源标记，游戏内根据这个 query 切换皮肤、计入留存埋点、显示专属奖励。
- 同一个 Activity 可以被多个 Event 复用，每个 Event 用不同的 query 区分，省掉为每个事件单独写一套入口的成本。

**In-App Events 的发布节奏**：限时活动、季节性内容、特殊促销都用这个通道。事件需要：badge（标识事件类型）、本地化名字和短描述、Event card 的 artwork 或视频、详情页的高质量素材、deep link 指向游戏内目的地（[19:01](https://developer.apple.com/videos/play/wwdc2025/215/?time=1141)）。把 Publish Start Date 设在实际开始日期之前两周，事件就会以"Upcoming Event"出现，玩家可以预约通知。设成高优先级则优先在 Game Page 顶部展示。

**配置入口**：以前 Game Center 的成就、排行榜、挑战、活动只能在 App Store Connect 配置。今年新增了在 Xcode 内直接配置的能力（[07:14](https://developer.apple.com/videos/play/wwdc2025/215/?time=434)），加上 App Store Connect API，三种路径都能用。

## 核心启发

**1. 把游戏分类和 Game Controller Capability 先补齐**

为什么值得做：这是 Apple Games 的入场券，没有正确分类游戏就不会出现在 Apple Games 的页面里；手柄徽章直接影响玩家的 Library 过滤结果。

怎么开始：在 App Store Connect 的 App Information 里把 Primary Category 设成 Games、选好 Subcategory；在 Xcode 项目里勾选 Game Controller Capability。一次性投入，后续每个版本都受益。

**2. 给所有排行榜补 Description 字段**

为什么值得做：Description 是 2025 年新增的展示字段，Apple Games 的排行榜页面会用它。老排行榜没补的话，玩家看到的就是空白。

怎么开始：在 App Store Connect 的 Game Center tab 里逐一打开排行榜，补 Description 和高质量图片，所有支持的语言都要做本地化。把这步当作维护任务，发版前列入清单。

**3. 用 Activity + Leaderboard + Challenge 串起一个完整社交闭环**

为什么值得做：这三者绑在一起后，Apple Games 的 Home、Play Together、Game Page 多个位置都会推荐你的游戏；玩家点 Play 直接进对应关卡，点 Challenge 直接跟朋友开战。一份配置覆盖三种入口。

怎么开始：选一个核心可竞争关卡（比如最受欢迎的副本），创建对应的 Leaderboard，再创建一个 Challenge 关联这个 Leaderboard，最后建一个 Multiplayer Activity 也指向这个关卡的 deep link。验收标准：从 Apple Games 任意入口点进，都能正确跳到关卡。

**4. 上线前两周用 In-App Event 做预热**

为什么值得做：Publish Start Date 提前两周，事件就以 Upcoming 出现，玩家能订阅通知，启动当天会被推送回游戏。这是 Apple 官方的"预热-唤回"通道，比自建 push 系统覆盖面更广。

怎么开始：在 App Store Connect 的 In-App Events tab 创建事件，准备短视频 + 高质量图、本地化文案、深链参数（建议加 `event=xxx` 让游戏内 handler 知道来源）。把 Publish Start Date 设成实际开始日前 14 天，Priority 设成 High。
