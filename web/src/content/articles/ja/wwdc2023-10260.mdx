## ハイライト

>visionOS の空間コンピューティング プラットフォームは、SwiftUI、RealityKit、ARKit という 3 つのよく知られたフレームワークに基づいています。ウィンドウ、ボリューム、フル スペースの 3 つのコンテナを通じて、開発者は同じコード セットを使用して、2D ウィンドウから完全に没入型のエクスペリエンスまでのアプリケーションを構築できます。

## 主な内容

### 3種類のスペースコンテナ

visionOS の核となる設計は、3 種類のコンテナを中心に展開されます ([01:27](https://developer.apple.com/videos/play/wwdc2023/10260/?time=87))。

**ウィンドウ**

Window は SwiftUI の Scene であり、サイズ変更や再配置が可能で、macOS の Windows と同様に動作します。ただし、2D コンテンツと 3D コンテンツの混合はサポートされており、ボタンと 3D モデルを同じウィンドウに配置できます。

**音量**

ボリュームは、共有スペースに 3D コンテンツを表示する固定境界コンテナです ([02:07](https://developer.apple.com/videos/play/wwdc2023/10260/?time=127))。チェス盤や地球儀など、さまざまな角度から見ることができる 3D コンテンツの表示に適しています。 Volume も SwiftUI シーンであり、RealityKit を使用して 3D レンダリングを行います。

**フルスペース**

フルスペースでは、アプリが視野全体を占めることができ、他のアプリは非表示になります ([02:47](https://developer.apple.com/videos/play/wwdc2023/10260/?time=167))。 ARKit の API は、スケルタル ハンド トラッキングなどのフルスペースで使用できます。 Full Space には 3 つの没入スタイルがあります。

- **混合**: 仮想コンテンツを実環境に重ね合わせます (パススルー)
- **フル**: 現実の環境を完全に非表示にし、仮想コンテンツのみを表示します。
- **プログレッシブ**: 最初は実際の環境が表示され、ユーザーはデジタル クラウンを通じて没入レベルを調整できます。

### 自然なインタラクション手法

visionOS のインタラクションは目と手に基づいています ([04:30](https://developer.apple.com/videos/play/wwdc2023/10260/?time=270)):

- ボタンを見て指でタップして選択します
- 3D 空間で手を伸ばしてボタンに直接触れることができます
- システムはタップ、長押し、ドラッグ、回転、ズーム、その他のジェスチャをサポートしています
- SwiftUIのジェスチャAPIとRealityKitエンティティのシームレスな統合

ARKit のスケルトン ハンド トラッキングにより、ユーザーの手をボーリング用の仮想クラブに変えるなど、より複雑なジェスチャが可能になります ([05:36](https://developer.apple.com/videos/play/wwdc2023/10260/?time=336))。

### プライバシー最優先のアーキテクチャ

visionOS のプライバシー設計は非常に厳格です ([07:47](https://developer.apple.com/videos/play/wwdc2023/10260/?time=467))。アプリケーションはセンサー データに直接アクセスできません。システムは生データをアプリケーションに渡す前にイベントと視覚的合図に変換します。例えば：

- システムはユーザーの目と手の 3D 位置を認識しますが、アプリケーションにはタッチ イベントのみを渡します。
- ユーザーがビューを見ると、システムはホバー効果をレンダリングしますが、ユーザーがどこを見ているのかをアプリに伝えません
- シーン理解 (壁、家具の検出) または骨格手の追跡にアクセスする必要がある場合、システムは最初にユーザーの許可を求めます。

### ウィンドウの作成

ウィンドウパス`WindowGroup`作成すると、2D コンテンツと 3D コンテンツを混合できます。

```swift
import SwiftUI
import RealityKit

@main
struct HelloWorldApp: App {
    var body: some Scene {
        WindowGroup {
            ContentView()
        }
    }
}

struct ContentView: View {
    var body: some View {
        VStack {
            Text("Hello, World!")
            
            // 在窗口中嵌入 3D 内容
            Model3D(named: "Satellite") { model in
                model
                    .resizable()
                    .aspectRatio(contentMode: .fit)
            } placeholder: {
                ProgressView()
            }
        }
    }
}
```

キーポイント:
- `Model3D`似ている`Image`、RealityKit によってレンダリングされた 3D モデルをロードして表示します。
- ウィンドウ内の 3D コンテンツが Z 軸に沿ってはみ出し、奥行き感が増します。
- 使用できます`DragGesture`3D エンティティを直接ドラッグ アンド ドロップする

### ボリュームの作成

設定による音量`windowStyle`のために`.volumetric`作成する：

```swift
@main
struct EarthApp: App {
    var body: some Scene {
        WindowGroup(id: "earth") {
            EarthView()
        }
        .windowStyle(.volumetric)
        .defaultSize(width: 0.6, height: 0.6, depth: 0.6, in: .meters)
    }
}
```

キーポイント:
- `.windowStyle(.volumetric)`WindowGroup をボリュームに変換する
-`defaultSize`ボリュームの幅、高さ、深さを指定します。単位は次のとおりです。`.points`または`.meters`- ボリュームの内容は境界内にとどまる必要があります
- 共有スペースに適しており、他のウィンドウと共存できます

### RealityView と添付ファイル

RealityView は、SwiftUI で RealityKit エンティティを管理するためのコア ビューです。

```swift
import SwiftUI
import RealityKit

struct GlobeView: View {
    var body: some View {
        RealityView { content, attachments in
            // make closure: 创建实体并添加到根实体
            if let earth = try? await Entity(named: "Earth") {
                content.add(earth)
            }
            
            // 把 attachment 添加到场景中
            if let pin = attachments.entity(for: "pin") {
                pin.position = [0, 0.5, 0]
                content.add(pin)
            }
        } update: { content, attachments in
            // update closure: 状态变化时调用
        } attachments: {
            // attachments closure: 定义 SwiftUI 视图
            Attachment(id: "pin") {
                Image(systemName: "mappin")
                    .font(.largeTitle)
                    .foregroundColor(.red)
            }
        }
    }
}
```

キーポイント:
- `make`クロージャは、エンティティを初期化するためにビューが作成されるときに 1 回実行されます。
-`update`SwiftUI の状態が変化するとクロージャーが呼び出されます
-`attachments`SwiftUI ビューを 3D シーンに配置できるエンティティに変換します
- 各添付ファイルには一意のファイルが必要です`id`

### フルスペースを作成する

フルスペースパス`ImmersiveSpace`シーンタイプの作成:

```swift
@main
struct SpaceApp: App {
    @State private var immersiveStyle: ImmersionStyle = .full
    
    var body: some Scene {
        WindowGroup {
            ContentView()
        }
        
        ImmersiveSpace(id: "outerSpace") {
            OuterSpaceView()
        }
        .immersionStyle(selection: $immersiveStyle, in: .full, .mixed, .progressive)
    }
}

struct ContentView: View {
    @Environment(\.openImmersiveSpace) var openImmersiveSpace
    @Environment(\.dismissImmersiveSpace) var dismissImmersiveSpace
    
    var body: some View {
        Button("Enter Space") {
            Task {
                await openImmersiveSpace(id: "outerSpace")
            }
        }
    }
}
```

キーポイント:
- `ImmersiveSpace`アクセス可能なフルスペース シーンを定義する
-`.immersionStyle`没入スタイルを設定します。デフォルトは次のとおりです。`.mixed`
- `openImmersiveSpace`環境値はスペースを開くために使用されます
-`dismissImmersiveSpace`アンビエント値はスペースを閉じるために使用されます
- 没入型エクスペリエンスに入るかどうかを選択するボタンをユーザーに提供することをお勧めします

### 3D エンティティと対話するためのジェスチャ

SwiftUI ジェスチャは、RealityKit エンティティを直接ターゲットにすることができます。

```swift
Model3D(named: "Satellite") { model in
    model
        .resizable()
        .aspectRatio(contentMode: .fit)
}
.placeholder {
    ProgressView()
}
.gesture(
    DragGesture()
        .targetedToEntity(named: "Satellite")
        .onChanged { value in
            // 根据拖拽值移动实体
            value.entity.position = value.convert(value.location3D, from: .local, to: .parent)
        }
)
```

キーポイント:
- `.targetedToEntity(named:)`ジェスチャを特定のエンティティにバインドする
-`value.location3D`3D空間でのドラッグ位置を取得します
-`convert(_:from:to:)`座標空間間で位置を変換する

### 既存のアプリから移行する

visionOS は 3 つの移行パスをサポートしています ([15:40](https://developer.apple.com/videos/play/wwdc2023/10260/?time=940)):

1. **互換モード**: iPad/iPhone アプリは変更せずに実行でき、システムがウィンドウの拡大縮小と回転を自動的に処理します。
2. **再コンパイル**: Xcode にvisionOS ターゲットを追加し、再コンパイル後にネイティブの間隔、サイズ、リフローを取得します。
3. **新しいデザイン**:visionOS アプリ テンプレートを使用し、ウィンドウまたはボリュームから始めて、空間コンピューティング機能を最大限に活用します。

## 重要なポイント

**Model3D を使用して既存のアプリに深みを追加**

- **やるべきこと**: 既存の SwiftUI アプリにビューを追加する`Model3D`、3D 製品モデルを表示
- **価値がある理由**: RealityKit コードを記述する必要はありません。`Model3D`使うのと同じように`Image`シンプルですが、インターフェイスに空間的な奥行きを加えます。
- **開始方法**: USDZ モデルを Xcode プロジェクトにドラッグし、使用します。`Model3D(named: "模型名")`負荷

**回転して表示できる 3D 製品ディスプレイを作成します**

- **何をすべきか**: ボリュームを使用して、ユーザーがあらゆる角度から見ることができる 3D 製品モデルを表示します。
- **実行する価値がある理由**: ボリュームは、当然のことながら 3D コンテンツの表示に適しています。ユーザーはジェスチャを使用して回転やズームを行うことができ、2D 画像よりもはるかに直感的です。
- **開始方法**: 作成する`WindowGroup`、設定`.windowStyle(.volumetric)`、中に入れます`RealityView`製品モデルのロード

**徐々に没入型の瞑想アプリをデザインする**

- **対処方法**: アプリの起動時に共有スペースにコントロール パネルを表示し、[開始] をクリックしてフル スペースに入り、プログレッシブ没入スタイルを使用してユーザーが没入レベルを自分で調整できるようにします。
- **価値がある理由**: プログレッシブイマージョンではユーザーがコントロールできるようになり、軽いイマージョンから完全なイマージョンに徐々に移行し、不快感が軽減されます。
- **開始方法**: を使用します`ImmersiveSpace`シーンの作成、セットアップ`.immersionStyle(selection: $style, in: .progressive)`

**RealityView アタッチメントを使用して 3D マップ マーカーを作成します**

- **やるべきこと**: SwiftUI ビューを 3D グローブまたはマップ上のピンとして使用する
- **価値がある理由**: アタッチメントを使用すると、新しい UI フレームワークを学習しなくても、使い慣れた SwiftUI コードを使用して 3D シーンで UI 要素を作成できます。
- **開始方法**:`RealityView`の`attachments`クロージャでマークアップ ビューを定義します。`make`クロージャで使用`attachments.entity(for: "id")`手に入れて置く
