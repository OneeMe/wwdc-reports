## ハイライト

> ScreenCaptureKit は、Apple が発表した高性能 macOS 画面キャプチャ フレームワークです。ビデオ/オーディオ キャプチャをサポートし、GPU メモリ バッファリング、ハードウェア アクセラレーション、柔軟なコンテンツ フィルタリングなどの機能を備えています。画面共有、ゲームのライブブロードキャスト、ビデオ会議などのシナリオに使用されます。

---

## 主要内容

macOS 画面キャプチャの分野には、これまで統一されたソリューションがありませんでした。開発者は、CGDisplayCreateSnapshot() を呼び出してスクリーンショットを撮るか、AVFoundation を使用して画面を記録することができます。前者はパフォーマンスが制限されており、後者は機能が複雑すぎます。さらに重要なのは、これらのソリューションには「何をキャプチャするか」についてのきめ細かい制御が欠けており、アプリ ウィンドウを簡単に除外したり、ディスプレイの一部だけをキャプチャしたり、同時に音声を処理したりすることができません。 ([00:30](https://developer.apple.com/videos/play/wwdc2022/10156/?time=30))

ScreenCaptureKit はこのギャップを埋めます。これは画面キャプチャ用に特別に設計されたフレームワークであり、プロセス全体をカバーする 4 つのコア オブジェクトを備えています。`SCShareableContent`キャプチャ可能なコンテンツを取得し、`SCContentFilter`何をキャプチャするかを定義し、`SCStreamConfiguration`出力パラメータを構成します。`SCStream`データのキャプチャと配信を実行します。 ([02:15](https://developer.apple.com/videos/play/wwdc2022/10156/?time=135))

典型的なアプリケーション シナリオは画面共有です。ユーザーがZoomで「画面共有」をクリックすると、アプリはウィンドウセレクターを表示し、Zoom自身のウィンドウを除外し（それ以外の場合は「無限ミラーリング」）、選択したコンテンツを適切な解像度とフレームレートでキャプチャし、システムオーディオを同期処理する必要があります。以前は複数の API を組み合わせる必要がありましたが、ScreenCaptureKit では 1 つの API ですべてを処理できるようになりました。 ([04:40](https://developer.apple.com/videos/play/wwdc2022/10156/?time=280))

もう 1 つのシナリオは、ゲームのライブ ストリーミングです。ゲーム開発者は、ライブ ストリーミング ソフトウェア独自の UI のキャプチャを避けながら、1080p 60fps でゲームプレイ映像をキャプチャしたいと考えています。 ScreenCaptureKit のコンテンツ フィルタリング メカニズムは、「このウィンドウのみを含めて他のすべてを除外する」ように正確に行うことができ、出力解像度は元のウィンドウから切り離されます。ゲーム ウィンドウ 4K は 1080p ストリームも出力できます。 ([08:10](https://developer.apple.com/videos/play/wwdc2022/10156/?time=490))

## 詳細

### キャプチャ可能なコンテンツを取得する

([06:53](https://developer.apple.com/videos/play/wwdc2022/10156/?time=413)) 最初のステップは、現在システムで利用可能なディスプレイ、アプリ、ウィンドウを取得することです。`SCShareableContent.excludingDesktopWindows()`キャプチャ可能なすべてのコンテンツを含むオブジェクトを返します。

```swift
// 获取可捕获内容
let content = try await SCShareableContent.excludingDesktopWindows(
    false,
    onScreenWindowsOnly: true
)
```

キーポイント:
- `excludingDesktopWindows: false`デスクトップの壁紙を含むウィンドウを表します
- `onScreenWindowsOnly: true`表示されているウィンドウのみが返され、最小化されたウィンドウは除外されます
- `content.applications`キャプチャ可能なすべてのアプリの配列です
- `content.displays`すべてのディスプレイの配列です
- この呼び出しでは、ユーザーが「画面録画」権限を承認する必要があります。

### コンテンツフィルターを作成する

([08:32](https://developer.apple.com/videos/play/wwdc2022/10156/?time=512)) キャプチャできるものがすべて揃ったら、次のステップは「何をキャプチャしたいのか」を定義することです。`SCContentFilter` 支持三种模式：

**ディスプレイによるフィルター**: ディスプレイ全体をキャプチャするか、特定のアプリ ウィンドウを除外します。

```swift
let excludedApps = content.applications.filter { app in
    Bundle.main.bundleIdentifier == app.bundleIdentifier
}

filter = SCContentFilter(display: display,
                         excludingApplications: excludedApps,
                         exceptingWindows: [])
```

キーポイント:
- `display: display` 捕获整个显示器
- `excludingApplications`指定したアプリのすべてのウィンドウを除外します
- `exceptingWindows`特定のウィンドウをさらに除外することもできます
- これは画面共有ソフトウェアの典型的な使用法です - 「無限ミラーリング」を避けるために独自のウィンドウを除外します

**単一ウィンドウによるフィルター**: モニターの境界に関係なく、1 つのウィンドウのみをキャプチャします。上級セッション (10155) では、このパターンについて詳しく説明します。

**ウィンドウ リストによるフィルター**: 複数のウィンドウを同時にキャプチャし、他のすべてを除外します。マルチウィンドウのコラボレーションシナリオに適しています。

### フローパラメータを構成する

（[10:23](https://developer.apple.com/videos/play/wwdc2022/10156/?time=623)）`SCStreamConfiguration`制御出力フォーマット:

```swift
let streamConfig = SCStreamConfiguration()

// 输出分辨率 1080p
streamConfig.width = 1920
streamConfig.height = 1080

// 60fps 捕获
streamConfig.minimumFrameInterval = CMTime(value: 1, timescale: CMTimeScale(60))

// 隐藏鼠标光标
streamConfig.showsCursor = false

// 启用音频捕获
streamConfig.capturesAudio = true

// 48kHz 立体声
streamConfig.sampleRate = 48000
streamConfig.channelCount = 2
```

キーポイント:
- 解像度は元のコンテンツのサイズに依存せず、ScreenCaptureKit は自動的にスケーリングします。
- `minimumFrameInterval`固定フレーム レートではなくフレーム レートを制御します - システムはコンテンツの変化に応じて動的に調整します
- 音声キャプチャには別のユーザー認証が必要です
- デフォルトのピクセル形式は BGRA であり、渡すことができます。`pixelFormat`プロパティの変更

### キャプチャストリームの開始

([11:46](https://developer.apple.com/videos/play/wwdc2022/10156/?time=706)) 設定が完了したら、`SCStream`そしてキャプチャを開始します:

```swift
// 创建捕获流
stream = SCStream(filter: filter, configuration: streamConfig, delegate: self)

// 启动捕获
try await stream?.startCapture()

// 错误处理 delegate
func stream(_ stream: SCStream, didStopWithError error: Error) {
    DispatchQueue.main.async {
        self.logger.error("Stream stopped with error: \(error.localizedDescription)")
        self.error = error
        self.isRecording = false
   }
}
```

キーポイント:
- `startCapture()`これは非同期呼び出しであり、待機が必要です
- ストリームエラーと状態変更を処理するにはデリゲートを提供する必要があります
- 一般的なエラーには、ユーザーによる権限の取り消し、システム リソースの不足、構成パラメータの競合などがあります。
- 通話のキャプチャを停止する`stream?.stopCapture()`

### メディアデータの受信

([13:07](https://developer.apple.com/videos/play/wwdc2022/10156/?time=787)) 実装`SCStreamOutput`プロトコルはデータを受信します。

```swift
func stream(_ stream: SCStream, didOutputSampleBuffer sampleBuffer: CMSampleBuffer, of type: SCStreamOutputType) {
    switch type {
    case .screen:
        handleLatestScreenSample(sampleBuffer)
    case .audio:
        handleLatestAudioSample(sampleBuffer)
    }
}

// 添加输出
try stream?.addStreamOutput(self, type: .screen, sampleHandlerQueue: screenFrameOutputQueue)
try stream?.addStreamOutput(self, type: .audio, sampleHandlerQueue: audioFrameOutputQueue)
```

キーポイント:
- `SCStreamOutputType.screen`そして`.audio`映像と音声にそれぞれ対応
- `sampleHandlerQueue`コールバック キューを指定します。メイン スレッドのブロックを避けるために、専用のシリアル キューを使用することをお勧めします。
- `CMSampleBuffer`AVFoundation の標準タイプであり、エンコード、ストリーミング、録画に直接使用できます。
- 画面データはBGRAピクセル形式、音声はPCMデータです。

## 重要ポイント

- **やるべきこと**: macOS アプリに画面共有機能を追加します。
**実行する価値がある理由**: ScreenCaptureKit は、Apple が推奨する画面キャプチャ ソリューションであり、従来の API よりも優れたパフォーマンスとキャプチャされたコンテンツの正確な制御を備えています。ビデオ会議、リモート コラボレーション、ライブ ブロードキャスト ツールはすべて、この機能に依存しています。
**開始方法**:から`SCShareableContent.excludingDesktopWindows()`キャプチャ可能なコンテンツを取得し、それ自体を除外するウィンドウを作成します`SCContentFilter`、1080p 30fps 出力を構成し、開始します`SCStream`そして、`SCStreamOutput`プロセスデータ。

- **内容**: ゲーム記録ツールを構築します。
**価値がある理由**: ゲーマーは高フレームレートの映像を録画する必要があります。 ScreenCaptureKit は、元のウィンドウに関係なく出力解像度をサポートします。ゲームの 4K 解像度は 1080p 60fps ストリームを出力することもできるため、エンコード圧力が軽減されます。
**開始方法**: ウィンドウ モードで作成します`SCContentFilter.desktopIndependentWindow`、 構成`minimumFrameInterval`60fpsの場合、`width`/`height`1080p に設定し、ハードウェア エンコーダーを使用してストリーミングします。

- **やるべきこと**: マルチウィンドウの共同作業用ホワイトボードを作成します。
**実行する価値がある理由**: コラボレーション シナリオでは、複数のウィンドウを同時にキャプチャする必要がありますが、無関係な干渉を排除する必要があります。 ScreenCaptureKit のウィンドウ リスト フィルター モードは、キャプチャされる内容を正確に制御します。
**開始方法**: を使用します`SCContentFilter.init(independentWindows:)`複数のターゲット ウィンドウ、オーディオ キャプチャを false に設定 (ホワイトボードにサウンドは必要ありません)、およびユーザーのモニターに合わせた出力解像度を使用してフィルターを作成します。

- **機能**: 教育注釈を含む画面録画を作成するためのツール。
**実行する価値がある理由**: ScreenCaptureKit は画面をキャプチャするだけでなく、インテリジェントなエンコードと注釈の追跡のために各フレームのダーティ レククト (変更領域) も提供します。アドバンスト セッション (10155) では、フレーム メタデータの適用について詳しく説明します。
**開始方法**: ストリーミングを開始してから聞いてください`SCStreamDelegate`の`didUpdateConfigurations`構成変更からダーティ Rect 情報を取得するためのコールバック。
