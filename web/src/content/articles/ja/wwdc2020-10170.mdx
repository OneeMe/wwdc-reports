([05:15](https://developer.apple.com/videos/play/wwdc2020/10170/?time=315)) ヒープ メモリの例は、Swift 値型の利点を示しています。400 個のモデル オブジェクトは、Swift では約 20 KB のヒープ メモリを占有しますが、Objective-C バージョンでは約 35 KB のヒープ メモリを占有します。 Swift 5.3 では、起動キャッシュ、プロトコル適合性、型情報、Objective-C ブリッジングに関連するオーバーヘッドも削減され、Swift アプリのヒープ メモリを前年バージョンの 3 分の 1 以下に抑えることができます。

([06:52](https://developer.apple.com/videos/play/wwdc2020/10170/?time=412)) 標準ライブラリが Foundation の下に配置された後は、Swift を使用して Objective-C レベルの下のフレームワークを実装できます。この変更は、Apple がランタイム メモリを圧迫し続ける理由を説明しています。システム デーモンと低レベルのフレームワークはあらゆるバイトに敏感です。

### クロスプラットフォームの Swift と AWS Lambda

([12:34](https://developer.apple.com/videos/play/wwdc2020/10170/?time=754)) Swift 5.3 では、Ubuntu サポートが更新され、CentOS と Amazon Linux 2 が追加され、初期 Windows サポートがプレビューされます。その後、Session は AWS Lambda にクロスプラットフォーム機能をもたらし、オープンソースの Swift AWS ランタイムを使用してサーバーレス関数を作成しました。

```swift
import AWSLambdaRuntime

Lambda.run { (_, event: String, callback) in
    callback(.success("Hello, \(event)"))
}
```

キーポイント:

- `import AWSLambdaRuntime`この機能は、Foundation やシステム SDK API ではなく、オープン ソース ランタイム パッケージから得られるものであることを説明します。
-`Lambda.run`Lambda ハンドラーを登録すると、クロージャがイベントを受け取り、コールバックを通じて結果を返します。
-`event: String`デモで最小の入力モデルを示します。これは、サーバー関数で Swift がどのように開始されるかを説明するのに適しています。
-`callback(.success(...))`戻り値を Lambda ランタイムに渡す際、この例は意図的に「Hello, world」レベルに保たれています。

### `@main`型にエントリポイントを与える

([20:09](https://developer.apple.com/videos/play/wwdc2020/10170/?time=1209)) 以前は AppDelegate を使用できました`UIApplicationMain`コンパイラに暗黙的に生成させる`main.swift`。 Swift 5.3 では、この機能を次のように一般化しています。`@main`: プロトコルまたは親クラスでライブラリ作成者によって定義されます。`static main`、ユーザーは入口タイプを次のようにマークします。`@main`、コンパイラはエントリ コードを生成します。

```swift
// Type-based program entry points

import ArgumentParser

@main
struct Hello: ParsableCommand {
    @Argument(help: "The name to greet.")
    var name: String

    func run() {
        print("Hello, \(name)!")
    }
}
```

キーポイント:

- `import ArgumentParser`Swift オープンソース パッケージが導入され、以下の Argument Parser の例はそれを拡張し続けます。
-`@main`にマークが付いている`Hello`型に関して、エントリ ポイントは別個のファイルから型宣言の一部に変わります。
-`ParsableCommand`コマンド ライン ツールの規則を提供することで、ライブラリ作成者はプロトコルを通じてエントリ ルールをユーザーに公開できます。
-`@Argument`コマンドラインの位置パラメータを属性として宣言します。`run()`ここでコマンド ロジックが実際に実行されます。

### enum 自動合成`Comparable`

([23:29](https://developer.apple.com/videos/play/wwdc2020/10170/?time=1409)) Swift 4.1 はすでに合成できます`Equatable`そして`Hashable`。 Swift 5.3 は対象となる列挙型への拡張を継続`Comparable`、自然な順序で状態列挙型を使用して定型コードを少なく書くことができます。

```swift
// Synthesized comparable conformance for enums

enum MessageStatus: Hashable, Comparable {
    case draft
    case saved
    case failedToSend
    case sent
    case delivered
    case read

    var wasSent: Bool {
        self >= .sent
    }
}
```

キーポイント:

- `MessageStatus`も宣言します`Hashable`そして`Comparable`、比較ロジックはコンパイラによって合成されます。
- case の宣言順序は比較順序となり、`.sent`その後のステータスは送信済みを意味します。
-`wasSent`使用`self >= .sent`ビジネス ルールを表現しており、手書きのスイッチよりも短いです。
- この例は、ステート マシン、メッセージ キュー、同期フェーズなどの線形順序を持つ列挙型に適しています。

### Apple アーカイブと Swift システム

([26:55](https://developer.apple.com/videos/play/wwdc2020/10170/?time=1615)) Apple Archive は、Apple がシステムアップデートを配信するために使用しているテクノロジーに基づく新しいモジュール式アーカイブ形式で、Finder 統合、コマンドラインツール、および Swift API を提供します。この例では、ディレクトリへの書き込みを示しています。`.aar`ファイルを作成し、LZFSE で圧縮します。

```swift
// Apple Archive

import AppleArchive

try ArchiveByteStream.withFileStream(
    path: "/tmp/VacationPhotos.aar",
    mode: .writeOnly,
    options: [.create, .truncate],
    permissions: [.ownerReadWrite, .groupRead, .otherRead]
) { file in
    // Receives raw bytes and writes compressed bytes to `file`
    try ArchiveByteStream.withCompressionStream(using: .lzfse, writingTo: file) { compressor in
        // Receives archive entries, and writes bytes to `compressor`
        try ArchiveStream.withEncodeStream(writingTo: compressor) { encoder in
            // Writes all entries from `src` to `encoder`
            try encoder.writeDirectoryContents(archiveFrom: source, keySet: fieldKeySet)
        }
    }
}
```

キーポイント:

- `ArchiveByteStream.withFileStream`ターゲットファイルストリームを作成し、`options`そして`permissions`厳密に型指定された列挙を使用します。
-`withCompressionStream(using: .lzfse, writingTo: file)`元のバイトを圧縮してファイルに書き込みます。
-`ArchiveStream.withEncodeStream`アーカイブ エントリを受信し、圧縮ストリームに渡します。
-`writeDirectoryContents(archiveFrom:keySet:)`例に示すように、ソース ディレクトリをアーカイブに書き込む役割を果たします。`source`そして`fieldKeySet`プレゼンテーションのコンテキストから。
- Session は、FileStream コンストラクターが Swift System に依存していることを特に指摘しました。Swift System は、強力な型指定を使用して低レベルのシステム コールをラップし、Darwin オーバーレイの元のインターフェイスのエラーが発生しやすい点を減らします。

### OSLog の文字列補間と書式設定

([28:11](https://developer.apple.com/videos/play/wwdc2020/10170/?time=1691)) OSLog は、低オーバーヘッドとプライバシー保護をターゲットとしています。 Swift 5.3 は、コンパイラの最適化によって OSLog を高速化し、文字列補間と書式設定オプションを追加して、ログの書き込みを通常の Swift 文字列に近づけます。

```swift
logger.log("\(offerID, align: .left(columns: 10), privacy: .public)")
// Logs "E1Z3F    "

logger.log("\(seconds, format: .fixed(precision: 2)) seconds")
// Logs "1.30 seconds"
```

キーポイント:

- `privacy: .public`明らかに`offerID`デフォルトで機密データを保護する統合ログの設計と一致し、一般公開としてマークされています。
-`align: .left(columns: 10)`後で見やすくするために、ログ内の列のフィールドを揃えます。
-`format: .fixed(precision: 2)`値を小数点第 2 位までに保ち、手動による文字列の書式設定を避けてください。
- プロジェクトがまだ使用中の場合`print`オンラインの問題をデバッグするには、この API セットが統合ログへの移行のエントリ ポイントとなります。

### ArgumentParser はコマンド ライン ツールを宣言型に保ちます

([29:48](https://developer.apple.com/videos/play/wwdc2020/10170/?time=1788)) Swift Argument Parser は、新しいオープンソース パッケージです。セッションは同じものを使用します`Hello`デモを続行するコマンド: add`count`オプションを使用すると、ツールは挨拶を繰り返し出力し、パラメータの検証とヘルプ情報を自動的に取得できます。

```swift
// Swift ArgumentParser

import ArgumentParser

@main
struct Hello: ParsableCommand {
    @Option(name: .shortAndLong, help: "The number of times to say hello.")
    var count: Int = 1

    @Argument(help: "The name to greet.")
    var name: String

    func run() {
        for _ in 1...count {
            print("Hello, \(name)!")
        }
    }
}
```

キーポイント:

- `@Option(name: .shortAndLong)`させて`count`短いパラメーター形式と長いパラメーター形式の両方がサポートされています。
-`var count: Int = 1`型とデフォルト値を同時に宣言すると、引数パーサーはそれに応じてそれらを解析して検証します。
-`@Argument`引き続き位置パラメータを表し、`help`コピーライターは、自動生成されたヘルプ ページに入ります。
-`run()`ビジネス ロジックのみが保持され、エントリ、パラメーター解析、およびヘルプ画面はすべてパッケージによって処理されます。

## 重要ポイント

- **やるべきこと**: 既存の Swift アプリでサイズとヒープ メモリの回帰チェックを実行します。 **実行する価値がある理由**: Swift 5.3 のコード サイズ、SwiftUI アプリのロジック サイズ、およびランタイム ヒープ オーバーヘッドはすべて明確に最適化されており、古いプロジェクトはアップグレードの恩恵を直接受けられる可能性があります。 **開始方法**: 同じコードを使用して古い Xcode と Xcode 12 でそれぞれアーカイブし、バイナリ サイズを比較します。 Instruments で起動後にヒープ メモリを記録します。

- **何をすべきか**: 内部スクリプトを Swift Argument Parser コマンド ライン ツールに変更します。 **実行する価値がある理由**:`@main`そして`ParsableCommand`入口、パラメータ宣言、ヘルプ情報を1種類にまとめて手書きを軽減`main.swift`パラメータ解析コード。 **開始方法**: 新しい Swift パッケージを作成してインポートします`apple/swift-argument-parser`、スクリプトパラメータを次のように分割します。`@Option`そして`@Argument`。

- **何をすべきか**: オンライン診断ログ用の OSLog ラッパー レイヤーを作成します。 **実行する価値がある理由**: Swift 5.3 の OSLog は、文字列補間、プライバシー マーキング、および書式設定をサポートしており、散在する文字列を置き換えることができます。`print`、機密情報が漏洩するリスクも軽減できます。 **開始方法**: 主要なビジネス リンクから開始し、定義します`Logger`分類し、デフォルトでユーザー入力を非公開にし、必要な ID のみをマークします。`.public`。

- **何をすべきか**: リソース コンポーネントを Swift パッケージに分割します。 **実行する価値がある理由**: このセッションでは Swift パッケージのエコロジカル拡張について言及し、関連するセッション 10169 では引き続きリソースとローカリゼーションについて話します。コンポーネント パッケージには、コード、画像、ストーリーボード、ローカライズされた文字列を同時に含めることができます。 **開始方法**: まずデザインシステムまたは空の状態のコンポーネントパッケージを描画し、 を押します。`Sources`、`Resources`そして`.process`ファイルを整理し、アプリ ターゲット内のローカル参照を置き換えます。

- **対処方法**: Apple Archive を開発資産パッケージ化ツールとして使用します。 **価値がある理由**: Apple Archive は、サンプル データ、ログ パッケージ、またはデザイン リソースをトランスポータブル ファイルにアーカイブするための Swift API、LZFSE 圧縮、およびコマンドライン ツールを提供します。 **開始方法**: セッションを入れる`withFileStream`、`withCompressionStream`、`withEncodeStream`この例は、内部 CLI、入力ディレクトリ、出力に変更されています。`.aar`。
