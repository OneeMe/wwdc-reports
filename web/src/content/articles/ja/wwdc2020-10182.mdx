## ハイライト

> HealthKit は 2020 年に 30 の新しい症状データ タイプを追加し、Apple Watch の心電図の読み取りを可能にし、歩行速度、歩幅、歩行の非対称性などの移動性指標を追加して、健康アプリが症状、心拍リズム、活動能力を同じユーザーの健康記録リンクに追加できるようにしました。

## 主要内容

ヘルスケア アプリはしばしば限界点に達します。ユーザーは自分の何が問題なのかを理解しており、Apple Watch は心拍数やアクティビティ データを記録しますが、アプリは点と点を結びつけるのが困難です。胸の圧迫感、心電図、1週間以内のペースの低下などは、個別に見れば断片にすぎません。医師とケアチームに本当に必要なのはコンテキストです。

このセッションの更新は、このコンテキストを追加するだけです。 HealthKit には 30 の新しい症状データ タイプが追加され、開発者は症状サンプルの読み取りと書き込みが可能です。 Apple WatchのECG（心電図、心電図）サンプルは、`HKElectrocardiogram`読む;モビリティ（移動性）指標は、歩行速度、歩幅、歩行の非対称性、二重支持時間の割合、階段の上り下りの速度、6 分間の歩行距離を HealthKit に入力します。

その結果、アプリは単なる「値を記録する」インターフェイスである必要はありません。ユーザーが息切れを記録するときに重症度を軽減したり、心電図を読み取るときに症状が関連しているかどうかを確認したり、リハビリテーションや高齢者介護のシナリオでの可動性の長期的な変化を追跡したりできます。これらの機能は HealthKit から提供されており、ユーザーの承認後にのみ使用でき、データはシステムの健康データ モデルに残ります。

## 詳細

### 30 の症状データ タイプ

([00:49](https://developer.apple.com/videos/play/wwdc2020/10182/?time=49)) Apple は、30 の症状データ タイプを HealthKit に追加しました。トランスクリプトでは、息切れ、睡眠の変化、食欲の変化、鼻水などの例が明確に示されており、開発者が症状サンプルを読み書きして仮想健康体験を構築できることが説明されています。

```text
Symptom sample workflow
1. Choose one of the new HealthKit symptom data types.
2. Record what the user experienced, such as shortness of breath.
3. Record the severity of that symptom.
4. Write the symptom sample to HealthKit, or read existing symptom samples back.
```

キーポイント:

- セッションのサポートは、HealthKit に 30 の新しい症状データ タイプが追加されたという事実によってサポートされています。
- 息切れ、睡眠の変化、食欲の変化、鼻水などは、記録に見られる症状の例です。
- メタデータには、これらの症状の重症度を記録できることが記載されており、遠隔診療前の症状日記や自己記録に適しています。
- トランスクリプトには、開発者が症状のサンプルを読み書きできることが明確に記載されているため、これはワークフローとして予約されており、特定の Swift API は記述されていません。

### Apple Watch ECG を読む

([01:45](https://developer.apple.com/videos/play/wwdc2020/10182/?time=105)) Apple Watch の ECG アプリは、心拍数と心臓のリズム波形を記録します。 2020 年のアップデートにより、ECG サンプルを次のように読み取ることができるようになりました。`HKElectrocardiogram`。このサンプルには分類があり、`symptomsStatus`、平均心拍数、サンプリング周波数、測定数、その他の属性。

```text
HKElectrocardiogram overview
- waveform: a series of voltage values
- classification: sinus rhythm, atrial fibrillation, or inconclusive
- symptomsStatus: whether the user associated a symptom with this ECG
- measurement context: average heart rate, sampling frequency, and number of voltage measurements
```

キーポイント:

- `HKElectrocardiogram`トランスクリプトによって明示的に言及されている ECG サンプル表現です。
-`classification`Apple Watchによって記録された結果に対応して、洞調律、心房細動、および決定的ではないものがセッションにリストされます。
-`symptomsStatus`これはトランスクリプトに表示される属性名で、この ECG が症状と関連しているかどうかを示すために使用されます。
- 平均心拍数、サンプリング頻度、測定回数が記録に測定の説明として表示されます。これらは概念別にここにリストされており、Swift 属性呼び出しとしては記述されていません。

([03:47](https://developer.apple.com/videos/play/wwdc2020/10182/?time=227)) ECG 波形を構成する個々の電圧値を読み取りたい場合、セッションは次を指します。`HKElectrocardiogramQuery`。このプロセスでは、まず HealthKit クエリを使用して ECG サンプルを取得し、次にこのサンプルを使用してクエリを初期化し、最後にヘルス ストア上で実行します。

```text
ECG voltage measurement workflow
1. Fetch ECG samples with any HealthKit query.
2. Initialize HKElectrocardiogramQuery with the fetched ECG sample.
3. Execute that query on the health store.
4. Receive individual voltage measurements in the query data handler.
```

キーポイント:

- `HKElectrocardiogramQuery`入力が取得されました`HKElectrocardiogram`サンプル。
- セッションはクエリ プロセスとデータ ハンドラーのみを記述し、クロージャ シグネチャや結果の列挙は提供しません。
- データ ハンドラーは、ECG を構成する個々の電圧測定値を返します。
- このプロセスは波形表示をサポートするのに適していますが、この記事では実行可能なコードには記述しません。

### モビリティ データ タイプ

([04:41](https://developer.apple.com/videos/play/wwdc2020/10182/?time=281)) モビリティ指標は、ユーザーの機能的な移動能力を測定します。セッションには、歩行速度、歩幅、歩行の非対称性、二重支持率、階段上昇速度、階段下降速度、および 6 分間の歩行テスト距離という名前が付けられました。このデータは最新のiOSやwatchOSで読み書き可能です。

```text
Mobility data types mentioned in this session
- walking speed
- step length
- walking asymmetry
- double support percentage
- stair ascent speed
- stair descent speed
- six-minute walk test distance

Availability
- These data types are available for reading and writing on the latest iOS and watchOS.
```

キーポイント:

- 歩行速度と歩幅は歩行速度と歩幅に対応しており、セッションでは筋力、フィットネス、バランス、調整に影響されると述べています。
- 歩行の非対称性と二重のサポート率はバランスと調整に対応します。
- 階段の上り速度と下り速度は階段を上り下りする能力を反映し、セッションはそれらを心肺機能、バランス、調整に関連付けます。
- 6 分間の歩行テスト距離は、臨床で一般的に使用される 6 分間の歩行テスト距離に対応します。
- トランスクリプトでは、これらの型が最新の iOS および watchOS で読み書きできることのみが述べられており、特定の列挙名や認証コードは示されていません。

## 重要ポイント

- **症状日記**: 機能: ユーザーは毎日の症状と息切れの重症度、睡眠の変化、食欲の変化などを記録できます。 なぜ価値があるのか​​: HealthKit はすでに症状サンプルのリテラシーを提供しています。開始方法: まず、サポートする症状のタイプを選択し、次にユーザー入力を症状サンプルとして保存します。詳細ページには、日付ごとの重大度の変化が表示されます。

- **ECG レビューページ**: 操作内容: 各 Apple Watch ECG の分類、平均心拍数、症状との関連性を表示します。実行する価値がある理由:`HKElectrocardiogram`ECG サンプルは、分類、症状の状態、測定の説明を明確に示すトランスクリプトとともに提供されます。開始方法: まず ECG サンプルをクエリし、次に分類、症状ステータス、および測定コンテキストのタイムラインを作成します。

- **ECG 波形チェック エントリ**: 実行内容: ユーザーが ECG を開いたときに、単一の電圧測定シーケンスをロードします。実行する価値がある理由:`HKElectrocardiogramQuery`心電図を構成する電圧値を取得できます。開始方法: 取得した ECG サンプルを使用してクエリを初期化し、データ ハンドラーで電圧測定値を受信し、ロード後に波形を描画します。

- **リハビリテーション モビリティ ダッシュボード**: やるべきこと: ペース、歩幅、歩行の非対称性、ダブルサポート時間、6 分間の歩行距離を追跡します。実行する価値がある理由: このセッションは、モビリティを呼吸器疾患、心臓の健康、怪我からの回復、高齢者のモビリティに明確に結び付けます。開始方法: この一連のモビリティ データに関する週ごとの傾向ビューを作成します。単一の変動を結論とはみなしません。
