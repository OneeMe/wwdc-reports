## ハイライト

> Xcode 14 は、新しい watchOS アプリを単一の Watch アプリ ターゲットに簡素化します。 WatchOS 9 の TextFieldLink、Stepper、ShareLink、Swift Charts、digitalCrownRotation を使用すると、開発者はウォッチ上でタスクの入力、編集、共有、トレンド チャートの閲覧を完了できます。

## 主要内容

Apple Watch の生産性向上アプリは iPhone からコピーできません。ユーザーの手首を上げる時間は短く、作業は速く、情報は少なく、入り口は明確でなければなりません。スピーチの冒頭で、迅速なインタラクション、重要な情報への簡単なアクセス、そして中心的な目的に沿ったデザインという 3 つの基準が示されました ([01:59](https://developer.apple.com/videos/play/wwdc2022/10133/?time=119))。

このセッションでは、ToDo リスト アプリを使用して、完全なプロセスをつなぎ合わせます。つまり、監視専用アプリの作成、タスク リストの表示、タスクの追加、タスクの編集、タスクの共有、そしてグラフを使用して完了傾向を表示します。各ステップは、watchOS 9 または Xcode 14 の特定の変更に対応します。

最初の変更はエンジニアリング構造です。 Xcode 14 は、新しい Watch アプリを作成するときに単一の Watch アプリ ターゲットを使用します。コード、リソース、ローカリゼーション、Siri インテント、ウィジェット拡張機能はすべてこのターゲットに配置されます。この構造は、watchOS 7 ([03:31](https://developer.apple.com/videos/play/wwdc2022/10133/?time=211)) までサポートされます。アイコンも、さまざまなデバイス サイズに合わせて拡大縮小できる 1024x1024 の画像に簡略化されています ([05:20](https://developer.apple.com/videos/play/wwdc2022/10133/?time=320))。

2 番目の変更は、対話型コントロールにあります。`TextFieldLink`ボタンからのテキスト入力を担当し、`Stepper`小さな画面での連続値の調整を担当し、`ShareLink`共有フォームを開く責任を負い、`Swift Charts`完了したレコードをヒストグラムに描画します。やっと、`digitalCrownRotation`チャートをウォッチに合わせてスクロール可能なビューに変更します。

### 単一のデータ モデルを使用してタスク リストを推進する

([06:12](https://developer.apple.com/videos/play/wwdc2022/10133/?time=372)) このデモでは、まず最小限のデータ モデルを確立します。各タスクは識別可能でハッシュ可能であり、表示用に説明テキストが保存されている必要があります。

```swift
struct ListItem: Identifiable, Hashable {
    
    let id = UUID()
    var description: String
    
    init(_ description: String) {
        self.description = description
    }
}

class ItemListModel: NSObject, ObservableObject {
    @Published var items = [ListItem]()
}

@main
struct WatchTaskListSampleApp: App {
    
    @StateObject var itemListModel = ItemListModel()
    
    @SceneBuilder var body: some Scene {
        WindowGroup {
            ContentView()
                .environmentObject(itemListModel)
        }
    }
}
```

キーポイント:

- `ListItem`従う`Identifiable`，`List`そして`ForEach`各ラインを安定して識別できます。
-`Hashable`タスク値が SwiftUI のデータ比較および収集操作に参加できるようにします。
-`ItemListModel`従う`ObservableObject`，`@Published`の`items`ドライブインターフェイスを更新します。
-`@StateObject`アプリの入り口でモデルを作成し、そのライフサイクルはアプリのシーンに従います。
-`.environmentObject(itemListModel)`モデルをビュー ツリーに挿入すると、リスト行と詳細ページの両方で同じデータを読み取ることができます。

([06:37](https://developer.apple.com/videos/play/wwdc2022/10133/?time=397)) このモデルを使用すると、インターフェイスは配列要素を直接バインドできます。リストが空のときにプロンプ​​トを表示し、ユーザーに無意味な空白スペースが表示されないようにします。

### シートとステッパーを使用してタスクを編集する

([09:40](https://developer.apple.com/videos/play/wwdc2022/10133/?time=580)) タスクの詳細は編集プロセスに属します。このスピーチでは、ナビゲーション構造を階層ナビゲーション、ページ ナビゲーション、フル スクリーン ビュー、モーダル シートに分割します。タスクを編集するには、リストに戻る前にユーザーが完了するかキャンセルする必要があるため、ここではシートが使用されます。

```swift
struct ItemRow: View {
    @EnvironmentObject private var model: ItemListModel
    
    @Binding var item: ListItem
    @State private var showDetail = false
    
    var body: some View {
        Button {
            showDetail = true
        } label: {
            HStack {
                Text(item.description)
                    .strikethrough(item.isComplete)
                Spacer()
                Image(systemName: "checkmark").opacity(item.isComplete ? 100 : 0)
            }
        }
        .sheet(isPresented: $showDetail) {
            ItemDetail(item: $item)
                .toolbar {
                    ToolbarItem(placement: .confirmationAction) {
                        Button("Done") {
                            showDetail = false
                        }
                    }
                }
        }
    }
}
```

キーポイント:

- `@Binding var item`行ビューで元の配列内のタスクを編集させます。
-`showDetail`シートを表示するかどうかを制御します。
-`Button`クリック後`showDetail`に設定`true`。
- `.sheet(isPresented:)`現在のプロセスの上に詳細ページを表示します。
-`ToolbarItem(placement: .confirmationAction)`モーダルシート上に完了ボタンを配置します。

([12:36](https://developer.apple.com/videos/play/wwdc2022/10133/?time=756)) 推定ワークロード、作成日、完了日を詳細ページに追加します。`isComplete`計算されたプロパティを使用して完了ステータスをカプセル化し、スイッチを切り替えるときに書き込みまたはクリアします`completionDate`。

```swift
struct ListItem: Identifiable, Hashable {
    
    let id = UUID()
    var description: String
    var estimatedWork: Double = 1.0
    var creationDate = Date()
    var completionDate: Date?
    
    init(_ description: String) {
        self.description = description
    }

    var isComplete: Bool {
        get {
            completionDate != nil
        }
        set {
            if newValue {
                guard completionDate == nil else { return }
                completionDate = Date()
            } else {
                completionDate = nil
            }
        }
    }
}
```

キーポイント:

- `estimatedWork`タスクの推定作業負荷を保存します。
-`creationDate`タスクの作成時間を記録します。
-`completionDate`はオプションの値です。`nil`未完成を表します。
-`isComplete`からのゲッター`completionDate`派生ステータス。
-`isComplete`設定者は完了時に現在時刻を書き込み、キャンセル時に時刻をクリアします。

([13:11](https://developer.apple.com/videos/play/wwdc2022/10133/?time=791)) watchOS 9`Stepper`時計上の連続値の編集に適しています。数値だけでなく、論理的に順序付けされた離散値も処理できます。

キーポイント:

([17:00](https://developer.apple.com/videos/play/wwdc2022/10133/?time=1020)) Swift Chart は watchOS 9 で利用できます。ここでは、まず完了日別にタスクを集計し、次に使用します。`BarMark`毎日の完了数をプロットします。

```swift
/// Aggregate data for charting productivity.
struct ChartData {
    struct DataElement: Identifiable {
        var id: Date { return date }
        let date: Date
        let itemsComplete: Double
    }
    
    /// Create aggregate chart data from list items.
    /// - Parameter items: An array of list items to aggregate for charting.
    /// - Returns: The chart data source.
    static func createData(_ items: [ListItem]) -> [DataElement] {
        return Dictionary(grouping: items, by: \.completionDate)
            .compactMap {
                guard let date = $0 else { return nil }
                return DataElement(date: date, itemsComplete: Double($1.count))
            }
            .sorted {
                $0.date < $1.date
            }
    }
}
```

キーポイント:

- `DataElement`グラフ内の集計データの一部です。
-`id`使用`date`、同じ日のデータは同じ識別子に対応します。
-`Dictionary(grouping:by:)`完了日ごとにグループ化します。
-`compactMap`飛び越える`completionDate == nil`未完了のタスクの数。
-`Double($1.count)`その日の完了数量をチャートで使用される数値に変換します。
-`sorted`グラフを日付順に表示します。

```swift
struct ProductivityChart: View {
       
    let data = ChartData.createData(
        ListItem.chartSampleData)
             
    var body: some View {
        Chart(data) { dataPoint in
            BarMark(
                x: .value("Date", dataPoint.date),
                y: .value("Completed", dataPoint.itemsComplete)
            )
            .foregroundStyle(Color.accentColor)
        }
        .navigationTitle("Productivity")
        .navigationBarTitleDisplayMode(.inline)
    }
}
```

キーポイント:

- `Chart(data)`集約された配列を Swift Chart に引き渡します。
-`BarMark`単一のデータ系列と離散値に適したヒストグラムを選択します。
-`x`使用日、`y`完成した数量を使用します。
-`.foregroundStyle(Color.accentColor)`アプリのアクセントカラーを使用して列をペイントします。
-`.navigationBarTitleDisplayMode(.inline)`ナビゲーション タイトルが占めるスペースを減らします。

### Digital Crown でチャートをスクロールする

([18:50](https://developer.apple.com/videos/play/wwdc2022/10133/?time=1130)) ウォッチ画面は、一度にあまりにも多くの列を表示するのには適していません。スピーチ用`digitalCrownRotation`クラウンを監視し、現在のインデックス、クラウン オフセット、アイドル状態を SwiftUI 状態に保存します。

```swift
struct ProductivityChart: View {
       
    let data = ChartData.createData(
        ListItem.chartSampleData)

    /// The index of the highlighted chart value. This is for crown scrolling.
    @State private var highlightedDateIndex: Int = 0

    /// The current offset of the crown while it's rotating. This sample sets the offset with
    /// the value in the DigitalCrownEvent and uses it to show an intermediate
    /// (between detents) chart value in the view.
    @State private var crownOffset: Double = 0.0

    @State private var isCrownIdle = true
  
    var body: some View {
        chart
            .focusable()
            .digitalCrownRotation(
                detent: $highlightedDateIndex,
                from: 0,
                through: data.count - 1,
                by: 1,
                sensitivity: .medium
            ) { crownEvent in
                isCrownIdle = false
                crownOffset = crownEvent.offset
            } onIdle: {
                isCrownIdle = true
            }
            .navigationTitle("Productivity")
            .navigationBarTitleDisplayMode(.inline)
    }
}
```

キーポイント:

- `highlightedDateIndex`現在ドッキングされているデータ ポイント インデックスを保存します。
-`crownOffset`クラウンスクロール時の中間オフセット値を保存します。
-`isCrownIdle`回転と停止を区別します。
-`.focusable()`ビューが Digital Crown 入力を受信できるようにします。
-`digitalCrownRotation(detent:from:through:by:sensitivity:)`クラウンストップをデータインデックスにマップします。
-`onChange`スクロール オフセットはクロージャに記録されます。
-`onIdle`クロージャはスクロールの停止を示します。

([21:07](https://developer.apple.com/videos/play/wwdc2022/10133/?time=1267)) リューズの現在位置を表示するためにグラフを追加しました`RuleMark`。これは直線であり、しきい値または現在の選択位置をマークするのに適しています。

```swift
/// The date value that corresponds to the crown offset.
private var crownOffsetDate: Date {
    let dateDistance = data[0].date.distance(
        to: data[data.count - 1].date) * (crownOffset / Double(data.count - 1))
    return data[0].date.addingTimeInterval(dateDistance)
}

private var chart: some View {
    Chart(data) { dataPoint in
        BarMark(
            x: .value("Date", dataPoint.date),
            y: .value(
                "Completed", 
                dataPoint.itemsComplete)
        )
        .foregroundStyle(Color.accentColor)
             
        RuleMark(x: .value("Date", crownOffsetDate))
            .foregroundStyle(Color.appYellow)
    }
    .chartXAxis {
        AxisMarks(format: shortDateFormatStyle)
    }
}
```

キーポイント:

- `crownOffsetDate`クラウン オフセットを日付に変換します。
-`data[0].date.distance(to:)`チャートデータの期間を取得します。
-`addingTimeInterval`開始日から現在のスクロール位置を導出します。
-`RuleMark(x:)`現在の日付に垂直線を引きます。
-`AxisMarks(format:)`カスタム日付形式で X 軸ラベルを表示します。

([22:44](https://developer.apple.com/videos/play/wwdc2022/10133/?time=1364)) 最後のステップは、現在のインデックスに基づいて表示されるデータ範囲を移動することです。このようにして、ユーザーがリューズを回すと、それに応じてチャート ウィンドウがスクロールします。

```swift
@State var chartDataRange = (0...6)

private func updateChartDataRange() {
    if (highlightedDateIndex - chartDataRange.lowerBound) < 2, chartDataRange.lowerBound > 0 {
        let newLowerBound = max(0, chartDataRange.lowerBound - 1)
        let newUpperBound = min(newLowerBound + 6, data.count - 1)
        chartDataRange = (newLowerBound...newUpperBound)
        return
    }
    if (chartDataRange.upperBound - highlightedDateIndex) < 2, chartDataRange.upperBound < data.count - 1 {
        let newUpperBound = min(chartDataRange.upperBound + 1, data.count - 1)
        let newLowerBound = max(0, newUpperBound - 6)
        chartDataRange = (newLowerBound...newUpperBound)
        return
    }
}

private var chartData: [ChartData.DataElement] {
    Array(data[chartDataRange.clamped(to: (0...data.count - 1))])
}
```

キーポイント:

- `chartDataRange`現在表示されている 7 つのデータ ポイントを保存します。
- ハイライトされたインデックスが左端に近い場合、ウィンドウは 1 つ左に移動します。
- ハイライトされたインデックスが右端に近い場合、ウィンドウは 1 つ右に移動します。
-`max`そして`min`範囲が配列の境界を越えないようにします。
-`chartData`現在の範囲内のデータのみを渡します`Chart`。

## 重要ポイント

- **時計専用のパンチリストを作成する**: 毎日しなければならないことを 3 ～ 5 つ時計に入力します。実行する価値がある理由: セッションの説明 監視専用アプリは、機能が集中し、高速な対話が行われ、データが制限されているシナリオに適しています。開始方法: 使用する`ListItem`、`ObservableObject`、`List`そして`TextFieldLink`追加と表示のプロセスを設定します。

- **手首を上げることで更新できるワークロード推定ツールを作成します**: 各タスクは、名前、推定日数、完了ステータスのみを記録します。実行する価値がある理由:`Stepper`小さな画面でも連続した数値を管理できるようになり、キーボードで数値を入力する必要がなくなりました。開始方法: で`Form`縛られている`Stepper(value:in:step:format:)`そして`Toggle(isOn:)`。

- **Make a task sharing button to ask companions for help**: When a task is stuck, send it directly to your friends from the details page.実行する価値がある理由:`ShareLink`現在のアプリを離れることなく、watchOS 上のシステム共有フォームにアクセスします。開始方法: 詳細フォームに追加します`ShareLink(item:subject:message:preview:)`。

- **先週の完了傾向のみを表示する傾向グラフを作成します**: 1 日あたりの完了数がヒストグラムで表示され、デフォルトでは 7 日のみが表示されます。実行する価値がある理由: 講演では、Watch 画面では一度に表示されるデータの量を制限する必要があり、ヒストグラムは単一のデータ系列に適していると指摘しました。開始方法: 完了日を次のように集計します。`ChartData.DataElement`、次に使用します`Chart`そして`BarMark`描く。

- **クラウンを使用して履歴データを参照できるチャートを作成します**: ユーザーが Digital Crown を回すと、ハイライト ラインと表示されるデータ範囲が移動します。実行する価値がある理由:`digitalCrownRotation`これは時計の自然な入力方法であり、小さな画面で長距離を閲覧するのに適しています。開始方法: 使用する`highlightedDateIndex`、`crownOffset`、`RuleMark`そして`chartDataRange`スクロール状態を保存します。
