## ハイライト

> ResearchKit と CareKit を併用して、ResearchKit 調査プロセスを CareKit タスク カードに埋め込み、「ケア プランにアクセスするにはインフォームド コンセントが完了する必要がある」というゲート型オンボーディングを実現すると同時に、HealthKit、通知、およびデバイス移動の許可に対する統合リクエストをサポートします。

## 主な内容

ヘルスケア研究アプリケーションの 2 つの主要な要件: 参加者データの収集 (ResearchKit) とケア プランの継続的な管理 (CareKit)。以前は、これら 2 つのフレームワークは別々に使用されることがよくありましたが、iOS 15 では、これらを組み合わせる方法が示され始めています。

具体的なシナリオは次のとおりです。理学療法研究アプリ (Recover と呼ばれます) は、参加者が膝の手術後にリハビリテーションを行うのに役立ちます。新しいユーザーは、特定のリハビリテーション タスクを表示する前に、インフォームド コンセントを完了する必要があります。このプロセスは ResearchKit に実装されていますが、CareKit のインターフェイスに埋め込まれています。

主要な設計ポイント:
- オンボーディングタスクは完了するまで毎日繰り返し表示されます
- 他のタスクは完了するまでケア フィードに表示されません
- 署名と許可リクエストは 1 つのプロセスに統合されます

### CareKit ストアでのオンボーディング タスクの永続化

（[05:39](https://developer.apple.com/videos/play/wwdc2021/10068/?time=339)）

まず AppDelegate で CareKit タスクを作成し、ストアに永続化します。

```swift
// 创建每日重复的日程
let dailySchedule = OCKSchedule.dailyAtTime(
    hour: 8, minutes: 0,
    start: Date(), end: nil,
    text: "请在每天上午 8 点前完成"
)

// 创建任务
let onboardingTask = OCKTask(
    id: TaskID.onboarding,
    title: "参与同意与引导",
    carePlanUUID: UUID(),
    schedule: dailySchedule
)
onboardingTask.instructions = "请阅读并同意研究条款"
onboardingTask.impactsAdherence = false  // 不影响完成度环

// 持久化到 Store
store.addTaskAndWait(onboardingTask) { result in
    switch result {
    case .success:
        print("Onboarding task added successfully")
    case .failure(let error):
        print("Failed to add onboarding task: \(error)")
    }
}
```

キーポイント:
- `OCKSchedule.dailyAtTime`毎日の定期的なスケジュールを作成する
- `impactsAdherence = false`このタスクは完了としてカウントされないようにします
- タスク ID は一意である必要があり、後続のクエリに使用されます。

### オンボーディングの完了ステータスを確認する

（[07:20](https://developer.apple.com/videos/play/wwdc2021/10068/?time=440)）

CareFeedViewController で、オンボーディングが完了したかどうかに基づいて、どのタスクを表示するかを決定します。

```swift
func checkIfOnboardingIsComplete(completion: @escaping (Bool) -> Void) {
    let query = OCKOutcomeQuery()
    query.taskIDs = [TaskID.onboarding]

    store.fetchOutcomes(query: query) { outcomes, error in
        guard error == nil else {
            completion(false)
            return
        }

        // 如果找到 outcome，说明已完成
        completion(!(outcomes?.isEmpty ?? true))
    }
}

// 在 prepare 方法中使用
override func prepareListViewController(
    _ listViewController: OCKListViewController,
    for date: Date
) {
    checkIfOnboardingIsComplete { [weak self] isComplete in
        guard let self = self else { return }

        if isComplete {
            // 显示所有任务
            self.appendAllTasks(to: listViewController, for: date)
        } else {
            // 只显示 onboarding 任务
            self.appendOnboardingTask(to: listViewController)
        }
    }
}
```

キーポイント:
- `OCKOutcomeQuery`タスク完了レコードのクエリ
- 結果がない場合は、ユーザーがまだ終了していないことを意味します
- クエリは非同期であり、完了ハンドラーで処理する必要があります。

### ResearchKit オンボーディング アンケートを作成する

（[09:31](https://developer.apple.com/videos/play/wwdc2021/10068/?time=571)）

Surveys.swift で 5 段階のオンボーディング プロセスを作成します。

```swift
func createOnboardingSurvey() -> ORKTask {
    // 步骤 1：欢迎页
    let welcomeStep = ORKInstructionStep(
        identifier: "onboarding.welcome"
    )
    welcomeStep.title = "欢迎参与 Recover 研究"
    welcomeStep.detailText = "本研究的目的是帮助术后康复"
    welcomeStep.image = UIImage(named: "welcome_header")

    // 步骤 2：知情说明（带图标的要点列表）
    let consentStep = ORKInstructionStep(
        identifier: "onboarding.consent"
    )
    consentStep.title = "知情同意"
    consentStep.detailText = "参与本研究需要您了解以下信息"

    // 使用 SF Symbol 作为项目符号
    let healthDataItem = ORKBodyItem(
        text: "您将被要求分享健康数据",
        detailText: nil,
        image: UIImage(systemName: "heart.fill"),
        learnMoreItem: nil,
        bulletPoint: true
    )

    let tasksItem = ORKBodyItem(
        text: "您需要完成指定的康复任务",
        detailText: nil,
        image: UIImage(systemName: "checkmark.circle.fill"),
        learnMoreItem: nil,
        bulletPoint: true
    )

    let signatureItem = ORKBodyItem(
        text: "您需要提供签名以表示同意",
        detailText: nil,
        image: UIImage(systemName: "signature"),
        learnMoreItem: nil,
        bulletPoint: true
    )

    let privacyItem = ORKBodyItem(
        text: "您的数据将被安全保存",
        detailText: "所有数据均经过加密处理",
        image: UIImage(systemName: "lock.fill"),
        learnMoreItem: nil,
        bulletPoint: true
    )

    consentStep.bodyItems = [
        healthDataItem,
        tasksItem,
        signatureItem,
        privacyItem
    ]

    // 步骤 3：签名（HTML 知情同意书）
    let signatureStep = ORKWebViewStep(
        identifier: "onboarding.signature",
        html: getConsentDocumentHTML()
    )
    signatureStep.showSignatureAfterContent = true

    // 步骤 4：权限请求
    let healthTypesToWrite: Set<HKSampleType> = [
        HKObjectType.quantityType(forIdentifier: .stepCount)!
    ]
    let healthTypesToRead: Set<HKSampleType> = [
        HKObjectType.quantityType(forIdentifier: .activeEnergyBurned)!
    ]

    let healthPermission = ORKHealthKitPermissionType(
        typesToWrite: healthTypesToWrite,
        typesToRead: healthTypesToRead
    )

    let notificationPermission = ORKNotificationPermissionType()
    let motionPermission = ORKMotionActivityPermissionType()

    let permissionsStep = ORKRequestPermissionsStep(
        identifier: "onboarding.permissions"
    )
    permissionsStep.permissionTypes = [
        healthPermission,
        notificationPermission,
        motionPermission
    ]

    // 步骤 5：完成页
    let completionStep = ORKCompletionStep(
        identifier: "onboarding.completion"
    )
    completionStep.title = "感谢您的参与"
    completionStep.detailText = "您现在可以开始使用 Recover App"

    // 组装成有序任务
    return ORKOrderedTask(
        identifier: "onboarding",
        steps: [
            welcomeStep,
            consentStep,
            signatureStep,
            permissionsStep,
            completionStep
        ]
    )
}
```

キーポイント:
- `ORKInstructionStep`説明テキストを表示するために使用されます
- `ORKBodyItem`SFシンボルを箇条書き記号としてサポート
- `ORKWebViewStep`の`showSignatureAfterContent = true`署名ボックスを表示
- iOS 15の新機能`ORKNotificationPermissionType`そして`ORKMotionActivityPermissionType`

### ResearchKit アンケートを CareKit に表示する

（[11:59](https://developer.apple.com/videos/play/wwdc2021/10068/?time=719)）

新しく導入されたものを使用してください`OCKSurveyTaskViewController`：

```swift
func appendOnboardingTask(
    to listViewController: OCKListViewController
) {
    // 创建 event query
    let eventQuery = OCKEventQuery(
        for: Date(),
        taskIDs: [TaskID.onboarding]
    )

    // 创建调查任务视图控制器
    let surveyVC = OCKSurveyTaskViewController(
        taskID: TaskID.onboarding,
        eventQuery: eventQuery,
        storeManager: storeManager,
        survey: createOnboardingSurvey(),
        resultHandler: { result in
            // 将 ResearchKit 结果转换为 CareKit outcome 值
            let dateAnswer = result.results?.first(where: {
                $0.identifier == "onboarding.completion"
            }) as? ORKDateQuestionResult

            let outcomeValue = OCKOutcomeValue(
                dateAnswer?.dateAnswer ?? Date()
            )

            return [outcomeValue]
        }
    )

    surveyVC.delegate = self

    // 创建任务卡片并添加到列表
    let card = OCKSimpleTaskView(
        taskID: TaskID.onboarding,
        eventQuery: eventQuery,
        owner: self
    )
    card.controller = surveyVC

    listViewController.appendView(card)
}
```

キーポイント:
- `OCKSurveyTaskViewController`CareKit で ResearchKit アンケートを表示するために特別に設計されています
- `resultHandler`クロージャは、ResearchKit の結果を CareKit の結果に変換する役割を果たします。
-完了イベントをリッスンするようにデリゲートを設定します

### オンボーディングの完了を処理し、インターフェースを更新します

（[12:49](https://developer.apple.com/videos/play/wwdc2021/10068/?time=769)）

ユーザーがオンボーディングを完了したときにフィードを更新するためのデリゲート メソッドを実装します。

```swift
extension CareFeedViewController: OCKSurveyTaskViewControllerDelegate {
    func surveyTaskViewController(
        _ viewController: OCKSurveyTaskViewController,
        didFinish task: ORKTask,
        with result: TaskResult
    ) {
        // 检查是否成功完成（用户没有取消）
        guard case .success = result else {
            return
        }

        // 重新加载 feed，显示其他任务
        reload()
    }

    func surveyTaskViewController(
        _ viewController: OCKSurveyTaskViewController,
        didCancel task: ORKTask
    ) {
        // 用户取消了，不需要特殊处理
    }
}
```

キーポイント:
- `reload()`カレンダー ページ全体を更新する
- 完了後、オンボーディング カードは表示されなくなり、他のタスクが表示され始めます。
- ユーザーによるキャンセルは完了したとみなされず、次回開いたときにもオンボーディングが表示されます。

### HealthKit 権限タイプの説明

HealthKit 権限をリクエストするときは、読み書きしたいタイプを明示的に指定する必要があります。

|カテゴリー |一般的なタイプ |使い方 |
|------|----------|------|
|スポーツデータ |`stepCount`、`distanceWalkingRunning`|活動統計 |
|体力指数 |`activeEnergyBurned`、`basalEnergyBurned`|カロリー消費 |
|健康指標 |`heartRate`、`bloodPressure`|生理学的指標 |
|睡眠データ |`sleepAnalysis`|睡眠の質 |

キーポイント:
- 必要なデータ型のみをリクエストします
- インフォームドコンセントフォームに各データの使用目的を明確に記載
- ユーザーは設定でいつでも権限を取り消すことができます

## 重要ポイント

1. **医学研究向けのゲート付きオンボーディング**
- **やるべきこと**: ユーザーはアプリの主要機能にアクセスするにはインフォームドコンセントを完了する必要があります
- **実施する価値がある理由**: 医学研究では参加者から明示的な同意を得る必要があり、同意しないと法的リスクが発生します。ゲート付きオンボーディングにより、各ユーザーが同意フォームを読んだことが保証されます
- **開始方法**: ResearchKit を使用して同意プロセスを作成し、CareKit で結果ステータスをクエリしてコンテンツ表示を制御します

2. **SF シンボルを使用して情報メモの読みやすさを最適化します**
- **やるべきこと**:`ORKInstructionStep`の`bodyItems`通常の箇条書きの代わりにSFシンボルを使用します。
- **価値がある理由**: 医学/法律の文章は理解するのが難しいことが多いですが、視覚的な要素は理解を助け、ユーザーの離脱率を減らすことができます。
- **開始方法**: 作成する`ORKBodyItem`渡されたとき`UIImage(systemName:)`

3. **統合された HealthKit、通知およびモーション許可リクエスト**
- **やるべきこと**: オンボーディング プロセス中に、必要なすべての権限を一度にリクエストします。
- **実行する価値がある理由**: 分散したアクセス許可リクエストはユーザー エクスペリエンスを中断しますが、統合されたリクエストはインフォームド コンセントのコンテキストでより意味があります。
- **開始方法**: を使用します`ORKRequestPermissionsStep`組み合わせ`ORKHealthKitPermissionType`、`ORKNotificationPermissionType`、`ORKMotionActivityPermissionType`

4. **検証可能な電子署名を作成します**
- **やるべきこと**: を使用します`ORKWebViewStep`ユーザーの署名を収集し、CareKit の結果に保存します
- **価値がある理由**: 電子署名には法的拘束力があり、単純な「同意する」ボタンよりも正式です
- **開始方法**:`showSignatureAfterContent = true`+ HTML同意書

5. **個人に合わせたリハビリテーション計画を指導します**
- **何をすべきか**: オンボーディングの最後にユーザーに回復目標について尋ね、目標に基づいて CareKit タスクをカスタマイズします。
- **価値がある理由**: パーソナライズされたケア プランにより、ユーザー エンゲージメントと回復の成果が大幅に向上します。
- **開始方法**: 前に完了ステップを追加します。`ORKFormStep`ユーザー設定を収集し、結果に保存してタスクのスケジュールに使用します。
