## ハイライト

> ストアキット 2 新規`showManageSubscriptions()`そして`beginRefundRequest()`API を使用すると、ユーザーはアプリ内でサブスクリプションを管理し、返金を申請できます。 Consumption API を使用すると、開発者は消費データを Apple に提供し、払い戻しの決定に参加できます。

## 主な内容

ユーザーはサブスクリプションをキャンセルしたいのですが、入り口が見つかりません。ユーザーは払い戻しを申請したいと考えていますが、その方法がわかりません。このようなシナリオでは、ユーザーはアプリに対して否定的なレビューを残したり、Apple サポートに連絡したりする可能性があります。これらの問題にアプリ内で直接対処できれば、ユーザー エクスペリエンスははるかに向上するでしょう。

StoreKit 2 では、これらの問題点に対処するために、今年 3 つの新しい API を追加しています。

### アプリ内でサブスクリプションを管理する

（[11:42](https://developer.apple.com/videos/play/wwdc2021/10175/?time=702)）

以前は、サブスクリプションを管理するには、ユーザーはアプリを終了して App Store にアクセスする必要がありました。管理者ページをアプリ内で直接開くことができるようになりました。

```swift
import StoreKit

// 显示订阅管理页面
func showSubscriptionManagement() {
    if let windowScene = view.window?.windowScene {
        Task {
            try await AppStore.showManageSubscriptions(in: windowScene)
        }
    }
}
```

（[12:20](https://developer.apple.com/videos/play/wwdc2021/10175/?time=740)）

**キーポイント:**
- `AppStore.showManageSubscriptions(in:)`システム管理ページを表示する
- ユーザーは現在のサブスクリプションと更新のオプションを確認できます
- サブスクリプションをアップグレード、ダウングレード、またはキャンセルできます
- すべての操作は App Store に同期されます

管理ページの前に保持オファーを表示することもできます。

```swift
// 在用户点击取消前展示优惠
func showRetentionOffer() {
    // 展示自定义挽留界面
    // 如果用户仍想取消，再调用 showManageSubscriptions
}
```

### アプリ内で返金を申請する

（[13:36](https://developer.apple.com/videos/play/wwdc2021/10175/?time=816)）

ユーザーは、Apple サポートに連絡せずに、アプリ内で直接払い戻しをリクエストできます。

```swift
import StoreKit

// 申请退款
func requestRefund(for transaction: Transaction) async {
    do {
        let refundStatus = try await transaction.beginRefundRequest(
            in: view.window!.windowScene!
        )

        switch refundStatus {
        case .success:
            // 退款申请已提交
            showRefundSubmittedMessage()
        case .userCancelled:
            // 用户取消了申请
            break
        }
    } catch {
        // 处理错误
        print("Refund request failed: \(error)")
    }
}
```

（[14:14](https://developer.apple.com/videos/play/wwdc2021/10175/?time=854)）

**キーポイント:**
- `transaction.beginRefundRequest(in:)`返金リクエストを開始する
- システムは返金理由選択インターフェイスを表示します
- 払い戻しの承認がサーバーによって受信される`REFUND`通知する
- 返金が拒否された後、サーバーが受け取ります`REFUND_DECLINED`通知する
- サンドボックス環境で返金テストをサポート

### Invoice Lookup API

（[03:44](https://developer.apple.com/videos/play/wwdc2021/10175/?time=224)）

ユーザーはカスタマー サービスに連絡し、「何かを購入したが届かない」と言いました。顧客サービスはユーザーに注文番号 (注文 ID) の提供を求め、請求書検索 API を介してそれを照会できます。

```
GET https://api.storekit.itunes.apple.com/inApps/v1/lookup/{orderId}
```

戻る：

```json
{
  "status": 0,
  "signedTransactions": [
    {
      "transactionId": "1000000123456789",
      "originalTransactionId": "1000000098765432",
      "productId": "com.example.coins",
      "purchaseDate": 1620000000000,
      "quantity": 100
    }
  ]
}
```

（[04:20](https://developer.apple.com/videos/play/wwdc2021/10175/?time=260)）

**キーポイント:**
- `status`0 は有効であることを意味し、1 は注文番号が無効であることを意味し、2 は一致するトランザクションがないことを意味します
- 署名されたトランザクション データを JWS 形式で返します
- 取引状況と返金状況を確認できます
- カスタマー サービスが問題を迅速に特定できるように支援します

### Refund Lookup API

（[06:02](https://developer.apple.com/videos/play/wwdc2021/10175/?time=362)）

ユーザーのすべての払い戻しレコードをクエリします。

```
GET https://api.storekit.itunes.apple.com/inApps/v1/refund/lookup/{originalTransactionId}
```

サーバー停止の処理と返金データの同期に適しています。

（[06:44](https://developer.apple.com/videos/play/wwdc2021/10175/?time=404)）

**キーポイント:**
- 使用`originalTransactionId`クエリ
- このユーザーのすべての返金トランザクションを返します
- 補完的な同期と監査に適しています
- JWS形式のデータを返却します

### Subscription Extension API

（[09:40](https://developer.apple.com/videos/play/wwdc2021/10175/?time=580)）

サービス障害（ライブ配信の中断など）が発生した場合は、ユーザーのサブスクリプションを無料で延長することで補償できます。

```
PUT https://api.storekit.itunes.apple.com/inApps/v1/subscriptions/extend

{
  "originalTransactionId": "1000000098765432",
  "extensionDuration": 7,
  "extensionReason": 1,
  "requestIdentifier": "unique-request-id"
}
```

（[10:23](https://developer.apple.com/videos/play/wwdc2021/10175/?time=623)）

**キーポイント:**
- 各サブスクリプションは年に 2 回まで延長できます
- 一度に最大90日間延長可能
- 理由コードが必要です
- ユーザーは電子メール通知を受け取ります
- 延長は 85% 分割の 1 年間にはカウントされません。

### Consumption API

（[19:12](https://developer.apple.com/videos/play/wwdc2021/10175/?time=1152)）

ユーザーが返金をリクエストすると、Apple はサーバーを送信します`CONSUMPTION_REQUEST`通知します。 Apple による払い戻しの決定に役立てるため、12 時間以内に消費データを返信できます。

```
PUT https://api.storekit.itunes.apple.com/inApps/v1/consumption/{originalTransactionId}

{
  "customerConsented": true,
  "consumptionStatus": 1,
  "consumptionPlatform": 1,
  "sampleContent": 1,
  "deliveryStatus": 0,
  "appAccountToken": "uuid-string",
  "accountTenure": 365,
  "playTime": 120,
  "lifetimeSpend": 99.99,
  "userStatus": 0
}
```

（[20:00](https://developer.apple.com/videos/play/wwdc2021/10175/?time=1200)）

**キーポイント:**
- `customerConsented`: ユーザーがデータの共有に同意するかどうか
- `consumptionStatus`: 0=未消費、1=部分的に消費、2=完全に消費、3=転送
- `deliveryStatus`:0=配信成功、1=配信失敗
- 12時間以内に返信する必要があります
- データは Apple がより正確な払い戻し決定を行うのに役立ちます

## 重要なポイント

1. **アプリ内にサブスクリプション管理の入り口を提供します**。ユーザーはアプリを離れることなく、サブスクリプションを表示および変更できます。入口API：`AppStore.showManageSubscriptions(in:)`。

2. **アプリ内に返金申請ポータルを提供します**。ユーザーが否定的なレビューを残したり、Apple サポートに連絡したりする可能性を減らします。入口API：`transaction.beginRefundRequest(in:)`。

3. **Invoice Lookup API を使用して顧客サービスを支援します**。ユーザーが問題を報告すると、注文番号を使用して取引ステータスをすぐに確認できます。入口API：`GET /inApps/v1/lookup/{orderId}`。

4. **サブスクリプション拡張 API を使用してサービスの障害を補います**。ライブ ブロードキャストが中断されたり、サーバーに障害が発生した場合、ユーザーのサブスクリプションは無料で延長されます。入口API：`PUT /inApps/v1/subscriptions/extend`。

5. **消費リクエストに返信し、払い戻しの決定に参加します**。不当な返金を減らすために消費データを提供します。入口API：`PUT /inApps/v1/consumption/{originalTransactionId}`。
