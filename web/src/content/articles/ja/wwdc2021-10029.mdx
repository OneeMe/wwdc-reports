## ハイライト

> Safari 15 ではブラウザのインターフェイスが再設計されています。 macOS のタブ バーとアドレス バーは 1 行に統合され、iOS のタブ バーは一番下に移動します。ウェブサイトには以下からアクセスできます`theme-color`メタタグはCSSを使用してタブバーの色を制御します`aspect-ratio`属性を使用するとレイアウトが簡素化されます。`env(safe-area-inset-bottom)`下部のタブバーに適応します。

## 主な内容

Safari 15 は、Safari のビジュアル デザインに対する最大のアップデートです。ブラウザのインターフェイスは、「Web の支配」から「Web に道を譲る」へと変化します。

macOS のタブ バーは別の行を占めるのではなく、アドレス バーと統合されます。ブラウザ インターフェイス全体が 1 行に圧縮され、Web コンテンツの縦方向のスペースが増えます。iOSのタブバーが画面下に移動し、片手で操作できるようになりました。

これらの変更は、Web デザイナーに直接的な影響を与えます。

### タブバーの色を制御する

Safari 15 では、Web ページから色を抽出し、タブ バーの背景に適用します。開発者はこの色をアクティブに制御できます。

```html
<head>
    <!-- 基本のテーマカラー -->
    <meta name="theme-color" content="#0071e3">

    <!-- ダークモードへの対応 -->
    <meta name="theme-color"
          content="#0071e3"
          media="(prefers-color-scheme: light)">
    <meta name="theme-color"
          content="#000000"
          media="(prefers-color-scheme: dark)">
</head>
```

（[02:50](https://developer.apple.com/videos/play/wwdc2021/10029/?time=170)）

キーポイント:
- `theme-color`これを HTML ヘッドに配置し、Safari ページが読み込まれたときにすぐに取得します。
- `media`属性は HTML 仕様に新しく追加され、Safari 15 で初めてサポートされました。
- メディア属性をサポートしていないブラウザでは、最初の属性が使用されます。`theme-color`したがって、フォールバックを最初に置きます
- JavaScriptを使用して動的に変更することもできます

```javascript
// テーマカラーを動的に切り替える
function enterTheaterMode() {
    document.querySelector('meta[name="theme-color"]')
        .setAttribute('content', '#000000');
}

function exitTheaterMode() {
    document.querySelector('meta[name="theme-color"]')
        .setAttribute('content', '#0071e3');
}
```

### iOS の下部タブ バーに適応する

iOS 15 のタブ バーは画面の下部にあり、ユーザーがスクロールするとドメイン名のプロンプトまで縮小します。ページ下部の内容が見えにくくなる場合があります。

CSS 環境変数を使用して以下を処理します。

```css
.footer {
    position: sticky;
    bottom: 0;
    padding: 1rem;
    padding-bottom: calc(1rem + env(safe-area-inset-bottom));
}
```

（[14:21](https://developer.apple.com/videos/play/wwdc2021/10029/?time=861)）

キーポイント:
- `env(safe-area-inset-bottom)`の値は、タブ バーが展開/縮小されると動的に変化します。
- Safari はページを自動的に並べ替えます
- 4 つの方向に対応する変数があります。`top`、`right`、`bottom`、`left`
- で見つけることができます`calc()`で使用される

### viewport-fit=全画面エクスペリエンスをカバーします

iPhone が横向きの場合、Safari はデフォルトで Web コンテンツを安全な領域にインデントして、前髪や丸い角によって隠れないようにします。ウェブサイトのデザインがこれらの領域を考慮している場合は、次のようにすることができます。`viewport-fit=cover`コンテンツを端まで拡張させます。

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
```

（[16:03](https://developer.apple.com/videos/play/wwdc2021/10029/?time=963)）

環境変数を使用して、テキストが読み取れるようにします。

```css
.header-text {
    margin-left: env(safe-area-inset-left);
}

.paragraph {
    margin-left: env(safe-area-inset-left);
    margin-right: env(safe-area-inset-right);
}
```

### CSS アスペクト比プロパティ

以前は、固定アスペクト比の div を維持するには、パディング ハックまたは JavaScript が必要でした。Safari 15 はネイティブをサポートします`aspect-ratio`：

```css
/* 正方形 */
.card {
    aspect-ratio: 1 / 1;
}

/* 短縮記法 */
.card {
    aspect-ratio: 1;
}

/* 16:9 の動画 */
.video-container {
    aspect-ratio: 16 / 9;
    width: 100%;
}

/* 黄金比 */
.banner {
    aspect-ratio: 1.618;
}
```

（[24:38](https://developer.apple.com/videos/play/wwdc2021/10029/?time=1478)）

キーポイント:
- コンテンツが多すぎる場合、オーバーフローを避けるためにボックスの高さがデフォルトで大きくなります。
- 比例関係を強制的に維持するには (オーバーフローを許可します)、次のように追加します。`min-height: 0`
- 協力できる`overflow: scroll`オーバーフローコンテンツの処理
- 次のような 10 進数の書き込みをサポートします。`aspect-ratio: 1.618`

### Flexbox gap

Safari 14.1 が Flexbox のサポートを開始`gap`財産：

```css
.navbar {
    display: flex;
    gap: 1rem;
}
```

子要素に個別のマージンを設定したり、エッジ要素の余分なスペースを処理したりする必要はもうありません。

### フォーム コントロールの更新

iOS 15 では、ネイティブ UIKit に近づくようにフォーム コントロールが再設計されています。

```html
<!-- 日付ピッカー -->
<input type="date">

<!-- 時刻ピッカー -->
<input type="time">

<!-- カラーピッカー（スポイト付き） -->
<input type="color">
```

（[30:38](https://developer.apple.com/videos/play/wwdc2021/10029/?time=1838)）

カラー ピッカーには 3 つの新しいパネルとカラー ピッカー (スポイト) があります。サイトがデフォルトのスタイルをオーバーライドする場合は、カスタム スタイルが通常どおり適用されます。

### ページタイトルの最適化

新しいタブ バーのスペースは限られており、ページ タイトルの書き方がユーザー エクスペリエンスに影響します。

```html
<!-- 悪い例：サイト名が先頭 -->
<title>My Company - Products - Detail</title>

<!-- 良い例：コンテンツのタイトルが先頭 -->
<title>Detail - Products - My Company</title>
```

（[07:37](https://developer.apple.com/videos/play/wwdc2021/10029/?time=457)）

ユーザーが同時に複数のタブを開いた場合、前のコンテンツのタイトルが区別しやすくなります。

### ファビコンの提案

- Retina スクリーンに適応する高解像度のアイコンを提供します
- 背景が透明なファビコンは、新しいタブ バーでより適切に機能します
- 自動ツールによって生成された小切手`theme-color`、色がウェブサイトのデザインと一致していることを確認してください

## 重要ポイント

**1. Web サイトの没入型ブランド エクスペリエンスをデザインします**

`theme-color` を使用して Safari のタブ バーを Web サイトのメインの色と一致させます。`viewport-fit=cover` でヘッダー画像を画面端まで表示します。入口 API: `<meta name="theme-color">` + `viewport-fit=cover`。

**2.レスポンシブな画像ギャラリーを構築する**

`aspect-ratio` を使用して画像カードを均一な比率に保ち、CSS グリッドを使用してウォーターフォール フローまたはグリッド レイアウトを実装します。入口 API: `aspect-ratio` + `display: grid`。

**3.モバイル端末の下部ナビゲーションを最適化**

iOS の下部タブ バー用に安全な領域を予約し、`env(safe-area-inset-bottom)` を使用してナビゲーション ボタンが隠れないようにします。入口 API: `padding-bottom: env(safe-area-inset-bottom)`。

**4.ビデオ Web サイトにシアター モードを実装**

JavaScript を使用してクリック時にシアター モードを切り替え、`theme-color` を黒にしてタブバーを暗い背景になじませ、映画鑑賞の没入感を高めます。入口 API: `document.querySelector('meta').setAttribute('content', ...)`。

**5.クロスプラットフォームで一貫したフォームを設計**

Safari 15 の新しいフォーム コントロール スタイルを使用してカスタム スタイル コードを削減します。日付、時刻、カラー ピッカーは、iOS でネイティブ エクスペリエンスを自動的に取得します。入口 API: `<input type="date">` + `<input type="color">`。
