## ハイライト

> iOS 17 と macOS Sonoma では、カスタム シンボルを含むすべての SF シンボルに統一アニメーション API を提供するシンボル フレームワークが導入されています。開発者パス`.symbolEffect()`モディファイアとドット区切りのエフェクト名を使用して、SwiftUI、UIKit、AppKit でバウンス、パルス、可変カラーなどのアニメーション効果を追加できます。

## 主な内容

### シンボルアニメーションの 4 つの動作

以前はアイコンを動かしたい場合は手書きする必要がありました。`UIView.animate`または`withAnimation`、キーフレームを自分で計算する必要があります。シンボル フレームワークはこれを簡素化します。必要な効果を宣言するだけで済み、アニメーションの詳細はシステムが処理します。

すべての効果は 4 つの動作に分類できます ([04:25](https://developer.apple.com/videos/play/wwdc2023/10258/?time=265)):

|行動 |説明 |代表的な効果 |
|-----|------|----------|
|ディスクリート (ディスクリート) | 1 回限りのアニメーション、再生後に自動的に終了 |バウンス |
|無期限 (永続的) |シンボルのステータスを変更して維持するには、明示的に削除する必要があります。スケール、可変色 |
|移行 |シンボルの表示と非表示を制御する |現れる、消える |
|コンテンツの移行 | 2 つのシンボルを切り替える |置換 |

各動作は Swift プロトコルに対応します。エフェクトは、これらのプロトコルに従って、どの動作をサポートするかを宣言します。たとえば、Variable Color は Independent と Discrete の両方をサポートします。具体的な動作は、API の使用方法によって異なります。

### ドット区切りのエフェクト名

シンボル フレームワークの設計上のハイライトは、エフェクト名をドットで区切った構文です ([02:03](https://developer.apple.com/videos/play/wwdc2023/10258/?time=123))。

```swift
.bounce
.variableColor.iterative.reversing
.scale.up
```

これらは文字列ではなく、実際の Swift コードです。 Xcode は各部分を自動的に完了し、コンパイル中に構成エラーが報告されます。 SF シンボル アプリの [アニメーション] タブでエフェクトをプレビューし、エフェクト名をコードに直接コピーできます。

### SwiftUI で使用される

SwiftUIが追加されました`symbolEffect`修飾子 ([05:11](https://developer.apple.com/videos/play/wwdc2023/10258/?time=311))。最も簡単な使用法は直接`Image`以下にエフェクトを追加します。

```swift
Image(systemName: "wifi.router")
    .symbolEffect(.variableColor.iterative.reversing)
    .symbolEffect(.scale.up)
```

エフェクトは重ねて使用できます。上記のコードは、可変カラー アニメーションと拡大効果の両方を適用します。

### UIKit/AppKit で使用されます

UIKitとAppKit`UIImageView`/`NSImageView`追加した`addSymbolEffect`方法 ([05:30](https://developer.apple.com/videos/play/wwdc2023/10258/?time=330)):

```swift
let imageView: UIImageView = ...
imageView.addSymbolEffect(.variableColor.iterative.reversing)
imageView.addSymbolEffect(.scale.up)
```

### 無限の効果: アニメーションの開始と停止を制御します。

無期限の効果は削除されるまで継続して再生されます。 SwiftUI経由`isActive`パラメータ制御 ([06:49](https://developer.apple.com/videos/play/wwdc2023/10258/?time=409)):

```swift
struct ContentView: View {
    @State var isConnectingToInternet: Bool = true
    
    var body: some View {
        Image(systemName: "wifi.router")
            .symbolEffect(
                .variableColor.iterative.reversing,
                isActive: isConnectingToInternet
            )
    }
}
```

キーポイント:
- `isActive`のために`true`アニメーションの再生が始まります
-`isActive`なる`false`アニメーションはスムーズに終了します
- ネットワーク接続やファイルアップロードなどの「進行中」ステータスを示すのに適しています

UIKit/AppKit では、次を使用します。`removeSymbolEffect(ofType:)`アニメーションを停止します ([07:09](https://developer.apple.com/videos/play/wwdc2023/10258/?time=429)):

```swift
imageView.addSymbolEffect(.variableColor.iterative.reversing)
// 连接成功后停止动画
imageView.removeSymbolEffect(ofType: .variableColor)
```

### 個別効果: イベントに応じた 1 回限りのアニメーション

Discrete エフェクトは、値が変更されると 1 回発生します。バウンスは典型的なディスクリート エフェクトです ([08:26](https://developer.apple.com/videos/play/wwdc2023/10258/?time=506)):

```swift
struct ContentView: View {
    @State var bounceValue: Int = 0
    
    var body: some View {
        VStack {
            Image(systemName: "antenna.radiowaves.left.and.right")
                .symbolEffect(
                    .bounce,
                    options: .repeat(2),
                    value: bounceValue
                )
            
            Button("Animate") {
                bounceValue += 1
            }
        }
    }
}
```

キーポイント:
- `value`パラメータが変化したときにアニメーションをトリガーする
-`options: .repeat(2)`アニメーションを 2 回繰り返します
- ボタンクリック後のフィードバックなど、ユーザーの操作に対する応答に適しています

パルスと可変カラーも離散動作をサポートします。使用時`value`トリガーされると、1 回限りのアニメーション シーケンスが再生されます。

### 置換エフェクト: シンボル切り替えアニメーション

置換エフェクトを使用すると、2 つのシンボル間のアニメーション遷移が可能になります ([09:40](https://developer.apple.com/videos/play/wwdc2023/10258/?time=580))。

```swift
struct ContentView: View {
    @State var isPaused: Bool = false
    
    var body: some View {
        Button {
            isPaused.toggle()
        } label: {
            Image(systemName: isPaused ? "pause.fill" : "play.fill")
                .contentTransition(.symbolEffect(.replace.offUp))
        }
    }
}
```

キーポイント:
- `contentTransition(.symbolEffect(.replace.offUp))`上に飛ぶ置換アニメーションでシンボルを切り替えます
-`.offUp`、`.offDown`他のオプションは置換方向を制御します
- 再生/一時停止、収集/収集のキャンセル、その他の状態切り替えシナリオに適しています

UIKitで使用される`setSymbolImage(_:contentTransition:)`同じ効果を実現します ([09:57](https://developer.apple.com/videos/play/wwdc2023/10258/?time=597)):

```swift
let pauseImage = UIImage(systemName: "pause.fill")!
imageView.setSymbolImage(pauseImage, contentTransition: .replace.offUp)
```

### 出現と消滅: 2 つの使用方法

出現と消滅は 2 つの動作モードをサポートしています ([10:15](https://developer.apple.com/videos/play/wwdc2023/10258/?time=615)):

**方法 1: 不定の動作 (レイアウトは変更されません)**

シンボルが消えるか所定の位置に表示され、周囲のビューのレイアウトは変更されません。

```swift
Image(systemName: "moon.stars")
    .symbolEffect(.disappear, isActive: isMoonHidden)
```

**方法 2: 遷移動作 (レイアウトの変更)**

シンボルがビュー階層に挿入または削除され、周囲のビューが再配置されます。

```swift
if !isMoonHidden {
    Image(systemName: "moon.stars")
        .transition(.symbolEffect(.disappear.down))
}
```

キーポイント:
- 無期限モードはバッジやステータスマークの表示/非表示に適しています
- 遷移モードは条件付きでレンダリングされたビューに適しています
-`.automatic`トランジション効果は最適なアニメーションを自動的に選択します

UIKit では、完了ハンドラーを使用して、アニメーション終了後にビューを削除できます ([12:59](https://developer.apple.com/videos/play/wwdc2023/10258/?time=779))。

```swift
imageView.addSymbolEffect(.disappear) { context in
    if let imageView = context.sender as? UIImageView, context.isFinished {
        imageView.removeFromSuperview()
    }
}
```

### 効果の伝播と無効化

SwiftUI の`symbolEffect`修飾子は下方向に伝播されます ([14:19](https://developer.apple.com/videos/play/wwdc2023/10258/?time=859)):

```swift
VStack {
    Image(systemName: "figure.walk")
        .symbolEffectsRemoved()
    Image(systemName: "car")
    Image(systemName: "tram")
}
.symbolEffect(.pulse)
```

キーポイント:
- 親ビュー上`.symbolEffect(.pulse)`すべてのサブビューのシンボルがパルス化されます
-`.symbolEffectsRemoved()`特定のビューが効果を継承しないようにすることができます
- リストやツールバーのアニメーションを一元管理するのに適しています

### アニメーション適用効果なし

場合によっては、最初はシンボルをエフェクト状態にしておく必要がありますが、トランジションをアニメーション化する必要はありません。 SwiftUIで使用される`Transaction`アニメーションを無効にする ([14:55](https://developer.apple.com/videos/play/wwdc2023/10258/?time=895)):

```swift
Image(systemName: "iphone.radiowaves.left.and.right")
    .symbolEffect(.scale.up, isActive: isScaledUp)
    .onAppear {
        var transaction = Transaction()
        transaction.disablesAnimations = true
        withTransaction(transaction) {
            isScaledUp = true
        }
    }
```

UIKit/AppKitで直接使用`animated: false`パラメータ:

```swift
imageView.addSymbolEffect(.disappear, animated: false)
```

### 変数値のスムーズな遷移

iOS 16 で導入された変数値は、iOS 17 で自動アニメーションをサポートします ([15:44](https://developer.apple.com/videos/play/wwdc2023/10258/?time=944)):

```swift
struct ContentView: View {
    @State var signalLevel: Double = 0.5
    
    var body: some View {
        Image(systemName: "wifi", variableValue: signalLevel)
    }
}
```

SwiftUI の`variableValue`変更時にクロスフェードアニメーションが自動生成されます。 UIKitで使用される`setSymbolImage(_:contentTransition: .automatic)`同じ効果が得られます。

### UIKit コントロールの組み込みアニメーション

iOS 17 の一部の UIKit コントロールには、シンボル アニメーションが組み込まれています ([13:47](https://developer.apple.com/videos/play/wwdc2023/10258/?time=827))。

- `UISlider`スライダーが両端に達すると跳ね返ります
-`UIBarButtonItem`サポート`addSymbolEffect`
- `UIControl`そして`UIBarButtonItem`新しい`isSymbolAnimationEnabled`アニメーションを再生するかどうかを制御するプロパティ

## 重要なポイント

**ネットワーク ステータス インジケーターに可変色のアニメーションを追加**

- **内容**: Wi-Fi またはルーターのアイコンをナビゲーション バーまたはツールバーに配置し、接続時に可変カラー アニメーションを再生します。
- **実行する価値がある理由**: これは、離散 + 不定効果の古典的なシーンです。接続中は再生が継続され、接続が成功するとスムーズに停止します。
- **開始方法**: を使用します`.symbolEffect(.variableColor.iterative.reversing, isActive: isConnecting)`

**Replace エフェクトを使用して再生コントロール ボタンを最適化**

- **やるべきこと**: 再生/一時停止ボタン アイコン スイッチにアニメーションの置換を追加します
- **実行する価値がある理由**: 置換エフェクトを使用すると、2 つのシンボル間の切り替えに方向性が生まれ、画像を直接置き換えるよりも質感が増します。
- **開始方法**: を使用します`.contentTransition(.symbolEffect(.replace.offUp))`

**バウンス フィードバックをリスト操作に追加します**

- **内容**: ユーザーがお気に入り、削除などのボタンをクリックすると、アイコンが 1 回バウンドします。
- **実行する価値がある理由**: バウンスは個別のエフェクトであり、当然操作フィードバックに適しており、静的なハイライトよりも鮮やかです。
- **開始方法**: を使用します`.symbolEffect(.bounce, value: tapCount)`、クリックするたびに増加します`tapCount`

**非表示トランジションを使用して条件付きビューを作成します**

- **対処方法**: 条件付きで表示されるアイコンが使用されます`.transition(.symbolEffect(.disappear))`出現・消滅アニメーションの追加
- **実行する価値がある理由**: 遷移動作によりレイアウトが変更され、バッジやプロンプト マークの表示と非表示に適しています。
- **開始方法**:`if`条件内の画像に追加`.transition(.symbolEffect(.automatic))`
