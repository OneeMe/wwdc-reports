## ハイライト

> Metal ハイブリッド レンダリング パイプラインは、メイン レンダリングにラスタライゼーションを使用し、反射、シャドウイング、周囲光の遮蔽にライト トレースを使用します。メイン メモリへの G バッファの書き込みを回避するために、タイル メモリを使用した単一のレンダリング パスで完了します。

## 主な内容

ゲームにはすでに完全なラスタライズ レンダリング パイプラインが存在します。画像は素晴らしいですが、反射は偽物で (スクリーン スペース反射)、影はハードエッジで (シャドウ マップ)、角には触れない影がありません。レイ トレーシングを追加して画質を向上させたいが、レンダラー全体を書き直す必要はありません。

ハイブリッド レンダリングはこの問題に対する答えです。ラスタライゼーションが主導権を握り、レイ トレーシングが後回しになります。

### ハイブリッド レンダリング パイプライン アーキテクチャ

（[01:19](https://developer.apple.com/videos/play/wwdc2021/10150/?time=79)）

中心となるアイデアは 3 つのステップに分かれています。

1. **ラスタライズにより G バッファが生成されます** — 従来の方法でシーンをレンダリングし、位置、法線、およびマテリアルの情報を出力します
2. **G バッファからレイを放射する** — コンピューティング パスまたはフラグメント シェーダで G バッファを読み取り、レイを放射します。
3. **最終イメージを合成** — レイ トレーシングの結果とラスタライズの結果を混合します。

```
Render Pass 1 (光栅化):
  - 渲染场景到 G-Buffer (position, normal, albedo)

Compute Pass (光追):
  - 读取 G-Buffer
  - 发射 shadow rays / reflection rays / AO rays
  - 输出 shadow mask / reflection color / AO factor

Render Pass 2 (合成):
  - 读取 G-Buffer 和光追结果
  - 计算光照并合成
```

（[06:32](https://developer.apple.com/videos/play/wwdc2021/10150/?time=392)）

**キーポイント:**
- G-Buffer は 1 回だけ生成する必要があります
- それぞれのライトトレース効果を独立して実現可能
- レイ トレーシングの解像度は画面解像度よりも低い場合があります
- 一時的な蓄積を使用してノイズを低減します

### Ray-Traced Shadows

（[08:35](https://developer.apple.com/videos/play/wwdc2021/10150/?time=515)）

シャドウ マップの問題は、解像度が制限されていること、近距離ではエイリアシングが明らかであること、そしてソフト シャドウがサポートされていないことです。ライト トレース シャドウは、G バッファから光源に直接光を放射し、オクルージョンがあるかどうかを判断します。

```metal
kernel void rayTracedShadows(
    texture2d<float> gBufferPosition [[texture(0)]],
    texture2d<float> gBufferNormal [[texture(1)]],
    texture2d<float> shadowMask [[texture(2)]],
    uint2 gid [[thread_position_in_grid]]
) {
    float3 position = gBufferPosition.read(gid).xyz;
    float3 normal = gBufferNormal.read(gid).xyz;

    // 偏移起点避免自相交
    float3 origin = position + normal * 0.01;
    float3 direction = normalize(lightPosition - position);

    ray ray;
    ray.origin = origin;
    ray.direction = direction;
    ray.max_distance = distance(lightPosition, position);

    intersector<instancing> intersector;
    intersector.set_acceleration_structure(accelerationStructure);

    auto intersection = intersector.intersect(ray, accelerationStructure);

    // 如果有交点，说明被遮挡
    float shadow = (intersection.type == intersection_type::none) ? 1.0 : 0.0;
    shadowMask.write(shadow, gid);
}
```

（[11:54](https://developer.apple.com/videos/play/wwdc2021/10150/?time=714)）

**キーポイント:**
- G バッファからワールド空間位置を読み取ります
- 自己交差を避けるために、開始点は法線に沿ってオフセットされます。
- `max_distance`光源からの距離に設定
- 合成時にライティングを掛け合わせた出力シャドウマスク

ソフト シャドウは、光源領域に複数のポイントをランダムにサンプリングすることで実現できます。

```metal
float shadow = 0.0;
for (int i = 0; i < sampleCount; i++) {
    float3 lightSample = lightPosition + randomOffset(i);
    float3 direction = normalize(lightSample - position);
    ray.direction = direction;
    ray.max_distance = distance(lightSample, position);

    auto intersection = intersector.intersect(ray, accelerationStructure);
    shadow += (intersection.type == intersection_type::none) ? 1.0 : 0.0;
}
shadow /= sampleCount;
```

### Ray-Traced Ambient Occlusion

（[13:30](https://developer.apple.com/videos/play/wwdc2021/10150/?time=810)）

スクリーン スペース アンビエント オクルージョン (SSAO) は、画面の端とオクルージョンの背後で失敗します。ライトトレースAOは、G-Bufferから半球に向けて近距離光を照射し、オクルージョンの割合をカウントします。

```metal
kernel void rayTracedAO(
    texture2d<float> gBufferPosition [[texture(0)]],
    texture2d<float> gBufferNormal [[texture(1)]],
    texture2d<float> aoTexture [[texture(2)]],
    uint2 gid [[thread_position_in_grid]]
) {
    float3 position = gBufferPosition.read(gid).xyz;
    float3 normal = gBufferNormal.read(gid).xyz;

    float ao = 0.0;
    for (int i = 0; i < sampleCount; i++) {
        float3 sampleDir = sampleHemisphere(normal, i);

        ray ray;
        ray.origin = position + normal * 0.01;
        ray.direction = sampleDir;
        ray.max_distance = aoRadius; // 短距离，比如 1.0 米

        auto intersection = intersector.intersect(ray, accelerationStructure);
        ao += (intersection.type != intersection_type::none) ? 1.0 : 0.0;
    }
    ao = 1.0 - (ao / sampleCount);
    aoTexture.write(ao, gid);
}
```

（[15:07](https://developer.apple.com/videos/play/wwdc2021/10150/?time=907)）

**キーポイント:**
- サンプリング方向は通常の半球に限定されます。
- 光の距離が短い (AO は近くのオクルージョンのみを考慮します)
- 結果をぼかし、ノイズを軽減することができます
- ピクセルごとに 4 ～ 8 個の光線を使用すると、良好な結果が得られます。

### ノイズリダクションとタイムドメイン蓄積

（[20:30](https://developer.apple.com/videos/play/wwdc2021/10150/?time=1230)）

ピクセルあたり少数の光線 (1 ～ 4) のみを放射すると、ノイズが発生します。解決策は時間的な蓄積、つまり現在のフレームの結果と過去のフレームをブレンドすることです。

```metal
// 当前帧的光追结果
float4 currentResult = traceRays(...);

// 重投影到上一帧的屏幕坐标
float2 prevUV = reproject(currentPosition, prevViewProjMatrix);

// 读取历史帧结果
float4 historyResult = historyTexture.sample(sampler, prevUV);

// 混合（指数移动平均）
float blendFactor = 0.9; // 90% 历史 + 10% 当前
float4 denoisedResult = lerp(currentResult, historyResult, blendFactor);
```

（[22:15](https://developer.apple.com/videos/play/wwdc2021/10150/?time=1335)）

**キーポイント:**
- 再投影には、前のフレームのビュー投影行列が必要です
- ブレンド係数は適応的に調整できます（動きが速い場合は減少します）。
- 無効な履歴サンプルは拒否する必要があります (オクルージョンが変化した場合)
- 空間フィルターを使用してノイズをさらに低減します

## 重要なポイント

1. **シャドウ マップからライト トレース シャドウに移行**。 G バッファの位置を使用して光源に光線を放射し、任意の精度とソフト シャドウをサポートします。入口API：`intersector.intersect(ray, accelerationStructure)`。

2. **SSAO をライト トレーシング AO に置き換えます**。コーナーや接触面でより正確なオクルージョン情報を取得します。入口 API: 半球サンプリング + 短距離光線交差。

3. **Apple GPU でのハイブリッド レンダリングにはタイル シェーダーを使用します**。 G バッファはタイル メモリに残り、ライト トレースと合成は同じレンダー パスで完了します。入口API：`[[kernel]] tileShader` + tile memory texture。

4. **ライト トレースの結果は、時間領域の蓄積を使用してノイズ除去されます**。ピクセルあたりのレイが少ない + 履歴フレーム ブレンディング = スムーズな結果。 Entry API: 再投影 + 指数移動平均。

5. **光の追跡効果を徐々に追加します**。最初にシャドウを追加し、次に AO、最後に反射を追加します。各エフェクトは既存のパイプラインに影響を与えることなく独立して実装されます。エントリ API: 独立したコンピューティング パスまたはタイル シェーダー。
