## ハイライト

> iOS 17の新機能`GroupSessionJournal`この API を使用すると、SharePlay アプリは最大 100 MB の添付ファイル (画像、PDF、音声など) を転送でき、Apple のクラウド インフラストラクチャを利用して高速なエンドツーエンドの暗号化転送が可能になり、後発者向けのステータス同期が自動的に処理されます。

## 主な内容

### GroupSessionMessenger の制限事項

以前使用していたSharePlayアプリ`GroupSessionMessenger`同期状態ですが、小さなメッセージ データの送信にのみ適しています。共同描画アプリケーションを想像してください。ブラシ トレースはメッセンジャーを通過できますが、ユーザーが写真をキャンバスにドラッグした場合、このパスは機能しません。

（[00:58](https://developer.apple.com/videos/play/wwdc2023/10241/?time=58)）`GroupSessionJournal`このギャップを埋めます。 FaceTime と同じ Apple クラウド インフラストラクチャを使用し、送信データ量と待ち時間を削減するために複数のレイヤーのテクノロジーが積み重ねられており、完全にエンドツーエンドで暗号化されています。

### Journal の仕組み

（[02:14](https://developer.apple.com/videos/play/wwdc2023/10241/?time=134)）`GroupSessionJournal`にバインドする`GroupSession`、すべての参加者は同じジャーナル インスタンスを共有します。ローカルに電話をかける`add`、みんなの`attachments`AsyncSequence は新しい添付ファイル イベントを受け取ります。電話`remove`、全員が同時に削除されます。

添付ファイルの種類は次のとおりです`Transferable`プロトコルに従うと、システムが残りの送信ロジックを処理します。

### 2 つの重要な設計制約

([03:37](https://developer.apple.com/videos/play/wwdc2023/10241/?time=217)) 添付ファイルのサイズ制限は 100MB です。このため、開発者はコンテンツ タイプを区別する必要があります。ユーザーが作成した写真、PDF、および音声メモは Journal に適しています。映画などの大きなファイルは、アプリケーション独自のサーバーに送信する必要があります。

([04:18](https://developer.apple.com/videos/play/wwdc2023/10241/?time=258)) ライフサイクルは GroupSession にバインドされています。添付ファイルは、ユーザーがオンラインにいる限り残ります。全員が退席すると自動的にクリアされます。これは、セッションが終了する前に重要なデータをローカルに保存する必要があることを意味します。

### 後発者の問題は自動的に解決されます

([04:47](https://developer.apple.com/videos/play/wwdc2023/10241/?time=287)) 以前は、新しい参加者は他の参加者に状態データを再送信する必要がありました。ステータスに大きな添付ファイルが含まれている場合は、全員がそれを再アップロードする必要があります。 Journal は、他のユーザーが添付ファイルを再アップロードする必要がなく、既存の添付ファイルを新しい結合者に自動的に同期するようになりました。

### DrawTogether にジャーナルを統合する

Session では、DrawTogether アプリケーションを例として、4 段階の統合を示します。

**ステップ 1: データ モデルを定義する**

作成する`CanvasImage`Journal 内の画像を追跡するための構造:

```swift
struct CanvasImage: Identifiable {
    let id: UUID
    let image: UIImage
    var position: CGPoint
}
```

**ステップ 2: キャンバス モデルでジャーナルを作成します**

```swift
class Canvas: ObservableObject {
    @Published var images: [CanvasImage] = []
    @Published var selectedImageData: Data?

    private var journal: GroupSessionJournal?

    func configureGroupSession(_ session: GroupSession<DrawTogether>) {
        // 创建 Journal
        journal = GroupSessionJournal(session: session)

        // 监听附件变化
        Task {
            for await attachment in journal!.attachments {
                await handleAttachment(attachment)
            }
        }
    }

    func addImageToJournal(_ imageData: Data) {
        guard let journal = journal else { return }

        // 创建 Transferable 附件并上传
        let attachment = TransferableAttachment(data: imageData, type: .image)
        journal.add(attachment)
    }
}
```

キーポイント:
- `GroupSessionJournal(session:)`GroupSession で初期化する
-`attachments`は AsyncSequence です。使用します`for await`新しい添付ファイルをリッスンする
-`add()`添付ファイルをアップロードすると、参加者全員が次のメッセージを受け取ります。

**ステップ 3: 画像選択ボタンを追加します**

```swift
import PhotosUI

struct ControlBar: View {
    @ObservedObject var canvas: Canvas

    var body: some View {
        HStack {
            // 其他按钮...

            PhotosPicker(selection: $canvas.selectedImageData,
                         matching: .images) {
                Image(systemName: "photo")
            }
        }
    }
}
```

**ステップ 4: キャンバスに画像を表示します**

```swift
struct CanvasView: View {
    @ObservedObject var canvas: Canvas

    var body: some View {
        ZStack {
            // 绘制笔画...

            // 显示所有图片
            ForEach(canvas.images) { canvasImage in
                Image(uiImage: canvasImage.image)
                    .position(canvasImage.position)
                    .gesture(
                        DragGesture()
                            .onChanged { value in
                                canvasImage.position = value.location
                            }
                    )
            }
        }
    }
}
```

キーポイント:
- `PhotosPicker`SwiftUI 組み込みコンポーネントであり、iOS 16 以降で利用可能
- 写真の場所について`DragGesture`ドラッグアンドドロップを実装する
- すべての写真のステータスはジャーナルを通じてすべての参加者に同期されます

### 添付ファイルの処理プロセス

```swift
func handleAttachment(_ attachment: GroupSessionJournal.Attachment) async {
    do {
        let data = try await attachment.load(Data.self)
        if let image = UIImage(data: data) {
            let canvasImage = CanvasImage(
                id: attachment.id,
                image: image,
                position: .center
            )
            await MainActor.run {
                images.append(canvasImage)
            }
        }
    } catch {
        print("Failed to load attachment: \(error)")
    }
}
```

キーポイント:
- `attachment.load(Data.self)`添付ファイルデータを非同期的にロードする
- 読み込みが完了したら、メインスレッドに戻って UI を更新します
- 添付ファイル ID は後続の削除操作に使用できます

## 重要なポイント

1. **画像コラボレーションを備えたホワイトボード アプリケーションを作成します**
   - **やるべきこと**: 複数の人が同じキャンバス上で写真を投稿し、注釈を付け、議論することができます
   - **実行する価値がある理由**: Journal は画像の送信と同期を自動的に処理するため、開発者はキャンバスの対話ロジックだけに集中する必要があります。
   - **開始方法**: を使用します`GroupSessionJournal`画像添付ファイルを転送するには、次を使用します。`GroupSessionMessenger`ブラシの軌跡を同期する

2. **フォトアルバムを共有するパーティーアプリケーション**
   - **やるべきこと**: イベントや旅行でグループの人々とリアルタイムで写真を共有すると、全員がお互いの撮ったばかりの写真を見ることができます
   - **価値がある理由**: Journal のエンドツーエンド暗号化と自動同期により、写真共有が安全かつ即時に行われます。
   - **開始方法**: 写真を選択して使用します`journal.add()`アップロード、監視`attachments`他の人の写真を順番に受信する

3. **共同注釈のためのドキュメントレビューツール**
   - **やるべきこと**: チーム メンバーが PDF ドキュメントを一緒に確認し、コメントやハイライトを個別に追加します。
   - **実行する価値がある理由**: PDF ファイルは通常 100MB 未満であるため、Journal に適しています。データに注釈を付けるために、Messenger を使用して完全なエクスペリエンスを作成できます。
   - **開始方法**: PDF ファイルはジャーナルの添付ファイルとして転送され、注釈の座標とテキストはメッセンジャーを通じてリアルタイムで同期されます。

4. **プレイリストを共有する音楽アプリケーション**
   - **やるべきこと**: 複数のユーザーが一緒にプレイリストを編集し、全員が曲を追加できます
   - **実行する価値がある理由**: オーディオ ファイル自体は Journal に送信されませんが、アルバム カバーやユーザー ノートなどのメタデータは Journal に送信され、迅速に同期できます。
   - **開始方法**: ジャーナルを使用してカバー画像とプレイリストの変更を同期し、メッセンジャーを使用して再生ステータスを同期します
