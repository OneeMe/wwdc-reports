## ハイライト

> Xcode 13 の Metal Debugger には、Acceleration Structure Viewer、GPU タイムライン、シェーダー検証、テクスチャ コンバーターが追加され、ライト トレース デバッグ、パフォーマンス分析、リソース作成のプロセス全体をカバーします。

## 主な内容

Metal アプリにはレンダリングの問題があります。画像にアーチファクトが発生したり、一部のシーンでフレーム レートが突然低下したりします。問題を正確に特定するにはツールが必要です。シェーダに問題があるのでしょうか?リソースのバインドに問題があるのでしょうか?それとも GPU パフォーマンスのボトルネックでしょうか?

Xcode 13 の Metal Debugger は今年メジャーアップデートされ、レイトレーシング、プロファイリング、テクスチャリングがカバーされます。

＃＃詳細

### Acceleration Structure Viewer

（[01:25](https://developer.apple.com/videos/play/wwdc2021/10157/?time=85)）

ライトトレースの加速構造はブラックボックスとなっており、問題があった場合のデバッグが困難です。 Xcode 13 では、BVH の階層を視覚化できる Acceleration Structure Viewer が追加されています。

GPU フレーム キャプチャでレイ トレーシング ディスパッチを選択し、バインドされたリソースでアクセラレーション構造を見つけて、クリックしてビューアを開きます。

ビューアの左側にインスタンス階層ツリーが表示され、右側に3Dプレビューが表示されます。インスタンスをクリックすると、その境界ボックス、プリミティブの数、および変換行列が表示されます。

（[02:00](https://developer.apple.com/videos/play/wwdc2021/10157/?time=120)）

**キーポイント:**
- GPU フレーム キャプチャでアクセラレーション構造を表示
- 左側のツリー構造はインスタンスの階層を示します。
- 右側の 3D ビューにはジオメトリが表示されます
- 各インスタンスのバウンディングボックスと変形を確認できます

### GPU Timeline

（[04:30](https://developer.apple.com/videos/play/wwdc2021/10157/?time=270)）

GPU タイムラインは、Xcode 13 の新しいパフォーマンス分析ビューです。タイムラインでの GPU 作業の実行を表示します。

タイムラインには次のことが表示されます。
- 各レンダー パスとコンピューティング ディスパッチの開始時刻と期間
- メモリ帯域幅の使用量
- タイルのメモリプレッシャー
- ステージ間の重複度

タイムラインを通じて、次の質問に答えることができます: どのパスが最も時間がかかりますか? GPU にはアイドル サイクルがありますか?帯域幅がボトルネックになっていますか?

（[05:15](https://developer.apple.com/videos/play/wwdc2021/10157/?time=315)）

**キーポイント:**
- タイムラインには、GPU ワークの実際の実行シーケンスが表示されます
- ズームインして単一パスの詳細を表示できます
- 色分けはさまざまな種類の作業 (レンダリング/コンピューティング/ブリット) を示します
- GPU カウンターを使用して特定のインジケーターを表示する

### Shader Validation

（[08:20](https://developer.apple.com/videos/play/wwdc2021/10157/?time=500)）

Xcode 13 は、新しい検出によりシェーダー検証の範囲を拡張します。

- 境界外のメモリアクセス
- 初期化されていない変数の使用
- ゼロ除算エラー
- NaN/Inf の伝播

有効にする方法: Scheme の Metal オプションで「Shader Validation」にチェックを入れます。

（[09:10](https://developer.apple.com/videos/play/wwdc2021/10157/?time=550)）

**キーポイント:**
- 開発中はオン、リリース時はオフ
- 一定のパフォーマンスのオーバーヘッドがあります
- リリースされたバージョンで再現するのが難しいシェーダーのバグを検出できる
- 頂点、フラグメント、計算シェーダーをサポート

### Texture Converter

（[12:00](https://developer.apple.com/videos/play/wwdc2021/10157/?time=720)）

Xcode 13 には、最新の GPU テクスチャ形式をすべてサポートする新しいコマンドライン テクスチャ変換ツールが追加されています。

```bash
# 把 PNG 转换为 ASTC 压缩纹理
xcrun textureconverter input.png -o output.astc -f ASTC_4x4_LDR

# 把 HDR 图像转换为 RGBM 编码
xcrun textureconverter input.hdr -o output.rgbm -f RGBM
```

（[27:51](https://developer.apple.com/videos/play/wwdc2021/10157/?time=1671)）

RGBM エンコードは、HDR 値を RGBA8 テクスチャにエンコードします。

```metal
// RGBM 编码
float4 encodeRGBM(float3 hdrColor) {
    float maxRGB = max(hdrColor.r, max(hdrColor.g, hdrColor.b));
    float M = saturate(maxRGB / 6.0);
    M = ceil(M * 255.0) / 255.0;
    float3 rgb = hdrColor / (M * 6.0);
    return float4(rgb, M);
}

// RGBM 解码
float3 decodeRGBM(float4 rgbm) {
    return rgbm.rgb * (rgbm.a * 6.0);
}
```

（[28:41](https://developer.apple.com/videos/play/wwdc2021/10157/?time=1721)）

**キーポイント:**
- Xcode ツールチェーンに統合されたコマンド ライン ツール
- ASTC、BC、PVRTC、その他の圧縮形式をサポート
- RGBM エンコーディングにより、HDR テクスチャを 8 ビットで保存できます
- ビルドスクリプトに統合可能

### Metal Texture Swizzles

（[30:55](https://developer.apple.com/videos/play/wwdc2021/10157/?time=1855)）

テクスチャ スウィズルを使用すると、シェーダ コードを変更せずに、サンプリング中にチャネルの順序を再配置できます。

```swift
let descriptor = MTLTextureDescriptor()
descriptor.swizzle = MTLTextureSwizzleChannels(
    red: .blue,
    green: .red,
    blue: .green,
    alpha: .one
)
```

（[30:55](https://developer.apple.com/videos/play/wwdc2021/10157/?time=1855)）

**キーポイント:**
- テクスチャ作成時にスウィズルを設定します
- すべてのサンプリング操作は自動的に適用されます
- さまざまな形式のソースデータの処理に適しています
- 実行時のオーバーヘッドがゼロ

### Reconstruct Normal from Height

（[31:55](https://developer.apple.com/videos/play/wwdc2021/10157/?time=1915)）

Xcode 13 のテクスチャ コンバータは、高さマップから法線マップを生成することをサポートしています。

```bash
xcrun textureconverter height.png -o normal.astc -f ASTC_4x4_LDR --generate-normal-map
```

（[31:55](https://developer.apple.com/videos/play/wwdc2021/10157/?time=1915)）

**キーポイント:**
- シングルチャンネルのハイトマップから 3 チャンネルのノーマルマップを生成
- 出力用に複数の圧縮形式をサポート
- 高さスケールとラップモードを指定できます

## 重要なポイント

1. **Acceleration Structure Viewer を使用してライト トレースの問題をデバッグします**。 BVH の境界ボックスが適切であるかどうか、およびインスタンスの変換が正しいかどうかを確認します。エントリ API: Xcode 13 GPU フレーム キャプチャ → 加速構造ビューア。

2. **GPU タイムラインを使用してパフォーマンスのボトルネックを特定します**。最も時間のかかるパスを見つけて、十分な並列オーバーラップがあるかどうかを確認します。エントリ API: Xcode 13 → Metal GPU タイムライン。

3. **開発中は常にシェーダー検証を有効にしてください**。範囲外アクセスや初期化されていない変数などのシェーダーのバグを捕捉します。入口 API: スキーム → メタル → シェーダー検証。

4. **テクスチャ コンバータを使用して、テクスチャ圧縮をビルド プロセスに統合します**。ソース テクスチャを GPU 圧縮形式に自動的に変換します。入口API：`xcrun textureconverter`。

5. **テクスチャ スウィズルを使用して、さまざまなチャネル順序でソース データを処理します**。フォーマットごとに個別のシェーダーを作成する必要はありません。入口API：`MTLTextureDescriptor.swizzle`。
