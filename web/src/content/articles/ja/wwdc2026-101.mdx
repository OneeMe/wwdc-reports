## ハイライト

> Apple は WWDC26 で iOS 27、iPadOS 27、macOS Golden Gate、watchOS 27、tvOS 27、visionOS 27 を発表しました。中心となるアップデートは、プラットフォームの応答性と Liquid Glass デザインの磨き込み、子ども向けの安全性とプライバシーツール、そして Apple と Google の協業による Foundation Models アーキテクチャを基盤にした Siri AI と次世代 Apple Intelligence です。

## 主要内容

### システム全体の磨き込み

これまで、アプリを開く、画面を切り替える、ファイルを転送するといった操作には、どこか一歩足りない感覚がありました。iOS 27 では重要なデータを事前に読み込むことで、iPhone と iPad のアプリ起動速度が 30% 向上します。開発者がコードを変更する必要はなく、システム層で自動的に処理されます。([10:28](https://developer.apple.com/videos/play/wwdc2026/101/?time=628))

写真を撮った後に Photos を開くと、新しい写真が表示される速度は 70% 向上します。AirDrop の転送速度は 80% 向上します。iPad に外付けドライブを接続してファイルを転送する速度は 5 倍になり、Mac の Finder と同じくらい速くなります。([11:07](https://developer.apple.com/videos/play/wwdc2026/101/?time=667))

さらに意外なのは、iPhone 11 も iOS 27 を利用できることです。Apple はもともと新しい機種だけに搭載していた高度な CPU スケジューラを最適化し、iPhone 11 以降に広げました。2019 年の端末が 2026 年でも滑らかに動き続けることになります。これは史上もっとも多くのユーザーを対象にする iOS バージョンです。([12:01](https://developer.apple.com/videos/play/wwdc2026/101/?time=721))

ネットワークの切り替えも賢くなりました。以前はカフェの入口に近づくと、弱い Wi-Fi をつかんだまま離さず、手動でモバイル通信に切り替える必要がありました。今の iPhone は、いつ接続を維持し、いつ離れるべきかを自動で判断します。帯域の細い環境で大きなファイルを送るとき、Messages は送信進捗インジケータを表示し、待たされているだけの状態をなくします。([12:33](https://developer.apple.com/videos/play/wwdc2026/101/?time=753))

検索も全面的に書き直された領域です。Spotlight、Photos、Mail の検索インデックスは再設計され、より安定し、効率的になりました。アップデート後、システムは自動的にインデックスを再構築し、新しい内容はほぼリアルタイムで取り込まれます。Mail には新しいランキングシステムも入り、探しているメールが Top Hits の先頭に出やすくなります。([13:41](https://developer.apple.com/videos/play/wwdc2026/101/?time=821))

### Liquid Glass デザインの進化

昨年導入された Liquid Glass デザイン言語は、今年さらに磨き込まれました。([06:46](https://developer.apple.com/videos/play/wwdc2026/101/?time=406)) Apple は複雑な背景コンテンツに対する Liquid Glass の拡散効果を最適化し、文字とコントロールを読みやすくしました。さらに、ultra clear から fully tinted まで調整できる透明度スライダーが追加され、ユーザーが自分で見え方を変えられます。Liquid Glass に対応済みのアプリは、このカスタマイズを自動的にサポートします。

macOS では、ツールバーがより統一されたデザインに戻り、サイドバーはウインドウの端まで伸び、アイコンには再び色がつき、ウインドウの角丸もより一貫したものになりました。アプリアイコン自体にも Liquid Glass のレイヤー感が増え、屈折効果によってよりシャープに見えます。([08:01](https://developer.apple.com/videos/play/wwdc2026/101/?time=481))

### 子どもの安全とペアレンタルコントロール

今年はペアレンタルコントロールが大きなテーマになりました。基本的な考え方は、子どもは一人ひとり違い、親が自分の子どもをもっともよく理解している一方で、システムは専門家の研究に基づくデフォルトの提案を用意すべきだというものです。([18:00](https://developer.apple.com/videos/play/wwdc2026/101/?time=1080))

追加された機能は次のとおりです。

- **Child Account**: 新しい子ども用アカウントでは、年齢に応じた保護が自動的に有効になります。既存アカウントも変換できます。13 歳未満では Ask to Buy と新しい **Ask to Browse** がデフォルトで有効になります。Ask to Browse では、新しい Web サイトにアクセスする前に親の承認が必要で、どちらの承認フローも Messages で処理されます。([19:54](https://developer.apple.com/videos/play/wwdc2026/101/?time=1194))
- **Time Allowances**: Entertainment、Games、Social Media といったカテゴリ別に 1 日の使用時間を設定できます。推奨値は年齢と米国小児科学会の研究に基づきます。13 歳未満ではソーシャルメディアがデフォルトで無効になります。([23:53](https://developer.apple.com/videos/play/wwdc2026/101/?time=1433))
- **Schedules**: 授業時間は学習アプリだけを残す、といった形で時間帯ごとに利用できるアプリを制御できます。Time Allowances と組み合わせれば、週末だけ映画のために追加時間を与えることもできます。([25:07](https://developer.apple.com/videos/play/wwdc2026/101/?time=1507))
- **Communication Safety の拡張**: 露出のあるコンテンツに加え、暴力的でショッキングな画像や動画も遮断します。FaceTime のリアルタイム通話も対象です。([23:14](https://developer.apple.com/videos/play/wwdc2026/101/?time=1394))
- **Screen Time の再設計**: 子どものデバイス利用状況をひと目で確認し、アクセス権限をワンタップで調整できます。([25:43](https://developer.apple.com/videos/play/wwdc2026/101/?time=1543))

開発者向けには、Apple は `Declared Age Range API` を提供します。アプリはプライバシーを守りながらユーザーの年齢帯を取得し、それに応じてコンテンツ表示を調整できます。Communication Safety API と Contact Approval API も、より安全な子ども向け体験の構築を助けます。([26:54](https://developer.apple.com/videos/play/wwdc2026/101/?time=1614))

### 次世代 Apple Intelligence と Siri AI

これは今年最大のアーキテクチャ変更です。Apple は Google と深く協業し、Gemini 技術を基盤にした次世代 Apple Foundation Models を構築しました。オンデバイス実行と Private Cloud Compute サーバー実行の両方に対応します。([29:29](https://developer.apple.com/videos/play/wwdc2026/101/?time=1769))

新しいアーキテクチャは 4 つの中核能力層で構成されます。

1. **Personal context understanding**: Spotlight のセマンティックインデックスを通じて、写真、メモ、メールなどを理解します。Spotlight に接続したすべてのアプリが参加できます。([30:57](https://developer.apple.com/videos/play/wwdc2026/101/?time=1857))
2. **Broad world knowledge**: Web から最新情報を取得し、Private Cloud Compute を通じて回答を生成します。([31:17](https://developer.apple.com/videos/play/wwdc2026/101/?time=1877))
3. **App Actions**: アプリのツールボックスから適切なツールを見つけ、メールの下書きや写真編集のようなリクエストを完了します。([31:31](https://developer.apple.com/videos/play/wwdc2026/101/?time=1891))
4. **On-screen awareness**: 現在使っているアプリと操作内容に基づいて、状況に合った支援を提供します。([31:45](https://developer.apple.com/videos/play/wwdc2026/101/?time=1905))

これらの能力はすべて新しい **System Orchestrator** によって調整されます。プライバシーについて、Apple は AI のプライバシーは妥協できないと強調しています。オンデバイス処理と Private Cloud Compute を組み合わせ、データは保存されず、Apple も第三者もアクセスできません。([32:17](https://developer.apple.com/videos/play/wwdc2026/101/?time=1937))

Siri は完全に再構築され、新しいバージョンは **Siri AI** と呼ばれます。複数ターンの会話、画面内容の認識、個人コンテキストの利用に対応し、新しい **Siri App** で会話履歴を振り返ることもできます。履歴は iCloud でプライベートに同期され、デバイスをまたいで会話を続けられます。([33:45](https://developer.apple.com/videos/play/wwdc2026/101/?time=2025))

Siri AI は **Visual Intelligence** ももたらします。iPhone の Camera アプリには新しい Siri モードが追加され、食べ物に向けると栄養情報を取得でき、請求書に向けると支払いを分割できます。macOS ではキーボードショートカットで起動し、画面上の内容を選択してそのまま質問できます。iPad ではスクリーンショット体験に統合されます。visionOS では、対象物を見ながら Siri に質問でき、「Hey Siri」と言う必要はありません。([47:20](https://developer.apple.com/videos/play/wwdc2026/101/?time=2840))

Writing Tools も強化されました。ゼロから文書の下書きを作成したり、Mail と Messages で特定の連絡先とのやり取りの文体をまねたり、自動校正したりできます。自動校正はシステム全体で使え、多くのサードパーティアプリにも対応します。([49:41](https://developer.apple.com/videos/play/wwdc2026/101/?time=2981))

## 詳細

### Siri AI の実際の利用場面

デモでは、Mike が Siri AI が日常場面で複数の能力をどうつなぐかを示しました。

**シナリオ 1: 世界知識と個人コンテキストの組み合わせ**

ユーザーが「Suki Waterhouse のサンフランシスコ公演はいつ？」と聞くと、Siri は Web から情報を取得して答えます。続けて「チケットはどう買うの？」と聞くと、抽選が必要だと答えます。その後「抽選が始まったらリマインドして」と言うと、Siri はリマインダーを作成します。最後に「彼女の新曲を再生して」と言うと、Music を開いて再生します。会話全体が自然につながります。([35:06](https://developer.apple.com/videos/play/wwdc2026/101/?time=2106))

**シナリオ 2: 画面認識と個人コンテキスト**

ユーザーが海辺の写真を見て「これはどこ？」と聞くと、Siri は Santa Cruz の Natural Bridges State Beach だと認識します。友人が近くに引っ越したことを思い出し、「Jeff の新しい家はどこ？」と聞くと、Siri は Messages の記録から住所を見つけます。そして「そのアーチまで案内して、途中で Jeff の家に寄って」と言うと、Siri は自動的にルートを計画します。([36:05](https://developer.apple.com/videos/play/wwdc2026/101/?time=2165))

**シナリオ 3: 複数ターンの創作会話**

ユーザーが「ワールドカップ開幕週末の試合予定は？」と聞くと、Siri は日程表を提示します。ユーザーは下にスクロールして会話モードに入り、「ブラジル対モロッコは観戦パーティに良さそう。両国を代表する料理を教えて」と言います。Siri は画像付きのメニュー案を出します。娘がデザートを持っていきたいと言っていたことを思い出し、「Maria が最近話していたデザートは何？」と聞くと、Siri は Messages から「ココナッツクッキー」を見つけます。最後に「これらを組み合わせてユニークなパーティメニューにして」と言うと、Siri は両国の料理を融合した創造的なメニューを生成し、そのままグループチャットに送れます。([39:56](https://developer.apple.com/videos/play/wwdc2026/101/?time=2396))

**シナリオ 4: macOS 上の Siri**

ユーザーが Spotlight から「物置に makerspace を作るには？」と聞くと、Siri は詳しい提案を出します。ユーザーは形式の異なる 3 つの見積書ファイルを選択し、Control-click して「これらを比較して、どれを選ぶべきか教えて」と聞きます。Siri は比較表を生成します。息子が電気の問題について話していたことを思い出し、「どれなら解決できる？」と聞くと、Siri は Messages から関連内容を見つけておすすめを出します。その後「Modular Workshops に、納期を早められるか聞く親しみやすいメールを書いて」と言うと、Siri は請負業者のメールアドレスと名前を自動抽出し、完全なメールを書きます。([43:01](https://developer.apple.com/videos/play/wwdc2026/101/?time=2581))

### Safari の AI 強化

Safari には今年、実用的な機能が 3 つ追加されます。

**Tab Topics**: Apple Intelligence が開いているタブを自動的にトピック別に分類します。閲覧中に新しく開いた関連ページは、対応するトピックに自動で追加されます。使い終わったらトピック全体をワンタップで閉じるか、Tab Group として保存できます。([52:28](https://developer.apple.com/videos/play/wwdc2026/101/?time=3148))

**Notify Me**: Web ページ上で待っている変化、たとえば「このキャンプの申込が始まる」といった内容を Safari に伝えてからタブを閉じます。Safari はバックグラウンドで監視し、変化を検出すると通知します。([53:28](https://developer.apple.com/videos/play/wwdc2026/101/?time=3208))

**Describe an extension**: 欲しいブラウザ拡張の機能を自然言語で説明すると、Safari が Web ページの内容を変更するカスタム拡張を自動生成します。たとえば「試したレシピを保存して評価するボタンをツールバーに追加して」といった指定ができます。([54:13](https://developer.apple.com/videos/play/wwdc2026/101/?time=3253))

### パスワードの自動修復

Passwords アプリは、弱いパスワードや漏洩したパスワードをワンタップで強いパスワードに自動更新できるようになりました。裏側では Apple Intelligence と Safari が連携し、各サイトに自動ログインして、パスワード変更ページへ移動し、更新フローをエージェントとして完了します。([54:37](https://developer.apple.com/videos/play/wwdc2026/101/?time=3277))

### Call Context

通話中、Phone アプリは Mail、Calendar などのアプリから関連情報を自動的に探します。たとえば航空会社に電話してフライトを変更する場合、Phone アプリは確認コードを自動的に見つけて表示できます。処理全体は完全にデバイス上で実行され、「誰に電話したか」だけを見て、「何を話したか」は聞きません。Apple も航空会社も内容を見ることはできません。([56:29](https://developer.apple.com/videos/play/wwdc2026/101/?time=3389))

### 自然言語で Shortcuts を作成

以前 Shortcuts を作るには、アクションノードを手動でドラッグする必要がありました。今はやりたいことをそのまま説明できます。たとえば「職場を出たら、Pedro に向かっているとメッセージし、到着予定時刻も添えて」と入力すると、Shortcuts はトリガー、ETA の計算、メッセージ送信を自動で組み立てます。調整が必要なら、「さらにお気に入りのポッドキャストを自動再生して」のように続けて説明できます。([59:14](https://developer.apple.com/videos/play/wwdc2026/101/?time=3554))

### Image Playground のアップグレード

Image Playground は Private Cloud Compute を使った photorealistic、つまり写真のようにリアルなスタイルに対応しました。Photos ライブラリ内の人物をもとに画像を生成したり、自然言語で写真のスタイルを変換したり、対象を囲って移動、拡大縮小、要素追加を行ったりできます。Web サイト向けの横長、チラシ向けの縦長など、複数サイズも追加されました。Contact Posters、ロック画面の壁紙、Messages の背景にも統合されます。([01:00:30](https://developer.apple.com/videos/play/wwdc2026/101/?time=3630))

開発者は **Image Playground API** を通じて、これらの機能を取り込めます。([01:02:27](https://developer.apple.com/videos/play/wwdc2026/101/?time=3747))

### Photos の AI 編集

新しいツールは 3 つです。

- **Clean Up の強化**: より高品質で自然な塗りつぶしを行い、複雑な場面にも対応できます。([01:03:20](https://developer.apple.com/videos/play/wwdc2026/101/?time=3800))
- **Extend**: 画像の境界を広げ、被写体に余白を持たせたり、内容を切り取らずに水平線をまっすぐにしたりできます。([01:03:41](https://developer.apple.com/videos/play/wwdc2026/101/?time=3821))
- **Spatial Reframing**: オンデバイスの空間モデルでリアルタイムプレビューし、カメラ位置を置き直したように写真の視点を調整できます。端で欠けた部分は Private Cloud Compute の生成モデルが埋め、視点がずれた部分だけに新しい内容を生成するため、元の場面との一貫性が保たれます。([01:04:23](https://developer.apple.com/videos/play/wwdc2026/101/?time=3863))

これらの機能は、古い写真や他のカメラで撮った写真を含む、ほぼすべての写真に使えます。([01:06:37](https://developer.apple.com/videos/play/wwdc2026/101/?time=3997))

### 開発者ツール

- **Foundation Models framework**: オンデバイスモデルが画像入力、カスタム skills、サーバーモデル、統一された Swift API に対応しました。Daydream アプリは実際の使い方を示しています。写真を選び、オンデバイスモデルで服のアイテムを認識し、ファッション知識を使ってコーディネートを提案します。([01:09:38](https://developer.apple.com/videos/play/wwdc2026/101/?time=4178))
- **Core AI framework**: すべてのプラットフォームで他のモデルを実行し、Apple Silicon の性能をフルに使って高速化します。これはまったく新しいフレームワークで、サードパーティモデルにも Apple 自社モデルと同等のハードウェアアクセラレーションを提供します。([01:10:27](https://developer.apple.com/videos/play/wwdc2026/101/?time=4227))
- **Xcode Coding Agent**: アプリ全体のローカライズ、シミュレートされたデバイスとのやり取り、カスタム skills、Gemini を含むモデル選択、Figma と GitHub への接続に対応します。([01:11:02](https://developer.apple.com/videos/play/wwdc2026/101/?time=4262))
- **Device Hub**: すべてのシミュレータと実機を管理する統一インターフェイスです。マルチタッチのシミュレーション、外観のワンタップ切り替え、サイズの動的調整に対応します。([01:11:21](https://developer.apple.com/videos/play/wwdc2026/101/?time=4281))

### その他の注目点

- **Photos 共有アルバム**: Android と Windows のユーザーも iCloud 共有アルバムに参加して写真を追加できるようになり、フル解像度共有にも対応します。([14:56](https://developer.apple.com/videos/play/wwdc2026/101/?time=896))
- **Health**: Cycle Tracking に閉経移行期と更年期のサポートが追加され、周期パターンの変化を識別し、症状を記録できます。([15:14](https://developer.apple.com/videos/play/wwdc2026/101/?time=914))
- **AirPods**: カスタム EQ が追加され、音質をさらにパーソナライズできます。([15:34](https://developer.apple.com/videos/play/wwdc2026/101/?time=934))
- **Vision Pro**: パノラマ写真を空間シーンに変換し、個人用環境として使えます。([15:47](https://developer.apple.com/videos/play/wwdc2026/101/?time=947))
- **Maps Flyover**: 航空画像と視覚知能モデルを組み合わせ、建物の細部、木の形、ガラスの反射がよりシャープに描画されます。([16:07](https://developer.apple.com/videos/play/wwdc2026/101/?time=967))

### 提供状況

Siri AI は初期段階では英語のみに対応し、その後すばやく多言語へ拡大されます。ベータ版は今年後半に提供されます。欧州連合では iOS と iPadOS で当面利用できず、Apple はプライバシーを保護する解決策を探しています。中国本土では、規制要件が解決されるまで Siri AI とその他の新しい Apple Intelligence 機能は利用できません。([01:08:16](https://developer.apple.com/videos/play/wwdc2026/101/?time=4096))

すべての Apple Intelligence 機能は、現在と同じ対応デバイスをサポートします。もっとも強力なオンデバイスモデルと、それに対応する機能、たとえば表現力豊かな音声や高度な音声入力は、もっとも高性能な iPhone、iPad、Mac でのみ利用できます。([01:07:54](https://developer.apple.com/videos/play/wwdc2026/101/?time=4074))

## 重要な示唆

**1. Siri AI の App Actions に対応する**

- **何をするか**: 自分のアプリを Siri AI から自然言語で呼び出せるようにします。
- **なぜ価値があるか**: Siri AI は複数ターンの会話、画面内容の理解、個人コンテキストの利用ができるようになりました。アプリが App Intents を公開していれば、ユーザーは Photos を手動で開かなくても「先週 Shasta で撮った写真を家族共有アルバムに追加して」と言えます。Line アプリはメッセージ内容を Spotlight にインデックスし、ユーザーが Siri にチャット履歴を直接探させられます。Structured カレンダーアプリは App Intents によって、Siri から直接イベントを作成できます。
- **始め方**: `AppIntents` フレームワークで中核操作を定義し、コンテンツが Spotlight にインデックスされるようにします。Session 345 (App Intents New) と 343 (App Intents Advanced) を参照してください。

**2. Image Playground API でパーソナライズされたコンテンツを作る**

- **何をするか**: Contact Posters、チャット背景、イベント招待状など、アプリ内でユーザーがカスタム画像を生成できるようにします。
- **なぜ価値があるか**: Image Playground は photorealistic スタイルに対応し、Private Cloud Compute でプライバシーも保護します。ユーザーは写真をサードパーティサービスにアップロードする必要がありません。
- **始め方**: `ImagePlayground` framework を使い、ユーザーの Photos ライブラリ内の人物とテキスト説明を渡します。

**3. Declared Age Range API でコンテンツを年齢に合わせる**

- **何をするか**: ユーザーの年齢帯に応じてアプリのコンテンツを動的に調整します。
- **なぜ価値があるか**: Apple は今年、子どもの安全を中核テーマに据えました。ペアレンタルコントロールは非準拠アプリを厳しく制限します。Age Range API に早めに対応すれば、ファミリー共有の文脈でアプリがブロックされにくくなります。13 歳未満の子どもではソーシャルメディアがデフォルトで無効になるため、アプリは年齢に応じて機能と内容を調整する必要があります。
- **始め方**: アプリ内で `DeclaredAgeRange` API を呼び出し、返された年齢帯に応じて表示内容と操作を調整します。

**4. Liquid Glass デザインに対応する**

- **何をするか**: iOS 27 / macOS Golden Gate 上で、自分のアプリが Liquid Glass 効果を正しく表示するようにします。
- **なぜ価値があるか**: ユーザーは Liquid Glass の透明度を ultra clear から fully tinted まで調整できます。アプリがすでにシステム提供の Liquid Glass API を使っていれば、これらの設定は自動的に反映されます。macOS ではサイドバーが端まで伸び、アイコンに色が戻り、ウインドウの角丸が統一されます。未更新のアプリも恩恵を受けます。
- **始め方**: 既存 UI がシステムの material とツールバー API を使っているか確認し、システム設定と衝突する独自実装を避けます。Session 269 (SwiftUI) と 289 (AppKit Modernization) を参照してください。

**5. Core AI と Foundation Models でローカルモデルを試す**

- **何をするか**: アプリにカスタムモデルを組み込むか、Apple の Foundation Models を呼び出し、完全ローカルまたは Private Cloud Compute 上で実行します。
- **なぜ価値があるか**: Foundation Models framework は画像入力、カスタム skills、サーバーモデル、統一 Swift API に対応しました。Core AI は新しいフレームワークで、サードパーティモデルをすべてのプラットフォームで Apple Silicon のフル性能を使ってローカル実行できます。Daydream アプリは、オンデバイスモデルで服を認識し、コーディネートを提案する実際の流れを示しました。
- **始め方**: Session 241 (Foundation Models)、324 (Core AI)、328 (MLX Swift) を見て、モデル変換と呼び出し方法を理解します。
