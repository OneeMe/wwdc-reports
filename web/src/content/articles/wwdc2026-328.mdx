## Highlight

> MLX Swift 把 NumPy 风格的数组计算带到了 Swift 里——写法和数学公式几乎一样，自动用 GPU 加速，还支持自动微分。如果你厌倦了在 Python 和 Swift 之间来回传数据，这是让你留在 Swift 生态里完成整个 ML 工作流的钥匙。

## 核心内容

### 1. 这场演讲解决什么问题

Apple 平台上的数值计算生态很丰富：Accelerate 做 CPU 向量运算、BNNS 做神经网络层、Metal Performance Shaders 做 GPU kernel、Swift Numerics 提供复数类型。但每个框架有自己的 API 风格和适用场景，开发者经常需要在多个层之间切换。

MLX Swift 提供了一个统一的、NumPy 风格的数组计算层。它的核心设计是：n 维数组（`MLXArray`）作为中心抽象，操作这些数组的代码读起来像数学公式，背后自动利用 GPU 加速和自动微分。

### 2. MLX Swift 基础：代码像数学

以一个经典的幂迭代（Power Iteration）算法为例——求矩阵最大特征值对应的特征向量：

```swift
import MLX

let n = 100
let steps = 10
let B = MLXRandom.normal([n, n])
var v = MLXRandom.normal([n])

// 构造对称矩阵 A = B^T + B
let A = B.T + B

// 幂迭代：v ← Av / ‖Av‖
for _ in 0 ..< steps {
    let Av = matmul(A, v)
    v = Av / norm(Av)
    eval(v)  // 强制求值，控制计算图大小
}

// 恢复特征值 λ = v^T A v
let lambda = matmul(matmul(v.T, A), v)
print(lambda)
```

关键点：

- `.T` 是转置，`+` 是矩阵加法，`matmul` 是矩阵乘法——和数学记号几乎一一对应
- `eval()` 强制立即执行，在循环中调用可以防止计算图无限增长
- 默认使用 GPU，不需要显式指定设备

### 3. 数组计算 vs 标量计算：Mandelbrot 集合

Mandelbrot 集合是展示数组计算威力的经典例子。先看标量版本的 Swift 代码：

```swift
// 纯 Swift，逐个像素计算
var counts = Array2D<Int>(width: w, height: h)

for y in 0 ..< h {
    for x in 0 ..< w {
        let c = Complex(xMin + Float(x) * xStep, yMin + Float(y) * yStep)
        var z = Complex<Float>.zero
        var limit = maxIterations
        for i in 0 ..< maxIterations {
            z = z * z + c
            if z.lengthSquared > radiusSquared {
                limit = i
                break
            }
        }
        counts[x, y] = limit
    }
}
```

嵌套循环、逐像素计算，性能受限于 Swift 的标量运算速度。MLX Swift 版本：

```swift
import MLX

// 在复数网格上并行计算 Mandelbrot
let x = linspace(-2.0, 0.5, count: w)
let y = linspace(-1.25, 1.25, count: h).reshaped(h, 1)
let c = x + y.asImaginary()

var z = MLXArray.zeros(like: c)
var counts = MLXArray.zeros(c.shape, dtype: .int16)

for _ in 0 ..< maxIterations {
    z = z * z + c                    // 迭代 z ← z^2 + c
    counts = counts + (abs(z) .< 2)  // 统计有界迭代次数
}
```

关键点：

- `linspace` + `reshaped` + `asImaginary()` 构造整个复数网格，没有显式循环
- `abs(z) .< 2` 是逐元素的布尔比较，返回和 `z` 同形状的 mask 数组
- 整个计算在 GPU 上并行执行，速度比标量版本快 orders of magnitude
- 代码更短、更易读，而且更接近数学描述

### 4. 卷积与迭代求解：热传导模拟

Jacobi 迭代是求解偏微分方程的经典方法。用 MLX Swift 的 `conv2d` 实现：

```swift
// Jacobi 迭代：用四个邻居的平均值更新每个点

let kernel = MLXArray(converting: [
    0,    0.25, 0,
    0.25, 0,    0.25,
    0,    0.25, 0,
]).reshaped(1, 3, 3, 1)

var temperature = heatSources

// 循环直到收敛
let next = conv2d(temperature, kernel, padding: 1)
temperature = which(heatMask, heatSources, next)
```

更进一步的 Successive Over-Relaxation（SOR）加速：

```swift
let ω: Float = 2.0 / (1.0 + sin(Float.pi / Float(max(M, N))))

let redMask   = checkerboard(rows: M, cols: N, phase: 0)
let blackMask = checkerboard(rows: M, cols: N, phase: 1)

// 更新红色格子（用黑色邻居）
let sorRed = ω * conv2d(temperature, kernel, padding: 1) + (1 - ω) * temperature
temperature = which(redMask, sorRed, temperature)
temperature = which(heatMask, heatSources, temperature)

// 更新黑色格子（用已更新的红色邻居）
let sorBlack = ω * conv2d(temperature, kernel, padding: 1) + (1 - ω) * temperature
temperature = which(blackMask, sorBlack, temperature)
temperature = which(heatMask, heatSources, temperature)
```

关键点：

- `conv2d` 不只是深度学习里的卷积，任何需要邻域平均的操作都可以用它
- `which(condition, a, b)` 是 MLX 的条件选择函数，相当于 `condition ? a : b` 的数组版本
- SOR 用棋盘格更新策略，红色和黑色格子交替更新，加速收敛
- `checkerboard` 生成布尔 mask，让数组操作只影响特定位置的元素

### 5. 自动微分：曲线拟合

MLX 的 `grad` 函数自动计算梯度，不需要手动写导数：

```swift
// 定义损失函数，然后用 autodiff 优化
func f(_ θ: MLXArray) -> MLXArray {
    θ[0] + θ[1] * x + θ[2] * x ** 2
}

func loss(_ θ: MLXArray) -> MLXArray {
    mean((f(θ) - y) ** 2)
}

var θ = zeros([numParams])
let gradLoss = grad(loss)  // 自动求导

for _ in 0 ..< steps {
    let g = gradLoss(θ)         // ∇L(θ)
    θ = θ - learningRate * g    // 参数更新
    eval(θ)                     // 强制求值
}
```

关键点：

- `grad(loss)` 返回一个新的函数，输入参数输出梯度
- 自动微分基于 lazy evaluation 的计算图，可以处理复杂的控制流
- 和 PyTorch 的 `autograd` 概念相同，但 API 更简洁

## 最佳实践

- **在循环中调用 `eval()`**：MLX 的 lazy evaluation 会累积计算图，循环中定期 `eval()` 可以防止内存爆炸
- **用数组操作替代循环**：如果发现自己写了嵌套循环遍历数组元素，停下来想想能不能用 `conv2d`、`where`/`which`、广播等数组操作替代
- **从 NumPy 迁移很直接**：大部分 NumPy 代码可以逐行翻译到 MLX Swift，API 设计高度一致
- **MLX 不只是深度学习**：任何需要大规模数值计算的场景（信号处理、物理模拟、金融建模）都可以考虑 MLX
- **注意数据类型**：`dtype` 默认可能是 float32，如果需要 float16 节省内存，显式指定
