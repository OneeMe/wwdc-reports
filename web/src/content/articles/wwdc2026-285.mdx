## Highlight

> Apple 终于给了 Swift 开发者原生的 USDKit——以前处理 USD 得捏着鼻子用 C++ 桥接，现在用 Swift 就能打开 Stage、遍历层级、编辑 Prim、导出压缩包。USD 正式成了 Apple 平台的一等公民。

---

## 核心内容

### 1. 这场演讲解决什么问题

USD（Universal Scene Description）是 3D 内容的通用语言，从 Pixar 起源，现在覆盖影视、游戏、工业、医疗等各个领域。但 Apple 平台上的开发者长期面临：

- 没有官方的 Swift API，只能用 C++ 桥接或社区库
- Mac 上缺少轻量级的 USD 编辑工具
- 网页上的 3D 内容缺乏标准格式支持

USDKit 和 OpenUSD 的更新把这些问题全解决了。

### 2. USDKit 基础：打开和遍历 Stage

```swift
import USDKit

// 创建一个新的内存 Stage
let stage = USDStage()

// 从文件打开 Stage
let url = URL(fileURLWithPath: "/ALab/entry.usda")
let stage = try USDStage.open(url)
```

**遍历层级：**

```swift
// 遍历所有 prim，查找特定对象
for prim in stage.descendants {
    if prim.name == "scope" {
        // 找到了！
    }
}

// 没找到就创建一个
let scope = stage.definePrim(at: "/World/scope", type: "Xform")

// 添加文件引用
try scope.references.add("/ALab/assets/scope.usda")
```

关键点：

- `USDStage()` 创建空 stage，`USDStage.open(url)` 从文件加载
- `stage.descendants` 遍历所有后代 prim
- `definePrim(at:type:)` 在指定路径创建 prim
- `references.add()` 引用外部 USD 文件，实现资产复用

### 3. 变换操作

```swift
// 自动创建 xformOp:translate 并更新 xformOpOrder
scope.addTransformOperation(type: .translate)
scope["xformOp:translate", as: USDValue.Vec3d.self] = [2.5, 0.0, -1.0]
```

关键点：

- `addTransformOperation` 自动管理 USD 的 transform stack
- 下标访问 `scope["xformOp:translate"]` 配合类型参数读写属性
- 支持 `.translate`、`.rotate`、`.scale` 等多种变换类型

### 4. 无障碍元数据

```swift
// 应用 AccessibilityAPI schema（多应用 schema，实例名为 default）
try scope.applyAPISchema("AccessibilityAPI", instanceName: "default")

// 创建 label 和 description 属性
scope.makeAttribute(named: "accessibility:default:label", as: .string)
scope.makeAttribute(named: "accessibility:default:description", as: .string)

// 设置值
scope["accessibility:default:label", as: String.self] = "Oscilloscope"
scope["accessibility:default:description", as: String.self] =
    "Vintage signal analyzer with a 3D wireframe display, topped by a color bar test monitor"
```

关键点：

- `applyAPISchema` 给 prim 添加标准 schema 的实例
- 无障碍信息让 VoiceOver 可以描述 3D 内容
- 这对教育应用和包容性设计很重要

### 5. 导出压缩包

```swift
let output = URL(fileURLWithPath: "/ALab/alab_compressed.usdz")

// 导出为 USDZ 包，启用压缩
try stage.exportPackage(
    to: output,
    options: [
        .preferSmallTextureFiles(quality: .standard),   // 压缩纹理
        .preferSmallMeshFiles                            // 压缩 mesh 几何
    ]
)
```

关键点：

- `.preferSmallTextureFiles(quality:)` 压缩纹理，`.standard` 是质量和体积的平衡点
- `.preferSmallMeshFiles` 压缩几何数据，减少文件体积
- 压缩后的 USDZ 更适合网络传输和存储

### 6. OpenUSD 标准的新进展

**Particle Fields（粒子场）—— Gaussian Splats 的标准化：**

Apple 与 NVIDIA、Adobe、Pixar 合作，在 USD 中引入了新的 primitive 类型 `Particle Fields`，可以描述 Gaussian Splats 和其他粒子表示：

- Gaussian Splats 用数百万个模糊粒子重建真实场景
- 现在可以和传统的 mesh、material 在同一个 USD scene 中混合使用
- 这是 3D 内容格式的重要演进

**OpenUSD 标准规范：**

- Apple 是 Alliance for OpenUSD 的创始成员
- 今年发布了核心 USD 的正式规范
- 几何、材质、物理等领域的规范正在制定中

**相关技术栈更新：**

- OpenUSD：场景描述核心
- MaterialX：材质描述（源自 Lucasfilm）
- OpenVDB：体积数据（源自 DreamWorks，今年新增支持）

### 7. Mac Preview App 的 3D 编辑能力

Mac 上的 Preview App 今年增加了 3D 编辑功能：

- 直接操作场景中的物体（移动、旋转、缩放）
- 切换材质显示模式（实体、线框、透明）
- 查看和编辑 USD 层级结构
- 导出修改后的文件

这让 Preview 从一个"查看器"变成了轻量级的 3D 编辑器，适合快速审查和调整。

### 8. Safari 的 `<model>` 标签

网页开发者现在可以用标准的 HTML `<model>` 标签嵌入交互式 3D 内容：

```html
<model src="product.usdz" alt="3D model of the product">
```

这打通了 Web 和 spatial computing 之间的内容管道，电商、教育、新闻等场景可以直接在网页中展示 3D 内容。

## 最佳实践

- **已有项目迁移**：如果正在用 RealityKit 的 `Entity.load` 加载 USDZ，考虑把"场景组装"逻辑迁移到 USDKit。用 USDKit 在内存里拼接多个 USDZ、调整位置、加元数据，再整体交给 RealityKit 渲染
- **新项目建议**：直接拥抱 USD 标准，放弃自己发明 JSON 格式描述 3D 场景。USDKit 的 `USDStage` 和 Composition 机制天生为"多部门协同、大场景管理"设计
- **路径硬编码陷阱**：USD 中 `/World/scope` 这样的路径是唯一的。尽量用遍历配合自定义 metadata 查找目标节点，不要写死路径
- **压缩策略**：发布前用 `exportPackage` 的 `.preferSmallTextureFiles` 和 `.preferSmallMeshFiles` 压缩，显著减少文件体积
- **无障碍支持**：为关键 3D 对象添加 `AccessibilityAPI` schema，让 VoiceOver 用户也能理解空间内容
