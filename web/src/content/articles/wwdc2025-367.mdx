## Highlight

> 这是一场高度浓缩的 recap，将 PSOTU 近一小时的内容压缩到约 4 分钟，覆盖 Liquid Glass、Foundation Models、Xcode 26、Swift 6.2、SwiftUI、Metal 4 等全部核心更新。

## 核心内容

每年 WWDC 一开场，PSOTU（Platforms State of the Union）会用近一小时把所有平台的技术更新讲一遍。开发者最大的痛点是：内容太密，信息流过得太快，一边记一边漏；事后想再回看，又不知道从哪条 Session 切入。

苹果今年给出的解法是这条 4 分钟的官方 Recap。它把 PSOTU 的全部主线压成快速剪辑，并且按主题切块——设计、AI、工具链、语言、UI、图形、闪电轮播——让你在一杯咖啡的时间里建立起本届 WWDC 的全局地图。看完这条视频，你能立刻判断：哪些更新与自己当前项目相关，需要去看哪些专题 Session。

## 详细内容

视频的节奏很紧凑，主持人用 7 段串讲覆盖了所有重点。

**Liquid Glass（[00:15](https://developer.apple.com/videos/play/wwdc2025/367/?time=15)）** 是新的动态材质，结合玻璃的光学特性与流体感，为内容带来层次和聚焦。配套工具 Icon Composer 支持模糊、半透明、高光测试，以及多种主题色下的图标预览。

**Foundation Models 框架（[00:57](https://developer.apple.com/videos/play/wwdc2025/367/?time=57)）** 让开发者直接调用端侧基础模型，专注日常任务，如文本提取、摘要等。模型在设备上运行，用户数据不出端，对开发者和用户都不收费。

**Xcode 26（[01:27](https://developer.apple.com/videos/play/wwdc2025/367/?time=87)）** 内置了对生成式编码模型的支持，自带 ChatGPT 接入，也可换其他模型。源码编辑器里新增 Coding Tools，相当于代码版 Writing Tools，可以让模型生成 preview、playground，或修复一处 issue。

**Swift 6.2（[01:57](https://developer.apple.com/videos/play/wwdc2025/367/?time=117)）** 主打性能、并发、互操作三件事。最实用的改动是可以把模块或单个文件配置为默认运行在 main actor 上，减少冗余的 `@MainActor` 标注。

**SwiftUI（[02:16](https://developer.apple.com/videos/play/wwdc2025/367/?time=136)）** 引入了新的 web API、3D Charts，以及富文本编辑：把 `TextEditor` 的 binding 从 `String` 换成 `AttributedString`，立刻得到一个支持样式定制的富文本编辑器。

**Metal 4（[02:45](https://developer.apple.com/videos/play/wwdc2025/367/?time=165)）** 专为 Apple Silicon 设计，带来 MetalFX 帧插值和降噪 API；Game Porting Toolkit 3 增加了对 Windows upscaling 的支持；Apple Vision Pro 开始支持 PlayStation VR2 Sense 控制器。

**闪电轮播（[03:21](https://developer.apple.com/videos/play/wwdc2025/367/?time=201)）** 把零碎更新一次性念完：Terminal 24 位色彩、新主题、powerline 字体；visionOS 上的 Apple Projected Media Profile（180/360 度沉浸式媒体）；CarPlay Live Activities；declared age range API；Accessibility Nutrition Labels；Family Sharing 与 Assistive Access 的更新。

整段视频的节奏告诉你一件事——本届 WWDC 的更新，纵深远不止 4 分钟能讲完，正片有超过 100 个 Session。

## 核心启发

- **做什么**：先看 Recap，再决定深入哪些 Session。
  - 为什么值得做：4 分钟可以建立全局认知，避免一头扎进 100+ Session 里迷失方向。
  - 怎么开始：按 Keynote → PSOTU → Recap → 专题 Session 的顺序刷一遍，看完 Recap 立刻列出要补看的 3–5 条。

- **做什么**：按自己当前的技术栈挑深入方向。
  - 为什么值得做：每年的更新覆盖面很广，但你真正会用到的只有 1–2 个领域，分散精力反而没收益。
  - 怎么开始：UI/设计走 Liquid Glass、Design、SF Symbols 7；AI/ML 走 Foundation Models；工具链走 Xcode 26、Swift 6.2；游戏/图形走 Metal 4；平台走 watchOS 26、visionOS 26。

- **做什么**：盯紧"闪电轮播"段，里头藏着小而美的改动。
  - 为什么值得做：Terminal 24-bit 色彩、CarPlay Live Activities、declared age range API、Accessibility Nutrition Labels 这种小更新，往往能直接命中你某条产品需求，且接入成本低。
  - 怎么开始：暂停在 [03:21](https://developer.apple.com/videos/play/wwdc2025/367/?time=201) 一项一项查，把和自己产品相关的 API 标记下来，一周内做一个最小试用 demo。

- **做什么**：把 Recap 当成给团队做内部分享的素材。
  - 为什么值得做：4 分钟视频比 60 分钟 PSOTU 更适合在周会上播放，PM、设计师、客户端同事都能跟上。
  - 怎么开始：播放完后准备 5–10 分钟讨论，让每个职能挑一项最关心的更新认领调研。
