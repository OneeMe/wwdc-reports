## Highlight

> Apple 把 NBA 场边视角的直播体验搬到了 Apple Vision Pro 上——8K 3D 视频 + 64 声道空间音频，通过 SMPTE 2110 IP 网络标准实时传输。这场演讲拆解了从摄像机采集到用户头显播放的完整直播管线，以及你可以用 VideoToolbox 和 AVFoundation 构建的工具。

## 核心内容

### 1. 这场演讲解决什么问题

Apple Immersive Video（AIV）之前主要是录播内容。今年 Apple 实现了直播——从 Lakers 比赛的真实场边视角，到 Vision Pro 里的沉浸式观赛体验。但 8K 3D 视频加上 64 声道空间音频，数据量是传统 2D 广播的 32 倍，传统 SDI 线缆和广播设备根本扛不住。

这场演讲介绍了 Apple 的解决方案：基于 SMPTE 2110 标准的 IP 网络传输，以及开发者可以用现有框架构建的生产工具。

### 2. 直播生产管线概览

一个典型的直播生产系统分为两个域：

- **Production Domain（制作域）**：摄像机采集、图形叠加、即时回放、音频混音
- **Delivery Domain（传输域）**：编码、封装、网络传输、用户播放

演讲聚焦制作域的关键组件：

| 组件 | 功能 | AIV 的特殊性 |
|------|------|-------------|
| Live Cameras | 多机位视频采集 | 8K 3D 双目，数据量巨大 |
| Graphics | 比分牌、字幕、动画 | 需要在 3D 空间中正确叠加 |
| Replay | 录制和即时回放 | 高帧率、低延迟要求 |
| Audio | 空间音频混音 | 64 声道，需要精确同步 |

### 3. SMPTE 2110：IP 网络传输标准

SMPTE 2110 是专业广播行业的 IP 传输标准，Apple 用它来处理 AIV 的实时数据流：

- **2110-20**：未压缩视频（或轻度压缩如 ProRes）
- **2110-30**：PCM 音频（64 声道空间音频）
- **2110-40**：辅助数据（逐帧 JSON 元数据）

元数据包含镜头校正参数、空间音频动态数据、场景描述等，与音视频帧严格同步。

### 4. 用 VideoToolbox 编码 AIV

在构建生产工具时，可以用 VideoToolbox 设置 AIV 特有的压缩属性：

```swift
import VideoToolbox

let compressionProperties: [String: Any] = [
    // ... 其他压缩参数 ...
    kVTCompressionPropertyKey_ProjectionKind as String:
        kVTProjectionKind_AppleImmersiveVideo
]
```

`kVTProjectionKind_AppleImmersiveVideo` 告诉编码器这是沉浸式视频，需要特殊的投影和封装处理。

录制和回放方面，利用 `AVAssetWriter` 和 Immersive Media Support 框架，可以直接把 ProRes 帧无损写入 MOV 文件：

- ProRes 提供视觉无损的压缩，适合制作域的存档和后期
- `ImmersiveMediaSupport` 框架处理 3D 视频的特殊封装需求
- 空间音频通过 `AVAudioEngine` 的 3D 音频 API 处理

### 5. 从制作到传输的关键挑战

演讲强调了 AIV 直播相比传统 2D 广播的几个独特挑战：

**带宽**：8K 3D 视频 + 64 声道音频需要 10GbE 甚至 25GbE/100GbE 网络。必须开启 IGMP Snooping 优化多播流量。

**同步**：视频、音频、元数据三路流需要在接收端精确同步。PTS（Presentation Time Stamp）必须严格对齐，否则画面边缘的畸变校正和声音的空间定位会出现撕裂。

**延迟**：直播要求端到端延迟控制在可接受范围。ProRes 的帧内压缩特性有助于降低编码延迟。

**硬件依赖**：M 系列芯片（尤其是 Ultra 级别）的 Media Engine 提供 ProRes 硬解硬编。Intel Mac 无法支撑实时 8K 3D 处理。

## 最佳实践

- **网络基础设施必须升级**：SMPTE 2110 需要万兆以上网络，普通千兆交换机无法支撑
- **元数据和音视频强绑定**：开发回放工具时，确保 JSON 元数据的 PTS 与 ProRes 视频帧严格对齐
- **全面拥抱 Apple Silicon**：Media Engine 的 ProRes 硬解硬编是实时处理的基石
- **从录播工具开始**：如果直播系统太复杂，先构建基于文件的工作流（录制 → 编辑 → 分发），再逐步加入实时组件
- **参考 WWDC25 的基础 session**："Learn about Apple Immersive Video technologies" 提供了 AIV 格式和技术的完整基础
