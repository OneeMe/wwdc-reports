## Highlight

> Apple 在 WWDC21 首日集中发布 iOS 15、SharePlay、Live Text、Universal Control、Xcode Cloud、Swift concurrency 和 Object Capture 等能力，开发者获得了面向协作、识别、自动化构建和 AR 内容生产的新入口。

## 核心内容

开发者看完 WWDC 第一天，常见问题很直接：今年先学什么，哪些新能力会影响自己的 App，哪些只是系统功能更新。

这段回顾把第一天压缩到两分多钟。它先从 iOS 15 开始，提到 Maps 的 3D 重新设计、Safari 的跨平台新外观、Live Text 对图片中文字的识别。随后转向 FaceTime、SharePlay、Apple TV、Find My、iCloud+、iPad 主屏幕、AirPlay to Mac 和 Universal Control。

对开发者来说，重点出现在几个地方。SharePlay 不只是系统视频通话功能，Apple 明确提到为开发者提供新的播放启动 API，并且这些 API 可以接入 App 现有的视频体验。Swift concurrency、SwiftUI、Object Capture for ARKit 和 Xcode Cloud 也在首日进入开发者工具链。

这场 session 的价值不是讲 API 细节。它的作用是给学习路线排序：先看 Keynote 建立全局视野，再看 Platforms State of the Union 找技术入口，最后按自己的 App 类型进入 SharePlay、Swift、Xcode Cloud、ARKit 等专题 session。

## 详细内容

### iOS 15：从系统体验开始影响 App 场景

（[00:13](https://developer.apple.com/videos/play/wwdc2021/10321/?time=13)）回顾先点出 iOS 15。Transcript 中列出的系统能力包括 Maps 3D redesigned（地图 3D 重新设计）、Safari 新外观、Live Text（实况文本）。这些能力会改变用户在 App 外部完成任务的方式，也会影响 App 的内容入口。

```text
iOS 15
- Maps: intuitive 3D redesign
- Safari: new look on iPhone, iPad, and Mac
- Live Text: text recognition in images
```

关键点：

- `iOS 15` 是首日平台更新的起点。
- `Maps` 的 3D 重新设计影响位置和导航类体验。
- `Safari` 在 iPhone、iPad、Mac 上同时变化，Web 内容和 App 深链要一起检查。
- `Live Text` 让图片中的文字变成可交互信息，适合票据、笔记、照片检索等场景。

### SharePlay：把同步播放接入现有视频体验

（[00:26](https://developer.apple.com/videos/play/wwdc2021/10321/?time=26)）FaceTime 新增 spatial audio（空间音频）和 Portrait mode（人像模式）。紧接着，SharePlay 支持和朋友同步共享屏幕、音乐、电视节目，覆盖 iPhone、iPad、Mac 和 Apple TV。

```text
SharePlay
- share your screen
- listen to music in sync
- watch a TV show in sync
- works across iPhone, iPad, Mac, and Apple TV
- new APIs to start playback inside an existing video experience
```

关键点：

- `share your screen` 说明 SharePlay 不只服务媒体播放，也服务协作演示。
- `in sync` 是核心约束，参与者看到或听到同一进度。
- `iPhone, iPad, Mac, and Apple TV` 说明体验需要跨设备保持一致。
- `new APIs to start playback` 是开发者入口，Apple 在回顾中明确把它和 App 现有视频体验连接起来。

### Universal Control：多设备工作流成为默认假设

（[01:05](https://developer.apple.com/videos/play/wwdc2021/10321/?time=65)）回顾提到 AirPlay coming to Mac（AirPlay 来到 Mac），随后展示 Universal Control（通用控制）。用户可以在不同设备之间移动，像使用一台设备一样操作，并且拖放文件。

```text
Universal Control
- move between different devices as if they were one
- drag and drop files between devices
```

关键点：

- `different devices` 指 Mac 和 iPad 这一类跨设备组合。
- `as if they were one` 说明输入焦点和指针移动要保持连续。
- `drag and drop files` 是具体交互，文件类 App 要检查拖放、导入、导出流程。

### Xcode Cloud、Swift concurrency、SwiftUI：开发工具链更新

（[01:43](https://developer.apple.com/videos/play/wwdc2021/10321/?time=103)）回顾后半段进入开发者内容。Transcript 连续提到 Xcode Cloud、Focus mode、Swift Playgrounds、Swift concurrency、SwiftUI、高端游戏开发工具、Object Capture for ARKit 和 SharePlay API。

```text
Developer tools and frameworks
- Xcode Cloud
- Focus mode
- Swift Playgrounds app building
- Swift concurrency
- SwiftUI
- high-end game development tools
- Object Capture for ARKit
- APIs for SharePlay
```

关键点：

- `Xcode Cloud` 指向 Apple 开发流程中的持续集成和交付能力。
- `Focus mode` 影响通知和用户注意力管理，App 需要尊重用户的专注状态。
- `Swift Playgrounds app building` 把 App 构建能力带到 Swift Playgrounds。
- `Swift concurrency` 是 Swift 并发模型入口，后续要继续看专题 session。
- `Object Capture for ARKit` 指向从现实物体生成 AR 内容的工作流。
- `APIs for SharePlay` 再次确认 SharePlay 有开发者 API 入口。

### Health、Wallet、Siri：系统服务打开新场景

（[01:18](https://developer.apple.com/videos/play/wwdc2021/10321/?time=78)）中段还提到 Walking Steadiness（步态稳定性）、Health App 的健康数据共享、Apple Watch 上的 Tai Chi、Pilates、mindfulness，以及 Wallet 中的 ID cards、Home Keys 和第三方设备上的 Siri。

```text
System services
- Walking Steadiness
- Health data sharing with family and doctors
- Tai Chi, Pilates, and mindfulness on Apple Watch
- ID cards in Wallet
- Home Keys in Wallet
- Siri on third-party devices
```

关键点：

- `Walking Steadiness` 把健康风险提示带入 Health 体验。
- `Health data sharing` 让家人和医生成为健康数据的使用场景。
- `Home Keys` 把 Wallet 扩展到门锁操作。
- `Siri on third-party devices` 说明语音入口会出现在更多家庭设备中。

## 核心启发

1. **做什么**：给视频 App 增加 SharePlay 观看入口。
   **为什么值得做**：回顾明确提到 Apple 提供新的播放启动 API，可以接入现有视频体验。
   **怎么开始**：先看 Group Activities 和 SharePlay 专题 session，确认同步播放、参与者状态和播放控制的框架入口。

2. **做什么**：给图片或扫描类 App 增加文字识别后的操作流。
   **为什么值得做**：Live Text 让图片中的文字成为用户可操作的信息。
   **怎么开始**：从照片、截图、票据、白板图片里提取文字，围绕复制、搜索、创建提醒事项设计下一步动作。

3. **做什么**：检查 iPad 和 Mac 之间的拖放导入流程。
   **为什么值得做**：Universal Control 把跨设备拖放文件变成首日重点展示的工作流。
   **怎么开始**：梳理 App 支持的文件类型，检查拖入、拖出、错误提示和导入后的状态恢复。

4. **做什么**：把项目接入 Xcode Cloud 的构建检查。
   **为什么值得做**：Xcode Cloud 在首日被放进开发者工具链，适合把构建、测试和分发前检查自动化。
   **怎么开始**：从一个主分支构建工作流开始，逐步加入测试、归档和 TestFlight 分发。

5. **做什么**：为 AR 展示类 App 建立 Object Capture 素材流程。
   **为什么值得做**：Object Capture for ARKit 出现在首日开发者能力列表中，说明 Apple 把真实物体到 AR 内容的生产流程前置。
   **怎么开始**：先选择一个小物体，拍摄多角度照片，继续阅读 Object Capture 专题资料，再把生成的 3D 内容接入 ARKit 展示。
