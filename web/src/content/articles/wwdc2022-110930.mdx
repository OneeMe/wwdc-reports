## Highlight

> Day 2 重点发布了 SwiftUI 导航新 API、Xcode 14 改进、Unity 的 Apple 框架插件、RoomPlan 3D 扫描、SF Symbols 多色支持，以及 iOS Push to Talk 框架。

## 核心内容

### SwiftUI 导航升级

Day 2 开场就是 SwiftUI 导航的新方案。iOS 16 引入了 `NavigationStack` 和 `NavigationSplitView`，解决了之前导航 API 在多平台适配上的痛点。（[00:09](https://developer.apple.com/videos/play/wwdc2022/110930/?time=9)）

`NavigationStack` 替代了原来的 `NavigationView`，支持程序化导航和深层链接。`NavigationSplitView` 为 iPad 和 Mac 提供了原生的多栏导航布局，不再需要自己用 `HStack` 拼凑。

### Xcode 14 改进

Xcode 14 带来了多项开发者体验提升。编译速度更快，尤其是 Swift 项目的增量编译。界面也有调整，开发者可以选择适合自己的信息密度级别。（[00:15](https://developer.apple.com/videos/play/wwdc2022/110930/?time=15)）

### Unity + Apple 框架

Apple 为 Unity 开发者推出了官方插件，让 Unity 游戏可以接入 Core Haptics、Game Center、ARKit 等 Apple 框架。Core Haptics 插件让游戏触感反馈达到新的沉浸级别。（[00:22](https://developer.apple.com/videos/play/wwdc2022/110930/?time=22)）

### RoomPlan 3D 扫描

RoomPlan 是一个全新的框架，利用 LiDAR 扫描仪快速创建室内空间的 3D 模型。扫描过程自动化，输出 USDZ 格式的 3D 模型。Apple 称之为"把现实世界带入 App 的强大新方式"。（[00:34](https://developer.apple.com/videos/play/wwdc2022/110930/?time=34)）

### SF Symbols 多色支持

SF Symbols 4 引入了多色渲染模式，开发者可以用颜色让符号表达更丰富的含义。系统会根据符号的语义自动应用合适的颜色层次。（[00:43](https://developer.apple.com/videos/play/wwdc2022/110930/?time=43)）

### Push to Talk 框架

iOS 16 新增了 Push to Talk 框架，让 App 可以实现对讲机功能。用户按住按钮说话，松开发送。这个框架管理后台音频和权限，开发者只需要处理业务逻辑。（[00:49](https://developer.apple.com/videos/play/wwdc2022/110930/?time=49)）

## 详细内容

### 技术专题分类

Day 2 的 Session 可以按技术栈分类：

**SwiftUI 开发者必看**：
- NavigationStack / NavigationSplitView：导航系统的完整重写
- 新 Layout 协议：自定义布局的官方方案
- Swift Charts：声明式图表

**游戏开发者关注**：
- Unity Apple 插件：Core Haptics、Game Center、ARKit
- Metal 3：新渲染特性

**AR/空间计算开发者关注**：
- RoomPlan：室内扫描和建模
- Object Capture 改进

**工具链升级**：
- Xcode 14：编译器、界面、调试
- Swift Package Manager 插件

### 导航 API 迁移建议

如果你在用 `NavigationView`，迁移到 `NavigationStack` 的优先级取决于项目复杂度。新项目直接用新 API，老项目可以逐步迁移。`NavigationSplitView` 只在 iPad 和 Mac 上有意义，iPhone 上会自动折叠。

## 核心启发

- **室内空间测量应用**：用 RoomPlan 扫描房间生成 3D 模型，自动计算面积、生成家具摆放预览。房产、装修、家具类 App 可以直接集成。入口 API 是 `RoomCaptureView` 和 `RoomBuilder`。

- **对讲机功能集成**：在协作类 App 中加入 Push to Talk 功能，比如工地管理、活动协调、团队协作。按住说话的体验比传统语音消息更即时。入口 API 是 `PushToTalkManager`。

- **多色图标系统**：利用 SF Symbols 的多色渲染模式，为 App 设计一套语义化的图标系统。不同状态用不同颜色层次表达，提升界面信息密度。入口 API 是 `Image(systemName:)` 配合 `.symbolRenderingMode(.multicolor)`。

- **Unity 游戏触感升级**：如果是 Unity 开发的 iOS 游戏，接入 Core Haptics 插件，为不同游戏事件设计精细的触感反馈。比如射击的后坐力、拾取物品的轻触、爆炸的震动。入口 API 是 Unity 的 Core Haptics 插件。
