## Highlight

> Apple 终于解耦了营销素材审核与 App 发版流程。Product Page Header、自定义搜索结果素材、Asset Library 独立审核，让你可以像运营网站一样灵活运营 App Store 页面，实时调整营销策略而不用等版本审核。

---

## 核心内容

### 1. 这场演讲解决什么问题

App Store 是大多数用户发现 App 的第一站，但长期以来，开发者对"门面"的控制力很有限：

- 产品页只能放截图和预览视频，品牌表达空间狭窄
- 搜索结果默认展示截图，无法突出核心卖点
- 想换一张营销 Banner 必须跟着 App 新版本一起提交审核
- 营销素材散落在各处，没有统一管理中心

这次 Apple 给了三个新能力：**Product Page Header**、**自定义搜索结果素材**、和 **Asset Library**。

---

### 2. Product Page Header：产品页的全新视觉入口

#### 2.1 什么是 Product Page Header

Product Page Header 是 App Store 产品页最顶部的视觉区域，用户进入产品页后第一眼看到的就是它。

与截图/预览视频不同，Header 素材**不局限于 App 界面**：

- 可以放品牌视觉、营销海报、场景图
- 支持**图片或视频**
- 与 App Icon、截图形成完整的品牌叙事

```
[Header: 品牌视觉/营销视频]
[App Icon + 名称 + 副标题]
[截图/预览视频轮播]
[描述 + 详情]
```

#### 2.2 使用场景

- **品牌展示**：用高质量的视觉素材传达品牌调性
- **功能亮点**：用视频动态展示核心功能
- **季节性营销**：节日主题、限时活动视觉
- **与网站保持一致**：把网站上的营销 Banner 同步到 App Store

---

### 3. 自定义搜索结果素材

#### 3.1 告别默认截图

以前 App Store 搜索结果中，你的 App 默认展示前几张截图。现在你可以**自定义搜索结果中展示的素材**：

- 用一张精心设计的图片或短视频代替默认截图
- 更精准地传达 App 的核心价值
- 在搜索结果中脱颖而出

#### 3.2 与 Apple Ads 联动

这些素材可以直接用于 Apple Ads 广告系列：

- Today 标签页广告
- 搜索结果广告
- 无需额外制作广告素材

#### 3.3 Custom Product Pages 整合

结合 Custom Product Pages（自定义产品页），你可以：

- 为不同的搜索关键词配置不同的搜索结果素材
- 从网站 deep-link 到特定功能的 Custom Product Page
- 保持从广告点击到 App 下载的一致性体验

---

### 4. Asset Library：素材的中央仓库

#### 4.1 独立审核，实时更新

Asset Library 是 App Store Connect 中新增的** centralized 素材管理中心**：

- 上传截图、预览视频、In-App Event 素材、营销图片/视频
- 素材可以**独立提交审核**，不需要绑定 App 版本
- 审核通过后，可以随时在产品页和搜索结果中切换使用

这意味着：

- 想换一张 Header 图？不需要发新版本，在 Asset Library 里切换即可
- 季节性营销活动？提前上传素材并通过审核，活动当天一键切换
- A/B 测试不同视觉？准备多套素材，用 Product Page Optimization 测试效果

#### 4.2 两种提交流程

**方式一：随版本提交**

在版本页面上传素材，与 App 一起提交审核。版本通过后，素材自动上线。

**方式二：Asset Library 独立提交**

1. 直接在 Asset Library 上传素材
2. 提交素材审核（不绑定任何版本）
3. 审核通过后，素材进入可用池
4. 随时在产品页或搜索结果中选用

#### 4.3 API 自动化

Asset Library 支持通过 **App Store Connect API** 自动化上传和管理：

```bash
# 上传素材到 Asset Library
curl -X POST \
  https://api.appstoreconnect.apple.com/v1/creativeAssets \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@marketing_banner.jpg"
```

Apple Ads Platform API 也支持自动化广告设置，包括 Swift 等语言的 open-source client library。

---

### 5. Preview 工具：上线前预览

App Store Connect 新增了 **Preview 功能**，让你在提交前就能看到素材在 App Store 上的实际效果：

- 支持 iPhone 和 iPad 预览
- 支持横屏和竖屏方向
- 支持多语言预览

这个工具特别重要，因为 Header 素材和 App Icon 在视觉上是紧挨着的，需要确认没有遮挡关键元素。

---

## 最佳实践

- **设计 Header 时注意遮挡**：Header 底部正中间的位置会被 App Icon 遮挡，不要把重要文字或按钮放在这个区域。务必用 Preview 工具确认。
- **建立素材管理规范**：从第一天起就在 Asset Library 里建立分类体系（截图、视频、Header、In-App Event 等），打标签、写描述，避免后期变成"素材垃圾场"。
- **提前准备季节性素材**：节假日营销活动需要提前 1-2 周准备素材并提交审核。利用 Asset Library 的独立审核流程，素材可以提前过审，活动当天直接切换。
- **用 PPO 做 A/B 测试**：Product Page Optimization 让你可以测试不同 Header 素材的转化效果。建议同时测试 2-3 套方案，跑满 14 天收集足够数据。
- **保持跨平台视觉一致**：网站、社交媒体、App Store 使用同一套视觉素材，降低用户认知成本。Custom Product Pages 可以 deep-link 到 App 内特定功能，保持从发现到使用的体验连贯。
- **搜索结果素材要"一眼懂"**：搜索结果中用户只扫一眼，素材必须在 1 秒内传达 App 的核心价值。避免复杂的界面截图，用简洁的视觉+文字组合。
