## Highlight

> Apple 为 App Store 产品页新增 Header 区域，搜索结果支持自定义图片和视频，并推出 Asset Library 将营销素材审核与 App 发版解耦，开发者可独立上传、审核和替换素材。

## 核心内容

### 产品页和搜索结果的视觉升级

以前，用户在 App Store 上发现你的 App 时，第一眼看到的只有截图和预览视频。这些素材虽然能展示功能，但很难传递品牌调性或营销信息。

（[00:56](https://developer.apple.com/videos/play/wwdc2026/205/?time=56)）Apple 现在为产品页新增了 **Product Page Header**。这是用户进入产品页后看到的第一个视觉元素，可以用图片或视频来展示品牌视觉、营销活动或核心卖点。Header 与 App Icon、截图配合，让用户更快理解 App 的价值。

（[01:48](https://developer.apple.com/videos/play/wwdc2026/205/?time=108)）搜索结果也发生了变化。以前默认展示 App 截图，现在可以上传一张更有冲击力的图片或一段视频，让 App 在搜索结果列表中脱颖而出。

### 素材审核与发版解耦

（[05:16](https://developer.apple.com/videos/play/wwdc2026/205/?time=316)）最大的变化是 **Asset Library**。以前换一张产品页 Banner 需要跟着 App 新版本一起提交审核，运营节奏被研发发版周期卡住。现在 Asset Library 把截图、预览视频、In-App Event 媒体和新的营销素材（Creative Assets）全部集中管理。你可以直接上传 Header 和搜索结果的素材并单独提交审核，不用更新 App 版本。

审核通过后，这些素材可以直接在产品页和搜索结果之间切换使用，不需要再次审核。比如夏天用一张登山素材做 Header，到了冬天直接在 Asset Library 里换成冬季版本，点击发布即可生效。

（[07:16](https://developer.apple.com/videos/play/wwdc2026/205/?time=436)）这套流程也支持 App Store Connect API 自动化上传和提交，Apple Ads Platform API 则可以自动化广告投放。

### 与 Custom Product Pages 配合

（[02:30](https://developer.apple.com/videos/play/wwdc2026/205/?time=150)）新素材和 Custom Product Pages（CPP，自定义产品页面）结合使用效果更好。比如你的 Yoga App 在官网推广"夏季瑜伽挑战"活动，用户点击后跳转到对应的 CPP。你可以为这个 CPP 配置专门的 Header 素材，保持官网和 App Store 的视觉一致。用户下载 App 后，通过 Deep Link 直接进入瑜伽活动页面，从广告到下载到 App 内体验形成完整链路。

（[03:17](https://developer.apple.com/videos/play/wwdc2026/205/?time=197)）你还可以针对不同搜索关键词配置不同的搜索结果素材。用户搜"瑜伽"看到一套素材，搜"冥想"看到另一套，让搜索结果更贴合用户意图。

## 详细内容

### 提交审核的两种方式

**方式一：通过版本页面提交**

（[04:30](https://developer.apple.com/videos/play/wwdc2026/205/?time=270)）在 App Store Connect 的版本页面上传素材，使用新的 Preview 工具预览产品页在 iPhone 和 iPad、不同屏幕方向、不同语言下的效果，确认无误后随版本一起提交审核。版本通过审核后，素材同步上线。

**方式二：通过 Asset Library 独立提交**

（[05:19](https://developer.apple.com/videos/play/wwdc2026/205/?time=319)）直接在 Asset Library 上传 Creative Assets 并单独提交审核。这个流程不需要更新 App 版本，也不需要预先指定素材将用于哪个位置。审核通过后素材进入 Asset Library，随时可以在产品页 Header 和搜索结果之间调配使用。

### Product Page Optimization 支持新素材

（[03:38](https://developer.apple.com/videos/play/wwdc2026/205/?time=218)）App Store Connect 中的 Product Page Optimization（PPO）现在支持用 Header 和搜索结果素材做 A/B 测试。你可以测试不同视觉方案，看哪种更能打动目标用户。

### 代码示例：处理 Custom Product Page 的 Deep Link

用户从外部营销链接进入 App 时，需要识别 CPP 参数并路由到对应页面。

```swift
func scene(_ scene: UIScene, continue userActivity: NSUserActivity) {
    guard userActivity.activityType == NSUserActivityTypeBrowsingWeb,
          let url = userActivity.webpageURL,
          let components = URLComponents(url: url, resolvingAgainstBaseURL: true) else {
        return
    }

    // 链接格式: https://yourapp.com/promo/summer-yoga?cpp=summer_challenge
    if let cppId = components.queryItems?.first(where: { $0.name == "cpp" })?.value {
        Router.shared.navigateToPromoPage(campaignId: cppId)
    }
}
```

关键点：
- `NSUserActivityTypeBrowsingWeb` 识别 Universal Link 唤起场景
- 从 URL query 参数中提取 `cpp` 标识，对应 Custom Product Page 的 campaign ID
- `Router` 根据 campaign ID 导航到 App 内对应的活动页面
- 需要在 App Store Connect 中为 CPP 配置对应的推广链接，才能正确归因

### 代码示例：在 App 内展示 StoreKit 产品页并附加追踪参数

在 App 内推荐其他 App（或同矩阵 App）时，可以带上营销追踪参数。

```swift
import StoreKit

func presentStoreProductPage(for appID: String, campaign: String) {
    let storeVC = SKStoreProductViewController()
    storeVC.delegate = self

    let parameters: [String: Any] = [
        SKStoreProductParameterITunesItemIdentifier: appID,
        SKStoreProductParameterCampaignToken: campaign
    ]

    storeVC.loadProduct(withParameters: parameters) { [weak self] success, error in
        if success {
            self?.present(storeVC, animated: true)
        }
    }
}
```

关键点：
- `SKStoreProductParameterITunesItemIdentifier` 指定目标 App 的 ID
- `SKStoreProductParameterCampaignToken` 附加营销活动标识，用于追踪转化来源
- `loadProduct` 异步加载产品页数据，成功后再 present
- 可额外传入 `SKStoreProductParameterProviderToken` 和 `SKStoreProductParameterAdvertisingPartnerToken` 做更细粒度的归因

## 核心启发

- **做季节性/节日营销自动化**：提前在 Asset Library 上传全年各节点的营销素材并过审，到了时间点直接在 App Store Connect 切换，不用等开发打包。配合 App Store Connect API 可以做成完全自动化的营销日历。

- **做搜索关键词定向素材**：为不同搜索关键词配置不同的搜索结果素材。用户搜"记账"展示简洁效率风，搜"理财"展示资产增长图表，让素材匹配搜索意图，提升点击率。

- **做官网到 App 的无缝链路**：官网 campaign 页面、App Store CPP、App 内落地页三套视觉保持一致。用户从广告到下载到使用，全程不跳出品牌语境。用 Universal Link 把 CPP 参数带进 App，新用户第一次打开就直接看到活动页。

- **做素材 A/B 测试流水线**：用 Product Page Optimization 测试不同 Header 素材的转化效果。同时测试品牌向素材（强调视觉调性）和功能向素材（强调核心卖点），用数据指导设计方向。

- **做跨 App 矩阵互推**：在自家 App 内用 `SKStoreProductViewController` 推荐同矩阵的其他 App，带上 campaign token 追踪互推效果。Asset Library 里的素材可以直接复用到 Apple Ads，一套素材多渠道使用。
