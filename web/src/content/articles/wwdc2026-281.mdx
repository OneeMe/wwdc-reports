## Highlight

> RCP 3 的插件系统让工程师写的自定义 Component 和 System 可以直接在编辑器里运行——艺术家调参数时实时看到效果，不需要等工程师打包 App。这是把 RCP 从"场景预览器"变成"游戏引擎编辑器"的关键一步。

---

## 核心内容

### 1. 这场演讲解决什么问题

在 visionOS 项目团队中，工程师和艺术家通常这样协作：

- 艺术家在 RCP 里摆模型、调材质
- 工程师在 Xcode 里写 Component 和 System 实现游戏逻辑
- 艺术家想看自定义逻辑的效果，必须等工程师编译、打包、部署

这个循环每次都要几分钟甚至更久，严重拖慢迭代速度。RCP 3 的插件系统让工程师写的代码以动态库形式被 RCP 加载，艺术家可以直接在编辑器里调试自定义属性。

### 2. 项目结构：Xcode + RCP 共享仓库

典型的项目结构：

```
ChaparralVillage/
├── ChaparralVillage.xcodeproj      # Xcode 项目
│   ├── ChaparralVillage (App)      # 最终 App target
│   └── RCPCustomComponents (Plugin) # RCP 插件 target
├── ChaparralVillage.rcproject      # RCP 项目
└── .git/                           # 共享 Git 仓库
```

- Xcode 项目有两个 scheme：一个 Build App，一个 Build Plugin
- RCP 项目通过 simulation bar 链接到 Xcode 项目
- 导入的 USD 文件会被转换为内部 JSON 格式，可以用 Git 管理
- RCP 自带自定义 merge 工具，比标准 git merge 冲突更少

### 3. 创建自定义 Component

```swift
import RealityKit

// 定义一个表示水位高度的 Component
public struct Cauldron: Component, Codable {
    public var waterLevel: Float

    enum CodingKeys: CodingKey {
        case waterLevel
    }
}
```

关键点：

- Component 必须遵循 `Component` 和 `Codable` 协议
- `Codable` 让 RCP 可以在 Inspector 中序列化和编辑属性
- 属性必须是基础类型（Float、Int、Bool 等）或符合 Codable 的自定义类型

### 4. 创建自定义 System

```swift
import RealityKit

public struct CauldronSystem: System {
    let query = EntityComponentQuery(Cauldron.self)
    public init(scene: Scene) {}

    public func update(context: SceneUpdateContext) {
        for (entity, cauldron) in context.entities(matching: query) {
            guard let water = entity.findEntity(named: "Cauldron_Water_mesh")
                else { continue }
            water.setPosition(SIMD3<Float>(0, 1, 0) * cauldron.waterLevel, relativeTo: entity)
        }
    }
}
```

System 驱动 Component 的行为。上面的例子中，`CauldronSystem` 每帧查找所有带 `Cauldron` component 的 entity，根据 `waterLevel` 调整水面 mesh 的位置。

### 5. 编写 RCP 插件

```swift
import RealityComposerPro

final class RCPCustomComponentsPlugin: RealityComposerProPlugin {
    public func setup(context: any RealityComposerProContext) {
        context.registerComponent(Cauldron.self)
        context.registerSystem(CauldronSystem.self)
    }
}

@_cdecl("createRealityComposerProPlugin")
public func createRealityComposerProPlugin() -> UnsafeMutableRawPointer {
    return RCPCustomComponentsPlugin().passRetained()
}
```

关键点：

- 插件是一个动态库（.framework），RCP 3 在启动时加载
- `setup(context:)` 中注册所有自定义 Component 和 System
- `@_cdecl("createRealityComposerProPlugin")` 是插件的入口点，RCP 通过这个名字找到插件实例

### 6. Component 与 ShaderGraph 联动

自定义 Component 的属性可以驱动 ShaderGraph material 的参数：

```swift
public struct Cauldron: Component, Codable {
    public var waterLevel: Float
    public var rotationSpeed: Float
    public var minWaterLevel: Float
    public var maxWaterLevel: Float
    public var vortexCoeff: Float
}

public func update(context: SceneUpdateContext) {
    for (entity, cauldron) in context.entities(matching: query) {
        guard let water = entity.findEntity(named: "Cauldron_Water_mesh") else { continue }
        water.setPosition(SIMD3<Float>(0, 1, 0) * cauldron.waterLevel, relativeTo: entity)

        guard var model = water.components[ModelComponent.self] else { continue }
        guard var mat = model.materials.first as? ShaderGraphMaterial else { continue }
        let surface = computeSurface(cauldron: cauldron)
        try? mat.setParameter(name: "Level Radius", value: .float(surface.levelRadius))
        try? mat.setParameter(name: "Lowest Point", value: .float(cauldron.waterLevel - surface.lowestPoint))
        try? mat.setParameter(name: "Height Change", value: .float(surface.heightChange))
        try? mat.setParameter(name: "Level Coeff", value: .float(surface.levelCoeff))
        try? mat.setParameter(name: "Is Level", value: .bool(surface.isLevel))
        model.materials[0] = mat
        water.components.set(model)
    }
}
```

关键点：

- System 每帧更新 Component 属性，并把这些值写入 ShaderGraph material 的参数
- 艺术家在 RCP 的 Inspector 中调 `waterLevel`，水面位置和波纹效果实时变化
- `ShaderGraphMaterial.setParameter(name:value:)` 支持 `.float`、`.bool`、`.vector` 等类型

### 7. 自定义 Action 和 Timeline 动画

```swift
import RealityKit

// 定义一个自定义 Action：设置水位
public struct SetWaterLevelAction: EntityAction, Codable {
    public let startWaterLevel: Float
    public let endWaterLevel: Float

    public var animatedValueType: (any AnimatableData.Type)? { Transform.self }
}

extension SetWaterLevelAction {
    static func subscribe() {
        Task { @MainActor in
            SetWaterLevelAction.subscribe(to: .updated) { event in
                let normalizedTime = (event.playbackController.time - event.startTime) / event.duration
                let action = event.action
                let currentLevel = action.startWaterLevel +
                    Float(normalizedTime) * (action.endWaterLevel - action.startWaterLevel)
                guard let entity = event.targetEntity else { return }
                guard var cauldron = entity.components[Cauldron.self] else { return }
                cauldron.waterLevel = currentLevel
                entity.components.set(cauldron)
            }
        }
    }
}
```

在插件中注册 Action：

```swift
final class RCPCustomComponentsPlugin: RealityComposerProPlugin {
    public func setup(context: any RealityComposerProContext) {
        context.registerComponent(Cauldron.self)
        context.registerSystem(CauldronSystem.self)
        context.registerAction(SetWaterLevelAction.self)
        SetWaterLevelAction.subscribe()
    }
}
```

关键点：

- `EntityAction` 是可以放在 RCP Timeline 上的动画片段
- `subscribe(to: .updated)` 在动画播放过程中每帧回调，实现属性插值
- 注册后，艺术家可以在 RCP 的 Sequencer 中拖入这个 Action，像使用内置动画一样

### 8. 暴露给 Script Graph

```swift
import RealityKit
import RealityKitScripting
import RealityKitScriptingMacros

@Scriptable
public struct Cauldron: Component, Codable {
    public var waterLevel: Float
    public var rotationSpeed: Float
    public var minWaterLevel: Float
    public var maxWaterLevel: Float
    public var vortexCoeff: Float
}
```

```swift
public func setup(context: any RealityComposerProContext) {
    // ... 注册 component、system、action

    Task { @MainActor in
        let config = RKS.Configuration(id: "ChaparralVillage")
            .onInitialize { _ in
                [
                    Module("ChaparralVillage") {
                        Cauldron.SchemaProvider.schema
                    }
                ]
            }
        try! RKS.addConfiguration(config)
    }
}
```

关键点：

- `@Scriptable` 宏自动生成 Component 的 schema，让 Script Graph 可以读写属性
- `RKS.Configuration` 注册脚本模块，让 Script Graph 的节点列表中出现自定义类型
- 这样不写代码的设计师也能通过可视化脚本控制自定义逻辑

## 最佳实践

- **项目结构**：Xcode 项目和 RCP 项目放在同一个 Git 仓库，两个 scheme 分别 Build App 和 Build Plugin
- **调试技巧**：Plugin 崩溃会带走整个 RCP 3，开发时在 Xcode 中 Attach to Process 连上 RCP 3 进程断点调试
- **首次加载**：RCP 3 首次加载插件会弹窗询问是否 Trust，CI/CD 环境需要处理这个信任授权
- **性能注意**：System 的 `update` 每帧调用，避免 heavy 计算。需要复杂逻辑时考虑分帧处理或缓存
- **团队协作**：工程师负责 Plugin 代码，艺术家负责在 RCP 中调参和摆场景，通过 Git 协作
