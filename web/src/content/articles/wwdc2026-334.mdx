## Highlight

> macOS 27 预装了 `fm` 命令行工具，同时发布了 `apple_fm_sdk` Python 包——这意味着你不需要建 Xcode 项目，在终端里打一行命令就能调用 Apple Foundation Models，而且可以用 Python 写完整的评估流水线和自动化脚本。

---

## 核心内容

### 1. 这场演讲解决什么问题

之前想用 Apple Foundation Models，你必须写 Swift 代码、建 Xcode 项目。对于数据科学家、ML 工程师、或者喜欢写 shell 脚本的开发者来说，这个门槛太高了。这场演讲介绍了两种新的访问方式：

- **`fm` CLI**：macOS 27 预装的命令行工具，支持交互式聊天和脚本化调用
- **Python SDK**：`apple_fm_sdk` 包，支持 tool calling、guided generation 等完整功能

### 2. fm CLI：终端里的 AI 助手

`fm` 是 macOS 27 预装的命令，开箱即用，不需要 API Key。

最简单的用法：

```bash
$ fm respond "Provide a basic regex in Swift to parse an email address"
```

切换模型（端侧 vs 云端）：

```bash
$ fm respond "Provide a comprehensive regex..." --model pcc
```

传入图片做多模态推理：

```bash
$ fm respond "What app is the user using in this screenshot?" \
    --model pcc --image Screenshot.png
```

用 schema 约束输出格式：

```bash
$ fm schema object --name AppsIdentified --string app_names --array > schema.json

$ fm respond "What apps are the user actively using?" \
    --image Screenshot.png --model pcc --schema schema.json
# {"app_names": ["Messages", "Mail", "Calendar"]}
```

交互式聊天模式：

```bash
$ fm chat
> What is the capital of France?
> And what about Spain?
/model pcc    # 切换到 PCC 模型
/save         # 保存会话
```

关键点：

- `fm respond` 适合脚本和自动化，`fm chat` 适合探索和调试
- `--model pcc` 切换到 Private Cloud Compute 的更强模型
- `--schema` 让模型输出结构化 JSON，配合 `jq` 在 shell 脚本中处理
- `--image` 支持直接传入图片做多模态分析

### 3. 用 fm CLI 做自动化脚本

结合 shell 脚本，`fm` 可以自动化各种日常任务。比如自动分类文件：

```bash
fm schema object --name "TriagedFileList" \
    --string 'final_files' --array \
    --string 'draft_files' --array > /tmp/schema.json

output=$(fm respond \
    --instructions "I just completed a project..." \
    "This is the list of all files:\n\n${files_list}" \
    --schema /tmp/schema.json)

echo "${output}" | jq -r '.final_files[]' | while read -r file; do
    cp "${DIRECTORY_TO_TRIAGE}/${file}" "${FINAL_FILES_STORAGE_DIRECTORY}"
done

echo "${output}" | jq -r '.draft_files[]' | while read -r file; do
    mv "${DIRECTORY_TO_TRIAGE}/${file}" "${DRAFT_FILES_STORAGE_DIRECTORY}"
done
```

### 4. Python SDK：完整的编程接口

安装：

```bash
pip install apple_fm_sdk
```

基础用法：

```python
import apple_fm_sdk as fm

INSTRUCTIONS = "You're an AI assistant for Cupertino Mart..."

async def answer_question(prompt: str) -> str:
    session = fm.LanguageModelSession(instructions=INSTRUCTIONS)
    return await session.respond(prompt)
```

Tool Calling：

```python
class GetPastOrdersTool(fm.Tool):
    name = "get_past_orders"
    description = "Retrieves information about this user's past orders."

    @fm.generable("Past orders query parameter")
    class Arguments:
        number_orders: str = fm.guide("How many of the last orders to retrieve")

    @property
    def arguments_schema(self) -> fm.GenerationSchema:
        return self.Arguments.generation_schema()

    async def call(self, args: fm.GeneratedContent) -> str:
        number_orders = args.value(int, for_property="number_orders")
        return await Orders.load_last_orders(
            user_id=user_id, amount=number_orders
        )
```

Structured Output：

```python
@fm.generable("Suggested items")
class ItemsSuggestion:
    item_names: list[str] = fm.guide("Names of the suggested items")

async def generate_suggested_cart_items(user_input: Optional[str]) -> ItemsSuggestion:
    session = fm.LanguageModelSession(
        instructions=INSTRUCTIONS,
        tools=load_tools()
    )
    prompt = """Using the tools to load the user's previous orders,
                return a list of items they might be interested in again."""
    if user_input is not None:
        prompt += f"\nAccount for: {user_input}"
    return await session.respond(prompt, generating=ItemsSuggestion)
```

关键点：

- Python SDK 的 API 和 Swift 的 Foundation Models Framework 几乎一一对应
- `fm.Tool` 基类让模型可以调用你的 Python 函数
- `@fm.generable` 宏和 Swift 的 `@Generable` 功能相同，生成结构化输出
- 可以和 Pandas、NumPy、Jupyter 等 Python 生态工具无缝集成

## 最佳实践

- **CLI 适合快速原型和自动化**：用 `fm respond` 测试 prompt、用 shell 脚本做文件处理等批处理任务
- **Python SDK 适合评估流水线和数据分析**：结合 Pandas 做批量 prompt 评估，用数据驱动的方式优化 AI 功能
- **生产环境仍用 Swift**：CLI 和 Python SDK 的定位是开发和评估工具，生产环境的 iOS/macOS App 应该用 Swift 原生 Foundation Models Framework
- **善用 schema 约束输出**：无论是 CLI 还是 Python，用 schema 让模型返回结构化数据，比解析自由文本可靠得多
- **PCC 模型需要网络**：`--model pcc` 会走 Private Cloud Compute，确保你的使用场景符合隐私要求
