## Highlight

> 网页里的 3D 模型可以一键"破框"，把用户拉进真实比例的虚拟环境。只需要 HTML `` `model` `` 标签和 `requestImmersive()` API，就能让用户从 Safari 直接"走进"剧院、密室或任何你设计的空间。而且网页 UI 还能作为 2D 窗口悬浮在 3D 场景旁边。

---

## 核心内容

### 1. 这场演讲解决什么问题

以前要在 visionOS 上做沉浸式体验，要么写原生 App，要么用 WebXR 处理兼容性。Web 端最多只能展示一个可旋转的 3D 模型。

现在 Apple 在 Safari 中加入了 Immersive API：

- 网页中的 3D 模型可以进入全沉浸式环境
- 保持网页可见，作为 2D 窗口悬浮
- 可以和 Fullscreen API 同时使用（比如沉浸式环境 + 全屏视频）
- 只需要几行 JavaScript

### 2. 基础：HTML Model Element

```html
<model src="teapot.usdz"></model>
```

加上环境贴图增强反射效果：

```html
<model src="teapot.usdz"
       environmentmap="kitchen.hdr">
</model>
```

`src` 是 USDZ 格式的 3D 模型，`environmentmap` 是 360 度环境光照图。可以用 Blender 等工具创建和导出。

### 3. Inline Preview：在页面中预览环境

以剧院选座网站为例：

```html
<div class="seat-preview">
    <model id="theater"
           src="theater-model.usdz"
           environmentmap="theater-lighting.hdr">
    </model>
</div>
```

默认情况下模型会缩放到元素边界内。要自定义视角，需要设置 `entityTransform`：

```javascript
const theater = document.getElementById("theater");

async function updateModelTransform() {
    await theater.ready;
    const transform = new DOMMatrix();
    // 将模型下移 1 米，模拟人眼高度
    transform.translateSelf(0, -1.0, 0);
    theater.entityTransform = transform;
}

updateModelTransform();
```

结合座位数据调整视角：

```javascript
function buildTransform(seat) {
    const transform = new DOMMatrix();
    const { x, y, z, ry } = seat;
    // 旋转和位移匹配座位位置和朝向
    transform.rotateSelf(0, -ry, 0);
    transform.translateSelf(-x, -y, -z);
    // 人眼高度偏移
    transform.translateSelf(0, -1.0, 0);
    return transform;
}
```

### 4. 进入沉浸式环境

检测功能可用性：

```javascript
if (document.immersiveEnabled) {
    immersiveButton.hidden = false;
}
```

请求沉浸式过渡：

```javascript
immersiveButton.addEventListener("click", async () => {
    await model.requestImmersive();
});
```

**Inline 和 Immersive 的坐标系差异**：

- Inline：原点在元素中心，比例遵循 CSS
- Immersive：原点在用户脚下（地板），比例对应真实世界

需要为两种模式分别计算 transform：

```javascript
function buildTransform(seat, immersive) {
    const transform = new DOMMatrix();
    // 座位变换逻辑...
    if (immersive) {
        // 沉浸式模式下旋转，避免舞台被 Safari 窗口遮挡
        transform.rotateSelf(0, 45, 0);
    } else {
        // Inline 模式下的人眼高度偏移
        transform.translateSelf(0, -1.0, 0);
    }
    return transform;
}
```

监听沉浸式状态变化：

```javascript
theater.addEventListener("immersivechange", () => {
    const isImmersive = !!document.immersiveElement;
    const transform = buildTransform(isImmersive, currentSeat);
    theater.entityTransform = transform;
    document.body.classList.toggle("immersive", isImmersive);
});
```

### 5. Video Docking：视频融入环境

视频可以从网页"停靠"到 3D 环境中的指定表面（如电视屏幕）：

```javascript
const trailerVideo = document.getElementById("trailerVideo");
const demoButton = document.getElementById("demoButton");

demoButton.addEventListener("click", async () => {
    await trailerVideo.requestFullscreen();
});
```

需要在 USDZ 模型中用 RealityKit 注释标记视频停靠区域。视频的光照会自然投射到周围环境，增强真实感。

### 6. 模型动画

在视频播放结束后触发环境动画：

```javascript
const trailerVideo = document.getElementById("trailerVideo");
const escapeRoom = document.getElementById("escapeRoom");

trailerVideo.addEventListener("ended", async () => {
    await document.exitFullscreen();
    escapeRoom.play();  // 播放 USDZ 中的动画
});
```

可以用 `currentTime` 属性控制动画时间线，实现多阶段环境变换。

### 7. 性能优化

环境模型通常比普通 3D 模型更复杂，需要优化：

```bash
# 压缩 USDZ 纹理
usdcrush model.usdz -o optimized.usdz
```

优化策略：

- **减少顶点数**：删除用户视角看不到的网格
- **减少 entity 数**：合并相关 mesh（如桌子及其上的物品）
- **使用低模接收阴影**：为 Scene Understanding 单独创建简化网格
- **简化 shader**：将光照烘焙到纹理，使用 unlit 材质
- **压缩纹理**：用 `usdcrush` 减小文件体积，加快加载

### 8. 延迟加载策略

如果不需要 inline 预览，可以隐藏模型元素：

```html
<model id="escapeRoom"
       src="escape-room.usdz"
       environmentmap="room-lighting.hdr"
       style="display: none">
</model>
```

这样资源不会预下载，直到 `requestImmersive()` 时才加载，节省带宽和内存。

```javascript
enterButton.addEventListener("click", async () => {
    showLoadingAnimation();
    try {
        await escapeRoom.requestImmersive();
    } catch (error) {
        console.log(error);
    } finally {
        hideLoadingAnimation();
    }
});
```

## 最佳实践

- **提供明确的退出方式**：虽然用户可以用 Digital Crown 退出，但 UI 中也要显示退出按钮
- **监听 `immersivechange` 事件**：UI 布局需要根据沉浸式状态更新
- **优化 3D 资产**：减少顶点、合并 mesh、烘焙光照、压缩纹理
- **使用延迟加载**：不需要 inline 预览时隐藏模型，节省资源
- **为两种坐标系分别计算 transform**：inline 和 immersive 的原点和比例不同
- **保持主内容可见**：沉浸式环境从 Safari 窗口后方打开，确保主要内容不被遮挡
