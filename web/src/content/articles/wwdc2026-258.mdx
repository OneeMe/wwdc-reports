## Highlight

> Xcode 27 把工作区定制、Coding Agent、Device Hub 和本地化工具打包升级，让开发流程更顺畅。主题系统、独立 Swift 文件编辑和 Agent 驱动的 String Catalogs 翻译是今年的亮点。

---

## 核心内容

### 1. 这场演讲解决什么问题

Xcode 是开发者每天花最多时间的工具，哪怕一个小改进也能累积成巨大的效率提升。Xcode 27 从工作区外观、项目创建、Agent 集成、设备调试和本地化五个维度做了全面升级。

### 2. 全新工作区外观

**Toolbar 重构**：

- 历史导航和编辑器控制从 jump bar 移到 Toolbar
- 构建进度显示在窗口标题下方
- 分支选择器移到底部栏，支持长分支名
- **Toolbar 完全可定制**：添加、删除、重新排序控件

**编辑器模式切换器**（三向选择器）：

- Canvas 模式：显示 Previews 和 Playgrounds
- Assistant 模式：显示相关内容
- Source Control 模式：查看代码变更

### 3. 主题系统

Xcode 27 引入了完整的主题系统：

- **预设主题**：Emerald、Neon Noir、Coral Reef 等
- **自定义调色板**：通过滑块调整文字和背景强度
- **背景渐变**：高背景强度下产生鲜艳的渐变效果
- **每个项目独立主题**：不同项目可以用不同主题快速区分
- **深色模式支持**：深色模式下主题可以非常鲜艳和富有表现力

字体也使用类似的定制系统：代码、散文、控制台的基础字体作为调色板，修改后会自动影响其他编辑器。

### 4. 内联问题提示改进

- **预测性问题**（live issues）使用更 subtle 的外观，减少打字时的干扰
- 构建时的问题以完整强度颜色显示
- 代码修改后，Xcode 自动预测问题，使用与主题融合的背景色

### 5. 快速创建项目

Xcode 27 简化了新项目创建流程：

- 从 File 菜单选择项目类型
- SwiftUI 项目选 **App**
- 无 UI 项目选 **macOS Command Line Tool**
- 库项目选 **Framework**

不需要先填 bundle ID，直接进入编辑器。

### 6. Coding Agent 集成

Xcode 27 把 Coding Agent 深度集成到编辑器中：

- **Toolbar 中心入口**：直接启动 Agent 对话
- **Tab 和分屏支持**：Agent 对话可以作为独立标签页或分屏
- **`/plan` 命令**：让 Agent 先规划再动手
- **String Catalogs 翻译**：Agent 可以自动翻译本地化字符串
- **Organizer 性能修复**：Agent 可以分析性能问题并生成修复方案

### 7. Device Hub

Device Hub 整合了模拟器和真机调试：

- 同一窗口管理所有设备
- 支持捏合、双指滚动等手势
- 可动态调整 iOS App 尺寸（测试 resize 适配）
- iPhone Mirroring 窗口缩放测试

### 8. 本地化更新

- **Agent 驱动的 String Catalogs 翻译**：自动翻译 UI 文案
- **上下文感知翻译**：Agent 理解 UI 上下文，提供更准确的翻译
- **人工校对流程**：Agent 生成翻译后，开发者可以逐项审核

### 9. 性能优化

- Xcode 27 体积减小 30%
- Apple Silicon only，组件后台下载
- 构建速度提升

---

## 最佳实践

- **为不同项目设置不同主题**：快速区分相似的项目，比如用 Neon Noir 做个人项目，Standard 做工作项目
- **利用独立 Swift 文件做原型**：不需要创建完整项目，直接打开 `.swift` 文件用 `#Preview` 测试 UI
- **渐进式采用 Agent**：先从 String Catalogs 翻译和 Organizer 性能分析开始，逐步扩展到代码生成
- **保持 Cmd + B 的习惯**：虽然内联问题提示变淡了，但定期构建仍然是发现问题的最佳方式
- **用 Device Hub 测试 resize**：iOS App 现在支持多种尺寸，确保在 Device Hub 中测试不同比例
