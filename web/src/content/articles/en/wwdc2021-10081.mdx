## Highlight

> iOS 15 launches virtual screen controller`GCVirtualController`, converts touch input to game controller input, and existing`GCController`Code compatible; also supports adaptive trigger effects for the PlayStation DualSense controller.

## Core Content

### Pain points of mobile game control

Games ported from console platforms to iOS/iPadOS are often designed to use two analog sticks, a d-pad, and number buttons.Developers have reported that it is difficult to build consistent, good-feeling, and beautiful-looking touch input for these games.Touch input handling code has a different path than keyboard, mouse, and game controller input code, increasing maintenance costs.([06:13](https://developer.apple.com/videos/play/wwdc2021/10081/?time=373))

### Solutions for virtual controllers

Apple has launched a new virtual screen controller specifically to address these issues.These screen controls:

- **Exquisite appearance**: Carefully adjusted for different hand grip positions, quick response
- **Code Unification**: The virtual controller is represented in the code as`GCController`Object, using the same input processing logic as the physical controller
- **Customizable**: Supports custom symbols, colors, and styles while maintaining the iOS/iPadOS design language
- **Adaptive Layout**: Automatically adjust layout according to configuration

The core principle of the virtual controller is that the left and right areas are configured independently, and the layout is determined by the configuration.Each side can contain 0-4 buttons, as well as a joystick, D-pad, or touchpad.([07:22](https://developer.apple.com/videos/play/wwdc2021/10081/?time=442))

### Game Controller Framework Basics

The goal of the Game Controller framework is to allow developers to easily support various efficient, low-latency input methods on Apple platforms.By abstracting input hardware through a common API, developers only need to write input code once and don't need to worry about how inputs are remapped or differ between different controllers.([00:40](https://developer.apple.com/videos/play/wwdc2021/10081/?time=40))

On iOS, iPadOS, and tvOS, players can create system-wide and per-app game controller input remaps to make games more customizable and accessible.([01:04](https://developer.apple.com/videos/play/wwdc2021/10081/?time=64))

## Detailed Content

### Controller connection and disconnection processing

Basic pattern for handling controller connections and disconnections: ([01:27](https://developer.apple.com/videos/play/wwdc2021/10081/?time=87))

```swift
import GameController

// 监听控制器连接通知
NotificationCenter.default.addObserver(
    self,
    selector: #selector(controllerDidConnect),
    name: .GCControllerDidConnect,
    object: nil
)

// 监听控制器断开通知
NotificationCenter.default.addObserver(
    self,
    selector: #selector(controllerDidDisconnect),
    name: .GCControllerDidDisconnect,
    object: nil
)

@objc func controllerDidConnect(_ notification: Notification) {
    let controller = notification.object as? GCController
    // 设置输入处理或轮询控制器状态
}

@objc func controllerDidDisconnect(_ notification: Notification) {
    let controller = notification.object as? GCController
    // 清理控制器相关资源
}
```

Key points:
- System creation or removal when controller is connected or disconnected`GCController`object
- send`GCControllerDidConnect`and`GCControllerDidDisconnect`notify
- The same pattern applies to`GCKeyboard`and`GCMouse`object
- Option to set value change handler or poll input status

### Create virtual controller

Steps to create a virtual controller: ([08:42](https://developer.apple.com/videos/play/wwdc2021/10081/?time=522))

```swift
import GameController

// 创建配置对象
let configuration = GCVirtualControllerConfiguration()

// 设置左侧元素
configuration.leftThumbstick = true
configuration.leftButtons = [GCInputButtonOptions.a]

// 设置右侧元素
configuration.rightThumbstick = true
configuration.rightButtons = [
    GCInputButtonOptions.a,
    GCInputButtonOptions.b
]

// 创建虚拟控制器
let virtualController = GCVirtualController(configuration: configuration)

// 连接控制器，触发 GCControllerDidConnect 通知
virtualController.connect()
```

Key points:
- `GCVirtualControllerConfiguration`Define the layout of the virtual controller
- Each side can be configured with a joystick, direction keys or touchpad (choose one of the three)
- Can be configured with 0-4 buttons per side
- call`connect()`Afterwards, the virtual controller behaves as a standard`GCController`object
- Configurations are fixed when created, elements can be shown and hidden, but cannot be added or removed

### Customize button appearance

Customize the button appearance of the virtual controller: ([09:17](https://developer.apple.com/videos/play/wwdc2021/10081/?time=557))

```swift
// 获取按钮配置
if let buttonA = virtualController.controller?.extendedGamepad?.buttonA {
    // 创建自定义形状（如旋转攻击图标）
    let attackPath = UIBezierPath()
    attackPath.move(to: CGPoint(x: 0.5, y: 0))
    attackPath.addLine(to: CGPoint(x: 1, y: 1))
    attackPath.addLine(to: CGPoint(x: 0, y: 1))
    attackPath.close()

    buttonA.path = attackPath
}

if let buttonB = virtualController.controller?.extendedGamepad?.buttonB {
    // 创建跳跃图标
    let jumpPath = UIBezierPath()
    jumpPath.move(to: CGPoint(x: 0.2, y: 0.8))
    jumpPath.addLine(to: CGPoint(x: 0.5, y: 0.2))
    jumpPath.addLine(to: CGPoint(x: 0.8, y: 0.8))
    jumpPath.close()

    buttonB.path = jumpPath
}

// 隐藏按钮
if let buttonX = virtualController.controller?.extendedGamepad?.buttonX {
    buttonA.isHidden = true
}
```

Key points:
- pass`path`Properties set custom shape for button
- use`UIBezierPath`Create vector graphics
- `isHidden`Property can show or hide the button
- Custom shapes should be simple and clear, suitable for quick recognition

### DualSense Adaptive Trigger

The PlayStation DualSense controller's adaptive trigger technology dynamically applies varying resistance based on player behavior, enhancing immersion.It can simulate the feeling of pulling a bow string, a slingshot under tension, etc.([10:45](https://developer.apple.com/videos/play/wwdc2021/10081/?time=645))

Steps to support adaptive triggers: ([12:06](https://developer.apple.com/videos/play/wwdc2021/10081/?time=726))

```swift
import GameController

// 获取当前控制器
guard let controller = GCController.current else { return }

// 验证是否为 DualSense 控制器
guard let dualSense = controller.physicalInputProfile as? GCDualSenseGamepad else {
    return
}

// 获取右自适应扳机
let rightTrigger = dualSense.rightAdaptiveTrigger

// 玩家瞄准时应用阻力
func updateSlingshotResistance(isAiming: Bool, pullAmount: Float) {
    if isAiming {
        if pullAmount < 1.0 {
            // 未完全拉回，应用反馈效果
            // FeedbackEffect 提供恒定阻力
            let feedbackEffect = GCAdaptiveTriggerFeedbackEffect(
                strength: pullAmount
            )
            rightTrigger.applyEffect(feedbackEffect)
        } else {
            // 完全拉回，应用振动效果
            // VibrationEffect 让扳机振动，模拟保持张力
            let vibrationEffect = GCAdaptiveTriggerVibrationEffect(
                strength: pullAmount,
                frequency: 0.5
            )
            rightTrigger.applyEffect(vibrationEffect)
        }
    } else {
        // 不瞄准时关闭效果
        rightTrigger.applyEffect(nil)
    }
}

// 玩家发射弹弓后关闭效果
func fireSlingshot() {
    rightTrigger.applyEffect(nil)
}
```

Key points:
- examine`physicalInputProfile`Is it`GCDualSenseGamepad`type
- `rightAdaptiveTrigger`and`leftAdaptiveTrigger`Access left and right adaptive triggers
- `GCAdaptiveTriggerFeedbackEffect`Provide constant resistance
- `GCAdaptiveTriggerVibrationEffect`Make the trigger vibrate
- Remember to call after use`applyEffect(nil)`Turn off effect

### App Store Tagging and Customization

Add Game Controllers capability in Xcode to mark the app as supporting game controllers: ([03:10](https://developer.apple.com/videos/play/wwdc2021/10081/?time=190))

1. Open project settings
2. 选择 Signing & Capabilities
3. 添加 Game Controllers capability

This will add game controller capabilities to the app's Info.plist, and the App Store will add a "Controller Support" badge to the app.Apps will also be included in the per-app customization section of the game controller preferences.([03:22](https://developer.apple.com/videos/play/wwdc2021/10081/?time=202))

### Correct glyphs in UI

Displaying the correct button glyphs in the UI is important.Different controllers have different button layouts:

- MFi or Xbox controller: Show Y button
- PlayStation Controller: Show triangle button

The correct glyph should be displayed even if the player remaps the button in the system remapping UI.([03:36](https://developer.apple.com/videos/play/wwdc2021/10081/?time=216))

```swift
// 获取与动作关联的按钮
guard let buttonA = controller.extendedGamepad?.buttonA else { return }

// 获取按钮的 SF Symbols 名称
let symbolName = buttonA.sfSymbolsName

// 创建系统图像
if let symbolName = symbolName, let image = UIImage(systemName: symbolName) {
    // 在 UI 中显示图像
    buttonImageView.image = image
}
```

Key points:
- `sfSymbolsName`Property returns the system symbol name of the button
- use`UIImage(systemName:)`Create image
- This will automatically reflect system remapping
- Another method is to display positional relationships (such as "top button") instead of specific button names

### Share button and screen capture

Controllers that support the Share button allow players to capture the screen and record video: ([03:46](https://developer.apple.com/videos/play/wwdc2021/10081/?time=226))

- Double-click the Share button: capture screenshot to photo album
- Long press the Share button: start and stop ReplayKit recording

iOS 15 adds a 15-second highlight clip feature.Players can turn on automatic background buffering and long press to save the last 15 seconds of game footage at any time.([13:31](https://developer.apple.com/videos/play/wwdc2021/10081/?time=811))

Global or per-app settings can be toggled in the Game Controller preferences panel.If you want to trigger your own highlight clips at important moments in the game, there is a dedicated API available.
