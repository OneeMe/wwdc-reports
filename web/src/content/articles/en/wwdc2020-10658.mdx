## Highlight

> Apple 在 2020 年把 Schoolwork 2.0、ClassKit Catalog API、Apple School Manager 与 Classroom 集成、Shared iPad Temporary Session 和 Mac 上的 Automatic Assessment Configuration 放进同一套教育应用接入路线。

---

## 核心内容

教育 app 的难点通常不在一节课本身，而在它如何进入学校的日常流程。教师要布置活动，学生要从作业进入正确内容，IT 管理员要批量管理账号、设备和 app。一个做得很好的学习功能，如果不能出现在 Schoolwork、Classroom 或 Shared iPad 的流程里，学校很难把它稳定用起来。

这场 session 先把入口讲清楚。Schoolwork 2.0 换了新的 Handout 和 Student 视图，教师可以从 App Activity Chooser 把 ClassKit app 的活动加入作业。新的选择器会显示缩略图和摘要信息，作业详情页会显示时间、完成百分比和测验分数。这里的展示效果不由 Schoolwork 单独完成，它依赖 app 通过 ClassKit 提供元数据和进度。

接着，Apple 把内容发现从本机 context store 推到更早的环节。过去，教师通常要先下载 app、打开并浏览某个活动，app 才会把 `CLSContext` 发布给 ClassKit。ClassKit Catalog API 改变的是这个发现路径：开发者可以用 Web API 发布 app 的公开活动，只要 app 已安装，教师就能在 Schoolwork 的 Activity Chooser 中看到这些活动。

学校端也在变得更连贯。Apple School Manager 创建的班级会自动出现在 Classroom 和 Schoolwork，学生用 Managed Apple ID 登录后会进入对应班级。Classroom 还可以把 app 启动到正确的 ClassKit 活动。Shared iPad 新增 Temporary Session，学生没有 Apple ID 也可以临时使用设备，登出后本次数据会删除。

最后一块是考试。Automatic Assessment Configuration Framework 来到 Mac，并支持 iOS、macOS 和 Catalyst。考试 app 可以让系统在测试期间禁用屏幕共享、Universal Clipboard、Dictation 等可能影响公平性的功能。Apple 也提醒开发者，旧的 UIKit Assessment mode 已在 iOS 上弃用，新的 assessment framework 才是后续入口。

## 详细内容

### Schoolwork 2.0 依赖 app 提供更丰富的活动数据

（[01:12](https://developer.apple.com/videos/play/wwdc2020/10658/?time=72)）Schoolwork 的 App Activity Chooser 是教师把 app 活动加入 Handout 的地方。2020 年的新设计会展示活动缩略图和摘要信息，Handout 详情页还能显示全班和单个学生的进度。

关键点：

- app 需要采用 ClassKit Framework，活动才会进入 Schoolwork 的分配流程。
- 新的元数据字段用于 Activity Chooser，缩略图和摘要会直接影响教师能否快速识别内容。
- app 可以向 ClassKit 报告 time spent、percentage complete 和 quiz scores。
- 进度只会展示给有权限的人，例如被分配活动的学生对应教师。

### ClassKit Catalog API 改变活动发现路径

（[03:10](https://developer.apple.com/videos/play/wwdc2020/10658/?time=190)）过去，app 要先把活动作为 `CLSContext` 发布到本地 ClassKit store，教师才可能在 Schoolwork 中选择它。这个流程适合已经熟悉内容的教师，却不适合第一次寻找课程资源的人。

关键点：

- ClassKit Catalog 是 app 公开活动的集中目录。
- 只要 app 已安装，Schoolwork 就能从 Catalog 发现 app 的活动，不再只依赖本地 context store。
- 开发者通过 Web API 发布活动数据。
- Catalog 也包含新的元数据字段，帮助教师搜索和识别内容。
- 这场 session 没有展开 Catalog 的请求格式，而是指向同年 "What's new in ClassKit"。

### Apple School Manager、Schoolwork 和 Classroom 开始共享班级数据

（[04:29](https://developer.apple.com/videos/play/wwdc2020/10658/?time=269)）Apple School Manager 是学校管理账号、设备和内容的 Web 门户。2020 年的重点是它和 Schoolwork、Classroom 的集成更紧。Apple School Manager 创建的班级会自动出现在 Classroom 和 Schoolwork，后续更新也会同步。

关键点：

- IT 管理员可以在 Apple School Manager 中创建班级，并管理教师和学生登录凭据。
- 系统支持 Student Information Systems、SFTP，以及基于 Microsoft Active Directory 的 federated authentication。
- 设备可通过 Mobile Device Management 远程注册，不需要管理员在分发前逐台接触。
- Apps and Books 区域是学校购买内容的位置，教育 app 需要考虑采购和部署路径。

### Classroom 可以把学生带到正确的 app 活动

（[06:08](https://developer.apple.com/videos/play/wwdc2020/10658/?time=368)）Classroom 让教师把同一个 app 同时打开到所有学生的 iPad 上，也可以按学生分组打开不同 app。如果 app 已接入 ClassKit，教师还能把 app 打开到正确的活动。

关键点：

- Classroom 支持查看学生 iPad 屏幕，并新增 pinch to zoom。
- 教师可以通过 AirPlay Class Code 按钮，把课堂加入信息显示到 Apple TV。
- 使用 Apple School Manager 和 Schoolwork 创建的班级会出现在 Classroom。
- 2020 年秋季，教师也可以在 Classroom 中创建供 Apple School Manager 和 Schoolwork 使用的班级。

### Shared iPad 要求 app 把学生数据同步到云端

（[07:20](https://developer.apple.com/videos/play/wwdc2020/10658/?time=440)）Shared iPad 让学生登录一台共享设备后，把它当成自己的 iPad 使用。开发者要假设本地没有这个学生的数据，因为学生登出后数据可能不再保留。

关键点：

- app 在 Shared iPad 上应像个人设备上一样工作，但用户数据必须从云端同步。
- Temporary Session 允许学生无需 Apple ID 使用共享 iPad。
- Temporary Session 登出后，本次会话创建的数据会被删除。
- Temporary Session 默认开启；MDM 开发者可以使用新的 supervised restriction 让客户选择关闭。
- Apple 明确提到 longLived CKOperations 和 UIBackgroundTasks，用来支持学生登出后的后台同步。

### Automatic Assessment Configuration 来到 Mac

（[08:48](https://developer.apple.com/videos/play/wwdc2020/10658/?time=528)）Automatic Assessment Configuration Framework 让考试 app 在测试期间提供安全环境。这个能力过去先在 iPad 标准化考试场景出现，2020 年扩展到 Mac，并支持 iOS、macOS 和 Catalyst。

关键点：

- 测试期间，学生会被锁定在考试 app 中。
- Screen Sharing、Universal Clipboard 和 Dictation 等系统功能会在考试期间自动禁用。
- 开发者需要申请新的 entitlement。
- iOS 上旧的 UIKit Assessment mode 已弃用，应切换到新 framework。
- iOS 还可以通过 configuration options 自定义考试期间可用的系统功能。

## 核心启发

### 1. 让课程活动先进入 Schoolwork

**做什么**：为教育 app 的课程、单元和练习建立 ClassKit 活动，并补齐缩略图、摘要和进度字段。

**为什么值得做**：Schoolwork 2.0 的 Activity Chooser 会展示更丰富的活动信息，Handout 详情页也依赖 app 上报的进度数据。

**怎么开始**：先梳理 app 中能被教师分配的活动，把它们发布为 ClassKit 活动，再给每个活动补上 thumbnail、summary、time spent、percentage complete 或 quiz scores。

### 2. 把公开课程内容提交到 ClassKit Catalog

**做什么**：为教师还没浏览过的公开内容建立 Catalog 提交流程，让 Schoolwork 能直接发现这些活动。

**为什么值得做**：本地 `CLSContext` 依赖教师先进入 app 浏览内容，Catalog API 让活动发现发生在教师分配作业之前。

**怎么开始**：先挑选公开、稳定、适合布置作业的活动，按照 ClassKit Catalog API 的文档准备元数据和发布流程。

### 3. 为 Shared iPad 做云端恢复路径

**做什么**：让学生在任意共享 iPad 登录后，都能恢复课程状态、草稿和学习进度。

**为什么值得做**：Temporary Session 不需要 Apple ID，登出后也不会保留本地数据；教育 app 不能依赖上一次本地缓存仍在设备上。

**怎么开始**：检查所有学生数据是否有云端来源，并用 longLived CKOperations 与 UIBackgroundTasks 处理登出前后的后台同步。

### 4. 给考试 app 迁移到新的 assessment framework

**做什么**：把依赖旧 UIKit Assessment mode 的考试流程迁移到 Automatic Assessment Configuration。

**为什么值得做**：新的 framework 覆盖 iOS、macOS 和 Catalyst，Mac 也能进入受控考试环境。

**怎么开始**：先申请 entitlement，再按 "What's new in assessment" 中的流程建立考试开始、结束、失败和中断处理。

### 5. 为 Classroom 准备深链接到活动的体验

**做什么**：让教师从 Classroom 启动 app 时，学生直接进入被分配的 ClassKit 活动。

**为什么值得做**：Classroom 可以把全班或分组学生带到同一个 app，也可以在 ClassKit enabled app 中打开正确活动。

**怎么开始**：确认 app 的活动已经接入 ClassKit，并测试教师从 Classroom 启动后，学生看到的是对应活动而不是普通首页。
