## Highlight

> Xcode 27 的 Coding Agent 不只是代码补全，它能探索项目结构、生成架构文档、规划功能实现、并行执行多任务。从接手新项目到交付 polished app，Agent 贯穿整个开发流程。

---

## 核心内容

### 1. 这场演讲解决什么问题

Xcode 26.3 引入了 Coding Agent，但很多开发者只把它当作"高级自动补全"。Xcode 27 扩展了 Agent 的能力边界：它可以理解整个项目结构、查阅 Apple 文档、生成架构文档、并行执行多个子任务。这场演讲展示了如何把 Agent 融入日常开发流程。

### 2. 探索项目：从陌生到熟悉

接手一个新项目时，Agent 可以帮你快速理解代码库：

**创建独立对话窗口**：

按住 **Option + Shift** 点击 Toolbar 中的 Agent 按钮，Agent 对话会作为独立编辑器分屏打开，你可以同时查看代码文件。

**请求项目 walkthrough**：

```
请总结项目的数据模型和当前视图层级，并提供一份 walkthrough。
```

Agent 会：

- 分析源代码、构建设置、打开的文件
- 生成包含数据流概述、关键区域表格和源代码引用的 walkthrough
- 提供可点击的链接，直接跳转到关键文件

**生成架构文档**：

Agent 可以把探索结果保存为项目内的 Markdown 文档：

```
请用收集到的信息起草两份架构文档，并直接放在项目源码中。
```

这些文档成为项目的动态知识库，随代码一起演进。新团队成员可以通过阅读这些文档快速上手。

### 3. 对话界面：Transcript 和 Artifacts

Xcode 27 的 Agent 界面分为两个区域：

- **左侧 Transcript**：显示对话内容，包括进度评论、tool 调用、子 Agent 运行等
- **右侧 Artifacts**：显示创建的文件、编辑和预览

你可以：

- 聚焦最新消息产生的所有内容
- 查看整个对话的所有产物

### 4. 研究 API：让 Agent 帮你查文档

遇到不熟悉的 API 时，创建新对话让 Agent 研究：

```
我需要为 SwiftData 模型添加什么关系？
SwiftUI 中创建表格有哪些选项？
```

Agent 会查阅 Apple Document Search，结合项目上下文给出针对性建议。你可以引用之前生成的架构文档来提供项目背景。

### 5. 规划功能：Plan Mode

在动手写代码之前，先让 Agent 出方案：

```
/plan 为 workout app 添加一个 insights 视图，展示训练进度分析
```

Agent 会：

1. 分析现有代码结构
2. 确定需要修改的文件
3. 提出数据模型变更建议
4. 规划 UI 实现方案

你可以在对话中通过 **Queued messages** 实时纠偏，确认方案后再让 Agent 执行。

### 6. 并行执行：Orchestrate

对于复杂任务，Agent 可以自动拆解并并行执行：

```
请为整个 App 做无障碍适配
```

Agent 会：

1. 分析所有需要修改的视图
2. 创建多个子 Agent 并行处理不同模块
3. 汇总结果并生成统一报告

这比手动逐个文件修改高效得多。

### 7. 从原型到 polished app 的 workflow

演讲展示了一个完整的开发流程：

1. **探索阶段**：Agent 分析项目结构，生成架构文档
2. **规划阶段**：Agent 研究 API，制定实现方案
3. **实现阶段**：Agent 编写代码，开发者审核
4. **打磨阶段**：Agent 运行测试、检查 Previews、验证多语言

### 8. 使用技巧

- **拆分需求**：把大需求拆成小块，利用 Preview 和 Test 做闭环验证
- **保持人工审核**：Agent 是 Junior 开发的水平，关键逻辑需要人工确认
- **利用架构文档**：让 Agent 生成的文档成为后续协作的基准线
- **多对话并行**：不同任务用不同对话，避免上下文混乱
- **保存有价值的对话**：把探索结果保存为文档，供团队参考

---

## 最佳实践

- **先探索再动手**：接手新项目时，先让 Agent 生成 walkthrough 和架构文档
- **用 Plan mode 做复杂功能**：先出方案再实现，避免返工
- **小步快跑**：每次让 Agent 改一小部分，立刻测试验证
- **把 Agent 当 Junior 开发**：它记忆力好但缺乏业务常识，关键决策需要你来把关
- **保存探索成果**：让 Agent 把项目分析写成文档，成为团队知识库
- **多对话管理**：不同任务用不同对话，保持上下文清晰
